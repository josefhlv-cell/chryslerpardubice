[424]Test of air pollution sensor

This function is used to test pollution of the air quality sensor. To perform the test, use a spray for this purpose - can be ordered as spare part with part number 71715571.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
