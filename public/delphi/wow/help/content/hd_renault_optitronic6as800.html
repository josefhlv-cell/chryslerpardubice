[697]Optitronic 6AS800

This function is used to activate the solenoid valves connected to the MID 130 gearbox control unit.

Note:

The valve is activated only for a short time before returning to its original position.

Activations may not be used if the engine is running.

Test conditions:

  • Parking brake applied.

  • Ignition on.

  • Engine off.

Procedure:

  1. Select the valve to be activated.

  2. Check conditions.

  3. Activate the valve.

  4. Check the status.

  5. Function complete.

    • If the function fails, check the test conditions and repair any faults.
