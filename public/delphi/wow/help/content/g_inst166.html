[921]Throttle control unit

Preconditions for the test:

  • Ignition on.

  • No faults stored.

  • Battery voltage above 11.5 V.

  • All electrical loads switched off.

  • Throttle at idling position.

  • If cruise control is fitted, it must be working properly.

Note:

  • The basic setting matches (”adapts”) the throttle control unit to the engine control unit.

Adaption must be done when:

  • The throttle control unit has been removed from the vehicle.

  • The throttle control unit has been replaced.

  • The electric power to the engine control unit has been disconnected.

  • The engine control unit has been replaced.

Procedure:

  • Choose the function: Throttle control unit.

  • The throttle control unit operates in the min and max positions and several different intermediate positions. The control unit stores the corresponding throttle angle in the permanent memory. This process takes about 10 seconds. After adaption, the throttle returns to the starting position briefly, then closes.

  • Read adaption status. Prescribed value It must change from ”Adaption in progress…” to ”Adaption OK!” / Adaption Error!”.

Quit the basic setting mode and switch off the ignition. For the basic setting to be stored, the ignition must be switched off.
