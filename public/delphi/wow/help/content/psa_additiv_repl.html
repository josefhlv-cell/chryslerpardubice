[1435]Refilling hose with additive.

The basic setting will make sure that there is no air trapped in the additive system, and should only be performed when:

  • Replacement of the additive tank.

  • Replacement of pipes between the additive tank and the fuel tank.

  • After refueling an empty system.

Test prerequisites:

  • Ignition on, engine off.

  • All electrical loads should be switched off.

  • Battery voltage above 12 Volts.

Procedure:

  1. Start the function, press OK.

  2. A dialog box presents: operation succeeded/ failed.

    • If the function fails, check test prerequisites and repair possible fault codes.

  3. Exit the function and disconnect the diagnostic tool.
