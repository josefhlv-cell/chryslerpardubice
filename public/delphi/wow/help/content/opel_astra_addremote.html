[1100]Add remote controls

Description:

This function will allow you to add / remove remote controls to the car. All remote controls must be available, old and new. All remote controls have to be reprogrammed. Earlier remote controls will be erased from the system.

Conditions:

Keep all the desired remote controls present in good working order. Programming should be done with engine off, ignition on and good battery level. Stand within remote range from the car.

Method:

  1. Start the remote controlls programming procedure.

  2. Erase stored remote controls.

  3. After accepting that you want to add remote controls, you should press one off the remotes several times. If accepted you will be asked to program the next remote or exit. If not accepted you will recieve an timeout after 60sec. You can add upp to 5 remotes in the system.

  4. Repeat step 3 until you reached the desired amount off programmed remotes.

  5. Exit function.
