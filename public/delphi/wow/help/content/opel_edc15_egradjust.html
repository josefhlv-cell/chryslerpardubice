[39]Calibrate EGR

This function is used to adjust the amount of exhaust gas recirculation.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the function.

  2. A dialogue box shows status for "EGR, offset". Press "OK", and follow the instructions.

  3. After finished adjustment the current offset value for EGR is shown.

    • If the function fails, check the test conditions and repair any faults.
