[1432]Service reset

If a service of a maintenance item has been carried out, this has to be confirmed.

Observe:

After service comfirmation has been carried out the following actions are activated in the maintenance system

-Service interval number is increased with one for the actual service.

-The calculations for the next service dates are restarted

Testconditions

  • Ignition on, engine off

Procedure:

  1. Choose service to confirm

  2. Confirm with OK

  3. A dialogue with operation failed/succeed is displayed

  4. Confirm with OK
