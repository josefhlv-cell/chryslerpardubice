Switching between right and left-hand traffic (tourist mode)
This function is used to adjust the headlights beam pattern, for driving on the opposite side if the road than the car's home market (tourist mode). This prevents dazzling the oncoming traffic.
Note:
  • The switching is performed both in the control unit for light control and in the control unit for central electronics.
  • After switching to "tourist mode" fault code 02988 is stored in the control unit for light control, it will automatically be erased when switching back to normal mode.
  • An active "tourist mode" is also indicated in the car's main instrument.
Test prerequisites:
  • Ignition on.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. Exit the function and exit communication with the system.
  4. Select the system "Central electronics" and perform the function "Switching between right and left-hand traffic (tourist mode) also in this system.
  5. The function is done.
