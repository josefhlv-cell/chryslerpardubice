[802]Coding ABS control unit Mark 20IE ESP Sharan

Coding:

The ABS control unit must be recoded if the vehicle relevant coding is not displayed in the system basic data or the control unit has been renewed.

Code:

For coding Sharan the following codes are valid:

Vehicles with ABS control unit identification number 7M3 907 379 B: 18952

Vehicles with ABS control unit identification number 7M3 907 379 C (4WD): 18443

Note:

If the control unit is not coded, the ABS check lamp, the brake system check lamp and the ESP warning lamp flashes once per second.

Only valid for vehicles with ESP.

To perform coding:

  • Write the current code in the ABS coding field.

  • Click on the OK-button.

  • A dialogue box confirms: Operation succeeded / Operation failed.

  • Read the control unit basic data to check that the new code is programmed.

  • Check that no fault codes are stored.
