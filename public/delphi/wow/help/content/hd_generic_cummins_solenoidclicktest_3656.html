Adblue dosing unit air valve click test
This function is used to check the dosing unit's air valve.
Note:
At activation and deactivation of the air valve, a clicking sound should be heard.
Test conditions:
  • Engine off.
  • Ignition on.
  • Parking brake applied.
  • No active faults in the dosing unit's air valve.
Procedure:
  1. Start the function.
  2. Check test conditions.
  3. Select to activate/deactivate air valve.
  4. Listen for a clicking sound.
  5. Function complete.
  • If the function fails, check the test conditions and repair any faults.
