Basic setting of air conditioning system
This function is used if the control module for the climate control system has been replaced or a new actuator has been installed. During basic setting, the control unit learns the actuators' end-positions and stores these.
Note:
  • A started basic setting shall not be cancelled, then a fault code is stored in the fault memory and operation of the AC will not work. If this happens, repeat the basic setting.
Test conditions:
  • Ignition on, engine off.
  • Battery voltage above 12 V.
  • No faults in the system.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. After the function is completed, check any error codes.
  3. If the function fails, check the test conditions and repair any faults.
