Basic setting of climate control system
This function is used to learn the damper motors' end-position and should be done if:
  • The air conditioning system control unit has been replaced.
  • Actuators have been replaced or reinstalled.
  • Components for the climate control system have been replaced or reinstalled.
Note:
It is not possible to cancel basic setting after it has started.
Test prerequisites:
  • Battery voltage above 11.5V.
  • Ignition on, engine off.
  • The vehicle should have normal room temperature during calibration.
Procedure:
  1. Start the function.
  2. Follow the instructions in the dialogue boxes.
  3. Exit the function. Turn off the ignition to store new values.
  4. The function is complete.
  5. Turn on the ignition, re-establish communication, and check that no error codes have been stored.
    • If the function fails, check the test conditions and repair any faults.
