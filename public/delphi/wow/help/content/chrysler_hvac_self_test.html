[1708]Self test

This function is used to run a self test on the system.

All displays and LEDs light up during the test.

Test conditions:

  • Ignition on, engine off

  • Battery voltage above 12 V.

Procedure:

  1. Select the "Self test", press "OK".

  2. Follow the instructions in the dialogue box.

    • If the function fails, check the test conditions and repair any faults.
