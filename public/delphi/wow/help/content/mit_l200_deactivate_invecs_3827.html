Deactivate INVECS-2
This function is used to deactivate the control system "Intelligent & innovative vehicle electronic control system (INVECS-2)".
Note:
This function deactivates the control system INVECS-2 and change shift patterns to standard patterns. If the ignition is turned to OFF - ON - OFF, it will activate INVECS-2.
Below is information about performance of road test in conjunction with deactivated INVECS-2.
