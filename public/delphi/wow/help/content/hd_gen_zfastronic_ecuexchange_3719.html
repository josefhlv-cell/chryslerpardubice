ECU replacement
This function is used to read out the configuration from an old ECU and program it to a new ECU, after replacing of ECU.
Note:
All parameters are read out and presented even if they are not configurated in the current control unit.
Test conditions:
  • Engine off.
  • Ignition on.
  • Vehicle stationary.
Procedure:
  1. Start the function.
  2. Reading of the configuration is performed.
  3. Verify that the configuration data is correct.
  4. Select to continue with the programming or to cancel.
  5. Turn off ignition.
  6. Connect the new control unit to be programmed.
  7. Turn on the ignition.
  8. Programming is performed.
  9. Turn off ignition.
  10. Wait 10 seconds.
  11. Turn on the ignition.
  12. Function done.
  • If the function fails, check the test conditions and repair any faults.
