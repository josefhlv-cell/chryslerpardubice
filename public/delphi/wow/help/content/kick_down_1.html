[1073]Kick-down

Preconditions for the test:

  • Ignition on.

  • No faults stored.

Note:

  • Used when teaching kick-down position to vehicle with automatic transmission.

Adaption must be done when:

  • The engine control unit has been removed from the vehicle.

  • The gearbox control unit has been removed from the vehicle

  • The accelerator pedal has been replaced.

  • The throttle valve has been replaced.

  • The throttle valve potentiometer setting has been changed.

Procedure:

  • Choose the function: Kick-down.

  • A dialog box confirms: Operation succeeded / Operation failed

  • Press the throttle pedal past the kick-down position and keep it there for more then three seconds.

  • Exit the basic setting and perform test drive.
