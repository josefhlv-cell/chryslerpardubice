[1471]Code trailer function

When an aftermarket installation or a removal of a trailer detection module has been performed, it is necessary to activate/deactivate the function into/from the system, to make the system work correctly.

Note:

  • A faulty coding can reduce the car´s safety/performance.

Test prerequisites:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • Electrical consumers switched off.

Procedure:

  1. Choose the function: "Code trailer function".

  2. The actual status for the function is presented. "Activate/deactivate is presented. Confirm with YES.

    • Press NO to abort the function.

  3. The new actual status for the function is presented.

  4. Confirm with OK to exit the function.

  5. Switch off the ignition for 60 seconds to store the new code.

  6. Exit the function.
