[1294]Climatronic

Test condition:

  • Battery voltage above 11.5 V.

  • No faults stored.

  • Ignition on.

  • Correct coding of Climatronic

Note:

  • If the display is flashing after the ignition is turned on and no fault code is stored in the memory, then coding and basic setting of Climatronic must be performed.

  • During the basic setting the positioning motors values will be presented in the datalist. When all four positioning motors are presenting 0, the basic setting complete. During basic setting is it possible to hear the movement of the positioning motors.

Procedure:

  • Start the function.

  • Check the value of the four positioning motors.

  • When all four positioning motors are presenting 0, the basic setting is complete.

  • Exit.
