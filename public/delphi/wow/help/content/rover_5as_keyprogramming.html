[1177]Programming remote control (plip)

When programming remote controls (see Picture 1; Remote control), all remote controls need to be available both new and old. All remote controls have to be programmed at the same occasion.

Instructions for programming remote controls:

  1. Choose: Programming remote control (plip) and press OK (all programmed remote controls will be erased and the programming starts).

  2. Press the lock button continuously on the remote control until the horn sounds.

  3. Repeat this procedure (step 2) for each remote control to be programmed.

  4. Press OK.

Caution!

Programming is not possible with low battery voltage.
