[1377]Login procedure for ABS

To perform basic settings and coding on the ABS control unit, a login code is sometimes requiered. The code is: 40168.

Procedure:

  1. Choose the function: Login

  2. Enter the valid code in the field. Press OK.

  3. A dialogue box confirms: Operation succeeded / Operation failed.

  4. Proceed with the desired basic setting/coding.
