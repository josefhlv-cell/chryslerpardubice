[1284]Catalytic converter diagnosis.

Test condition:

  • Engine running.

  • No faults stored.

  • Engine temperature above 80°C.

  • Intake air temperature below 60 °C.

  • No leaks in the exhaust system.

  • All electrical loads switched off.

  • Gear selector set to P/N.

Note:

  • The diagnosis will only be initiated if the Lambda probe ageing diagnosis is first successfully completed.

Procedure:

  • Start the function.

  • Increase the engine speed to 1800-2200 rpm.

  • The temperature of the catalytic converter must be above 350 °C.

  • The diagnostic status field will change from ”Test off” to ”Test on”.

  • Amplitude ratio max 0.4.

  • Read off the value columns diagnosis status must change from ”Test on” to "Cat B1 OK"

  • If the specifications are not attained, interrogate fault memory.

  • Exit function.
