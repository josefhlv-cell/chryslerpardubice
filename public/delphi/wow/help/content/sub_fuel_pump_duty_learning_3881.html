Fuel pump learning
This function is used to learn the new fuel pump after replacement.
Note:
If the function is canceled, it must be run again until it is completed. When starting the function ,you will be asked to start the engine and keep engine speed at 2500 rpm for more than 5 seconds.
Preconditions for the test:
  • Ignition on.
Procedure:
  1. Start the function and follow the instructions in the program.
