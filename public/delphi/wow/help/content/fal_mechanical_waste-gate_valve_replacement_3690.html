Mechanical wastegate valve replacement
This function should only be used if the fault code P2288 is active. This means that the wastegate valve has reached its maximum mechanical life and needs to be replaced.
The function resets the parameters "Wastegate valve opening counter" and "Wastegate valve opening duration" in the control unit.
Note:
The valve reaches its maximum mechanical life in one of the following two ways:
  1. If the valve has been operating for totally 5 hours in open valve position.
  2. If the valve has performed 50 openings, then the tolerance for pressure limit may have exceeded.
Test conditions:
  • Ignition on.
Procedure:
  1. Start the function and follow the instructions in the program.
  • If the function fails, check the test conditions and repair any faults.
