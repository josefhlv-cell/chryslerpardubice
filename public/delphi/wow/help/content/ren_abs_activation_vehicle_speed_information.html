[1125]Vehicle speed information

Test conditions:

-Engine off

-Ignition on

This command serves to generate a speed other than 0 mph at the computer's vehicle speed wire output (Track 23 ) for users of that signal (discharge bulbs,radio,sunroof).

NOTE:This command has no visible effect on the dashboard speedometer needle.

–Xenon bulbs:

Turn on the dipped headlights and use the command .You should see a slight change in the height of the headlight beam (depending on vehicle speed,the height of the beam is adjusted to improve visibility).

–Radio:

Turn on the radio and see if the "adjust volume to speed"function is on.Run the command. During the command,you should notice the volume of the sound increase and then decrease.

–Sunroof:

This command has no visible effect on the sunroof.It changes the activation threshold of the anti-pinch system (the energy required to close the sunroof varies with vehicle speed due to aerodynamic constraints).
