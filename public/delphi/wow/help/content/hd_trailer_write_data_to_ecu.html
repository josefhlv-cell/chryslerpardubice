[405]Write configuration data from file to ECU

This function is used to write configuration data from a specific file to the ECU that belongs to the relevant trailer.

Test conditions:

  • The trailer shall be supplied with voltage with either a truck or another external voltage source.

  • The trailer is secured and cannot roll away.

Procedure:

  1. Start the function.

  2. Read the information about procedure under the information button.

  3. Select number of axles on the trailer in a scroll list.

  4. Select number of modulators on the trailer in a scroll list.

  5. Select number of sensors on the trailer in a scroll list.

  6. Enter the trailer's VIN-code in the VIN-code box.

  7. Press the "OK" button.

  8. Select the directory where the file is saved and select the file that appears.

  9. Press the "Open" button.

  10. Configuration data is written to ECU.

  11. The function is done.

  12. Make sure by using the available functions or by other appropriate manner that the function of the trailer is correct.

  13. Perform a testdrive of the vehicle before it is returned to the customer.
