[1643]Programming of FollowMeHome lights

With this function it is possible to change the time setting for "FollowMeHome" lights.

From factory, the vehicle is delivered with a time setting of 30 seconds. It is possible to set the time to 30, 60, or 90 seconds.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select function "Programming FollowMeHome lights" and press "OK".

  2. Programmed time setting for FollowMeHome lights is shown.

  3. Press "OK" to change time setting. Select "Cancel" to cancel the function.

  4. Select desired time setting, 30, 60, or 90 seconds, and press "OK" to start programming.

  5. After successful programming, the programmed time setting is shown. Press "OK" to exit the function.
