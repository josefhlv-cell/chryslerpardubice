[969] Throttle control unit

Preconditions for the test:

  • Ignition on.

  • No faults stored.

  • Battery voltage min. 11 volt.

  • All electrical loads switched off.

  • Throttle at idling position.

Note:

  • The basic setting matches (”adapts”) the throttle control unit to the engine control unit.

Adaption must be done when:

  • The throttle control unit has been removed from the vehicle.

  • The throttle control unit has been replaced.

  • If the electric power supply to the engine control unit has been disconnected.

  • If the engine control unit has been replaced.

  • Fault code 17967 has been logged in the fault code memory.

Carry out adaption of the throttle control unit:

  • Choose the throttle control unit function.

  • The throttle control unit operates in the min and max positions and several different intermediate positions. The control unit stores the corresponding throttle angle in the permanent memory. After adaption, the throttle returns to the start position for about 20 seconds, then goes to the rest position.

  • During adaption, ”Adaption in progress…” shows in the adaption status field. When adaption has been done, ”Adaption OK!” is displayed. / Adaption Error”.
