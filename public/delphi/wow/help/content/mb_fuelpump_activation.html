[323]Activate fuel pump

This function is used to change the fuel pump's status from permanent to operational mode.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. A dialogue box shows if the function succeeded or failed.

    • If the adaptation fails, check the test conditions and repair any faults.
