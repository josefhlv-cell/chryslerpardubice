[265]Proxi configuration procedure

This function is used if a control unit has been replaced. The function performs an adaptation between the body computer (NBC) and the control unit that has been replaced. This means that data is read out from the body computer (NBC) and is loaded in the selected control unit. The units in the car are read out at start and are presented after reading out in a list. Perform steps 1 to 3 during the procedure at the bottom in the help file before replacing change control unit to see with which control units the car is configured.

The procedure cannot be used to add units that are not found in the car's original configuration. Body computer (NBC) cannot use this procedure, as it can only be configured from factory or as a spare part from the aftermarket.

If data loaded in an ECU is not compatible, the download is cancelled and an error message is shown. The cause of the cancellation may be corrupt data, configuration data and vehicle data do not match, system not compatible with version installed in vehicle.

Note:

Control unit for body computer (NBC) cannot use this procedure, as it can only be configured from factory or as a spare part from the aftermarket.

Test conditions:

  • Ignition on

Procedure:

  1. Start the function.

  2. A read-out of which control units are in the car's CAN-network is run and presented, check if the relevant control unit is in the list, if the control unit is not in the presented list the 'proxi configuration procedure' cannot be run. Acknowledge with "OK".

  3. Continue by pressing "OK" or cancel the function.

  4. Select the control unit that has been replaced from the scroll list that is shown, and follow the instructions in the program.

  5. After finished procedure, read out and erase any error codes that may have been generated in central units and replaced units.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
