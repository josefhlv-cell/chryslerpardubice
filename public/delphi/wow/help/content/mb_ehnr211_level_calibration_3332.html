Calibrating level sensor
This function is used to calibrate the rear level sensors on the vehicle.
Note:
A calibration needs to be performed only after the following events:
  • A level sensor is replaced.
  • The control unit is replaced.
  • After an incorrect calibration.
Reference values for the tilt angle on the rear axle is in the range: -1,5°- -0,9°.
When reference level is reached, level sensor voltage shall be in the range: 2,2V - 3,0V.
Test conditions:
  • Ignition on, engine off.
  • Calibration shall be performed on a wheel alignment rig.
  • "Romess"-tool to measure chassis angle.
Procedure:
  1. Start the function.
  2. Run the suspension to the specified reference levels with +/- buttons and store with inclination measuring equipment, e.g. 'Romess CM-09606'.
  3. Continue in the function with "OK" when the level is approved.
  4. Enter the values that is stored in the inclination measuring equipment.
  5. Select Yes/No, if the vehicle is equipped with sport suspension or not.
  6. Save the new values to exit the function.
If the function fails, check the test conditions and repair any faults.
