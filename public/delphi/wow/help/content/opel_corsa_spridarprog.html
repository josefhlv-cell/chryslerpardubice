[1103]Injector programming

Conditions:

After replacing 1 or more injectors the following programming function has to be performed.

Engine off

Ignition on

Procedure:

  • Edit injector code and press the OK button to perform the programming.

    (The 9-digit quantity adjustment codes are written on the injectors)

  • Programmed injector codes can be read out in the datalist.

    Caution: If the programming failes check faultcodes and that the right code is entered.
