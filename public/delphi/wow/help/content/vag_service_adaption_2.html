[365]Configure service interval data

On vehicle with flexible service interval, the service intervals are calculated, in addition to driven distance and time, also using fuel consumption and oil temperature. This calculation gives a value of the oil's degradation in relation to thermal loading. On vehicles with diesel engines the oil's degradation is calculated based on engine rpm, engine load, driven distance, and oil temperature. This gives values for thermal loading and soot deposits. Oil degradation is the decisive factor for when the next service shall take place. The shortest oil change interval for flexible service is 15,000 km or 12 months. If an oil is used which is not approved by the standard, it is possible to re-code the car to fixed oil change intervals of 15,000 km or 12 months.

This function enables adaptation of parameters for service interval data.

  • Certain vehicles indicate not only values for oil change interval but also values for time and distance-dependent extra work (for example, brake fluid change, spark plugs, etc.)

  • Incorrect adaptation leads to incorrect calculation of future service.

  • When adapting to flexible service intervals, the car must be equipped with technology for this (Pr.no.: QG1) and oil approved according to standard must be used.

Note:

The following function shall only be used by experienced users with the help of a suitable workshop manual, when service is done the normal function for resetting service indication shall be used.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

Procedure:

  1. Select the desired service parameter to be adapted, press "OK".

    The following parameters can be adapted for fixed service intervals:

    • Upper limit value for time to next service (for fixed service interval).

    • Upper limit value for driving distance to next service (for fixed service interval).

    • Oil grade, always value 1 for fixed oil change interval.

    • Days since last service.

    • Distance driven since last service.

    The following parameters can be adapted for flexible service intervals:

    • Lower limit value for time to next service.

    • Lower limit value for driving distance to next service.

    • Upper limit value for time to next service.

    • Upper limit value for driving distance to next service.

    • Days since last service.

    • Distance driven since last service.

    • Soot covering.

    • Thermal load.

    • Oil quality, always value 2 for flexible interval.

    The following parameters are additional for time and distance-dependent extra work:

    • Max. time to next time-dependent inspection/extra work.

    • Max. time to next distance-dependent inspection/extra work.

    • Distance driven since last distance-dependent inspection/extra work.

    • Days since last time-dependent inspection/extra work.

  2. Follow the instructions shown during the adaptation sequence.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
