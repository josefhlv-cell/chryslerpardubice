[72]Configure control unit

The function shall be run if the ABS control unit has been replaced.

Fault code C1103 will be generated if the central computer's configuration and ABS-configuration do not match.

With this function the central computer will accept the new configuration, if it is correct. The fault code will change status to intermittent.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function.

  2. Follow given instructions.

  3. Erase fault codes.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
