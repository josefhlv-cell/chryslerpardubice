[770]Zero compensation of the brake pressure sensors

This basic setting is used to zero-compensate the value from the brake pressure sensors.

This must be done if:

  • The ABS control unit has been replaced.

  • Any of the brake pressure sensors in the main brake cylinder has been replaced.

  • An error code that requires zero compensation is stored in the ABS control unit.

Note:

The basic setting can only be done after entering a login code.This is done in the programming menu, using the function:Login

During basic setting, the ignition must not be switched off.

Method:

  • Do not depress the brake pedal.

  • Choose the basic setting:Zero compensation of brake pressure sensors.

  • The text:”Adaption correct” confirms that zero compensation has been done.

  • If the value for the brake pressure sensors is too high, zero compensation will not be accepted (adaption not possible).Values for both brake pressure sensors are presented in data list five.
