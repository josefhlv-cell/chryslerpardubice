[12]Calibrate kneeling

Calibration of kneeling level shall be performed when:

  • The control unit has been replaced.

  • Work has been done on level sensors or these have been replaced.

  • Defective or incorrect calibration.

Note:

Therefore it is extremely important that no persons or equipment remain in the area around or under the vehicle's frame to prevent crushing injuries!

Test conditions:

  • Ignition on with external air supply connected or engine running.

  • The vehicle must stand on level ground.

  • No faults in the system.

Procedure:

  1. Select the calibration function.

  2. Run the vehicle down to kneeling level with the buttons.

  3. Perform calibration.

  4. Exit the function.

  5. Check the kneeling function and read out any fault codes.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
