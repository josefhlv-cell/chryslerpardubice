[3]Bleed air from fuel system

If the high-pressure pump or components in the fuel system have been replaced or removed it is necessary to bleed air from the fuel system.

  • Air bleeding shall take place on a closed system.

  • If components in the fuel system have been replaced or removed, run air bleeding 1 time.

  • If the high-pressure pump has been replaced or removed, run air bleeding 3 times to make sure that the pump is not run dry. The ignition must be turned on and off between every air bleeding.

Test condition:

  • Ignition on, engine off.

  • battery voltage above 11.5 V.

Procedure:

  1. Select the function.

  2. The fuel pump in the tank starts and is active for approx. 1-2 minute.

  3. When bleeding air, "Test active" is shown in the dialogue box for "Electric fuel pump".

  4. When air bleeding is finished "Test finished" is shown in the dialogue box for "Electric fuel pump", press "OK".

  5. A dialogue box shows: "Function done", press "OK".

    • If air bleeding shall be repeated, finish communication, turn the ignition off and on, re-establish communication, repeat air bleeding.

  6. Exit the function.

    • If the function fails, check the test conditions or cause in the field for "Electric fuel pump" and repair any faults.
