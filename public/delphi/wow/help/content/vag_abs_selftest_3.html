[1662]Stability system driving test

This driving test is used to check the signals from the sensors: steering angle, sudden acceleration, brake pressure, and angle velocity. The test must be performed when one of the components of the stability system (ESP) is replaced or removed.

On vehicle models from 2006 the brake pedal must not be depressed during the ESP driving test (use the handbrake to stop the vehicle) - if the driving test is activated and the brake pedal depressed, trouble code "1487 system test activated" appears.

Note:

  • The ESP driving test cannot be aborted once it has been started.

  • The ignition must not be switched off during the driving test.

Test condition:

  • Engine on.

  • No faults in the system.

  • Access to a stretch of road that fulfils the conditions set out below.

Procedure:

  1. Select the "ESP driving test" function. The function starts (ABS light on).

  2. Complete the function and disconnect the diagnostic tool.

  3. Start the engine. Brake heavily until the ESP test lamp starts to flash (the driving test is now activated).

  4. Test drive at a speed of 15 to 30 km/h. No ABS/ESP control may be activated. Drive on a bend so that the steering wheel is turned at least 90°. This must be done within 50 seconds of the driving test being activated.

  5. The ABS and ESP test lamps go out to indicate that the driving test has been carried out correctly.

  6. The function is complete.

    • If the ESP test lamp stops flashing but the ABS test lamp does not go out, the driving test has failed. Reactivate the driving test by starting again from point 3.
