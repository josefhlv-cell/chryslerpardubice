[255]Reset adaptation values for cooling fan

This function is used after some component or control unit has been replaced. The function will reset the cooling fan's adaptation values.

Note:

The cooling fan will start during the function.

Test conditions:

  • Ignition on.

  • Make sure that the cooling fan runs free.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
