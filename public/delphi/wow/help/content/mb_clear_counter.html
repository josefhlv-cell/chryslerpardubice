[1642]Reset overload counter

The function resets the overload counter for the central lock system.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select function, press "OK".

  2. The function starts, the overload counter is reset. A dialogue box shows: "Operation successful" or "Operation failed".

  3. The function is done. If the function failed, check test conditions and resolve any error codes.
