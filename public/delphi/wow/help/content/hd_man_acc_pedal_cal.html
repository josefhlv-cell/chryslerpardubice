[1702]Calibrate accelerator pedal

This calibration must be performed if work has been carried out on the accelerator or other components which affect the accelerator pedal.

Test conditions:

  • Ignition on, engine off

Procedure:

  1. Start the function.

  2. Depress the accelerator pedal and hold it down for 3 seconds. Repeat the procedure 2-3 times to confirm the accelerator pedal limit values. press "OK"

  3. Switch off the ignition and wait 15 seconds for calibration to take place.

  4. Switch on the ignition.

  5. The function is complete.
