Deactivate/activate the wiper motor alternating turning position
Once the wiper motor has been replaced, the wiper motor's alternating turning position must be deactivated so that its crank arm can be fitted in the correct position. When the turning position is deactivated, the wiper motor always stops in the bottom position, which is the correct position for fitting.
Note:
  • The bonnet should be closed during activation and deactivation.
Preconditions for the test:
  • Battery voltage above 12 V.
  • Ignition on, engine off.
  • Wiper motor replaced with wiring connected.
  • Bonnet closed.
Procedure:
  1. Select function: "Turn position deactivation".
  2. A dialogue box shows the current value. Press "OK" to change the value.
  3. Activate pulse wiping and allow the wiper motor move to its limit position.
  4. Fit the crank arm on the wiper motor and the other wiper parts.
  5. Select function: "Turn position activation". A dialogue box shows the current value. Press "OK" to change the value.
  6. The function is complete. Check that the wipers operate correctly.
    • If the function fails, check the test conditions and repair any faults.
