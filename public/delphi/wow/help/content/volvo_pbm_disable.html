[1746]Deactivate service mode

This function is used to deactivate service mode after work on the brakes and the brake pads and returns to normal mode. Deactivation takes approx. 30 seconds, fault code "U210054" is erased.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select function, press "OK".

  2. Service mode is deactivated.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
