Configure A/C compressor
This function is used to configure the A/C compressor.
Possible configurations:
  • Not present.
  • With clutch.
  • Clutchless.
Test prerequisites:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. A datalist presents the current configuration. Press "Yes" to change the configuration.
  3. Select desired configuration in the displayed scroll list.
  4. Press "OK" and follow the instructions.
  5. The new configuration is displayed once programming is complete.
If the function is cancelled or fails, check fault codes and test conditions.
