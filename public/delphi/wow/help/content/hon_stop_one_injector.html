[194]Shut off cylinder

This function is used to temporarily shut off an injector at a time to check the injectors' function. The function should be run with the engine on. When the chosen injector is off the engine will run rough and smoke.

Test conditions:

  • Engine on.

  • Engine temperature between 85 and 100°C.

  • Parking brake applied.

  • Transmission in neutral.

  • Do not touch the accelerator pedal during the test.

Procedure:

  1. Start the function.

  2. Follow the instructions in the programme.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
