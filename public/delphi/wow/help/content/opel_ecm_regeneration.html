[85]Regeneration diesel particle filter

This function is used to burn soot particles in the particle filter.

Note:

Burning of soot particles (regeneration) shall be done outdoors. The particle filter gets very hot, leave the vehicle on a non-flammable ground surface. To avoid subsequent damage, only perform regeneration once! The burn process may take up to 1 hour.

Test conditions:

  • Engine idling.

  • Coolant temperature at least 70 °C.

  • No pedal may be activated.

Procedure:

  1. Press "OK" to start the function.

  2. A dialogue box instructs "Turn off ignition".

  3. A dialogue box instructs "Start the engine".

  4. A dialogue box shows status for coolant temperature, wait for correct temperature, see test conditions.

  5. Press "OK" to start the regeneration.

  6. A dialogue box shows status for regeneration, if burn has to be cancelled, select "Cancel".

  7. Regeneration takes approx. 40 min. When the engine rpm returns to idle and regeneration status shows "finished", then regeneration is done. Select "OK" to finish.

    If the burn fails or is cancelled, check test conditions, the particle filter may need to be replaced.
