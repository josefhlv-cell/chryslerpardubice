Configuration of windshield
This function is used to teach-in the windshield's version to obtain correct function of rain sensor and thermal camera. Configuration should be run after the windshield has been replaced.
Test conditions:
  • Ignition on, engine off.
  • Battery voltage above 12V.
  • No faults in the system.
Procedure:
  1. Start the function.
  2. Select version of windshield, press "OK"
  3. A data list presents teach-in version.
  4. The function is done.
    • If the adaptation fails, check the test conditions and repair any faults.
