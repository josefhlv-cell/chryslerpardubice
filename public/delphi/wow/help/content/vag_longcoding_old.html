[93]General version coding

The control unit's version code controls one or several specific functions in the control unit. When replacing control unit it has to be programmed with the correct version code to function correctly. You may also need to change version code when, e.g., retrofitting equipment.

With this function you can do the following:

  1. Read out and save old version code when replacing control unit.

  2. Possibility to change version code in existing control unit.

Note:

  • Incorrect version coding may reduce the car's safety / function.

  • Valid version code is listed in workshop manual or similar.

  • The control unit must be of the correct type to approve the version code.

  • On some control units it is not possible to change version code.

Test conditions:

  • Value "code long" shall be shown from parameter "Control unit version coding".

  • Battery voltage above 12 V

  • Ignition on, engine off.

  • All power consumers disconnected.

Procedure:

Version 1, When replacing control unit:

  1. The defective control unit is still installed.

  2. Start the function "Code control unit".

  3. Existing version code in the control unit is read off and shown.

  4. Select "Save to file" to save read-off version code.

  5. Name the file as desired and select a location where it is to be saved, press "Save".

    • It may be suitable to name the file using the car's registration number and choose to save on the computer's desktop.

  6. A dialogue box with the text "Saved" confirms that the read version code is saved, press "OK".

  7. Press "Cancel", exit the function, and exit communication with the car.

  8. Replace the control unit.

  9. Re-establish communication with the car and select the function "Code control unit".

  10. The version code in the new control unit is read off and shown.

  11. Select "Load from file".

  12. Double-click on the file with the saved version code from the defect control unit.

  13. The version code from the defect control unit is uploaded and shown on the screen, press "OK".

  14. You are asked if you want to code the system, press "YES" to perform coding, press "NO" to cancel.

  15. Version coding is performed.

  16. "Coding OK" is shown. If coding fails, check that the version code is valid for the control unit in question.

  17. Exit the function and turn off the ignition for 30 seconds to save the new code.

Version 2, Change version code in existing control unit:

  1. Start the function "Code control unit"

  2. Existing version code in the control unit is read off and shown.

  3. The version code is shown by byte. Click on desired byte and enter the new value for the relevant byte.

  4. Press "OK".

  5. You are asked if you want to code the system, press "YES" to perform coding, press "NO" to cancel.

  6. Version coding is performed.

  7. "Coding OK" is shown. If coding fails, check that the version code is valid for the control unit in question.

  8. Exit the function and turn off the ignition for 30 seconds to save the new code.
