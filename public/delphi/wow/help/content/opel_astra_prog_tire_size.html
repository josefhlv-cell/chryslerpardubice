[1665]Configure tyre size

This function is used to configure the tyre size. The tyre dimensions must be programmed to enable the control unit to calculate the correct speed.

The tyre dimensions are divided into 4 groups:

  • Group 1: 185/65 R15, 215/45 R17

  • Group 2: 195/65 R15, 195/60 R16, 205/55 R16, 205/50 R17, 225/45 R17, 225/40 R18

  • Group 3: 195/60 R15

  • Group 4: 235/35 R19

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the "Programme tyre size" function then press "OK".

  2. A dialogue box appears containing the stored tyre group. Press "OK" to programme the new tyre size.

  3. Select the required tyre group, press "OK" and follow the instructions. Press "Stop" to abort the function.

  4. The programmed tyre group is displayed when programming is complete.

  5. The function is complete.
