[330]Code control module for parking assistance

When installing a new control unit or modified equipment in the car, the control unit for parking assistance must be coded for existing equipment. New control unit may have code 0 stored.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Existing code in control unit is shown, press "YES" to change value.

  3. Enter the desired code (see below) in the displayed entry field, press "OK".

    Code number:Function:
    0 0 0 0 0 0Without optic parking system, without back-up camera, without trailer hitch
    1 0 0 0 0 0With optic parking system
    2 0 0 0 0 0With back-up camera
    0 1 0 0 0 0With trailer hitch (manually removable)
    0 2 0 0 0 0With trailer hitch (electric folding)
    0 0 1 0 0 0Tailgate assist with warning signal via instrument (only applies to Eos)
    0 0 2 0 0 0Tailgate assist with warning signal via buzzer (only applies to Eos)
    0 0 0 0 0 0Manual transmission
    0 0 0 1 0 0Automatic transmission
    0 0 0 0 0 1Golf V, Golf VI, Golf Plus, Caddy, Jetta, Passat CC, Scirocco, Eos, Touran, Multivan
    0 0 0 0 0 2Commercial vehicles, Tiguan
    0 0 0 0 0 3Passat V

    Coding example: Touran without optic parking system, without back-up camera, with trailer hitch (manually removable), with manual transmission = 010001

  4. A dialogue box shows that the code is stored (with the new value) in the memory.

  5. Press "OK" to exit the function.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
