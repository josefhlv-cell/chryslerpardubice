Key programming
This function is used when the new keys need to be programmed and stored in the system.
Note:
Old keys will be erased.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Remove key from ignition lock.
  3. Wait 2 seconds, then press in the lock button on the key for 1 second.
  4. Follow the instructions shown in the dialogue boxes.
