Resetting the adaptation values
This function is used to reset the adaptation values in the engine control unit.
Test conditions:
  • Engine off.
  • Ignition on.
Note:
The function should be run if any of the following parts have been replaced or repaired. The function may also need to be run if any neighbouring component has been replaced or repaired:
  • EGR valve
  • Particle filter.
  • Air mass sensor.
  • Intake damper.
  • Diffuser.
  • Emission control components.
  • Flywheel.
