[95]Self-test

This function runs a self-test of the system and a predetermined number of components are activated. If the control unit detects that any of these components gives an unreasonable value, a fault code will be stored in the system. The function finished with a fault code reading where any fault codes in the system are shown.

Erase fault codes before the self-test to avoid showing historical fault codes.

Test conditions:

  • Battery voltage above 12 V.

  • Vehicle stationary.

  • Radio unit on, tuned to a station with good reception.

  • No faults in the system.

Procedure:

  1. Start the function.

    • The self-test starts and components are activated one at a time.

  2. The self-test can be cancelled with "Cancel".

  3. When the self-test is done, an automatic fault code reading is performed.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
