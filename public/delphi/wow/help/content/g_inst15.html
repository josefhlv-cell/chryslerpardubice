[903] Lambda regulation, catalytic converter efficiency

Preconditions for the test:

  • Engine running.

  • No faults stored.

  • Engine temperature above 80 °C.

  • Induction air temperature below 60 °C.

  • All electrical loads switched off.

  • Automatic gearbox set to ”P/N”.

Note:

  • Catalytic converter efficiency test.

  • See readiness test

  • The test takes about 100 seconds. If no result is displayed after 150 seconds, change the engine speed within the limits.

Procedure:

  • Choose the function Lambda regulation, catalytic converter efficiency.

  • Engine speed 2200…2800 rpm.

  • The catalytic converter status changes from ”Test off” to ”Test on”.

  • The temperature of the catalytic converter must be at least 352 °C.

  • Check the amplitude. Prescribed value max 0.55 seconds.

  • Maintain the engine speed until the catalytic converter status shows ”Cat B1 OK! / Cat B1 not OK”.
