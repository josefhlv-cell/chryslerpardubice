[267]Basic setting of engine control system

This function is used for basic setting of the engine control system after any of the following workshop jobs have been done:

  • Engine control unit has been replaced.

  • Engine control unit has been reprogrammed.

  • If any of the following components have been replaced:

    • HFM sensor (hot-film mass air flow sensor).

    • Throttle.

    • Cooler's bypass valve.

    • EGR-valve.

When replacing engine control unit or reprogramming, all 4 initiations described below should be run.

Test conditions:

  • Ignition on.

Procedure:

  1. Select the function to be run.

  2. Follow the instructions in the program.

  3. The function is done.
