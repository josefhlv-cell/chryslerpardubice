Fluid replacement and bleeding the clutch actuator
This function is used when replacing fluid and at clutch actuator bleeding.
The function only works on vehicles without clutch pedal.
Test prerequisites:
  • Ignition on, engine off.
  • Transmission in neutral.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. A dialogue box shows the test conditions, check these and press "OK".
  3. Open the bleed nipple, press "OK".
  4. Bleeding of the system starts.
  5. Function done.
  6. Close the bleed nipple.
  7. Function done.
  • If the function fails, check the test conditions and repair any faults.
