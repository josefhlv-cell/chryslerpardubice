Activation of ABS solenoid valves on a rolling road dynamometer.
This function is used to test the ABS solenoid valves using a rolling road dynamometer.
Test conditions:
  • Dynamometer.
  • The engine at idle to reach enough air pressure.
  • Parking brake released.
Procedure:
  1. Start the function.
  2. Answer the questions and follow the instructions in the different boxes.
  3. The function is done.
    • If the function fails, check the test conditions and repair any faults.
