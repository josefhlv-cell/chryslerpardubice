Reset alignment values
This function is used to erase adaptation values.
Note:
This function should only be performed when the ACC/FCM-ECU must be adapted, due to removal and installation. It must not be performed when the ACC/FCM-ECU is replaced with a new ECU.
Test conditions:
  • Ignition on.
Procedure:
  1. Select the function and follow the instructions.
  2. Then perform the function "Radar calibration".
