Customer parameters
This function is used to manually change the parameter settings.
Preconditions for the test:
  • Ignition on.
Procedure:
  1. Start the function.
  2. A list shows the current settings.
  3. Proceed with the function.
  4. Select the customer parameter to be changed.
  5. Choose the selection to be stored from the list shown.
  6. The selected alternative is saved and the newly updated list is shown.
