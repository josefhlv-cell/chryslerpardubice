Learning of clutch with manual gearbox
This function must be run if the clutch has been replaced, or if repair work has been carried out on the clutch involving replacement of the plates.
Note:
This function may only be performed on vehicles with manual gearbox.
Test conditions:
  • Parking brake applied.
  • Engine off, ignition on.
  • Battery voltage above 20 V.
Procedure:
  1. Start the adjustment.
  2. A dialogue shows the test conditions, check these.
  3. A dialogue shows "The learning process of the clutch pedal has started, do not operate the clutch pedal". Press "OK" to continue.
  4. A dialogue shows "Depress the clutch pedal". Press "OK" to continue and then release the pedal.
  5. A dialogue shows "Clutch pedal is learned". Press "OK".
  6. A dialogue shows "Turn off the ignition". Press "OK".
  7. A dialogue shows "Turn on the ignition". Press "OK".
  8. The function is done.
