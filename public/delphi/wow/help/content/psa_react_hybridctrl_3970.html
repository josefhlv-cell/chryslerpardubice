Reactivation of hybrid control unit
This function is used to reactivate the hybrid control unit after memory storage of a crash.
Test conditions:
  • The function "Reactivation of traction battery" in the device for traction battery must be performed.
  • Ignition on.
  • Indicator light "READY" is off.
Procedure:
  1. Start the function.
  2. A dialogue box shows the result.
  3. The function is done. If the function failed, check test conditions and resolve any error codes.
