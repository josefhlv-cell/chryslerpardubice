[1267]Coding of control units for trailers

During the installation of a towbar and a trailer control module, it is necessary to code the trailer control module to get all the functions to work correctly.

Note:

  • A new control unit can have the code 0 stored.

Test prerequisities:

  • The battery voltage should be above 12V.

  • Ignition on, engine off.

  • No faults should be stored in the fault memory.

Procedure:

  1. Start the function: "Code the control unit".

  2. A dialog box presents the actual code and "Change value". Confirm with YES.

  3. Enter the new code (se below) in the presented input field, confirm with OK.

    When assembling a retractable towbar with a handle: write 33 + market code.

    Example: Retractable towbar with handle / rest of the world: 331.

    Code number:Market:
    1Rest of the world
    2North America
    3Australia

  4. A dialog box confirms: Code stored (with the new value) in memory.

  5. Confirm with OK to exit the function.
