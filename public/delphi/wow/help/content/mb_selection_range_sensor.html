[156]Basic setting of position range sensors

When replacing transmission and/or transmission control module it is important to teach-in the gear selector's position sensors to obtain correct transmission function.

You are guided through the following steps:

Program the component (Position range sensor) in gear selector position P.

Program the component (Position range sensor) in gear selector position R.

Program the component (Position range sensor) in gear selector position N.

Program the component (Position range sensor) in gear selector position D.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • No faults in the system.

  • Parking brake and service brake applied.

Procedure:

  1. Start the function.

  2. Follow instructions in the dialogue box, move the gear selector to the position as instructed and press "OK".

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
