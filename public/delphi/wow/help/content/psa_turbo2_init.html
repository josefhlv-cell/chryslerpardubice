[1454]Turbo 2 solenoid valve

This function adapts the turbo 2 solenoid valve to the engine control unit. Carry out an adaption when the valve is replaced.

Test prerequisite:

  • Engine cold and not started for at least 10 minutes.

  • Ignition on, engine off.

  • The EGR valve connected and installed correctly.

  • No faults stored.

  • All electrical loads should be switched off.

  • Battery voltage above 12 Volts.

Procedure:

  1. Start the function, press OK.

  2. When the function starts, the old adaption values are cleared. A dialog box presents: operation succeeded/ failed.

    • If the function fails, check the test prerequisites and repair possible fault codes.

  3. Exit the function and disconnect the diagnostic tool.

  4. Switch off the ignition for 30 seconds, and then switch it on for 30 seconds.
