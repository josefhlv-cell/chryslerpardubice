Compression test
This function is used to perform a compression test and read out parameters for the offset balance adjustment, injectors 1-4.
Note:
The test must be performed in one sequence otherwise it may be canceled.
Test conditions:
  • Engine temperature above 70°C.
Procedure:
  1. Start the function, press OK.
  2. Start cranking the engine for about 10 seconds (the engine will not start) and then let the ignition remain on. Parameters related to this test are presented during the time you start cranking.
  3. Press "OK" to continue.
  4. To read out parameters for the offset balance adjustment, injectors 1-4, start the engine. The injector values will now be presented. If the engine speed exceeds 2000 rpm, the injector values will be frozen and then drop to 0.
  5. If the function fails, check the test conditions and repair any faults.
