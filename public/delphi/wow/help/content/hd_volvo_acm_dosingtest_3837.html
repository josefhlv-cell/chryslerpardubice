Dosing test
This function is used to check that the system delivers correct amount of AdBlue for a certain time.
Note:
  • Before running the dosing test, "Starting SCR operation, test" must be finished.
  • To avoid serious damage to the aftertreatment system the dosing module must be removed from the inlet pipe. The module should hang freely in its connections. Screws for the dosing module shall be installed back in the module and fastened with nuts on the back of the heat shield to prevent the dosing module from leaking.
  • Place a collection container under the dosing module to collect the Adblue that will be dosed.
  • The test takes approx. 2 minutes. Use a measuring beaker to check the dosage amount.
  • After the test has been finished the dosing module shall be reinstalled in the inlet pipe and the engine should be run at idle for awhile and then turned off. This ensures adequate afterventilation of the SCR-system.
  • Adblue may irritate skin and may react aggressively with electronic components.
  • Evaluation 60g: approximately 54g - 66g (49ml - 60ml).
  • Evaluation 240g: approximately 216g - 264g (196ml - 240ml).
Test conditions:
  • Before running the dosing test, "Starting SCR operation, test" must be finished.
  • Parking brake applied.
  • Engine off.
  • Ignition on.
  • Dosing module disconnected from inlet pipe.
  • Adblue in reservoir.
  • Battery voltage above 20V.
Procedure:
  1. Start the function.
  2. Check conditions.
  3. Select to start or cancel the test.
  4. The function is done.
  • If the function fails, check the test conditions and repair any faults.
