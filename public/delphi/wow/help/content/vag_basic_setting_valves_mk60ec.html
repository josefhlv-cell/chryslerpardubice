[189]Basic setting of inlet and abs valves

If the ABS control module has been replaced this basic setting should be run to adapt the old hydraulic unit to the new control module. After a basic setting of the inlet valves, a basic setting of the abs valves should also be performed. During the basic settings the brake pressure should be set in a reference value range by pressing down the brake pedal until the reference value is reached, then the control module automatically goes to the next reference value. The time of this sequence varies depending on model. If basic setting is cancelled a fault code is stored in the ABS control module. It can be erased after a completed basic setting.

Test conditions:

  • Engine idling.

  • Control module for ABS coded correctly.

  • Outdoor temperature 10°C-60°C.

Procedure:

  1. Start the function.

  2. The following is shown:

    • Relevant valve (valve type to which basic setting applies).

    • Brake pressure; lower setting value (lower limit value in bar).

    • Current brake pressure (in bar).

    • Brake pressure; upper setting value (upper limit value in bar).

    • Status for basic setting (in progress, function done, test cancelled).

  3. Slowly press down the brake pedal until current pressure is between lower and upper setting value, when the value has been reached the next setting value is shown automatically.

  4. This sequence is repeated several times per valve.

  5. When status changes from "In progress" to "function done" the basic setting is finished, press "OK" to exit the function.

  6. Now select the function: "Basic setting abs valves", press OK.

  7. Follow instructions under steps 2-5.

  8. After finished function, check that no fault codes are stored in the system.

    • If the function fails, check the test conditions and repair any faults.
