[1473]Double clutch

In the ABS control unit in vehicles with a gearbox with a double clutch exists a function to activate/deactivate a sportmode.

Note:

  • The basic setting can only be done after entering a login code. Use the function: Login.

  • It is only possible to activate the double clutch function on control units that support the function.

Test prerequisites:

  • Ignition on.

  • Battery voltage above 12 volt.

  • No fault codes stored.

Procedure:

  1. Choose the function: "Login". Enter the login code: 40168, press OK.

  2. Choose the function: "Double clutch".

  3. A dialog box presents the actual adaption value for the double clutch. Confirm with "Yes" to change the value. If the value is not to be changed, the function is aborted with "Abort"

    The following learning values shall be used:

    • 0= Sportmode deactivated

    • 1= Sportmode activated

  4. Write the actual value for the vehicle. Confirm with "OK".

  5. A dialog box presents the new value.

  6. Confirm with "OK" to store the new value.

    • If the dialog box "Operation failed" is presented, the function is not supported and the old value resumes automatically.
