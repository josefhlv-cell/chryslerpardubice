[8]Automatic brake bleeding

This function is used to bleed the brake system.

Note:

Before performing automatic bleeding of the ABS-system, air must first be forced out manually or with pressure from the basic system.

Automatic bleeding is recommended in the following cases:

  • Bleeding of the basic brake system does not give desired pedal height or feel.

  • Extreme loss of brake fluid.

  • Air intrusion is suspected in the brake control unit's secondary circuits.

Test conditions:

  • Ignition on, engine off.

  • Access to equipment for bleeding brakes.

  • No faults in the system.

Procedure:

  1. Start the function and follow the instructions in the program.

    If the brake pedal feels spongy after finished bleeding, repeat the procedure.
