Haldex clutch oil level check
This function is used to check the Haldex clutch temperature at a oil level check.
Note:
Only use manufacturer-approved oil.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. An automatic check of the oil temperature is performed.
    • If the oil is too cold, a test drive is required to raise the temperature to the correct level.
  3. At the correct temperature, the level plug should be removed.
    • Check the level plug position using the repair manual.
  4. The oil level is correct when the Haldex clutch is filled up to the bottom edge or maximum 3 millimeters below the level hole.
  5. The function is done.
