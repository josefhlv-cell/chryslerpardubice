[7]Basic setting of air conditioning system

At basic setting the control unit performs teach-in of the actuators' end-positions. This shall be done if:

  • the air conditioning system control unit has been replaced.

  • actuators have been replaced or reinstalled.

  • Components for the air conditioning system have been replaced or reinstalled.

Note:

It is not possible to abort the basic setting after it has started.

Test conditions:

  • Battery voltage above 11.5 V.

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Select the function.

  2. Follow the instructions in the dialogue boxes.

  3. Exit the function. Turn off the ignition to store new values.

  4. The function is done.

  5. Turn on the ignition, re-establish communication, and check that no error codes have been stored.

    • If the function fails, check the test conditions and repair any faults.
