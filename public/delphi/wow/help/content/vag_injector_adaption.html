[1372]Injector programming

When an injector is replaced it is necessary to program the injector to the engine control unit.

Note:

To exclude reduced driving ability, a programming must only be done when an injector is replaced.

Test prerequisities:

  • The battery voltage should be >12 V.

  • Ignition on, engine off.

Procedure:

  1. Choose the function: "Injector programming cylinder 1,2,3 or 4" depending on which injector to program.

  2. A dialogue box confirms: operation succeed/failed.

  3. Confirm with OK.

    • Continue from point 1 if more injectors shall be programmed. Otherwise continue from point 4.

  4. Exit the function.

  5. Switch the ignition off for 30 seconds to store the programming value.

  6. Re-establish contact with the system. Check in datalist 18 that the programmed injector has value 0.

  7. The function is finished.
