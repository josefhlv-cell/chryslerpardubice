[490]Injector programming

This function is used to program injector codes (calibration data) for injectors. The injector codes stored in the control unit will be shown. These can be written over if one or several injector codes do not match the engine's injectors.

This shall be done if:

  • One or several injectors have been replaced.

  • The engine control unit has been replaced.

The injector code is stamped in the top of each injector.

Turn off the ignition for at least 30 sec. after completed injector programming.

After successful injector programming, run "Teach-in pilot injection". Erase fault codes manually after completing "Teach-in pilot injection".

Fault code "P1601" and any other fault codes may be stored in the control unit before "Teach-in pilot injection" has been run.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Injector codes for cylinder 1-4 are shown.

  3. Press "YES" to continue.

  4. Choose the injector to be programmed with new injector code.

  5. Enter the new injector code.

  6. The new injector code is shown. Check that correct injector code is entered.

  7. The function is done.

    • If the function fails, check the test conditions and repair any faults.

  8. Turn off the ignition for at least 30 seconds.

  9. Run "Teach-in pilot injection".
