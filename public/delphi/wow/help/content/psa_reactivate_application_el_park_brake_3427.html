Reactivate automatic application of the electric parking brake
This function is used to reactivate automatic application of the electric parking brake, when a malfunction has deactivated the automatic application.
Note:
Warning: Only perform this function if the fault code "C155D", "Automatic application function prohibited", is present.
Preconditions for the test:
  • Engine off, ignition on.
  • Battery voltage above 12V.
  • Fault code "C155D" is present.
  • The fault has been rectified.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. Function complete.
  4. Check the function of the electric parking brake.
