[439]Reset adaptation value for mix ratio

This function is used to reset teach-in value for air/fuel sensor. Use it after air/fuel sensor has been replaced.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Adaptation values are erased.

  3. A dialogue box shows if the function succeeded or failed.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
