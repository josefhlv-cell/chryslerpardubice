[1768]Calibrate steering angle sensor

This function shall only be performed if steering angle calibration has been completed.

Note:

The ignition shall have been turned off for 10 seconds after communication with the steering angle system has ended before communication with the ABS/ASC system is started.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function and follow the instructions.

    • If the function fails, check the test conditions and repair any faults.
