Regeneration of particle filter
This function cleans the particle filter from soot particles by burning them off using an increase in the exhaust temperature. In certain driving conditions, the particle filter can not be cleaned automatically, e.g., in continuous city driving. Then this function is used to force a regeneration. Regeneration takes approx. 60 minutes.
Note:
Exhaust temperature is very high during this procedure. Therefore, perform the regeneration outdoors, without connected exhaust hose, with the hood open and all electrical consumers turned off (A/C, lighting etc.).
Test conditions:
  • Engine on.
  • Engine temperature above 70°C.
  • Fuel level at least 1/4.
  • Do not touch any controls or pedals while the function is in progress.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. When the conditions are correct and regeneration starts, the engine speed will increase while the regeneration is going on. When the regeneration is complete, the engine speed will decrease again. Exit the function when the regeneration is complete.
  4. If the function fails, check the test conditions and repair any faults.
  5. If the function is canceled, the vehicle must stand with ignition off for at least 5 minutes before a new start attempt is performed.
