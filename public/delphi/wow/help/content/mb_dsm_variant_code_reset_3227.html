Resetting variant coding
This function is used to reset variant coding in the control unit.
Test conditions:
  • Engine off, ignition on.
  • The control unit shall be approved by the start inhibitor system.
Procedure:
  1. Start the function.
  2. Follow the instructions in the dialogue box.
  3. A dialogue box shows if the operation was successful or failed when the function is finished.
  4. The function is done.
    • If the function fails, check the test conditions and repair any faults.
