Display test
This function is used to test the color scales in the display.
The following test images can be selected:
  • Blue test image.
  • Red test image.
  • Green test image.
  • White test image.
  • Test image all colors.
  • Exit the test.
Note:
Selected test image is lit up and is changed if a new test image is selected, or goes out if you choose to exit the test.
Test conditions:
  • Ignition on.
Procedure:
  1. Select the function and follow the instructions.
