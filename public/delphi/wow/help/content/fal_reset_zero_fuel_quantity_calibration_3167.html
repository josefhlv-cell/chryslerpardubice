Resetting zero fuel quantity calibration
This function will initiate zero calibration fuel quantity and normal voltage calibration. The function should only be used when ECM has been replaced and the original injectors are still used. Make sure that injector programming and quantity adjustment are done before continuing.
Note:
If injector programming has not been performed then this function should not be performed.
Test conditions:
  • Ignition on, engine off.
  • Injector programming completed.
Procedure:
  1. Select the function and follow the instructions.
