System test during operation
This function is used to test the retarder's different signals.
Note:
During the test the vehicle should be driven at approx. 30 km/h.
Test conditions:
  • Engine on.
Procedure:
  1. Start the function.
  2. Check test conditions.
  3. Drive the vehicle at approx. 30 km/h and press "OK".
  4. Stop the vehicle.
  5. Check the status.
  6. Function complete.
  • If the function fails, check the test conditions and repair any faults.
