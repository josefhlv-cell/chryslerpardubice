[299]Calibrate injection amount

This function is used to adjust injection amount for the injectors. The function is used after the function for engine adjustment has been used.

Test conditions:

  • Engine on.

  • All power consumers disconnected.

  • Engine temperature between 65 °C - 95 °C.

  • Intake air temperature between 15 °C - 65 °C.

  • Fuel temperature between 30 °C - 60 °C.

  • Do not touch any controls or pedals while the function is in progress.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
