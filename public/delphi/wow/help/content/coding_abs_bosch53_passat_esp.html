[789]Coding ABS control unit Bosch 5.3 with ESP Passat –97 ->

The ABS control unit must be coded if the vehicle's relevant code is not shown in the system's basic data or if a control unit has been replaced. To enable coding of the control unit, a valid log-in code must be entered.

Only applies to cars with ESP.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function.

  2. Read out from the table below which log-in code applies to the car and enter the relevant code in the field for logging in. Press "OK".

  3. A dialogue box shows if the operation was successful or failed.

  4. Read out from the table below which code applies to the car and enter the relevant code in the field for Coding ABS. Press "OK".

  5. A dialogue box shows if the operation was successful or failed.

  6. Read out the control unit's basic data to check that the code is programmed.

  7. Check that no fault codes are stored in the control unit.

  8. The function is done.
