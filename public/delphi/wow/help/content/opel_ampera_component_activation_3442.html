Fuel pressure regulation
This function is a component activation and is used to regulate the fuel pressure.
Note:
The fuel pressure is activated between 300 kPa - 400 kPa.
Test conditions:
  • Engine idling.
Procedure:
  1. Start the function.
  2. Follow instructions.
  3. The function is done.
    • If the function fails, check the test conditions and repair any faults.
