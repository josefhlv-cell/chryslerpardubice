[59]Initialise steering angle sensor

This function is used to initialise the steering angle sensor.

The function is used when:

  • The ABS control unit has been replaced.

  • The steering angle sensor has been replaced.

  • Error code that requires initiation of steering angle sensor is stored in the ABS control unit.

Test conditions:

  • Engine idling.

Procedure:

  1. Set the front axle in position straight ahead.

  2. Start the function, press "OK".

  3. Turn the steering wheel from end position to end position and finish in straight ahead position, press "OK".

    • A dialogue box shows: operation succeeded/failed.

    • If the function fails, check the test conditions and repair any faults.
