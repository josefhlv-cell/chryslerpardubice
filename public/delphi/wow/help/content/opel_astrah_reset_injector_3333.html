Injector programming
This function is used to perform an injector reset and must be done after replacing one or several injectors.
Note:
All injectors must be reset before injector programming. Thereafter each injector is programmed separately.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Select "Reset all" in the dropdown list.
  3. Follow given instructions.
  4. The reset is finished.
  5. Start the function again.
  6. Select an injector to be programmed.
  7. Follow given instructions.
  8. Repeat the function until all injectors have been programmed.
  9. Check and erase any fault codes.
  10. The function is done.
