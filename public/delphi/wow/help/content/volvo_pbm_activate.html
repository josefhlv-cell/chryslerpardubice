[1745]Activate service mode

This function is used to release the brake pads when working on the brakes, this takes approx. 30 seconds. When the repair is done the service mode must be deactivated to restore the brake system.

When service mode is activated, fault code "U210054" is stored, this is erased automatically when service mode is deactivated.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select function, press "OK".

  2. Service mode is activated.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
