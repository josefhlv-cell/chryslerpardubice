Standard adjustment and adaptation gearbox
This function is used to perform a standard adjustment and adaptation after replacing the gearbox.
Test conditions:
  • Engine off.
  • Place the vehicle on a level surface.
  • Parking brake applied.
  • Refrigerant compressor turned off.
  • Gear selector in position P.
  • Check that the steering wheel is straight and the front wheels point straight ahead.
  • The throttle pedal and brake pedal should not be operated.
  • Transmission temperature 30-100 C°.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. Note that the engine should be started when you are instructed in the function.
  4. A dialog box presents: operation succeeded/ failed.
  5. Exit the function, clear possible fault codes and disconnect the diagnostic tool.
  6. If the function fails, check the test conditions and repair any faults.
