[26]Reset read-in of components for automatic transmission

Reset of read-in components shall be done in the following cases:

  • Retrofitting trailer module.

  • Retrofitting ACC (active cruise control).

  • Incorrect installation of rear axle.

  • Incorrect installation of automatic transmission.

  • When replacing GWS (gear selector switch).

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Read-in components are reset.

  3. The function is done.
