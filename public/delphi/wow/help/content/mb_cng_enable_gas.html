[377]Enable gas operation

This function shall be used when gas operation is to be enabled in the engine control unit.

Test conditions:

  • Ignition on.

  • Battery voltage above 12V.

  • Gas system connected.

Procedure:

  1. Start the function.

  2. A dialogue box shows if the function succeeded or failed.

    • If the function fails, check the test conditions and repair any faults.
