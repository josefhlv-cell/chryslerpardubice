Configure automatic engagement of ESP
This function is used to set the ESP-system's automatic reconnection.
Note:
When the function is started the data list "ESP, automatic reconnection threshold" will be shown. If the value is not 50 km/h then you press "OK" to set the ESP-system's automatic reconnection. If the value is 50 km/h then you press "Abort" to cancel the function.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
