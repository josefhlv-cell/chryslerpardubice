[1718]Configure tire size

This function is used to configure the tire size. The tire dimensions must be programmed to enable the control unit to calculate the correct speed.

The tire dimensions are divided into 5 groups:

  • Group 1: 185/65 R15, 215/45 R17

  • Group 2: 195/65 R15, 195/60 R16, 205/55 R16, 205/50 R17, 225/45 R17, 225/40 R18

  • Group 3: 195/60 R15

  • Group 4: 235/35 R19

  • Group 5: 205/50 R17, 225/40 R18, 225/45 R17, 235/35 R19

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the function.

  2. A dialogue box appears containing the stored tire group. Press "OK" to programme the new tire size.

  3. Select the required tire group, press "OK" and follow the instructions. Press "Stop" to abort the function.

  4. The programmed tire group is displayed when programming is complete.

    • If the function fails, check the test conditions and repair any faults.
