[79]Injector calibration

This function is used to perform injector calibration. Calibration shall be performed after replacing engine control unit and/or injector.

Test conditions:

  • Engine idling.

  • Coolant temperature between 81 - 95 °C.

  • Fuel temperature between 31 - 59 °C.

  • All doors closed.

  • All power consumers and AC off.

  • Gear in neutral position.

  • Do not press on any pedal during calibration!

Procedure:

  1. Press "OK" to start the function.

  2. A dialogue box instructs "Turn off ignition".

  3. A dialogue box instructs "Start the engine"

  4. A dialogue box shows status of coolant temperature and fuel temperature, wait for correct temperature, see test conditions.

  5. Press "OK" when correct temperature is reached.

  6. A dialogue box shows status for "Learning small fuel quantity". Press "OK" to start calibrating.

  7. When status shows "programmed" and "inactive" the function is done, press "OK" to finish.

If the calibration failed, check test conditions. NOTE! The temperature must remain within the limit values.
