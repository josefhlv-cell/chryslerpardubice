[224]Restore counter for additive level

This function restores the counter for calculating additive level in the reservoir. This shall only be done after filling additive reservoir according to service instructions for the car.

Test conditions:

  • Ignition on, engine off.

  • Additive reservoir filled.

Procedure:

  1. Start the function.

  2. Follow the instructions in the programme.

  3. The function is done.

    • If the function failed, check test conditions and resolve any error codes.
