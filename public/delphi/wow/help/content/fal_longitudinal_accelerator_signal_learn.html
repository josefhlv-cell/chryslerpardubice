[682]Longitudinal acceleration signal learn

Note:

The function performs learning of the offset value for the longitudinal acceleration sensor, transferred by lateral acceleration/yaw node (NYL).

Faults in the performance affects, and the optimal functioning of the system such as an effective pick-up is not obtained.

This function is used when:

  • The transmission controller has been replaced.

  • The longitudinal accelerator sensor has been replaced.

Test conditions:

  • Ignition on.

  • The vehicle must be standing on level ground.

Procedure:

  1. Start the function and follow the instructions in the program.
