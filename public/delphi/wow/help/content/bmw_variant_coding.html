[545]Version coding

When replacing a control unit, it needs to be version-coded to function correctly.

Note! The control unit that contains the vehicle's coding data, e.g. "Combi-instrument" and "Lighting module" must not have been coded to another vehicle previously and must be new.

Note:

  • Incorrect version coding may reduce the car's safety / operation.

  • The control unit must be of the correct type to approve the version code.

Test conditions:

  • The battery voltage must be at least 12V, connect the battery charger if necessary.

  • Ignition on, engine off.

  • All power consumers disconnected.

Procedure:

  1. With the defective control unit still installed.

  2. Start the "Version coding" function.

  3. The vehicle's coding data is checked to see that it is OK.

  4. Select "Save data" to read and save data from the faulty control unit.

  5. Name the file as desired and select a location where it is to be saved, press "Save".

    • It may be suitable to name the file using the car's registration number and choose to save on the computer's desktop.

  6. A dialogue box confirms that the saved data has been saved to file.

  7. Click on "OK" and exit communication with the vehicle.

  8. Replace the control unit.

  9. Resume communication with the vehicle and select the "Version coding function".

  10. The vehicle's coding data is checked to see that it is OK.

  11. Select "Transfer data" to download the saved data to the new vehicle.

  12. Open the saved file containing the data from the faulty control unit by double-clicking on it, or mark it and click on "Open".

  13. You are asked whether coding should start. Click on "YES" to perform the coding and "NO" to cancel.

  14. Version coding is performed.

  15. After the version coding has been performed, the ignition must be turned off for 10 seconds before the function check is performed.
