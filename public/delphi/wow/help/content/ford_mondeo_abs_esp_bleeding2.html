[616]Bleed brake system

This function is used when air is suspected in the ABS-system, or in case of reduced brake function. Before running the function, bleed the primary hydraulic circuit.

Note:

Check all hydraulic connections and couplings if the ABS hydraulic unit has been replaced.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • Brake bleeding equipment contains at least 4 litres of brake fluid.

  • Brake bleeding equipment is set to 1-2 psi working pressure.

  • The primary hydraulic circuit is bled.

Procedure:

  1. Start the function.

  2. Follow the instructions.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
