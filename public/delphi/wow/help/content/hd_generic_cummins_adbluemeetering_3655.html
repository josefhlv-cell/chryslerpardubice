AdBlue dosing test
This function is used to test if the dosing pump is working correctly.
Note:
The AdBlue injection nozzle must be removed from the exhaust system and be placed in a measuring container. If the injection nozzle is not removed from the exhaust system, this will cause unnecessary AdBlue injection in the catalyst.
After completed test or if the test is prematurely stopped, an automatic emptying will be performed before the test is stopped.
If there are active faults in the system, these may affect the test result.
The test is ongoing for 360 seconds.
The test can be terminated prematurely by pressing the "Cancel" button.
Test conditions:
  • The AdBlue injection nozzle removed from the exhaust system and placed in a measuring container.
  • Engine on.
  • Parking brake applied.
  • No active faults in the system.
Procedure:
  1. Start the function.
  2. Check test conditions.
  3. Check the values presented during the test.
  4. When the test is complete, press the "OK" button.
  5. Function done.
  • If the function fails, check the test conditions and repair any faults.
