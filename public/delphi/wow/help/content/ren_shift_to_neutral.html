[445]Engage neutral in the transmission

This function is used to engage neutral gear on both input shafts and the rear axle. This is a component activation and shall only be used if the car is configured and equipped with the component. An activation may take up to a minute, during that time a window with the text "Please wait" is shown.

Test conditions:

  • Gear selector in position N.

  • Ignition on, engine off.

  • Brake pedal pressed down.

  • Parking brake applied.

Procedure:

  1. Start the function.

  2. Wait for "Function done".

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
