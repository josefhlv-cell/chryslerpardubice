[1024]EGR system

Preconditions for the test:

  • Ignition on.

  • No faults stored.

Note:

  • Adapts (matches) the EGS system to the engine control unit.

Procedure:

  • Choose the EGR system function.

  • Check the values in adaption status. Prescribed value Adaption status must change from ”Adaption in progress…” to ”Adaption OK!” / ”Adaption Error!”.
