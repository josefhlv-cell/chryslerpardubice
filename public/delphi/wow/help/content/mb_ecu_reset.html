[1608]Control unit reset

This function is used when a reset (restart) of the control unit is needed.

Note:

Some control units may have their settings erased, such as e.g., trip meter / time / date, or similar.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

Procedure:

  1. Start function, press "OK".

  2. A dialogue box shows if the function succeeded or failed.

  3. The function is done.
