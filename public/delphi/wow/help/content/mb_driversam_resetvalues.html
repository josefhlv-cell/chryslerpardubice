[1676]Reset MAX and MIN values

This function resets the stored MAX and MIN values to zero.

The ignition must not be switched off during the reset.

Test conditions:

  • Ignition on.

  • Battery voltage above 12 V.

  • No faults in the system.

Procedure:

  1. Select the "Reset actual value" function and press "OK".

  2. A dialogue box shows: "Ignition on". Press "OK".

  3. Once the function is complete, new MAX and MIN values are learnt.
