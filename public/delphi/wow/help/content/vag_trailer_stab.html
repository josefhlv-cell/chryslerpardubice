[1392]Trailer stabilization

When a trailer module is installed or the ABS control unit is changed, the trailer stabilization function shall be activated if the function is supported by the vehicle´s equipment and control units.

Note:

This function is only supported on vehicles from year model 2006 and forward. It is only possible to activate the trailer stabilization function on control units that support the function.

Test prerequisites:

  • Ignition on.

  • Battery voltage above 12 volt.

  • No fault codes stored.

Procedure:

  1. Choose the function: 'Trailer stabilization'.

  2. A dialog box presents the actual adaption value for the trailer stabilization. Confirm with "Yes" to change the value. If the value should not be changed, the function is aborted with "Abort".

    The following learning values shall be used:

    • 0= Trailer stabilization deactivated

    • 1= Trailer stabilization activated

  3. Write the actual value for the vehicle. Confirm with "OK".

  4. A dialog box presents the new value.

  5. Confirm with "OK" to store the new value.

    • If the dialog box "Operation failed" presents, the function is not supported and the old value resumes automatically.
