[320]Coding control unit

The control unit's version code controls one or several specific functions in the control unit. When replacing a control unit, it needs to be version-coded to function correctly. You may also need to change version code when, e.g., retrofitting equipment. With this function it is possible to do the following:

  • Version 1: Read off and save old version code when replacing control unit.

  • Version 2: Possibility to change version code in existing control unit.

Note:

  • Incorrect version coding may reduce the car's safety / function.

  • When version 2 is selected, on some systems there is a plus icon added to the dialogue box when reading out the version code. In these cases there is a guided help to read out the relevant code table.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • No faults in the system.

Procedure:

Version 1, When replacing control unit:

  1. With the defective control unit still installed, start the function.

  2. Existing version code in control unit is shown.

  3. Select "Save to file" to save read-out version code.

  4. Name the file as desired and select a location where it is to be saved, press "Save".

    • It is suitable to name the file according to the car's license plate number, and save on the computer's desktop.

  5. A dialogue box with the text "Saved" confirms that the read version code is saved, press "OK".

  6. Press "Cancel", exit the function, and exit communication with the car.

  7. Replace the control unit.

  8. Re-establish communication with the car and start the function again.

  9. The version code in the new control unit is shown.

  10. Select "Load from file".

  11. Double-click on the file with the saved version code from the defect control unit.

  12. The version code from the defect control unit is uploaded and shown on the screen, press "OK".

  13. You are asked if you want to code the system, press "YES" to perform coding, press "NO" to cancel.

  14. Version coding is performed.

  15. The new stored code is shown.

    • If coding fails, check that the version code is valid for the control unit in question.

  16. Exit the function and turn off the ignition for 30 seconds to save the new code.

Version 2, changing version code in existing control unit:

  1. Start the function.

  2. Existing version code in control unit is shown.

  3. If guided help is added in the dialogue box with the existing version code, press the plus icon to see relevant code table for the control unit.

  4. Click on desired position, enter the new value for the relevant position and press "OK".

  5. You are asked if you want to code the system, press "YES" to perform coding, press "NO" to cancel.

  6. Version coding is performed.

  7. The new stored code is shown.

    • If coding fails, check that the version code is valid for the control unit in question.

  8. Exit the function and turn off the ignition for 30 seconds to save the new code.
