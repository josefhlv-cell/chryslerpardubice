Coding ABS-control module Bosch 5.7 with ESP
This function is used to code variant in the ABS-control module after replacement. It is advantageous to read out the variant code from the old control module, see data list "Control module variant code". Valid variant coding is also listed in the table below.
Note:
  • When the control unit is coded a valid login code first must be entered. Only valid for cars with ESP.
  • A faulty variant coding can reduce the car safety and/or performance.
  • The control unit version must be correct to accept variant coding.
  • The coding table refers to PR-Number (production number), these may be found on a plate close to the spare tire or on the first page in the service booklet.
Test prerequisites:
  • A valid login for control unit.
  • A valid variant code for control unit.
  • The battery voltage should be above 12V
  • Ignition on, engine off.
  • All the electrical loads should be switched off.
To perform coding:
  1. Approved log-in must be performed before coding of the control module can be performed, see separate function.
  2. Read from the table below which variant code applies to the car, or have the old read-out variant code available.
  3. Enter the current code in the field for "Coding ABS".
  4. Click on the OK-button.
  5. A dialogue box confirms: Operation succeeded / Operation failed.
  6. Read out the control unit's basic data to check that the code is programmed.
  7. After coding the control module, the steering angle sensor has to be adapted.
