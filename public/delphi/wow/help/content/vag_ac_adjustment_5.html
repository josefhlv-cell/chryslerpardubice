[1632]Basic setting of climate control unit

If the control unit for the AC has been replaced or a new actuator has been installed, a basic setting of the AC must be performed. At basic setting, the control unit learns the actuators' end-positions and stores these.

Test conditions:

  • Battery voltage above 11,5 V.

  • Ignition on, engine off.

  • No fault in the system.

  • Correctly installed and connected actuators.

Procedure:

  1. Select the function: "AC unit".

  2. Basic setting starts and, depending on the car's equipment, the AC unit's display or the control light in the AC-button will start to flash.

  3. The text "Activated" is shown and changes to "Finished" when the basic setting is done.

  4. Exit the function and turn off the ignition for approx. 30 seconds.

  5. Turn on the ignition, re-establish communication, and check that no error codes have been stored.
