[366]Initiate control unit

This function is used to initiate a new control unit. The new control unit should be installed before the function is performed.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 Volt.

  • Control unit replaced.

Procedure:

  1. Start the function.

  2. The function initiates the new control unit.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
