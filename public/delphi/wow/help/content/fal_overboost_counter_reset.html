[1601]Reset boost pressure counter

This function is used to reset the boost pressure counter. Perform only when the turbocharger has been replaced.

Test conditions:

  • engine off, ignition on.

Procedure:

  1. Select the function.

  2. The boost pressure counter is reset.

  3. Turn off the ignition for 40 seconds to save new values.

  4. Turn on the ignition, the reset is finished.

    • If the function fails, check the test conditions and repair any faults.
