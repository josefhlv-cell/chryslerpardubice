Calibrate damper actuators
The IHKA control unit must measure the travel paths and the end stops individually, as the air distribution dampers in the climate control may differ between different devices. The IHKA measure these values, using the calibration of the damper motors. This is performed automatically each time the control unit is coded. An adjustment can also be done using this function, if the air distribution dampers conditions are implausible.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. Function complete.
