[961] Basic setting requirements

Preconditions for the test:

  • Engine idling.

  • No faults stored.

  • No leaks in the exhaust system.

  • Engine temperature above 80 °C.

  • All electrical loads switched off.

  • Automatic gearbox set to ”P/N”.

Note:

  • Used to check basic setting requirements.

  • These requirements must have been met when checking the idling speed.

Procedure:

  • Choose the function: Basic setting requirements.

  • Check the block of digits in the basic setting requirements column. Prescribed value 1X111­111.

  • Quit the basic setting requirements function and continue with the idling control.
