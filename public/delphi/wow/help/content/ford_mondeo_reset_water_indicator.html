[151]Reset warning indicator for water in fuel

This function is used to reset the warning indicator for water in fuel. Only run this function when water has been removed from the fuel.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
