[1631]Reset service information after oil change (only cars with DPF)

This function resets data list parameters for "Quality engine oil" and "Distance to next oil change". This shall be done in connection with oil change in engines featuring diesel particle filter (DPF). If the vehicle is not equipped with diesel particle filter (DPF) reset is performed of service message only in the instrument.

Explanation of data list parameters:

Quality engine oil: Shows how much the oil has been polluted by diesel, or how much the fuel has been polluted by oil through penetration via the piston rings (something that occurs after a number of regenerations of the vehicle have been performed).

Distance to next oil change: Shows number of km that can be driven to next oil change.

Test conditions:

  • Ignition on, engine off.

  • Oil change in engine done.

  • Note the values for "Quality engine oil" and "Distance to next oil change " in the data list, to be able to check that these values have been updated after the reset has been finished.

Procedure:

  1. Start the function.

  2. Turn off ignition, press "OK".

  3. Wait until reset is done, approx. 35 seconds.

  4. When reset is done, turn on ignition, press "OK".

  5. Check that update of data lists has taken place.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
