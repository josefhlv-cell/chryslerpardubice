Activating injector solenoid valves
This function is used to check if the injector solenoid valves works by force control them.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Select which solenoid valve to be tested.
  3. Press "Start" to activate the solenoid valve.
  4. Finish the test by pressing "OK".
  • If the function fails, check the test conditions and repair any faults.
