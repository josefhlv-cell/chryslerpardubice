[150]Activate clutch operation

This function is used to activate clutch operation. Control module "FR" (drive control) sends request for clutch position to control module "GS" (gear control) via the transmission's CAN-bus.

Test conditions:

  • Ignition on, engine off.

  • Parking brake applied.

Procedure:

  1. Start the function.

  2. A dialogue shows test conditions. Press "OK" to continue or "Cancel" to cancel the function.

  3. Select position to be activated, deactivate the position before next position is chosen. Press "OK".

  4. A dialogue shows "Function done". Press "OK".

  5. The function is done.
