Resetting the adaptation values
This function is used to reset the adaptation values in the engine control unit for lambda regulation.
Test conditions:
  • Engine off.
  • Ignition on.
Note:
The function must be run following replacement or repair of the following:
  • O2 sensor before catalyst.
  • Air mass sensor.
  • Rail pressure sensor.
  • Differential pressure sensor, diesel particle filter.
  • Leak in the intercooler system.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. If the function fails, check the test conditions and repair any faults.
