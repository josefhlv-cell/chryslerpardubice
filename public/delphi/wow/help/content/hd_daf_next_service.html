[102]Set service message

This function is used to set date and distance to next service. At the start of the function, a choice is given to use km or miles when setting the distance to next service. Select the unit to be used.

Test conditions:

  • Ignition on, engine off.

  • All doors closed.

  • Interior lights off.

  • Flashing hazard lights off.

Procedure:

  1. Start the function.

  2. Choose if existing service interval is to be kept or if a new interval shall be programmed.

  3. Choose km or miles in the dropdown menu (does not apply if you choose to keep service interval).

  4. An input box is shown, enter number of km/miles to next service (does not apply if you choose to keep service interval).

  5. Enter date for next service in the format YYYY-MM-DD.

  6. Programming is performed.

  7. The function is done.
