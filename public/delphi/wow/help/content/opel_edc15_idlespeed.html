[36]Calibrate idle speed

This function is used to adjust the idle speed.

Idle speed shall only be changed if the engine vibrates a lot when idling.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the function.

  2. A dialogue box shows status for "offset idle speed". Press "OK", and follow the instructions.

  3. After finished adjustment the current offset value for idle speed is shown.

    • If the function fails, check the test conditions and repair any faults.
