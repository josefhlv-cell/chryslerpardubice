[662]Deletion stored buttons

Note:

This function is used to delete some of the control unit's memories and to check that the buttons work correctly (status change from released to stored in memory). If this function is not used, a button assumed to have status 'stored' will also have this when the button is released and until communication with the control unit is finished.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function and follow the instructions in the program.
