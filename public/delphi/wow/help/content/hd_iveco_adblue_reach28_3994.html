AdBlue: REACH 28
This function is a test and is used to help to distinguish if the leak comes from the pump module or the pressure line/dosing module.
The test should only be performed if UDST (Urea dosing system test) writes matching fault code.
Note:
  • During start-up the AdBlue injection lines are pressurized. Where there are leaks AdBlue may run out on the vehicle.
  • The test should only be performed if UDST (Urea dosing system test) writes matching fault code.
Test conditions:
  • Ignition on, engine off.
  • Battery voltage above 20V.
  • The pressure line must be disconnected from the pump module outlet and the connector must be sealed before the test is run.
  • Check that no fault codes are stored in the engine control unit.
Procedure:
  1. Start the function.
  2. A dialogue box shows the test conditions, check these and press "OK".
  3. Communication will be established with the control system.
  4. The system builds up 2,8 bar pressure in the system and then shut down the pump module.
  5. All values remains closed in 120s.
  6. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
