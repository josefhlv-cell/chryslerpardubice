[1763]Activating trailer stabilization

When retrofitting a trailer control unit or replacing ABS control unit, the function for trailer stabilization shall be activated, if this function is supported by the vehicle.

Test conditions:

  • Ignition on.

  • Battery voltage above 12 V.

  • No faults in the system.

Procedure:

  1. Select the function: "Trailer stabilization", press "OK".

  2. A dialogue box shows the current adaptation value for "Trailer stabilization", press "YES" to change the value.

    The following adaptation values shall be used:

    • 0 = Trailer stabilization activated.

    • 1 = Trailer stabilization deactivated.

  3. Enter the new value, press "OK".

  4. A dialogue box shows the new value, press "OK".

  5. Exit the function and the diagnostics session by returning to the car selection.

  6. Turn off the ignition to store the new value.

  7. The function is done.

    • If the function fails, check the test conditions and repair any faults.
