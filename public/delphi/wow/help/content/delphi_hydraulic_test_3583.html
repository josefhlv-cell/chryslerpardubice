Hydraulic test
This function is used to test the function for the pump hydraulics.
Note:
The test can only be performed once in sequence. To perform it again, the ignition must first be turned off.
Test conditions:
  • Ignition on.
  • Coolant temperature at least 70 °C.
  • Do not touch the accelerator pedal during the test.
Procedure:
  1. Start the function.
  2. A dialogue box with a number of parameters is shown.
  3. Crank the engine for about 10 seconds and let the ignition remain on.
  4. Parameter for status function test changes from "in progress" to "complete" and values for fuel pressure parameters are set.
  5. If the function fails, check the test conditions and repair any faults.
