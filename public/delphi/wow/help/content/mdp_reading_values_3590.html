Reading MDP parameters
This function is used to read out parameters of the MDP (minimum drive pulse).
Test conditions:
  • Ignition on.
  • Battery voltage above 12V.
Procedure:
  1. Press "OK" to start the function.
  2. Values for the MDP parameters is presented.
  3. Press "OK" to continue.
  4. Values for the MDP updates is presented.
  5. Press "OK" to exit the function.
  6. If the function fails, check the test conditions and repair any faults.
