Reactivation of traction battery
This function is used to reactivate the traction battery after memory storage of a crash.
Note:
After performing this function, the "Reactivation of hybrid control unit" in the device for hybrid control 1 must be run.
Test conditions:
  • Ignition on.
  • Indicator light "READY" is off.
Procedure:
  1. Start the function.
  2. Turn off the ignition and wait for about 3 minutes.
  3. Turn on the ignition.
  4. A dialogue box shows the result.
  5. Run the function "Reactivation of hybrid control unit" in the device for hybrid control 1.
