[674]Replace clutch

The function resets certain parameters in the controller that relate to the component being replaced.

The function must be performed if the whole clutch is replaced.

When this function is performed, fault code P290E (Clutch self-calibration) is generated. In order to reset the fault codes, the "Clutch self-calibration" function must be performed".

Note:

Perform the following functions in the following order!

  • Before replacing the clutch:

    1. Accumulator depressurisation.

  • After replacing the clutch:

    1. Replace clutch.

    2. Bleed clutch.

    3. End of line/service self-calibration.

    4. Clutch self-calibration.

Test conditions:

  • Ignition on.

  • Stop&Start function disabled.

Procedure:

  1. Start the function and follow the instructions in the program.
