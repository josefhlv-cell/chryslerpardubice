Gear in neutral position
This function is used to set the gearbox in neutral position.
Test conditions:
  • Ignition on, engine off.
  • Parking brake applied.
  • Gear selector in position P.
  • Place the vehicle on a level surface.
  • Battery voltage above 12V.
Procedure:
  1. Start the function.
  2. While the function is in progress, the letter "F" flashes on the instrument panel.
  3. Follow the instructions shown in the dialogue boxes.
  4. If the function fails, check the test conditions and repair any faults.
