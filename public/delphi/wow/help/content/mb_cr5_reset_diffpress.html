[179]Basic setting of differential pressure sensor

This function is used when the differential pressure sensor has been replaced.

Note:

  • The ignition must not be turned off during the function.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. When the function is done, a dialogue box will be shown with instructions to turn the ignition off and on to end the function.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
