[208]Reset adaptation values for cold start

The engine control unit learns and corrects deviations for cold starts and stores this in the adaptation memory for cold starts. This function erases these adaptation values in the engine control unit.

Only used for complaints when cold engine is difficult to start.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. Adaptation values are erased.

  3. When the function is done, a dialogue box will be shown with instructions to turn the ignition off and on to end the function.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
