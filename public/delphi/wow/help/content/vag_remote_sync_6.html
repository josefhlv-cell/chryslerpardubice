[719]Erasing / Adaptation remote control

This function is used to erase and adapt new or existing remote controls for the vehicle.

Note:

It is possible to adapt a remote control without first erasing previously adapted remote controls. It should, however, be noted that the new remote control must always be allocated to a vacant memory location. If an occupied memory location is used, the remote control that was previously adapted for this location will not work.

If the "Erase all remote controls" function is performed, all remote controls will have to be adapted again.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Turn on the ignition.

  2. If you want to erase all remote controls, select the "Erase all remote controls" function.

    • Note that old remote controls are now erased.

    • All remote controls must be adapted again, including the existing remote controls.

  3. Select the "Adaptation remote control" function.

  4. A dialogue box shows the memory locations used. Press "OK".

  5. Select a vacant memory position from the displayed drop-down list to save the new remote control. Press "OK".

  6. Now press the unlock button and keep it pressed on the remote control to be adapted until the function continues automatically.

  7. Adaptation complete.

    • If you wish to adapt more remote controls, the function returns automatically to item 4; select a vacant memory location to adjust the next remote control.

  8. After completing adaptation, turn off the ignition and test the operation of all the remote controls.
