[1401]Add remote controls

Description:

Using this function you will add remote controls to the car.

All the new remote controls must be present.

Earlier remote controls will be erased from the system.

Conditions:

PIN code is needed to be able to add remote controls.

"VGLA remote key pin" is included when a new remote control is purchased.

Method:

Enter PIN code.

Add remote control 1. Press a button on remote 1 and hold when command is sent and at least 3 seconds after receiving response dialog.

Remote 1 is now programmed and the other remote controls are erased.

Add remote control 2. Press a button on remote 2 and hold when command is sent and at least 3 seconds after receiving response dialog.

Use the same procedure for remote 3, if neccesary.

Check the number of remote controls in the live data window.

Erase faultcodes. Turn ignition off, close all doors and test function on the added remotes.
