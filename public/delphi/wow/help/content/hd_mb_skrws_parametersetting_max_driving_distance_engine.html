[536]Parameter setting

This function is used to change parameter setting.

The parameter enables individual limitation of the engine's service interval over the driving distance.

It is time for engine service at the latest when the maximum driving distance is reached.

Basic setting corresponds to factory setting.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. A dialogue box shows test conditions, check these and press "OK".

  3. Select parameter setting and press "OK".

  4. A new dialogue box shows new parameter setting. Press "OK".

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
