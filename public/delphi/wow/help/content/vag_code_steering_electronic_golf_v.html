[295]Code steering wheel electronics

The control unit must be coded according to the corresponding equipment in order for all functions to work correctly. The control unit must be of the correct type to approve the code.

Note:

  • Incorrect coding may reduce the car's safety and function.

Test condition:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • All power consumers disconnected.

Procedure:

  1. Start the function.

  2. Existing code in control unit is shown.

  3. "Change value" is shown. Confirm with "Yes".

  4. Enter the desired code (see below) in the displayed entry field, confirm with "OK".

    Code number:Function:
    0 X X X X XNot special vehicle
    1 X X X X XSpecial vehicle (for example, taxi with multi-function control unit)
    X X X X 0 XManual transmission
    X X X X 1 XAutomatic transmission
    X X 0 X X XSteering wheel without multi-function
    X X 1 X X X3-spoke steering wheel without multi-function
    X X 2 X X XMulti-function steering wheel without cruise control function
    X X 3 X X XMulti-function steering wheel with cruise control function
    X X X 0 X XWithout control Tiptronic, without steering wheel heating
    X X X 1 X XWith control Tiptronic, without steering wheel heating
    X X X 2 X XWith steering wheel heating, without control Tiptronic
    X X X 3 X XWith steering wheel heating, with control Tiptronic
    X X X X 0 XWithout trip computer, without cruise control
    X X X X 1 XWith trip computer, without cruise control
    X X X X 2 XWith trip computer, without cruise control
    X X X X 4 XWith trip computer, with cruise control
    X X X X X 1Without rear window wiper
    X X X X X 2With rear window wiper
    Coding example:

    Vehicles with: manual transmission, multi-function steering wheel without cruise control, trip computer, cruise control, and rear window wiper = 002042

  5. A dialogue box shows: code stored (with the new value) in the memory.

    • If coding failed, check that the code is valid.

  6. Confirm with "OK" to exit the function.

  7. Turn off the ignition for 60 seconds to store the new code.

  8. Establish contact with the system. Read out and check any fault codes and the new code.

  9. Exit the function.

    • If the function fails, check the test conditions and repair any faults.
