[1397]Zero compensation of the yaw rate sensor

This basic setting is used to zero-compensate the values from the yaw rate sensor. This must be done if:

  • The ABS control unit has been replaced.

  • The electromechanical parking brake control unit has been replaced.

Note:

During the basic setting, the ignition must not be switched off.

Test prerequisites:

  • The battery voltage should be >12 V.

  • Ignition on, engine off.

Performance:

  1. Choose the basic setting: "Zero compensation of the yaw rate sensor".

  2. When the zero compensation has been performed, "Adaption correct / Adaption not possible" is displayed.

  3. Exit the function and check the yaw rate sensor´s values in the datalist meny.
