SCR system pressure buildup, test
This function is used to check functionality/leak at the pump and hoses.
The pressure should be built up to about 500 kPa.
Test conditions:
  • Parking brake applied.
  • Engine off.
  • Ignition on.
  • Adblue in reservoir.
  • Battery voltage above 20V.
Procedure:
  1. Start the function.
  2. Check conditions.
  3. Select to start or cancel the test.
  4. Check the working pressure while the test is in progress.
  5. The function is done.
    • If the function fails, check the test conditions and repair any faults.
