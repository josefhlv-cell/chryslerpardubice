Calibration of position sensors
This function is used to calibrate the position sensor in the gearbox.
The function must be performed if the control unit is replaced or has been dismounted from the gearbox.
Note:
Before performing the calibration, it is important that the control unit and the lever console are without faults.
Preconditions for the test:
  • Ignition on, engine off.
  • Gearlever in position N.
Procedure:
  1. When the test conditions have been reached, press "OK" to start the adaptation.
