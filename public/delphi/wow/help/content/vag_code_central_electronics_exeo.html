[165]Code central electronics

The control unit must be coded according to the corresponding equipment in order for all functions to work correctly. For example, when retrofitting/removing trailer hitch, you have to code/decode on/off function for trailer for it to work correctly.

Note:

  • Incorrect coding may reduce the car's safety/function.

  • The control unit must be of the correct type to approve the code.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • All power consumers disconnected.

Procedure:

  1. Start the function.

  2. Enter the desired code (see below) in the displayed entry field, confirm with "OK".

    Code number:Function:
    0XXXXSedan
    1XXXXAvant
    X0XXXWithout rain/light sensor
    X1XXXWith rain/light sensor
    XX0XXWithout trailer hitch
    XX1XXWith trailer hitch(removable/folding)
    XXX0XHalogen headlights without automatic low beams
    XXX1XHalogen headlights with automatic low beams
    XXX2XXenon headlights with automatic low beams
    XXXX1Country version (always a one)

    • Coding example: 01101

      Sedan, with rain/light sensor, with trailer hitch, halogen headlights without trave lights

  3. A dialogue box shows if the operation was successful or failed.

    • If coding failed, check that the code is valid.

  4. Finish communication and turn off the ignition for 60 seconds to store the new value.

  5. Re-establish contact with the system, read out and check any trouble codes.

  6. The function is done.
