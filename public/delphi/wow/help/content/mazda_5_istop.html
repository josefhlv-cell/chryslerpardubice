[555]Reset/change values for components in i-Stop system

This function is used when some component in the i-Stop system has been replaced.

Note:

If a completely new component has been replaced, the value 0 shall be stated in the function.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage between 12-15V.

  • All power consumers disconnected.

Procedure:

  1. Start the function.

  2. The current value for the component is shown, if the value is not to be changed the function can be cancelled.

    • If a completely new component has been replaced, the value 0 shall be stated.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
