[88]Enter driving distance to next service

This function is used to enter driving distance to next service, the entry interval is between 0-8388607 km. Before entering the driving distance, check the existing distance to next service.

Test conditions:

  • Check what the current distance is to next service.

Procedure:

  1. Start the function.

  2. Enter the desired driving distance to next service within the interval in the dialogue box, press "OK".

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
