[696]Shift the transfer gearbox

This function is used to test the function of the transfer gearbox.

Note:

  • Ensure that the vehicle cannot roll and apply the parking brake.

Test conditions:

  • Engine idling.

  • Gear in neutral position.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. If the function fails, check the test conditions and repair any faults.
