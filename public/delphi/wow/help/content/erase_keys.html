[834]Erase keys

Conditions:

Pin Code “Immobilizer pin” is required.

- New key delivery documents contains the “Immobilizer pin”.

- No fault codes stored.

- Ignition on.

- If unknown keys are programmed they can be deleted.

- All keys, but the inserted key, will be erased.

- Start “Add key” function, to only program keys that you own.

Description:

- Enter the car specific “PIN CODE”.*

- Press “Erase keys” button.**

- Read “Programmed keys”, in the datalist. Only 1 key left.

- Read faultcodes. Erase faultcodes if necessary.

- Use “Add key” to add more keys to the system.

Note:

* If wrong code is entered too many times, the system will be locked 5 minutes or more. See datalist “Security clock”.

** After erasing, new communication has to be established.

Go to the datalist and wait for the dialog to establish connection.
