[44]Solenoid valves test

This function is used to make sure that the valves works correctly, after work has been done on the hydraulic or electric part of the brake system.

Test conditions:

  • Ignition on.

  • Engine off.

  • Parking brake released.

  • Vehicle raised so that the wheels can rotate freely.

Procedure:

  1. Start the function.

  2. Press down the brake pedal completely and hold it down.

  3. Select the wheel to be tested.

  4. Press "Start" to test the inlet valves.

  5. Repeat from step 2 to test the other wheels.

  6. Press "OK" to access test of outlet valves.

  7. Select if you want to test outlet valves.

  8. Select the wheel to be tested.

  9. Press "Start" to test the outlet valves.

  10. Repeat from step 8 to test the other wheels.

  11. Function done.

    • If the function fails, check the test conditions and repair any faults.
