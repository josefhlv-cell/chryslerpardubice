Replacement of variable geometry turbo and/or turbo position sensor
This function is used to program the variable geometry turbo and/or turbo position sensor after replacement.
Note:
This function is used after any of the following components have been replaced:
  • Turbo position sensor.
  • Variable geometry turbo.
  • Injection control module.
Test conditions:
  • Ignition on, engine off - the engine is started during the procedure.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Start the engine.
  3. Press the "OK" button to start programming.
  4. Turn off the ignition for 40 seconds.
  5. Ignition on, engine off.
  6. The function is done.
  • If the function fails, check the test conditions and repair any faults.
