[1658]Basic setting of climate control unit

Test condition:

  • Battery voltage above 11.5 V.

  • No fault in the system.

  • Ignition on.

Note:

  • Basic setting shall be done when the control unit or any of the actuators have been replaced.

Procedure:

  1. Start the function "AC unit".

  2. Actuators' values are shown. When these two values have reached value 0, basic setting is finished.

  3. Exit the function.
