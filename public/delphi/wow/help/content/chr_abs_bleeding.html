[1678]Bleed brake system

This function must be run after the brake system has been manually bled. Check that the brake fluid level is correct before starting the bleeding procedure.

Bleeding is performed following an automatic procedure involving several steps with requests to the user.

Test conditions:

  • Battery voltage above 11.5 V.

  • Ignition on, engine off.

  • Handbrake applied.

Procedure:

  1. Select the "Bleed brake system" function and press "OK".

  2. Follow the instructions shown in the dialogue boxes.

    • Press "OK" in the dialogue boxes to progress through the bleeding procedure.

    • Press "Stop" to abort the bleeding procedure.
