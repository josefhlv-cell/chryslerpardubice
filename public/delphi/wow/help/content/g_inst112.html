[863] Throttle control unit

Preconditions for the test:

  • Ignition on.

  • No faults stored.

  • Battery voltage above 11.5V.

  • If cruise control is fitted, it must be working properly.

  • All electrical loads switched off.

  • Throttle at idling position.

Note:

  • The basic setting matches (”adapts”) the throttle control unit to the engine control unit.

Adaption must be done when:

  • The throttle control unit has been removed from the vehicle.

  • The throttle control unit has been replaced.

  • If the electric power supply to the engine control unit has been disconnected.

  • If the engine control unit has been replaced.

Procedure:

  • Choose the throttle control unit function.

  • The throttle control unit operates in the min and max positions and several different intermediate positions. The control unit stores the corresponding throttle angle in the permanent memory (this takes about ten seconds). After adaption, the throttle returns to the starting position briefly, then closes.

    When adaption is complete, the relevant columns must show: throttle control unit operating condition 0000100; adaption status 00.

  • Quit the basic setting mode and switch off the ignition. For the basic setting to be stored, the ignition must remain switched off for at least 15 seconds.
