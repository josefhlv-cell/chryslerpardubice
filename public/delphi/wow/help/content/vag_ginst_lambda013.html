[1326]Lambda adaption

Test condition:

  • Engine running

  • No faults stored

  • No leaks in the exhaust system

  • All electrical loads switched off

  • Coolant temperature at least 75 °C

  • Intake air no more than 90 °C

Note:

  • Used to see Lambda stored values.

Procedure:

  • Start the function.

  • Read off additive lambda adaption. Prescribed value -5.4 % to 5.4 %.

  • Read off multiplicative lambda adaption. Prescribed value -10 % to 10 %.

  • If the specifications are not attained, interrogate fault memory.

  • Exit function.
