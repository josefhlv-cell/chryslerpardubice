[1237]Tyre pressure monitoring sensors learning

The tyre pressure monitoring system consists a receiving unit in the car and a sensor mounted in each wheel. The wheel sensors are sending information at regular intervals when the vehicle is driven.

This information is processed in the central control unit (BSI). It is possible to read parameters of each sensor status and tyre pressure in the central control unit data list menu.

This procedure is used for learning new tyre pressure sensors on cars with tyre pressure monitoring.

It is required to perform tyre pressure sensor learning if a sensor is replaced.

Note:

All sensors must be learned again even if only one sensor is replaced.

When sensor learning is performed each sensor must be activated for 8 seconds with a sensor activator on demand according to an automatic procedure.

Observe:

The engine must be shut of and the communication with the system must be aborted before a new attempt is initiated if the sensor learning has failed.

Test prerequisites:

  • Engine idling.

  • Tyre pressure sensor activator available.

Performance:

  1. Choose function: Tyre pressure monitoring sensors learning.

  2. A dialog box presents which sensor to activate.

  3. Activate the sensor for 8 seconds with the sensor activator within 60 seconds.

  4. Confirm with the OK button.

  5. The dialog box: ”Learning of wheel sensors in progress!” is presented until the wheel sensor is learned.

  6. The procedure proceeds according to point 2 and forward until all sensors are learned.

  7. The dialog box: ”Learning of wheel sensors finished” is presented when all sensors are learned.

  8. Confirm with the OK button.

  9. Drive the vehicle above 50 km/h and verify that all the sensors are working by checking the data list parameters.
