[1444]Clear adaption memory.

When replacing the gearbox and/or the control unit, it is necessary to clear the adaption memory to obtain a correct gearbox function.

Test prerequisites:

  • Ignition on, engine off.

  • Gear in neutral position.

  • No faults in the system.

  • All consumers inactive.

Procedure:

  1. Choose the function, press "OK".

  2. The function starts, the adaption values are reset to zero. A dialog box shows: "Operation succeeded" or "Operation failed".

    • If the function fails, check the test prerequisites and adjust possible fault codes.

  3. Exit the function and disconnect the diagnostic tool.

  4. Switch off the ignition for 30 seconds before making any attempt to start.

  5. Drive the vehicle variously to complete the learning of the new adaption values.
