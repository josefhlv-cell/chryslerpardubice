Forced regeneration of particle filter
Regeneration of particle filter is a function that can be started with the diagnostic tool. This function burns particles present in the particle filter in order to clean it. Some driving conditions are unfavourable to automatic regeneration, e.g. urban driving. In these cases can this forced regeneration be used to avoid clogging of the particle filter.
Note:
The exhaust temperature is very high during this procedure. Therefore, perform the regeneration outdoors without connected exhaust hose. The regeneration is noisy, use ear protection. The procedure lasts up to 25 minutes. The procedure shall be performed with warm engine. Engine oil must be replaced after completed function.
Test conditions:
  • Engine idling.
  • handbrake applied.
  • Transmission in neutral.
  • Fuel level above ¼ full.
  • Do not activate the clutch, brake or accelerator pedal during the regeneration.
  • Engine at operating temperature (minimum 75°C).
  • Vehicle stationary.
Procedure:
  1. Start the engine, depress the clutch pedal (if it exists) and release.
  2. Start the function.
  3. A dialogue box is shown, Press "OK".
  4. The engine speed increases automatically to 3000 rpm.
  5. The regeneration lasts for up to 25 minutes.
  6. The engine speed returns to normal.
  7. A dialogue box shows when the function is complete.
  8. Turn off the engine.
  9. The function is done.
If the function fails check the test conditions, remedy any faults and try again.
