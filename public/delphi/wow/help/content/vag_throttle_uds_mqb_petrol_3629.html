Throttle valve adaptation
This function is used to perform a basic setting of the throttle valve. This should be done if:
  • The electric power to the engine control unit has been disconnected.
  • the throttle valve has been removed or replaced.
  • the engine control unit has been replaced.
Preconditions for the test:
  • Ignition on, engine off.
  • coolant temperature between 10 and 95°C.
  • All power consumers disconnected.
  • Battery voltage above 11.5 V.
  • Accelerator pedal fully released.
  • No fault in the system.
Procedure:
  1. Select the function: "Throttle control unit".
  2. The adaptation starts, this is indicated by "Adaptation in progress"
  3. When adaptation is finished, "Adaptation OK" is shown".
  4. Cycle the ignition according to presented instructions.
  5. Check that no trouble codes are stored in the engine control unit.
    • If the adaptation fails, check the test conditions and repair any faults.
