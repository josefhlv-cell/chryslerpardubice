HSR Preparation chassis measurement
This function is used to perform a chassis measurement on the rear axle or a 4-wheel measurement. The function run via diagnosis the rear axle camber control to center position (0 degrees).
Note:
If the rear axle isn't unloaded, there is a high risk of damages on the HSR-actuator!
Running to the center position must only be performed when the rear wheels are on the rotating bearing plates. If this isn't possible, the rear axle must be unloaded, use a vehicle lift.
Test prerequisites:
  • Ignition on.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Function complete.
  3. It is now possible to perform a chassis measurement on the rear axle or a 4-wheel measurement.
