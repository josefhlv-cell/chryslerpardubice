Fuel trim activated
This function is used to activate or deactivate the engine control unit programming of fuel adjustment.
Test prerequisites:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. A data list shows if "Fuel Trim Learn" is activated or deactivated.
  3. Select "Activated" or "Deactivated".
  4. Press "OK" to exit the function.
