[1261]Coding, activation/deactivation cruise control system

When an installation of the cruise control system is performed, it is necessary to activate the cruise control function in the engine control unit. It is also possible to deactivate the function, if the cruise control system is removed.

Note:

  • If "G00HS" is indicated in the data list parameter "Control unit identification code", the cruise control system is acitvated.

  • If "00HS" is indicated in the data list parameter "Control unit identification code", the cruise control system is deactivated.

Test condition:

  • Battery voltage above 11.5 V.

  • Ignition on.

  • No faults in fault memory.

Procedure:

  • Start the function.

  • Enter correct code number (5 digits).

    CodeStatus
    11463Activate the cruise control system.
    16167Deactivate the cruise control system.

  • Press OK.

  • Turn ignition OFF/ON. Check in the data list parameter "Control unit identification code" if the correct coding number is displayed.

  • After activating of the cruise control system, a test drive should be performed.
