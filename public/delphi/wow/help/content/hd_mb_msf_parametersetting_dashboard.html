[566]Parameter setting

This function is used to change parameter setting.

Note:

NOTE! Update the central data memory, ZDS, after changing parameter.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. A dialogue box shows test conditions, check these and press "OK".

  3. A dialogue box shows the current parameter setting, press "OK".

  4. Select the parameter to be changed.

  5. Select parameter setting and press "OK".

  6. Turn off the ignition and wait approx. 5 seconds.

  7. Turn on the ignition.

  8. A dialogue box shows the new parameter setting, press "OK".

  9. Select to change several parameters (skips to step 4) or exit the function.

  10. Function done.
