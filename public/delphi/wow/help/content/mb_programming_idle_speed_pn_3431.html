Idle adjustment
This function is used to adjust the idle speed.
Note:
The limit can be reached earlier than minimum/maximum value, depending on the control unit conditions.
Test conditions:
  • Engine idling.
  • Gear selector set to P/N.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Use +/- buttons to increase/decrease.
  3. Adjust to the desired value or until the limit is reached.
  4. Exit the function with "OK".
