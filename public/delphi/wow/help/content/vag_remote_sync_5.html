[482]Adaptation of the key's remote control

When replacing a defective remote control or increasing number of remote controls, these must be adapted to the control unit. It is also necessary if the code of the remote control and control unit no longer match. This may occur if the transmitter button is pressed when outside the system's operating range.

Note:

  • If you only are going to increase the number of remote controls you do NOT have to adapt the existing ones again, only the new or not yet adapted remote controls.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • All power consumers disconnected.

Procedure:

  1. Start the function.

    A dropdown list with two alternatives is shown:

    1. Erase all remote controls.

      This function erases all previously adapted remote controls. Note! If this is done, then all remote controls must be adapted again, even the existing ones.

    2. Adapting remote controls.

      This function enables adaptation of the remote control to the system. One adapts one remote control at a time, the function must be repeated to adapt several remote controls. Time to adapt each remote control may not exceed 15 seconds.

  2. Select desired alternative in the dropdown list and press OK. Then follow the instructions shown in the function.

  3. After finished adaptation the ignition shall be turned off and a function test shall be performed of all remote controls.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
