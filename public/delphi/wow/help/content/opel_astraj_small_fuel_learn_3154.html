Small injection quantity learning
This function is used to perform injector calibration. Calibration shall be performed after replacing engine control unit and/or injector.
Test conditions:
  • Engine idling.
  • Coolant temperature between 71 - 104°C.
  • Fuel temperature between 41 - 84°C.
  • Inlet air temperature between 11 - 69°C.
  • Fuel pressure between 23 - 32 MPa.
  • Diesel particulate filter ok.
  • Cooling fan off.
  • All power consumers and AC off.
  • Gear in neutral position.
  • Do not press on any pedal during calibration!
  • Learning of fuel pressure regulator done.
  • No fault codes stored except fault code: P268A.
Procedure:
  1. Start the function.
  2. A dialogue box shows status for inlet air temperature, fuel pressure, diesel particulate filter, coolant temperature, fuel temperature and cooling fan.
  3. When test conditions are fulfilled, press "OK" to continue or "Abort" to cancel.
  4. A dialogue box shows status for "Learning small fuel quantity". Press "OK" to start calibrating.
  5. A dialogue box shows learning status. The function finishes automatically when learning is done.
  6. The function is done.
If the calibration failed, check test conditions. NOTE! The temperature must remain within the limit values.
