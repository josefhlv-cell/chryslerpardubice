[1160]ABS/ESP calibration

Förutsättningar:

-Engine off

-Ignition on

Utförande:

-Type the code for which engine you want to configure the ECU for.

Ex. 0D if you wish to configure for a F4R .

-Start command

Possible configurations:

  • F4R = 0D

  • F4Rt = 0E

  • F9Q 754 = 0F

  • G9T = 10

  • F9Q 750 = 0F

  • P9X = 11

  • V4Y = 12

OBS! Use capital letters (A-F) and the figures 0-9.
