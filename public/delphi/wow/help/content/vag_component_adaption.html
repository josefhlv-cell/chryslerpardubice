[1618]Basic setting of components

At basic setting, the component in question is adapted to the engine control unit. During basic setting the component in question will alternate between opening and closing.

Adaptation shall be performed when:

  • The component in question has been removed or replaced.

  • Voltage to the engine control unit has been disconnected.

  • The engine control unit has been replaced.

Test condition:

  • Ignition on, engine off (applies to throttle, EGR-valve, and inlet manifold damper).

  • Engine on (applies to boost pressure control valve).

  • No faults in the system.

  • Battery voltage above 11,5 V.

  • Accelerator pedal not affected.

Procedure:

  1. Select the relevant component and press "OK" to start the basic setting.

  2. The component is shown and the value for it will change during the basic setting.

  3. The basic setting is done when the value for the component becomes a constant value.

  4. Exit the function.

    • If the function fails, check the test conditions and repair any faults.
