Venting
This function vents the hydraulic system.
Note:
Be careful, during this function the trailing axle will be controlled automatically to its end positions.
Make sure that nobody can become trapped between the tires and chassis.
Check the oil level in the reservoir during the whole function and add oil before the level becomes too low.
The oil level will drop, too low level may cause that air in the hydraulic system leads to damages on the hydraulic pump.
Test conditions:
  • Engine running.
  • Engine speed over 800 rpm.
  • Oil in the hydraulic reservoir.
  • handbrake applied.
  • Trailing axle lifted up.
Procedure:
  1. Start the engine and increase the engine speed to over 800 rpm.
  2. Start the function.
  3. Venting of the system is started, check the oil level! This can take up to 265 seconds.
  4. Result is shown.
  5. The function is done.
  • If the function gets a fault code, check the test conditions and rectify the fault code.
