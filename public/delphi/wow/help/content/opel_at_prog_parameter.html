[548]Programming gearbox parameters

After replacing the transmission, the clutch module or the clutch module with MTA-controller the gearbox parameters must be programmed.

Note:

The vehicle must be lifted so that the wheels can rotate freely.

After completed function check and erase any trouble codes.

Test prerequisites:

  • Ignition on, engine off.

  • Transmission in neutral.

Procedure:

  1. Start the function and follow the instructions in the program.

Exhortations that will come up during the programming:

  • Lift the vehicle so the wheels rotate freely.

  • Start the engine.

  • Press down brake pedal and hold.

  • Apply handbrake.
