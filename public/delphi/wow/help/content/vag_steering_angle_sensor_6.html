[132]Basic setting of steering angle sensor

This function resets the adaptation values for the power steering as well as initiates and adapts the steering angle sensor for the power steering. Before basic setting is carried out on the steering angle sensor, the power steering adaptation values must be cleared. This is done using the "Power steering" function.

This should be done if:

  • the steering servo has been replaced or refitted following repairs.

  • repairs have been carried out on the steering gear.

  • the front axle chassis geometry has been adjusted.

  • a trouble code that requires basic setting is stored in the power steering control unit.

    If the power steering control unit has been replaced, it must be correctly adapted.

Note:

The ignition must not be switched off during basic setting.

Test conditions:

  • Engine on.

  • access to a stretch of road that fulfils the conditions set out below.

  • Adaptation values for power steering erased.

Procedure:

  1. Turn the steering wheel approx. 90° to the left and right.

  2. test drive on a level surface at a maximum speed of 30 km/h and check that the steering wheel is in the correct position when driving in a straight line.

  3. stop the vehicle while driving in a straight line and ensure that the steering wheel has not turned.

  4. Select the function: "Power steering", press "OK".

  5. Once this function is complete, select the "Initiation of steering angle sensor", press "OK".

  6. A dialogue box shows: "steering angle sensor calibrated” confirms that initiation has been performed correctly. Depending on the car's equipment, the control lights for power steering, ESP, and tire pressure monitoring are turned on.

  7. Complete the function and disconnect the diagnostic tool.

  8. Drive a short distance straight ahead at approx. 15-20 km/h to initiate the steering angle sensor. The control lights turn off.

  9. Connect the diagnostic tool again. Check that no fault codes are stored in the control unit.

  10. The function is done.

    • If the function fails, check that the steering wheel is in the centre position and that the components are correctly fitted.
