Initialise convertible top
This function is used to initialise the convertible top's angle sensors for convertible top extension and the main pillar. The service function must be run if the following components are to be exchanged:
  • Convertible top.
  • Cabrio convertible top module CVM.
  • Main pillar angle sensor and/or convertible top extension angle sensor.
Test conditions:
  • The convertible top must be in the "closed and locked" end position.
  • No fault codes should be stored in the fault memory.
  • Ignition on.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. The function is done.
