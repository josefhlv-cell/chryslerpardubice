Zero point calibration of yaw rate sensor and deceleration sensor
This function is performed after replacing the ECU, yaw rate sensor or after performing front wheel alignment.
Note:
The car must be completely standstill and horizontal (The tilt must be less than 1°). The car must not be tilted, moved or shaken (do not start the engine). Cars with automatic gearbox must be in position "N". Cars with manual gearbox should have the gear selector in neutral position.
Test prerequisite:
  • No error codes in the system.
  • Battery voltage above 12V.
  • Engine off, ignition on.
  • Position the car on a flat and level surface.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Check that the anti-slip indicator flashes rapidly, the function was performed correct. If the indicator doesn't flash, the function has not been performed correctly. See test conditions and repeat the function.
