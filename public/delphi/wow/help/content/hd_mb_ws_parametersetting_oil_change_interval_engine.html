[531]Parameter setting

This function is used to change parameter setting.

If parameter is set to "YES" this corresponds to code MY8.

For engine model series OM501 with an extended oil change interval of 150,000 km, a bigger oil sump and an oil centrifuge must be installed.

For engine model series OM502 with an extended oil change interval of 150,000 km, an oil centrifuge must be installed.

NOTE! Update the central data memory, ZDS, after changing parameter.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. A dialogue box shows test conditions, check these and press "OK".

  3. Select parameter setting and press "OK".

  4. A new dialogue box shows new parameter setting. Press "OK".

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
