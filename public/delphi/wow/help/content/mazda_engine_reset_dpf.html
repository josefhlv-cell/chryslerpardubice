[1783]Reset the adaptation values for particle filter

This function is used to reset the adaptation memory for the particle filter in the engine control unit.

Test conditions:

  • Ignition on.

Procedure:

  1. Select the function: "Resetting diesel particle filter data", press "OK".

  2. Follow the instructions.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
