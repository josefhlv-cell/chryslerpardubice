[173]Basic setting of differential pressure sensor

This function is used for adapting the differential pressure sensor in the particle filter. This must be done if:

  • The differential pressure sensor has been replaced.

  • Repair of the differential pressure sensor has been performed.

  • The particle filter has been replaced.

  • The engine control unit has been replaced.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Confirm with "OK". A dialogue box with present values is shown. Confirm with "OK".

  3. Follow instructions (turn off ignition, turn on ignition) shown on the screen during the adaptation sequence.

  4. When adaptation is finished, a dialogue box is shown with new values. Confirm with "OK".

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
