Reset adaptation values for transmission
This function is used to erase the learned memory in the transmission ECU.
Note:
After resetting the memory, always perform calibration of the deceleration sensor (deceleration sensor's zero point) first, and then calibration of the continuously variable transmission oil pressure.
Test conditions:
  • Ignition on, engine off.
  • No faults stored.
  • Handbrake applied.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Turn off the ignition for 5 sec., and turn it on again.
  3. Drive the vehicle in a stop/start pattern for approx. 15 min.
