[1657]Coding control unit for parking assistance

When installing a new control unit or modified equipment in the car, the control unit for parking assistance must be coded for existing equipment.

Note:

  • New control unit may have code number 0 stored.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

  • No error codes in the system.

Procedure:

  1. Select the function: "Code control unit".

  2. A dialogue box shows existing code and "Change value". Confirm with "Yes" to change code number.

    • If the code is correct the function may be cancelled.

  3. Enter the desired code (see below) in the displayed entry field, confirm with "OK".

    Code number:Function:
    0 X X X X X XAlways
    X 0 X X X X XWithout optic feedback on display
    X 2 X X X X XWith optic feedback on display
    X X 0 X X X XWithout trailer hitch and back-up camera
    X X 1 X X X XWith trailer hitch, without back-up camera
    X X 2 X X X XWithout trailer hitch, with back-up camera
    X X 3 X X X XWith trailer hitch and back-up camera
    X X X 0 X X XManual transmission
    X X X 1 X X XAutomatic transmission
    X X X X 0 X XEuropean countries
    X X X X 1 X XS-variant European countries
    X X X X 2 X XUSA
    X X X X 3 X XS-variant USA
    X X X X 4 X XAllroad, European countries
    X X X X 5 X XAllroad. USA
    X X X X X 0 XSedan
    X X X X X 1 XAvant
    X X X X X X 66 = A6

    Coding example:

    A6 with optic feedback on the display, with trailer hitch, without back-up camera, automatic transmission, European countries, Avant =0211016

  4. A dialogue box shows: "Code stored" (with the new value) in the memory.

  5. Press "OK" to exit the function.
