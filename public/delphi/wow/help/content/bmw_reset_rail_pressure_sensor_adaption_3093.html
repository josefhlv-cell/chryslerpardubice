Reset adaptation data rail pressure sensor
For better rail pressure control, the rail pressure sensor's characteristics curve is adapted.
Note:
The service function "Reset adaptation data rail pressure sensor" must be run if one of the following components has been replaced:
  • Rail pressure control valve
  • Rail pressure sensor
  • Quantity control valve
  • High-pressure pump
  • One or more injectors
When the service function is run, the adaptation value is erased. After installing a new component the new value is learned again (teach-in), with the engine running, and saved in DDE (engine control unit).
Test conditions:
  • Ignition on.
Procedure:
  1. Start the function and follow the instructions in the program.
