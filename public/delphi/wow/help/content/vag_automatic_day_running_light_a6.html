[706]Automatic day running lights

This guide helps you to activate/deactivate the function for day running lights via the vehicle's MMI, which is controlled by the button on the central console.

Note:

If the function is active, the running lights are automatically turned on when the ignition is turned on.

Test conditions:

  • Ignition on.

Procedure:

  1. Press the "CAR" function button.

  2. Use the MMI control button and follow the instructions below, which are found in the MMI menu:

  3. Select "System settings".

  4. Select "External lights".

  5. Select "Running lights".

  6. Select "On/Off" as required.

  7. The function is complete.
