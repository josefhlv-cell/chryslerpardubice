[159]Calibrate the master cylinder's pressure sensor

This function is used to calibrate the master cylinder's pressure sensor when "ASC" control module has been replaced. Before calibrating, check that fault code C123A is not stored and repair any faults. Always perform calibration without affecting the brake pedal.

Test conditions:

  • Ignition on.

  • The vehicle must stand on level ground.

  • No faults in the system.

  • Brake pedal unaffected.

Procedure:

  1. Start the function.

  2. Follow instructions.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
