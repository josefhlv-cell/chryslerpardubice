[471]SCR exhaust aftertreatment system, operation start

This function enables activation of the exhaust aftertreatment system using parameter adaptation.

No activation of components takes place in this function.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. A dialogue box shows test conditions, check these and press "OK".

  3. A dialogue box shows "Do you want to activate the SCR exhaust aftertreatment system now?". Press "Yes" if you want to activate the system or press "No" if you want to cancel the function.

  4. If you pressed "Yes", follow the instructions.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
