[1759]Lambda control

This function is used for troubleshooting by connecting and disconnecting the lambda control.

Test conditions:

  • Engine idling.

  • No faults in the system.

  • Engine temperature above 85 °C.

  • No leaks in exhaust system.

  • Gear in position P/N.

Procedure:

  1. Select the function: "Lambda control", press "OK".

  2. Switch between lambda control connected or disconnected ("Active" or "Inactive " in the field ”Lambda control status”) using the buttons in the function.

  3. When finishing, the lambda control is activated automatically.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
