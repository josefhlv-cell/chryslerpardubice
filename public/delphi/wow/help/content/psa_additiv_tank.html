[1436]Additive tank capacity

Use this function to specify the additive tank capacity when the additive control unit is replaced.

Test prerequisites:

  • Ignition on, engine off.

  • Tank / control unit connected and installed correctly.

  • No faults stored.

  • All electrical loads should be switched off.

  • Battery voltage above 12 Volts.

Procedure:

  • Enter the desired value in the input field, confirm with "OK".

  • A dialogue box confirms: Operation succeeded / Operation failed.

    Additive tank capacityValue to enter

    1,7 l70
    1,8 l80
    1,9 l90
    2,0 l100

    2,2 l120
