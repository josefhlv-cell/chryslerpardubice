[1101]Program Idle Speed

With this function it is possible to program the idle speed within the interval 730 to 900 rpm, with steps of 10 rpm.

Test prerequisites:

  • Engine on.

  • The engine must have reached normal temperature (Coolant Temperature >80°C).

Procedure:

  1. Choose: "Program idle speed".

  2. The programmed idle speed is displayed.

  3. Press "Yes" if you want to change or "No" if you want to cancel.

  4. Write the desired rpm according to the interval and press "OK " to change or "Cancel" to exit.
