[1674]Configure control unit

This function is used when the control unit is replaced, to read out the configuration from the defective control unit and programme the new one.

To enable programming to take place, the data must be read out from the defective control unit before it is removed.

Note:

Aborting the function will result in the loss of previously gathered data.

Test conditions:

  • Ignition on, engine off.

  • Defective control unit fitted.

  • Access to the vehicle's handbook.

Procedure:

  1. Select the "Programme ECU" function.

  2. A dialogue box shows: "Read out data from the defective control unit" and press "OK" to start readout.

  3. When the readout is complete a message appears requesting removal of the defective control unit and fitting of the new one.

  4. Once the new control unit has been fitted, press "OK" to start programming. NB! Aborting the function will result in the loss of previously gathered data.

  5. Enter the date and time in accordance with the vehicle handbook.

  6. The function is complete.
