[1440]Bleeding the brake system

This basic setting is used when bleeding antilock brake systems (ABS). This is only needed when at least one of the chambers in the brake fluid reservoir has been emptied, or when changing the brake fluid.

Note:

A manual brake bleeding should be performed before starting this function. The bleeding should be done in a sequence of several steps by the user. Wait at least 5 minutes before bleeding the same wheel again.

Test prerequisites:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

  • Correct brakefluid level.

  • Brake fluid container should be pressurized with a minimum of 2 bar.

Procedure:

The recommended sequence when bleeding the brake system is as follows:

  • Left rear wheel.

  • Left front wheel.

  • Right front wheel.

  • Right rear wheel.

  1. Open the bleed screw at the brake system that will be bleeded.

  2. Start the function, press OK.

  3. Pump with the brake pedal until a dialog box presents: Operation succeded/failed. The bleeding will take between 25 and 120 seconds.

  4. Proceed to pump until the brake fluid is clean and without bubbles.

  5. Close the bleed screw.

  6. Continue the procedure from point 1-5 for the next wheel.

  7. After ended bleeding procedures, check fault codes. If there are any fault these shall be fixed and the bleeding procedure should be done again.
