[1539]Minor programming for control unit GS 1 gear control.

The minor programming has to be carried out if the transmission (same transmission type) or one of the position sensors for clutch, splitter, range, gear or gate has been replaced.

The programming process must be carried out if the clutch has been replaced or if work has been done on the clutch, clutch actuator, clutch booster or clutch travel sensor.

Note:

On vehicles with EAS, the programming is done automatically by the automatic shift.

At a minor programming the position values of the position sensors are calculated for clutch, splitter, range, gear and gate.

During the programming it is essential that the instructions to fully depress and fully release the clutch pedal are followed, in order to avoid damaging the transmission due to incorrect learned data of the clutch.

Splitter arrows will flash alternatly during the entire programming.

The neutral pushbutton is located on the passenger side of the gear lever.

If the programming is interrupted by a fault, a fault code is presented on the display. For explanation of the fault code see the list below.

Test prerequisities:

  • Ignition on, engine off.

  • No consumers active.

Procedure:

  1. Ignition off.

  2. Parking brake applied.

  3. Depress the clutch pedal fully and hold.

  4. Press the neutral pushbutton and hold it during the entire programming.

  5. Switch on ignition.

  6. Release the clutch pedal fully when the buzzer sounds for the 1:st time.

  7. Depress the clutch pedal fully and hold when the buzzer sounds for the 2:nd time

  8. If the readout N (Neutral) appears on the display, the programming has been successfully completed.

    If the programming failed: Redo the programming, adjust possible faults in control unit GS 1.

Fault codes of control unit GS 1 on the display of the instrument (faults at learning and manoeuvring).

GS 01 The operating button of the emergency shift is not in basic position.

GS 02 The emergency shift is active.

GS 09 Programming error: Neutral position.

GS 10 Programming error: Programmed values for splitter are faulty.

GS 11 Programming error: Programmed values for gear are faulty.

GS 12 Programming error: Programmed values for gear are faulty.

GS 13 Programming error: Programmed values for gate are faulty.

GS 16 Programming error: Programmed values for gate are faulty.

GS 17 Programming error: Programmed values for range are faulty.

GS 18 Fault at a solenoid valve or position sensor.

GS 19 Programming error: The vehicle is rolling.

GS 20 Programming error: Under-voltage.

GS 21 Programming error: Clutch operation.

GS 22 Programming error: The neutral selection is interrupted.

GS 23 Programming error: The transmission type is invalid.

GS 24 Programming error: The parking brake is not applied.

GS 25 Programming error: The emergency shift is operated.

GS 26 Programming error: Engine running.

GS 27 Programming error: No engine torque or invalid torque.

GS 28 Programming error: The engine is not started

GS 29 Programming error: No engine speed.

GS 30 Learning error: Idle throttle.

GS 31 Programming error: Clutch clearance.

GS 32 Programming error: Counter shaft speed.
