Heater function test
This function is used to run a function test of the heater unit after repair. During the test-drive, the heater's operating mode changes depending on coolant temperature between start, full load, partial load, after-circulation, and control pause.
Note:
  • The heater unit may not be activated in closed rooms without exhaust extraction fans.
  • The heater unit may not be activated in rooms where there is risk of fire and explosion.
Test conditions:
  • Engine idling.
  • No faults stored.
  • Heater unit disconnected at start of the function.
  • Passenger compartment fan at highest speed and temperature at max.
Procedure:
  1. Start the function and follow the instructions in the program.
    • If the function is cancelled by the user, the heater unit will go to after-circulation before it turns off completely.
