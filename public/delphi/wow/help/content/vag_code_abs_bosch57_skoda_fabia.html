[1260]Coding ABS control unit Bosch 5.7 Skoda Fabia

Coding:

  • The ABS control unit must be recoded if the vehicle relevant coding is not displayed in the system basic data or the control unit has been renewed.

Note:

  • Only valid for cars with ABS. Not valid for cars with ASR or ESP.

To perform coding:

  • Read from the table below which code is valid for the car.

  • Write the current code in the ABS coding field.

  • Click on the OK-button.

  • A dialogue box confirms: Operation suceeded/Operation failed.

  • Read the control unit basic data to check that the new code is programmed.

  • Check that no fault codes are stored.
