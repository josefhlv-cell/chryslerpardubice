[677]Replace electric pump

The function resets certain parameters in the controller that relate to the component being replaced.

The function must be performed if the electric pump is replaced.

Note:

Perform the following functions in the following order!

  • Replace electric pump:

    1. Accumulator depressurisation.

  • After replacement of the electric pump:

    1. Replace electric pump.

    2. Bleeding clutch.

Test conditions:

  • Ignition on.

  • Stop&Start function disabled.

Procedure:

  1. Start the function and follow the instructions in the program.
