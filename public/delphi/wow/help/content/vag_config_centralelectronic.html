[58]Configuring central electronics

When configuring different functions in the control unit for central electronics you are referred to adaptation channels in the control module. Each channel corresponds to a function. By changing value in the desired channel you affects its properties.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

  • All power consumers disconnected.

Procedure:

  1. Select the function "Configuring central electronics".

  2. Enter desired channel (acc. to list below) in the shown entry field, confirm with "OK".

    • If invalid channel is entered the function is cancelled.

  3. Now the present channel value can be read out.

    • If the channel value is not to be changed you can cancel the function with "No".

  4. Press "Yes". Enter new channel value, confirm with "OK".

  5. If the shown channel value matches, press "YES" to save.

    • If the channel value is not to be saved you can change the value with no (from step 3).

  6. If the value is stored, this dialogue is shown: "Saved in memory".

  7. Confirm with "OK" to exit the function.

    Function for each channel:

    • Channel 1: Coming Home light, setting between 1 to 60 seconds (accuracy 1 second)

      Standard value = 30

    • Channel 2: Dimmer brake/tail lights, setting between 13 to 40.

      Standard value = 30

    • Channel 3: Dimmer tail lights, setting between 13 to 40.

      Standard value = 32

    • Channel 4: Dimmer rear fog light, setting between 13 to 40.

      Standard value = 28

    • Channel 5: Dimmer daytime running lights, low beams (halogen), setting between 51 to 100.

      Standard value = 92

    • Channel 6: Dimmer daytime running lights, low beams (Bixenon), setting between 51 to 100.

      Standard value = 70

    • Channel 7: Dimmer daytime running lights fog lights (Only for Canada with halogen), setting between 51 to 100.

      Standard value = 92

    • Channel 8: Shut-off daytime running lights, setting 1 (daytime running lights activated) or 0 (daytime running lights deactivated).

      Standard value = 1

    • Channel 9: Shut-off delay low beams with light switch in AUTO mode, setting between 0 to 64.

      Standard value = 51 (4 seconds)

    • Channel 10: Low beam behaviour, setting 0 (parking lights turn off with clamp S off) or 1 (parking lights remain on with clamp 15 off).

      Standard value = 0

    • Channel 11: Low beam behaviour with clamp 15 off, setting 0 (no parking lights), 1 (alarm with door open) or 2 (parking lights off with door open).

      Standard value = 1

    • Channel 12: Highway direction indicators, setting 0 (not active) or 1 (active).

      Standard value = 1

    • Channel 13: Wiper settings, see table below:

      V-downshifting = value 1 (bit 1)

      Short-circuit monitoring to plus = value 2 (bit 2)

      Rain sensor on = value 4 (bit 3)

      Long after-wiping = value 8 (bit 4)

      Speed-dependent interval = value 16 (bit 5)

      Headlight cleaner activated = value 32 (bit 6)

      Rear window wiper available = value 64 (bit 7)

      If the setting is to be changed, the value for the desired function shall be added to / subtracted from the value that was read off.

      Standard value = 114

    • Channel 14: Shut-off parking lights for USA/Canada, setting 0 (not active) or 1 (active).

      Standard value = 1

    • Channel 21: Rain and light sensor, setting value light sensor.

      Standard value = 59

    • Channel 22: Rain and light sensor, setting value windshield's permeability.

      Standard value = 45
