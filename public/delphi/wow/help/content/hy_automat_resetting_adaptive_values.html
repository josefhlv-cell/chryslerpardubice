[1688]Reset automatic gearbox adaptation values

This function resets the adaptation values for the automatic gearbox. These must be reset after either the automatic gearbox or its control unit (TCM) has been replaced.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • Gear selector lever in position P.

Procedure:

  1. Start the function.

  2. Press "OK" to reset the adaptation values.

  3. The function is complete.
