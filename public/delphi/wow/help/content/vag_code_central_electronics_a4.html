[1462]Coding central electronics

To make all functions work correctly, the control unit must be coded according to the corresponding equipment. For example when an aftermarket installation or a removal of a towbar has been performed, it is necessary to code/decode the on/off function, to make the trailer function work correctly.

Note:

  • A faulty coding can reduce the car´s safety/performance.

  • The control unit must be of a correct version to accept the code.

Test prerequisites:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • Electrical consumers switched off.

Procedure:

  1. Choose the function: "Coding central electronics control unit".

  2. The actual code in the control unit is presented. "Change value is presented". Confirm with YES.

  3. Enter the new code (see below) in the presented input field, confirm with OK.

    Code number:Function:
    0 X X X XLimousine
    1 X X X XAvant
    2 X X X XCabriolet
    X 0 X X XWithout rain/light sensor
    X 1 X X XWith rain/light sensor
    X X 0 X XWithout towbar
    X X 1 X XWith towbar (detachable/retractable)
    X X X 0 XHalogen light without automatic controlled dipped lights
    X X X 1 XHalogen light with automatic controlled dipped lights
    X X X 2 XXenon light without automatic controlled dipped lights
    X X X 3 XXenon light with automatic controlled dipped lights
    X X X 4 XXenon light with automatic controlled dipped lights/rear light/number plate light
    X X X X 1Rest of the world/Nordic countries/Denmark/Croatia/Baltic States with Xenon light
    X X X X 2Nordic countries/Denmark/Croatia/Baltic States without Xenon light
    X X X X 3USA/Canada with Xenon light
    X X X X 4Canada without Xenon light
    X X X X 5Special cars
    Coding example:

    Audi A4 Avant without rain/light sensor, with towbar, Xenon light with automatic controlled dipped lights, rest of the world/Nordic countries/Denmark/Croatia/Baltic Stateswith Xenon light= 10131

  4. A dialog box will confirm: code stored (with the new value) in memory.

    • If the coding operation fails, check if the code is valid.

  5. Confirm with OK to exit the function.

  6. Switch off the ignition for 60 seconds to store the new code.

  7. Re-establish contact with the system. Read and check the fault codes and the new code.

  8. Exit the function.
