[121]Programming of gear positions

This function is used to program the different gear positions for the gear module.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • Parking brake and service brake applied during the whole process.

Procedure:

  1. Start the function.

  2. The gear module programs gear positions.

    • A warning signal and warning text may be active during the process.

  3. When programming is finished, a dialogue box will be shown where you are instructed to turn the ignition off and on to finish the function.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
