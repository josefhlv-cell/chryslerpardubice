Crankshaft variation learning
This function is used to activate the algorithm, for the crankshaft variation learning, which calculates the correction factors reference pulse for misfire diagnostics.
Test conditions:
  • Engine idling.
  • Gear selector set to P/N.
  • Parking brake applied.
  • Lock the drive wheels.
  • Engine temperature above 70°C.
  • Air conditioning off.
  • Vehicle stationary.
  • Brake pedal pressed down.
Procedure:
  1. Start the function.
    • If the function fails, check the test conditions and repair any faults.
