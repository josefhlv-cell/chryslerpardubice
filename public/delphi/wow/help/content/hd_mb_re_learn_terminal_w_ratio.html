[134]Basic setting of terminal W ratio

This function measures the speed relationship between alternator and crankshaft which is used to learn terminal W ratio again.

Test conditions:

  • Ignition on, engine off.

  • Parking brake applied.

  • Gear selector in position N.

  • Battery voltage above 20V.

Procedure:

  1. Start the function.

  2. A dialogue shows the test conditions, check these.

  3. A dialogue with "Start engine" is shown. Start engine and press "OK".

  4. A dialogue box shows "Turn off ignition". Turn off ignition, press "OK".

  5. A dialogue box shows "Turn on ignition". Turn on the ignition, press "OK".

  6. A dialogue shows "Function done". Press "OK".

  7. The function is done.

    • If the function fails, check the test conditions and repair any faults.
