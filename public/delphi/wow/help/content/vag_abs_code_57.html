[1245]Coding ABS control unit Bosch 5.7 with ESP Audi A6 -98->

When replacing the ABS control unit it is necessary to variant code it correct. The variant code can be read from the old control unit as a datalist parameter "Controller, variant coding". Valid variant code can also be found in workshop manual or similar.

Note:

  • When the control unit is coded a valid login code first must be entered. Only valid for cars with ESP.

  • A faulty variant coding can reduce the car safety and/or performance.

  • A workshop manual or the variant code from old control unit must be available.

  • The control unit version must be correct to accept variant coding.

Test prerequisites:

  • A valid login for control unit.

  • A valid variant code for control unit.

  • The battery voltage should be above 12V

  • Ignition on, engine off.

  • All the electrical loads should be switched off.

Procedure:

  1. Read from the table below which login code is valid for the car.

  2. Write the current code in the Login field.

  3. Click on the OK-button.

  4. A dialogue box confirms: Operation succeeded / Operation failed.

  5. Write the current code in the ABS coding field.

  6. Click on the OK-button.

  7. A dialogue box confirms: Operation succeeded / Operation failed.

  8. Turn the ignition "Off" and wait 60 seconds. Turn the ignition "On". Re-establish contact with system and check variant coding.
