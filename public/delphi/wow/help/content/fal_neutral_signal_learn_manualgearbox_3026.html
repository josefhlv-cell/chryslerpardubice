Calibrate neutral signal
This function is used to learn the gearbox its neutral position (only models with manual gearbox). Errors in the execution of this procedure will affect the operation of the Start & Stop system.
The function must be run if any of the following is done.
  • Work on the transmission.
  • Neutral position sensor is replaced.
  • Transmission control module is replaced.
  • Engine control module is replaced.
Test conditions:
  • Engine idling.
  • Transmission in neutral.
  • Clutch pedal unaffected during the function unless the test procedure requires otherwise.
  • No fault status (engine rpm, vehicle speed, and clutch sensor).
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. The function is done.
    • If the function fails, check the test conditions and repair any faults.
