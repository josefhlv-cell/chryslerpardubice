[859] Readiness test

When repairs have been done on an exhaust-related system, eg the secondary air system, a reading of the readiness test is recommended. The purpose of this is to guarantee that the systems are working properly. The readiness test consists of an eight-digit code which shows the status of an exhaust-related self-test. The diagnosis is performed at regular intervals while driving. When diagnosis for a system has been correctly done, the corresponding position in the block shows a zero. The code for the readiness test is deleted when the fault code memory is cleared. The readiness test can be found under data list 28.

In order that all exhaust-related systems in the readiness test are completed, the basic adjustments below should be done in the order shown:

  • Throttle control unit

  • Secondary air system

  • Tank ventilation system

  • Lambda regulation, probe before catalytic converter

  • Lambda regulation, catalytic converter efficiency
