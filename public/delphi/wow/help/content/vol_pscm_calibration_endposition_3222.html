If the steering angle limit is changed, the washer/spacer in the steering gear must also be changed! For information about part numbers, contact your local Volvo dealer.
Preconditions for the test:
  • Engine running.
Procedure:
  1. Determine steering angle limit using the list.
  2. Make sure that correct washer/spacer is used.
  3. Engine running.
  4. Select desired steering angle limit value and start the calibration.
  5. After completed calibration! Test the steering system by turning the steering wheel to full lock in both directions. The software-based steering angle limit makes the steering wheel harder to turn just before the mechanical steering angle stop prevents steering in each direction.
