[1743]Key programming

This function erases all keys and programs the key that is inserted in the ignition.

PIN-code (Immobilizer pin) is required. Supplied with new key, see figure 1.

Figure 2 shows control unit "Immo2".

Test conditions:

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Select the function, press "OK".

  2. Number of programmed keys is shown, press "OK".

  3. Number of programmed keys is shown after erasing and programming, press "OK".

    If several keys are to be programmed, select function: "Program key".

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
