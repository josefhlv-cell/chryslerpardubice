[1635]Basic setting of variable intake pipe

This function adapts the potentiometer for the variable intake pipe to the engine control unit.

The adaptation shall be done when:

  • Intake pipe after damper has been removed or has been replaced.

  • The power supply to the engine control unit has been cut.

Test conditions:

  • No faults in the system.

  • Engine idling.

  • Brake pedal and throttle pedal shall be pressed down according to instructions.

Procedure:

  1. Select the function: "Potentiometer for intake manifold damper".

  2. Follow the instructions shown in the field "control condition".

  3. When the adaptation is done, "Test finished, system OK" is shown in the field "control condition" and "test finished" in the field "status for the basic setting".

    • If the adaptation fails, the cause is shown in the field "control conditions".

  4. Exit the function by pressing "OK".

  5. Check that no trouble codes are stored in the engine control unit.

  6. The function is done.
