[1487]Clear mixture adaption

This is a function to restore all the preprogrammed adaption values in the control unit.

Note,clear mixture adaption should be done:

  • After replacing new fuel or ignition components.

  • If the vehicle has an incorrect fuel consumption.

Test prerequisites:

  • No faults in the system.

  • Ignition on, engine off.

Procedure:

  1. Press OK to start the function.
