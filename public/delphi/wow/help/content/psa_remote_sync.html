[731]Synchronising remote controls

This function is used to synchronise remote controls.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

Procedure:

  1. Start the function.

  2. Turn off the ignition. Wait 1 min. without pressing any of the remote control's buttons.

  3. Turn on the ignition. Within 10 sec. press and hold the lock button on the remote control for 5 seconds.

  4. Turn off the ignition and remove the key.

  5. Do you want to synchronise another remote control? If "Yes", you restart the function until all remote controls are synchronised.

  6. When all of the remote controls have been synchronised, wait 30 seconds to conclude the synchronisation.

  7. Function complete.
