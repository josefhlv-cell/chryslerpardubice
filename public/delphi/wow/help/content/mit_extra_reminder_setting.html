[227]Extra reminder service

This function is used to add an extra reminder for service if this is desired.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Display of current service driving distance and months.

  3. Select distance or month to adjust in the dropdown menu.

  4. Enter a new value in km or months.

  5. The new entered value is shown.

  6. If you want to perform more updates, press "Yes" and go to step 3. To finish, press "No".

  7. The function is done.

    • If the function fails, check the test conditions and repair any faults.
