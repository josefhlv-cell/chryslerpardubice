[1351]Park assistance, coding control unit

Test condition:

  • Battery voltage above 11.5 V.

  • Ignition on.

Note:

  • Use when change of configuration is desired.

Procedure:

  • Read, repair and erase eventual fault code.

  • Start the function.

  • Enter correct code number (5 digits).

    Example: Code 00103, Without towbar, Manual clutch, With manual activation, Octavia, Skoda

  • Press OK.

  • Coding performed, read datalist to control the coding number after ignition off/on.

    Code table:     
    0    Alhambra
    0    Without towbar
    1    With towbar
     0   Manual gearbox
     1   Automatic gearbox
      0  Without manual activation
      1  With manual activation
       0 Octavia
       1 Fabia, Alhambra
       2 Fabia Sedan, Combi
        3Skoda
        7Alhambra
