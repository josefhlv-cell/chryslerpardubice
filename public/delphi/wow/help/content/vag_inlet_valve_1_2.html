[370]Basic setting of variable intake pipe

This function is used to adapt the intake pipe valve for bank 1 and 2 for to the engine control unit.

Adaptation should be performed when:

  • Intake pipe valve for bank 1 or 2 has been removed or replaced.

  • Voltage to the engine control unit has been disconnected.

Test condition:

  • Engine on.

  • No fault codes stored.

Procedure:

  1. Start the function.

  2. During adaptation, "Adaptation in progress" is shown in the field diagnostic status.

  3. When adaptation is finished, "Adaptation OK" is shown.

  4. Exit communication with the vehicle.

  5. Turn on the ignition for 50 seconds to store the new code.

    • If the function fails, check the test conditions and repair any faults.
