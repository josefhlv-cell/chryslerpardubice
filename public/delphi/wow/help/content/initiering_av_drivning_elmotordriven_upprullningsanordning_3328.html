Initialization of driving
This function is used to initiate the driving for the motor-driven retractor. A counter in the control unit will then be reset.
Note:
This function may only be performed if the motor-driven retractor is replaced, and the vehicle is equipped with comfort seat (equipment code: SA456).
Test prerequisites:
  • The components are replaced.
  • Ignition on, engine off.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Function complete.
  3. Check and clear fault codes that may occur.
