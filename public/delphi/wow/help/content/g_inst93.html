[1053]Idling control

Test condition:

  • Engine idling.

  • No faults stored.

  • No leaks in the exhaust system.

  • Engine temperature above 90 °C.

  • Throttle at idling position.

  • All electrical loads switched off.

  • Automatic gearbox set to ”P/N”.

  • Pressure gauge not connected.

Note:

  • Used to check idling speed.

  • The idling speed cannot be adjusted.

Procedure:

  • Choose the idling check function.

  • Rev up the engine and let it idle for two minutes.

  • Compare the actual speed signal (actual value) with the specified speed signal (target value). Required values: engine speed signal (actual value) = (target value) ±50 rpm; idling regulator air mass -1 till 1 g/s; status 0000.
