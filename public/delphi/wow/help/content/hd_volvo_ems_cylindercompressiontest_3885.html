Cylinder compression
The test shows if there is any deviation in the compression pressure for any cylinder in relation to the other cylinders.
The engine should be warm for the test result to become correct.
Note:
After the test is finished the start key must be turned to position 0 and back to driving position to enable repeat of the test or to enable engine start.
Test conditions:
  • handbrake applied.
  • Engine off.
  • Ignition on.
  • Battery voltage above 20V.
  • Coolant temperature above 65 °C.
Procedure:
  1. Start the function.
  2. Check test conditions and press "OK".
  3. Press "OK" and turn the key to start position.
  4. Hold the key in start position until the status bar is filled, approx. 20 seconds.
  5. Result is shown.
  6. Check the result and press "OK".
  7. Function done.
    • If the function fails, check the test conditions and try again.
