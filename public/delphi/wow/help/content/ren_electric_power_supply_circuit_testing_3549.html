Electric power supply circuit testing
This function is used to perform a self test procedure for fuses and relays in the UPC.
Note:
Depending on whether the test finds any faults, the following components could be activated:
  • Windshield wiper.
  • Starter motor.
  • Cooling fan.
  • Exterior lighting.
Preconditions for the test:
  • handbrake applied.
  • Gear selector set to P/N.
  • Engine off.
  • Ignition OFF.
  • Battery voltage between 7,25V - 15,5V.
Procedure:
  1. Press "OK" to start the function.
