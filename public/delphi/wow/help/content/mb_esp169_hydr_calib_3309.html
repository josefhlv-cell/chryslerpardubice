Hydraulic unit calibration
This function is used to adapt the hydraulic unit to the car. Run a calibration when:
  • The hydraulic unit is replaced.
Note:
During adaption, the ignition must not be switched off.
Test prerequisites:
  • Ignition on, engine off.
  • Position the car on a flat and level surface.
  • Battery voltage above 12 Volts.
Procedure:
  1. Start the function, press OK.
  2. Calibration is run. A dialogue box shows: Operation succeeded/failed.
    • If the function fails, check test prerequisites and repair possible fault codes.
  3. Exit the function and disconnect the diagnostic tool.
  4. Start the engine.
  5. The warning light for ESP shall flash and the ABS-light shall be on.
  6. Press down hard on the brake pedal and hold it down for approx. 2 seconds.
  7. Warning light for ABS and ESP shall turn off.
  8. Calibration is now completed.
