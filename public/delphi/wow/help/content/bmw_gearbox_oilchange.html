[28]Reset calculation of transmission oil's wear

This function shall be run after oil change on the automatic transmission.

Calculation of the transmission oil's wear will be reset. After the oil change, check the oil level in the automatic transmission with the function "Checking oil level in the automatic transmission".

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Calculation of the transmission oil's wear is reset.

  3. Fault codes are erased.

  4. Check the oil level in the automatic transmission with the function "Checking oil level in the automatic transmission".

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
