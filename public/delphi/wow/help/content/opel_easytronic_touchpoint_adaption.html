[549]Touchpoint adaption

After replacing the transmission, the clutch module or the clutch module with MTA-controller, touchpoint adaption must be performed.

Note:

After completed function check and erase any trouble codes.

Test prerequisites:

  • Ignition on, engine off.

Procedure:

  1. Start the function and follow the instructions in the program.

Exhortations that will come up during the programming:

  • Start the engine.

  • Turn off all power consumer units.

  • Press down brake pedal and hold.

  • Apply handbrake.

  • Gear level in N- position.

  • Put the gear selector in position 'A' in 4 seconds.

  • Release brakepedal.
