[1605]Reset adaptation for sensor unit ESP

Sensor for lateral acceleration, angular rate, and longitudinal acceleration is a common unit, installed in the control unit for the electric parking brake. This function is used to reset adaptation values for all sensors. This shall be done if:

  • Control unit for the electric parking brake has been replaced.

  • Error code that requires resetting is stored in the ABS control unit.

Note:

During resetting, the ignition may not be turned off.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

Procedure:

  1. Place the car on level ground.

  2. Select the basic setting: Zero compensation of sensor unit ESP".

  3. The text: "Sensor adjustment in order" confirms that reset has been performed. If the value for the sensor unit is too high the reset is not accepted.

  4. Exit the function and check the value for the sensors in the data list.
