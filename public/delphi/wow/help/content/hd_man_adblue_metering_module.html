[487]Test of measuring module

The test activates the measuring module.

* Do not run this test if there still is pressure in the AdBlue- system.

* Clicking sounds should be heard in the measuring module.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
