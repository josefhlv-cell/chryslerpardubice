[367]Service work on the gas system

This function is used to drain the gas lines to the engine for service work. After service work is done, perform the function filling of gas system to reactiveate operating mode CNG.

Note:

The function does not empty the gas tanks.

Test conditions:

  • Engine idling and operating mode CNG.

Procedure:

  1. Start the function.

  2. Let the engine idle until it stops.

    • To cancel the function, the engine should be turned off and filling of the gas system should be performed.

  3. When the engine has stopped, dialogue box is displayed showing that the function is done.

    • If the function fails, check the test conditions and repair any faults.
