Bleed air from fuel system
This function is used to bleed the fuel system and should be run If the high-pressure pump or components in the fuel system have been replaced or removed.
Test condition:
  • Ignition on, engine off.
  • Battery voltage above 13V.
  • Battery charger connected to vehicle.
  • Air bleeding shall take place on a closed system.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. If the function fails, check the test conditions and repair any faults.
