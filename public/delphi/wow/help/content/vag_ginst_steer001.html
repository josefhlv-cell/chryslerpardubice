[1359]Multi-function steering wheel, code control unit.

Test condition:

  • Battery voltage above 11.5 V.

  • Ignition on.

Note:

  • Code control unit when change of unit is done or faulty code is stored.

Procedure:

  • Read, repair and erase eventual fault code.

  • Start the function.

  • Enter correct code number.

  • Press OK.

  • Coding performed, read datalist to control the coding number after ignition off/on.
