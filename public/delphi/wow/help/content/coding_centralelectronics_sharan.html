[812]Coding central electronics control unit, Sharan

Coding:

The control unit must be re-coded if a new control unit has been fitted.

Note:

  • If a code is entered that is not correct for the control unit, the old code will remain.

  • Since there is no fixed link between the actual position of the central locking motor and the internal lock control, the doors can be unlocked or locked without the central locking motor moving. If a door is unlocked with the internal lock control, it can only be locked electrically when it has been fully opened. Depending on how the control unit is coded, this happens either always or conditionally via a synchronisation cycle.

For always

All motors are unlocked and then locked again in sequence.

For conditionally

The unlocking cycles are performed only when:

  1. a door has been opened when the car is locked (not tailgate).

  2. the front passenger door or a back door has been opened with separate unlocking of the driver’s door.

  3. the driver’s door has been opened with separate unlocking of the front passenger door (rear door is localised – shared contact in the control unit)

If a further door is now unlocked from inside with the opening lever without the door being opened, the door will not be locked at the next locking sequence. Electric locking will only take place when the door is opened.

Method:

  • Refer to the table for the correct code for the car.

  • Enter the code in the field for coding the central electronics control unit.

  • Click the OK button.

  • A dialog box confirms: Operation successful/ Operation failed.

  • Read the basic date of the control unit to check that the code has been programmed in.

  • Check that no error codes are stored.
