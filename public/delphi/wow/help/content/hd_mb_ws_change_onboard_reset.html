[642]Change on-board reset

This function enables service reset with the on-board diagnostic unit.

Note:

Update the central data memory, ZDS, after changing parameter.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. A dialogue box shows test conditions, check these and press "OK".

  3. Select parameter setting and press "OK".

  4. Turn off the ignition and press "OK".

  5. Turn on the ignition and press "OK".

  6. A dialogue box shows new parameter setting.

  7. The function is done.

    • If the function fails, check the test conditions and repair any faults.
