[404]Read out configuration data from ECU to file

Procedure:

  1. Select number of axles on the trailer in a scroll list, 1,2,3, etc.

  2. Select number of modulators on the trailer in a scroll list. 1 m, 2 m, or 3 m.

  3. Select number of sensors on the trailer in a scroll list. 2 s or 4 s.

  4. Check that the VIN-code matches the VIN-code on the trailer's information plate.

  5. Press "OK" button to open a new window where you select directory in which to save the file. Do not change the file name since it cannot be found later in case of a new configuration.

  6. The file name is based on your selection of axles, modulators, sensors, and the VIN-code.

  7. Press the button. Now the file is saved in the directory.

  8. Press "OK" to exit the function.
