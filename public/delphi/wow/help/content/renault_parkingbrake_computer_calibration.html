[54]Calibration and activation control unit

This function is used to initiate a new control unit.

Note:

Always check that the parking brake works before the vehicle is returned to the customer.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function and follow the instructions in the program.

  2. Always check that the parking brake works after initiating.

  3. Read and erase any fault codes.
