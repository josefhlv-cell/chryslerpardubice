[1649]Injector programming

This function is used to program injector codes (calibration data) for injectors. The injector codes stored in the control unit will be shown. These can be written over if one or several injector codes do not match the engine's injectors.

This shall be done if:

  • One or several injectors have been replaced.

  • The engine control unit has been replaced.

Note:

  • The new injector code is read out manually on the injector.

  • If programming fails, check the injector code and read out error codes in the system.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

Procedure:

  1. Select function: "Injector programming", press "OK".

  2. Injector codes for cylinder 1-4 are shown.

  3. Press "OK" to proceed.

  4. Choose the cylinder to be programmed with new injector code.

  5. Enter the new injector code.

  6. The new injector code is shown. Check that correct injector code is entered.

  7. The function is done.
