Test high pressure control valve
This function is used to test HPV, high pressure control valve.
Note:
During this test will the engine rev up to approx. 3000 rpm.
Test conditions:
  • Ignition on, engine on.
  • Coolant temperature at least 70 °C.
  • Do not touch the accelerator pedal during the test.
Procedure:
  1. Start the function.
  2. The engine will now rev up to approx. 3000 rpm.
  3. Parameter for status functional test changes from "In progress" to "Complete" when the test is performed.
  4. Press "OK" to exit the function.
  5. The engine stops automatically.
  6. If the function fails, check the test conditions and repair any faults.
