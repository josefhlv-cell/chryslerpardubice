[198]Cylinder cut-off

This function is used to temporarily shut off a cylinder and check the injectors' function.

Test conditions:

  • Engine on.

  • Transmission in neutral.

  • Parking brake applied.

Procedure:

  1. Start the function.

  2. Set desired engine rpm and turn off one cylinder at a time by holding in the button. When the test is finished, turn off the engine.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
