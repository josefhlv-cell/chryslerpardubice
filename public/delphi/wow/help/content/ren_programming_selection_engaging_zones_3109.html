Programming selection/engaging zones
This function is used to program new selection/engaging zones after replacement of the control unit for the transmission.
Note:
If you have used the function "Shutting off hydraulics during work" it is important to run the function "Resetting: Shutting off hydraulics during work", before starting programming of the new engaging zones.
Test conditions:
  • Engine off.
  • Ignition on.
  • Gear selector in N.
  • handbrake applied.
  • Coolant temperature below 50 °C.
Procedure:
  1. Press "OK" to start the function.
