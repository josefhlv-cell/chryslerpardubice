[38]Brake test

This function is used to make sure that the valves works correctly, after work has been done on the hydraulic part of the brake system.

Test conditions:

  • Engine off.

  • Ignition on.

  • Parking brake released.

  • Vehicle raised so that the wheels can rotate freely.

Procedure:

  1. Start the function.

  2. Press down the brake pedal completely and hold it down.

  3. Select the wheel to be tested.

  4. Press "Start".

  5. Rotate the selected wheel by hand, it should lock up/release. The other wheels should be locked.

  6. Press "Stop".

  7. Repeat the procedure from step 3 to test the other wheels.

  8. The function is done.

    • If the function fails, check the test conditions and repair any faults.
