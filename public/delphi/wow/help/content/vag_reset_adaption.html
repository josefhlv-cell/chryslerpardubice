[1385]Clear adaption memory

The engine control unit learn and correct possible deviations in for example lambda regulation system. This deviations are stored in the adaption memory. This function erase all the adaption values in engine control unit. If a faulty lambdasond has been replaced or a leaking exhaust system been repaired, it is possible to clear the old and faulty adaption values with this function.

Note:

When the adaption memory is cleared, the EGR valve and electronic throttle control must be adapted with the functions: Electronic thottle control and EGR valve.

Test prerequisite:

  • Ignition on, engine off.

  • All electrical loads switched off.

Procedure:

  1. Choose function: Clear adaption memory.

  2. Function starts, the adaption values are cleared. A dialog box present: operation succeeded/ failed.

  3. Press OK to exit function.

  4. Continue with basic setting of electronic throttle control and EGR valve.
