Center coupling operation check
This function is used to drive the electronic control coupling (centre) with a control current of 3A for a maximum of 60 seconds.
Note:
The following checks in 4WD mode must be completed within one minute to protect the 4WD system's components.
When any of the conditions below is met, the forced activation will be cancelled:
  • Any of the wheel speed sensors detects an input of 20 km/h or more (excluding "Control off").
  • A system malfunction is detected.
  • The forced activation time has elapsed (maximum 60 seconds).
  • The tester is disconnected.
  • Press abort if you want to quit.
Preconditions for the test:
The test can be performed only when all the following conditions are satisfied.
  • Ignition on
  • Every wheel speed sensor input is 20 km/h or less.
  • No faults in the system.
  • The steering angle of steering wheel is within ±30° from the neutral position.
Procedure:
  • Start the function and follow the instructions in the program.
