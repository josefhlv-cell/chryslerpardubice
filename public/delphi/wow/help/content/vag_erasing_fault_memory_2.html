[64]Erase fault memory in all systems

In cars where communication takes place via gateway, you can use it to contact all systems included in the CAN-bus network in the car at the same time. With this function the fault memory can be erased in all systems.

  • Only remedied and intermittent fault codes can be erased.

  • Some engines do not support this function.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

Procedure:

  1. Select the function.

  2. A dialogue box is show, press "YES" to erase fault memory, "NO" cancels the function.

  3. Erasing is performed, this takes approx. 20 seconds.

  4. Exit the function.

  5. Return to the car selection and turn the ignition off and on.

  6. Select the function "System status gateway" to check that all fault codes are erased.

  7. If fault codes remain in any system, select it separately and check the cause.

    • If the function fails, check the test conditions and repair any faults.
