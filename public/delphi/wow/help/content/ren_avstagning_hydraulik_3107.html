Shutting off hydraulics during work
This function is used to shut off the hydraulics when working on the system.
Note:
After work is finished the hydraulics need to be turned on again using the function "Resetting: Shutting off hydraulics during work".
Test conditions:
  • Engine off.
  • Ignition on.
  • Gear selector in position N.
  • handbrake applied.
Procedure:
  1. Press "OK" to start the function.
