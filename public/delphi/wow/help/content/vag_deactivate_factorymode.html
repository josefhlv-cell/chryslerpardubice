[389]Deactivate factory mode in control module

At delivery of new control modules some functions are blocked, e.g., central locking, which does not work before factory mode is deactivated.

Deactivation is only needed when a new control module is installed, when replacing with a used control module no deactivation is needed.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • Control module correctly coded.

Procedure:

  1. Start the function.

  2. Current status is checked.

    • If factory mode already is deactivated, the function finishes.

  3. If factory mode is active, the question is asked if you want to perform deactivation. Press "YES" to perform deactivation.

  4. Deactivation is performed.

  5. Press "OK" to exit the function.

  6. Check that no fault codes are stored in the control unit.

  7. The function is done.

    • If the function fails, check the test conditions and repair any faults.
