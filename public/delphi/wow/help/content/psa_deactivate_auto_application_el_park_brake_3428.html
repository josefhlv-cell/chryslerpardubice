Deactivate the automatic application of the electric parking brake
This function is used to deactivate the automatic application of the electric parking brake.
Note:
Warning: The automatic application of the electric parking brake is deactivated with this function.
Preconditions for the test:
  • Engine off, ignition on.
  • Battery voltage above 12V.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. Function complete.
