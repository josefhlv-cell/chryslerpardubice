[1514]Coding of the regulation of the headlamp range

When a new control unit has been installed, or if the vehicle´s equipment is changed, the control unit for the regulation of the headlamp range must be coded for the existing equipment.

Note:

  • A new control unit can have the code 0 stored.

Test prerequisities:

  • The battery voltage should be above 12 V.

  • Ignition on, engine off.

  • No faults should be stored in the fault memory.

Procedure:

  1. Start the function: "Code control unit".

  2. A dialog box presents the actual code and "Change value". Confirm with "Yes" to change.

    • The function can be aborted with "No" if the code is correct.

  3. Enter the new code (se below) in the presented input field, confirm with OK.

    Code number:Variant:
    7Automatic/dynamic headlamp range control+steel spring (PR-number 8Q3+1BA/1BV/1BW)
    8Automatic/dynamic headlamp range control+air spring (PR-number 8Q3+1BK)
    Code example:

    Audi Q7 with steel spring (PR-number 8Q3+1BA/1BV/1BW) = 7

  4. A dialog box confirms: Code stored (with the new value) in memory.

  5. Confirm with OK to exit the function.
