[110]Test of flaps' control range

This function is used to check the flaps' control range. If the flaps' control range deviates from the stored value, a basic setting of flap motors should be run with a separate function.

  • The ignition must not be turned off during the basic setting.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • Flap motors correctly installed and connected.

Procedure:

  1. Start the function.

  2. Values are checked. The function may take up to 2 minutes to finish.

  3. A dialogue box shows if the function was successful or failed.

    • If the function fails, check the test conditions and repair any faults.
