[305]Reset adaptation values for rail pressure control valve

The rail pressure valve's operating range is taught in to the control unit to obtain better control. With this function this adaptation value is erased when a new component has been replaced, when the engine is started new adaptation values will be stored in the control unit.

This function must be run if any of the following components have been replaced.

  • Rail pressure control valve.

  • High-pressure pump.

  • One or more injectors.

Test conditions:

  • Ignition on, engine off.

  • The component shall be replaced.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Adaptation values are reset in the control unit.

  3. Start the engine and let it idle for a few minutes to teach in new adaptation values.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
