[1722]Reset air meter

This function is used to reset the air meter.

By resetting the air meter, the "APS" control unit behaves like a new control unit.

Test conditions:

  • Ignition on.

Procedure:

  1. Select the function and follow instructions.

  2. Exit the function and exit communication with the vehicle by returning to the car selection.

  3. Turn off the ignition for at least 5 seconds.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
