[633]Basic setting of flap motors

The actuators' actual positions are adapted during basic setting.

Adaptation should be performed when:

  • an air conditioning system component has been removed or replaced.

  • the air conditioning system control unit has been replaced.

Test conditions:

  • Battery voltage above 11.5 V.

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function and follow the instructions in the program.

  2. The adaptation is done when "Function done" is shown.

    • If the function fails, check the test conditions and repair any faults.

  3. Exit the function and turn off the ignition for 30 seconds.

  4. Turn on the ignition again and re-establish communication with the system.

  5. Check that no fault codes are stored in the system.

  6. The function is done.
