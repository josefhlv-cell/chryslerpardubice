[290]Reset adaptation values for fuel pressure control valve

This function enables reset of the fuel pressure control valve's adaptation values. This should be done when:

  • The control valve for fuel pressure has been replaced.

  • The high-pressure pump has been replaced.

Test conditions:

  • Battery voltage at least 12 V.

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. After finished adaptation, exit communication with the car and turn off the ignition for 30 seconds.

  4. Turn on the ignition again, re-establish communication with the car, and check that no fault codes are stored.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
