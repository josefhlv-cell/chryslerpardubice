[118]Reset cylinder balancing

This function is used to reset the cylinder balancing.

Test conditions:

  • Parking brake applied.

  • Ignition on, engine off.

  • Battery voltage above 20 V.

Procedure:

  1. Start the function.

  2. A dialogue box shows "Engine off Ignition on". Press "OK" to continue or "Cancel" to cancel the function.

  3. A dialogue box shows "Do you want to perform reset". Press "Yes" to continue or "No" to cancel the function.

  4. A dialogue shows "Function done". Press "OK".

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
