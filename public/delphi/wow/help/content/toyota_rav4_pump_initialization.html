[1233]Supply pump initialization

This function is used to initialize the learning value from the supply pump to the engine control module (ECM).

This must be done if:

  • The engine doesn't start, after replacing the supply pump and/or the ECM.

  • The engine starts but stalls, after replacing the supply pump and/or the ECM.

Note:

If the engine starts normally, initializaition is not necessary.

Test prerequisites:

  • The battery voltage should be >12 V.

  • Ignition on, engine off.

  • No stored fault codes.

Procedure:

  1. Choose the function: Supply pump initialization.

  2. NOTICE: Do not start the engine!

  3. Press OK button and a dialogue box confirms: operation succeded/failed.

  4. Confirm with OK.

  5. Start the engine to check if the initialization is complete. If the engine doesn't start, check fault codes, engagement and that the repair is done correctly. Then repeat the initialization procedure.

  6. Idle the engine for at least 1 minute under the following conditions:

    • The coolant temperature is 60°C (140°F) or more.

    • The fuel temperature is 20°C (68°F) or more.

      NOTICE:Do not race the engine immediately after starting the engine. After idling the engine, racing the engine is acceptable.

    • The actual values for the coolant temperature and the fuel temperature can be read as datalist parameters.

  7. Initialization is complete.
