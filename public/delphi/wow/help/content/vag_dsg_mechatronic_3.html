[6]Reset adaptation value for mechatronic

For the mechatronic to work correctly it is necessary to reset the adaptation value in the control unit.

Reset shall be performed when the mechatronic unit has been replaced or removed.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on.

  • Gear selector in position P.

Procedure:

  1. Start the function.

  2. The text "Resetting" is shown and indicates "in progress" during basic setting that switches to "done" when it is finished.

    • If the function fails, check the test conditions and repair any faults.

  3. Exit the function as well as diagnosis with the system, turn off the ignition.

  4. The function is done.
