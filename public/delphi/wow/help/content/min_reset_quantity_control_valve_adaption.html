[606]Reset adaptation data quantity control valve

Note:

For better rail pressure control, the quantity control valve's properties are adapted.

Use. The service function reset adaptation data quantity control valve must be run if one of the following components has been replaced:

  • Quantity control valve

  • High-pressure pump

  • One or more injectors

When the service function is run, the adaptation value is erased. After installing a new component the new value is learned again (teach-in), with the engine running, and saved in DDE (engine control unit).

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function and follow the instructions in the program.
