[317]Code trailer function

With this function it is possible to code or decode the trailer function in the engine control module.

On certain models recoding is required for several control modules in the vehicle for correct function, see manual for trailer hitch.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage 12 V.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. When "coding ok" is shown, press "OK" to exit the function.

  4. Exit communication with the vehicle.

  5. Turn off the ignition for 30 seconds.

  6. Turn on the ignition.

  7. Re-establish communication with the vehicle.

  8. Check that no fault codes are stored in the control unit.

  9. The function is done.

    • If the function fails, check the test conditions and repair any faults.
