Steering angle calibration
This function is used to initialise the steering angle sensor.
Run the function when the ECU has been replaced or work related to EPS has been done.
Press OK to start the function.
Note:
This function zero-compensates the value from the steering angle sensor.
Preconditions for the test:
  1. Ignition on.
  2. Engine running.
  3. Turn the steering wheel to centre position with the wheels straight ahead.
  4. No fault codes should be stored in the fault memory.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. After finished function, turn off the ignition and wait for 15 seconds before turning on ignition again.
  4. At completed function, check in the data list that the steering angle sensor is within +/- 5°.
