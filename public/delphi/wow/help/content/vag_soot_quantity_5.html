[322]Reset adaptation values for particle filter

This function is used when replacing the particle filter to reset the adaptation value for soot quantity and soot volume that are stored in the engine control unit.

Reset shall only be run if the particle filter has been replaced.

Test conditions:

  • Engine idling.

Procedure:

  1. Start the function.

  2. Press "OK", the function starts.

  3. Follow the instructions in the program.

  4. When the adaptation is done, exit communication with the vehicle.

  5. Turn off the ignition for 30 seconds.

  6. Turn on the ignition.

  7. Re-establish communication with the vehicle.

  8. Check that no fault codes are stored in the control unit.

  9. The function is done.

    • If the function fails, check the test conditions and repair any faults.
