Lateral and longitudinal acceleration sensor calibration
This function is used to calibrate the lateral and longitudinal acceleration sensor.
Note:
The function works correctly provided that fault code C006A-54 (Multi axis acceleration sensor - missing calibration) is available.
Test conditions:
  • Ignition on.
  • Vehicle stationary.
  • The vehicle on a level surface.
Procedure:
  1. Start the function and follow the instructions in the program.
