[1095]Dash panel

Code dash panel

Seat Alhambra –> 05.00

Dash panel must be coded according to engine type, gearbox type and brake system.

Procedure:

  1. Read, repair and erase eventual fault code

  2. Choose function write to ECU

  3. Edit correct code number

  4. Press OK.

  5. Coding performed, read ”Datalist 01” to control the coding number
