[1760]Reset service message

This function is used to reset the service reminder. Check that "Kilometre setting" and/or "Months to service" is "0" in the read out data list parameters shown at the start of the function. If incorrect service values are shown after resetting, the function "Extra reminder service" can be used to adjust the time to next service.

Test conditions:

  • Ignition on.

  • Service indicator light on.

  • "Kilometre setting" and/or "Months to service is "0".

Procedure:

  1. Start the function.

  2. Check kilometre setting and months to service, press "OK".

  3. Reset of service is performed.

  4. Time to new service is shown.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
