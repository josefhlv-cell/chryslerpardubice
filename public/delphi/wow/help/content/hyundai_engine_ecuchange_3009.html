ECU calibration
This function is used to initiate a new control unit. The new control unit should be installed before the function is performed.
This is done to calculate the amount of soot in the diesel particle filter.
Note:
The odometer shall always be stated in whole kilometres (1 mile = 1.609344 kilometres).
It is important that the mileage is entered using six figures.
When changing the ECU, the injector codes also need to be inputted again.
Test conditions:
Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Enter the current mileage from the instrument.
  3. Press "OK" to proceed.
  4. A dialogue box shows when the function is done.
