[55]Injector programming

Since individual injectors have different properties the engine's electronic control unit corrects the injection time for each cylinder to improve injection accuracy. The injector code is a pre-adjusted calibration which is sent to the engine's electronic control system.

Note:

If an injector's identification code is not registered the engine warning indication lights up and fault code P1626 is generated.

Fault at registration of injector identification code will entail rough idling, abnormal engine noise, and poorer emissions.

Test conditions:

  • Ignition on.

Procedure:

  1. Ignition on.

  2. Select the function, injector programming.

  3. The old registered codes are shown.

  4. Select the cylinder on which the injector is replaced.

  5. Enter the 30-digit code from the new injector, see figure.

  6. The new registered code is shown.

  7. After the code has been sent to the ECU the engine control indication shall change to a flashing light if it had a fixed light earlier.

  8. If several injectors are to be programmed, select "Yes" when asked "Do you want to adapt several injectors?", otherwise select "No".

  9. When injector programming is finished, perform the function "Fuel quantity learning procedure". This is chosen in basic adjustments. The engine control indication shall turn off after this function has been performed. The function "Fuel quantity learning procedure" may have to be done several times if the indication does not turn off.

  10. Erase any fault codes.
