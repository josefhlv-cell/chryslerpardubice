[1268]Coding of the headlamp range control

When a new control unit is installed, or if the vehicle´s equipment is changed, the control unit for the regulation of the headlamp range must be coded for the existing equipment.

Note:

  • A new control unit can have the code 0 stored.

Test prerequisities:

  • The battery voltage should be above 12 V.

  • Ignition on, engine off.

  • No faults should be stored in the fault memory.

Procedure:

  1. Start the function: "Code control unit".

  2. A dialog box presents the actual code and "Change value". Confirm with "Yes" to change.

    • The function can be interrupted with "No" if the code is correct.

  3. Enter the new code (se below) in the presented input field, confirm with OK.

    Code number:Variant:
    3Steel spring without Advanced frontlighting system (PR-nummer 8Q3+1BA/1BB/1BD/1BE/1BR/1BV/1BJ/2MC/2MS)
    4Air spring without Advanced frontlighting system (PR-nummer 8Q3+1BK/1BY)
    Code example:

    Audi A6 with Steel spring without Advanced frontlighting system PR-number 1BA=3

  4. A dialog box confirms: Code stored (with the new value) in memory.

  5. Confirm with OK to exit the function.
