[1275]Fuel system venting

If there is air in the fuel system after a repair has been performed, it is possible to ventilate the system with this function by activating the fuel pump. This function activates the fuel pump 2 times in 30 seconds with a 30 seconds interval.

Note:

  • This function shall only be performed on a sealed fuel system.

Test prerequisities:

  • Ignition on. Engine off

  • No faults stored.

  • Battery voltage above 12 V.

  • No leakage in the fuel system.

Procedure:

  • Choose the function: Fuel pump activation. The fuel pump starts (the value for the fuel pump status changes to: "Pump on") and runs for 30 seconds.

  • The fuel pump shuts off (value for the fuel pump status changes to "Pump off") and is disconnected for 30 seconds.

  • The fuel pump starts (value for the fuel pump status changes to: "Pump on") and runs for 30 seconds.

  • The fuel pump is shut off in 30 seconds and then the value for the fuel pump status changes to "XX Volt".

  • Exit the function.
