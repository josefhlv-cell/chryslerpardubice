[58]Particle filter regeneration during driving

This function cleans the particle filter from soot particles by burning them off using an increase in the exhaust temperature. In certain driving conditions, the particle filter can not be cleaned automatically, e.g., in continuous city driving. Then this function is used to force a regeneration.

Note:

  • Run the test with two persons in the vehicle.

  • The exhaust temperature is very high during this procedure.

  • The engine rpm should be between 2000-4000 rpm during regeneration.

  • Long stops at traffic lights or intersections should be avoided during the test-drive.

  • If the exhaust temperature exceeds 650°C when stationary, apply the parking brake, select neutral gear, and press the accelerator pedal so that the engine speed is between 1500 - 4000 rpm.

Test conditions:

  • Engine idling.

  • Coolant temperature above 60 °C.

  • Exhaust temperature above 200 °C.

  • Fuel level at least 1/4.

  • Set the climate system to max. cooling at ambient temperature above 0 °C, otherwise max. heat.

Procedure:

  1. Start the function, press "OK".

    • Regeneration starts with an increase of the engine speed, then drive off with the vehicle.

    • During regeneration a dialogue box shows current values that concern regeneration.

    • A dialogue box shows: operation succeeded/failed.

    • If the function fails, check the test conditions and repair any faults.
