[1560]Test of inclination sensor

The test is used to check the function of the inclination sensor.

Note:

The inclination sensor has a tolerance of ± 2 degrees, if the difference between the sensor and the measured value is too great, there may be a fault in the inclination sensor. The table below presents a help to translate percentage measurement to corresponding degrees.

Test prerequisites:

  • The vehicle must be on a level surface with the air suspension in driving mode.

Procedure:

  1. Place a protractor on the frame.

  2. Start the test.

  3. Compare the value of the protractor with the inclination sensor´s value.

  4. Exit the test.
