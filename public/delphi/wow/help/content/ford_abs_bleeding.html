[1629]Bleeding brake system

The brake bleeding function is only performed if air has entered the ABS-system's hydraulic unit, or in case of reduced brake function when the ABS-system has activated the ABS-function.

Note:

  • Check all hydraulic connections and couplings if the ABS hydraulic unit has been replaced.

  • Make sure that the battery is charged. Low battery voltage may impact the brake bleeding process.

  • The system shall be pre-bled before the function is performed.

  • After "Bleeding brake system", run bleeding of "brake system brake calipers"!

Test conditions:

  • Battery voltage above 11.5 V.

  • Ignition on, engine off.

Procedure:

  1. Select the function: "Bleeding brake system".

  2. Bleed the brake system with the following functions and order sequence:

    • "Bleeding brake system front", thereafter function: "brake system brake caliper front".

    • "Bleeding brake system rear", thereafter function: "brake system brake caliper rear".

  3. The bleeding sequence is now activated and the following check steps and instructions are shown:

    • Ensure that necessary steps, according to help file, are performed.

    • Ensure that the system has been pre-bled.

    • The function continues with bleeding front/rear.

  4. Continue bleeding by pressing down the brake pedal 16 times.

  5. Open left and right front/rear bleed nipple and connect reservoir to the bleed nipple.

    • A dialogue with instruction is shown, to press down/let up the pedal.

  6. Close left and right bleed nipple.

  7. The function is done.
