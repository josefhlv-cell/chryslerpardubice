Static test of solenoid valves
This function is used to force an error indication in the solenoid valves without starting the engine.
Note:
The diesel injection unit runs checks of the solenoid valves for turbo, EGR, bridge's pressure control, and of the 6 injectors.
Test conditions:
  • Ignition on and engine off.
Procedure:
  • Start the function.
  • When the function is done, read out error codes to see the result of the check.
