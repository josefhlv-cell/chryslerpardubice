[16]Addressing damper motors

Every damper motor has a definite address. The address determines which function the damper motor has in the system. Using this address each damper motor knows which message is addressed to it (e.g., open damper). Using this address the IHKA control unit also knows from which damper motor it has received a message.

This function should be performed to make an addressing of the damper motors. This may have to be done when the IHKA control unit has not succeeded with auto-addressing.

Test conditions:

  • Ignition on, engine off

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.
