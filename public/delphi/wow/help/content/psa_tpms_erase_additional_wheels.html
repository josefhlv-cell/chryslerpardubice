[712]Erasing additional wheels

This function is used when erasing non-relevant additional wheels in the TPMS system.

The function creates empty spaces in which new wheel sensors can be stored.

The TPMS system can save max 9 wheel sensors (4 x main wheels, 5 x additional wheels, 1 of which is the spare wheel).

Note:

In order to retain the current setting for the vehicle, it must be driven for at least 2 minutes at a speed of more than 40 km/h. After the drive, the additional wheels can be erased to create vacant spaces in the system.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. A dialogue box shows "Operation successful/failed".

  3. Function complete.
