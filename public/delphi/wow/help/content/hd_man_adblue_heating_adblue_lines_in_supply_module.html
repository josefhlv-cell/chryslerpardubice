[515]Heating of AdBlue lines in supply module

Measure current consumption across fuse F738 (20 A) in the electrical distribution box using an ammeter. Consumption shall be between 0.5 and 1 Ampere. (Depending on ambient temperature.)

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
