[501]Adaptation of wet start clutch

This adaptation will reset the adaptation values for the wet start clutch and new adaptation values will be learned.

This adaptation is only for AMG-models.

During adaptation the selected driving program will flash on the multi-function display.

Test conditions:

  • Ignition on, engine off - the engine is started during the procedure.

  • Battery voltage above 12V.

  • All power consumers disconnected.

  • The steering wheel stands straight and the front wheels point straight forward.

  • Gear selector in position P.

Procedure:

  1. Start the function.

  2. Start the engine and press down the brake.

  3. Engage position D and keep pressing the brake.

  4. The adaptation is run, may take up to 2 minutes.

  5. A dialogue box shows if the function succeeded or failed.

    • If the function fails, check the test conditions and repair any faults.
