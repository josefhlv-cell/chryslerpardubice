[1165]Language configuration.

Test prerequisites:

  • Engine Off.

  • Ignition On.

  • Battery voltage above 12 V.

Procedure:

  • Read from the table below which code that is required for the car.

  • Write the required code in the input field.

  • Confirm with ''OK''.

  • A dialogue box confirms: "Operation succeeded / Operation failed".

  • Check the parameter list to verify the configuration.
