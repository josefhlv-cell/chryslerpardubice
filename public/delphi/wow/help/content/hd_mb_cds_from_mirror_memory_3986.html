Transfer of parameter data from mirror memory to Central gateway
This function transfers parameters from the mirror memory to the central gateway, CGW. You can also choose to load the service life data from the mirror memory to the service module, MS.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. A dialogue box shows the test conditions; check these and press "OK".
  3. A dialogue box asks "Do you want to transfer the parameters from the mirror memory" Press "YES" if you want to continue the function. Press "NO" to cancel the function.
  4. Transfer starts, follow instructions.
  5. A dialogue box asks if you want to transfer service life data from the mirror memory to the service module, MS.
  6. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
