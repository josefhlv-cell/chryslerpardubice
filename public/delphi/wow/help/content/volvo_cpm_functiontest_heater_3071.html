Heater function test
This function is used to run a function test of the heater following repair.
Note:
The heater will not start if the coolant temperature exceeds 50°C.
Test conditions:
  • Coolant temperature max. 50°C.
  • Engine idling.
  • No flame detected from the heater.
  • The fuel lines must be filled.
  • No fault code should be stored.
Procedure:
  1. Start the function and follow the instructions in the program.
