[343]Reset adaptation values for engine control unit

The engine control module learns and corrects deviations for, e.g., lambda control and stores this in the adaptation memory. This function is used when some component in the engine management system has been replaced or a leaking exhaust or inlet system has been repaired. The function resets old adaptation values.

After resetting the adaptation memory, the throttle control unit must be adapted.

Test conditions:

  • Ignition on, engine off.

  • All power consumers disconnected.

Procedure:

  1. Start the function.

  2. Function starts, teach-in values are erased. "Function done" is shown after successful erasing.

  3. Press "OK" to exit the function.

  4. The function is done - continue by adaptaing the throttle control unit.

    • If the function fails, check the test conditions and repair any faults.
