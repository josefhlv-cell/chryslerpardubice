[15]Calibration damper motors

The IHKA control unit must measure the movements and end-positions individually since the air distribution dampers in the climate control system may differ between different devices. IHKA measures these values using calibration of the damper motors. This is done automatically every time the control unit is coded. An adjustment can also be performed using this function in case the air distribution dampers' behaviour is unreasonable.

Test conditions:

  • Ignition on, engine off

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.
