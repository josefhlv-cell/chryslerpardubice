Actuation of ABS solenoid valves without dynamometer
This function is used to activate the ABS unit solenoid valves.
Test conditions:
  • Connect pressure gauge to test connections of both brake cylinders of the front axle.
  • Read both pressure gauges.
  • The values indicated on the pressure gauges must change according to the activation of the different solenoid valves.
  • The engine at idle to reach enough air pressure.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. Press the "OK" button.
  3. The test is run automatically.
  4. The function is done.
    • If the function fails, check the test conditions and repair any faults.
