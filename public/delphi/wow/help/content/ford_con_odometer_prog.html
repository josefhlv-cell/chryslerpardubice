[579]Odometer programming

Run this procedure if the instrument in the panel has been replaced.

Note:

The odometer can only be set forward and shall always be stated in whole kilometres (1 mile = 1.609344 kilometre).

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function and follow the instructions in the program.

  2. A dialogue box with entry fields is shown.

    • The odometer shall always be stated in whole kilometres (1 mile = 1.609344 kilometres).

  3. A dialogue box shows if the function succeeded or failed.
