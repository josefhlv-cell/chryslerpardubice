[266]Calibrate window lifts

This function is used to erase the window's learned values. Then the window lift is calibrated manually.

Calibration may be necessary when:

  • The window glass is misaligned.

  • The window glass has been replaced

  • The door has been replaced.

  • The window lift has been replaced.

Test conditions:

  • Ignition on, engine off.

  • All doors and windows completely closed.

  • The vehicle must stand on level ground.

Procedure:

  1. Start the function.

  2. Press "OK" to erase the present resting position.

  3. Press "OK" to exit the function and program the resting position.

  4. Press the window switch to open the window to fully open, keep the switch in that position for 5 seconds and then release.

  5. Press the window switch to close the window to fully closed, keep the switch in that position for 5 seconds and then release.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
