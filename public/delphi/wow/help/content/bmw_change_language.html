[1774]Change language in information display and telephone

In the information display there are three pre-selected languages that differ depending on the vehicle's country version. These languages can be changed using this function.

The languages are divided into groups with three languages in each, and the language group you select replaces the three existing languages in the display. When the function has been performed the display starts with a different language, depending on car's country version. Read carefully in the version to find the right search path to change language in the information display when the function is done.

Language groups that can be selected:

  • Dutch, English, and French.

  • Italian, German, and English.

  • Spanish, French, and English.

  • German, French, and English.

Test conditions:

  • Ignition on, engine off.

  • Battery charger connected to vehicle.

Procedure:

  1. Select the function: "Language change in display/telephone ", press "OK".

  2. Select one of the language groups in the list, press "OK".

    • Recoding takes approx. 60 seconds.

  3. Press "OK" to finish.

    • If the function fails, check the test conditions and repair any faults.

Run the following procedure to change main language to another one.

  1. Start from the basic menu in the information display.

  2. Go to "Info" by pressing down the "iDrive controller" once.

  3. Turn the "iDrive controller" to the second alternative from the top "Display settings" and press down the "iDrive controller" once.

  4. Press the "iDrive controller" forward in the driving direction once to go to the upper menu.

  5. Then turn the "iDrive controller" to "Language" and press down the "iDrive controller" once.

  6. Select one of the languages and confirm by pressing down the "iDrive controller" once.

  7. Press the button "Menu" behind the "iDrive controller" to return to the basic menu.
