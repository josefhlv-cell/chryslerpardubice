[1247]ESP driving test

This driving test is used to check the sensor signals from: steering angle, lateral acceleration, brake pressure and the yaw rate sensor. The test must be done if any of the components of the ESP (Electronic Stability Program) system has been removed or replaced.

Note:

  • Once activated, the ESP driving test can not be interrupted.

  • If the ESP driving test has been activated, but not performed correctly, the fault code 1487 is stored in the fault memory. During the ESP driving test, the ignition must not be switched off.

Test prerequisite:

  • The engine should be running.

Performance:

  1. Choose the function: ESP driving test.

  2. Exit the function and diagnosis. The ESP control lamp is turned on.

  3. Depress the brake pedal heavily until the ESP control lamp turns off and the control lamp for the ABS turns on. (The driving test is now activated and the fault code 1486 is stored).

  4. Performe the test drive within 30 seconds, with a speed of 20 to 30 km/h through a left and right curve. Note: There must be no ABS/ESP regulation during the test drive.

  5. The ESP driving test has been performed correctly if the ABS control lamp turns off.

    If the ABS control lamp is still turned on, the ESP driving test has not been done. Re-activate the test by continuing from step 3.
