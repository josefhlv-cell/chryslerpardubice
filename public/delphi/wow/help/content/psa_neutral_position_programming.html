[373]Calibrate neutral position

When replacing transmission control unit or when adjusting the gearshift cable, it is important to teach in neutral position of the gear selector's position sensor since the control unit's installation cannot be adjusted. This function enables the control unit to determine a reference position and, based on it, all other positions can be determined for the gear selector.

Test conditions:

  • Ignition on, engine off.

  • Gearshift cable adjusted according to the car's service instruction.

  • Gear selector in neutral position.

  • No faults in the system.

  • All power consumers disconnected.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
