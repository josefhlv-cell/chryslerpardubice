[1448]Longitudinal acceleration sensor.

This function adapts the acceleration sensor to the ABS control unit. Carry out an adaption when:

  • A fault code regarding calibration of the clutch pedal sensor is present.

  • The clutch pedal sensor is replaced.

  • The ABS control unit is replaced.

Note:

During adaption, the ignition must not be switched off.

Test prerequisites:

  • Ignition on, engine off.

  • The sensor/control unit connected and installed correctly.

  • All electrical loads should be switched off.

  • Battery voltage above 12 Volts.

Procedure:

  1. Position the car on a flat and level surface.

  2. Start the function, press OK.

  3. The adaption is carried out. A dialog box presents: operation succeeded/ failed.

    • If the function fails, check the test prerequisites and repair possible fault codes.

  4. Exit the function, clear possible fault codes and disconnect the diagnostic tool.

  5. Switch off the ignition for 15 seconds, and then switch it on for 30 seconds.

  6. The function is now completed.
