[610]Reset the memory

Note:

This function is used to clear the learned memory in the ABS control unit if any of the following components has been replaced:

  • ABS control unit.

  • Yaw angle / yaw sensor.

Test conditions:

  • Vehicle stationary.

  • Ignition on.

Procedure:

  1. Start the function.

  2. Memory is reset.

  3. A dialogue box shows if the function succeeded or failed.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
