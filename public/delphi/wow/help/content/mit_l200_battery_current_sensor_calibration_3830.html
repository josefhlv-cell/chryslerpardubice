Battery current sensor calibration
This function is used to calibrate the battery current sensor.
Note:
The engine control unit performs a control of the charge level in the battery, based on the current battery sensor signal. This control is performed in order to improve the efficiency and to reduce the fuel consumption and it is necessary to carefully detect the charge level of the battery.
Shall be performed after:
  • Replacing battery sensor.
  • Replacing engine control unit.
Preconditions for the test:
  • Remove the battery current sensor from the battery cable (Do not disconnect the battery current sensor connector).
  • Ignition on, engine off.
Procedure:
  1. The ignition switch is in "LOCK" (OFF), disconnect the battery cable from the negative battery terminal.
  2. Remove the battery current sensor from the battery cable (Do not disconnect the battery current sensor connector).
  3. Connect the battery cable without the battery current sensor to the negative battery terminal.
  4. Ignition on, engine off.
  5. Start the function and follow the instructions in the program.
  6. Confirm that the battery current sensor calibration is "Completed".
  7. Exit diagnosis and turn ignition off.
  8. Install the battery current sensor.
