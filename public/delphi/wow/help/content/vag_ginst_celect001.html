[1293]Central electronics, code control unit.

Test condition:

  • Battery voltage above 11.5 V.

  • Ignition on.

  • All electrical loads switched off.

Note:

  • Use when control unit is replaced or when change of configuration is desired.

Procedure:

  • Read, repair and erase eventual fault codes.

  • Start the function.

  • Add together the code numbers you want to use.

    Example:

    08192 Rear windshield wiper with comfort circuit

    01024 Remote unlocking of tailgate impulse controlled

    00128 Heated outside mirrors

    00032 Heated seats

    00016 Four door version

    00008 Interior light control

    00002 Tailgate remote unlocking

    09402 The total value to use.

  • Enter correct code number (5 digits).

  • Press OK.

  • Coding performed, read datalist to control the coding number after ignition off/on.
