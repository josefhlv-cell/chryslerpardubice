[129]Basic setting neutral position

When replacing transmission and/or transmission control module it is important to teach-in neutral position of the gear selector's position sensors to obtain correct transmission function.

Check the gear selector's position switches.

Test conditions:

  • Ignition on, engine off.

  • Gear in P/N.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. The function is done.

    • If the function failed, check test conditions and that arrow markings on the control module's housing and the lever's shaft match. Remove the lever to see the arrow marking on the shaft.
