[1750]Change language

This function is used to change language in the instrument.

The language can only be adapted on instrument that supports the function.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

Procedure:

  1. Select the function: "Language change", press "OK".

  2. Current language setting is shown, press "OK".

  3. A scroll list with possible language settings is shown. Select desired language, press "OK".

  4. The new language setting is shown, press "OK" to save the new value.

  5. The function is done.
