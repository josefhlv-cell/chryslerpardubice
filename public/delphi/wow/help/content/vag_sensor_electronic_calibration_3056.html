Calibration sensor electronics
This function is used to run a calibration of the fitting mode for the sensor electronics control unit, and should be run when:
  • The control unit has been replaced or has been removed and then reinstalled.
  • Fault code that requires calibration is stored in the control unit.
Test conditions:
  • Ignition on, engine off.
  • Position the car on a flat and level surface.
  • Vehicle stationary.
  • Control unit correctly fitted.
Method:
  1. Start the function and follow the instructions in the program.
