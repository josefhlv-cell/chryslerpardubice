Manual settings menu
This function is used to perform manual adjustments in the instrument. The following parameters may be changed:
  • Maximum speed winter wheels:
    • Not active.
    • 240 km/h (150mph).
    • 230 km/h (140mph).
    • 220 km/h (140mph).
    • 210 km/h (130mph).
    • 200 km/h (130mph).
    • 190 km/h (120mph).
    • 180 km/h (110mph).
    • 170 km/h (110mph).
    • 160 km/h (100mph).
  • Choice of continuous viewing:
    • Outdoor temperature.
    • Vehicle speed.
  • Daytime running light:
    • Manual.
    • Permanent active.
  • Unit for speedometer and distance:
    • Kilometres.
    • Mile.
  • Extra speedometer:
    • On.
    • Off.
  • Automatic door locking:
    • On.
    • Off.
  • Interior light time delay:
    • On.
    • Off.
  • Ambient light:
    • On.
    • Off.
Preconditions for the test:
  • Ignition on.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. A list shows the current settings.
  3. Select the parameter to be changed.
  4. Press "OK" to continue.
  5. Select desired value, press "OK" to start programming.
  6. If you want to perform more updates, press "Yes" and go to step 3. To finish, press "No".
