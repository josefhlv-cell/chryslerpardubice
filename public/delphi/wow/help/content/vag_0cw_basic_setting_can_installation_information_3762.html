Basic setting of the CAN installation information
This function is used to perform a basic setting of the CAN installation information.
Note:
  • The adaptation of the installation information applies to the communication between the control units and should be performed after the following work:
    • Software update.
    • Replacing control unit.
    • Replacing selector lever.
    • Work has been done on the steering wheel gear lever.
    • Another control unit has been replaced, e.g. engine, ABS or gateway.
Test conditions:
  • Battery voltage above 12 V.
  • Ignition on.
  • Gear selector in position P.
Procedure:
  1. Start the function and follow the instructions in the program.
    • If the function fails, check the test conditions and repair any faults.
