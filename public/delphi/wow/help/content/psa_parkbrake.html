[1451]Service on electric parking brake.

These functions is used when service is required on the electric parking brake system. Use when:

  • The brake cable is replaced.

  • The electric parking brake motor replacement.

  • Fault code regarding calibration of force sensor is present.

Note:

  • The car should be placed in a position so it will not move when the parking brake is released.

  • During function, the ignition must not be switched off.

Test prerequisites:

  • Ignition on, engine off.

  • No faults stored.

  • All electrical loads should be switched off.

  • Battery voltage above 12 Volts.

Procedure:

  1. Service position.

    This function is used to make a dismounting / mounting of the brake cable easier.

    1. Start the function, press OK.

    2. The function starts, and the brake cable is now moved to the service position. A dialog box presents: operation succeeded/failed.

      • If the function fails, check the test prerequisites and repair possible fault codes.

    3. Exit the function.

  2. Brake cable tension.

    This function is used to tension the brake cable before calibration. Make sure that the brake cable is installed correctly before using this function.

    1. Start the function, press OK.

    2. The function starts, and the brake cable is now moved to it's max. and min. position. A dialog box presents: operation succeeded/ failed.

      • If the function fails, check the test prerequisites and repair possible fault codes.

    3. Exit the function.

    4. Repeat this function five times to get the brake cable in correct condition.

  3. Calibration.

    This function is used to calibrate the min. and max. position on the parking brake. The brake cable must be installed and tensioned correctly before using this function.

    1. Start the function, press OK.

    2. The function starts, a calibration of the min. and max. position is now performed. A dialog box presents: operation succeeded/ failed.

      • If the function fails, check the test prerequisites and repair possible fault codes.

    3. Exit the function, clear possible fault codes and disconnect the diagnostic tool.

    4. Switch off the ignition for 30 seconds, and then switch it on.

    5. Calibration is now completed.
