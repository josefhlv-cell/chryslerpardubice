Leakage check AdBlue system
This function is used to perform a leakage test on the metering pump.
The test will determine correct function in the metering pump and all of its associated components.
The following text contains information about the test. We recommend that you read the whole text before you continue and start the test.
Note:
The test will activate the metering valve to test if the component has a leak.
Test which is performed without disconnected metering valve may cause damages to the vehicle.
The test is performed manually by starting and stopping the activation.
Test conditions:
  • Ignition on, engine off.
  • Parking brake applied.
  • All components for the AdBlue system must be connected electrically and hydraulically correct.
  • AdBlue tank temperature above 5 °C.
  • The AdBlue tank must contain a fluid volume of at least 20%.
Procedure:
  1. Disconnect the AdBlue metering valve.
  2. Connect the metering valve to a suitable measuring tool.
  3. Start the function.
  4. Press "Start" to start the activation.
  5. Check that there are no leaks.
  6. Press "Stop" to stop the activation.
  7. Press "Abort" to cancel the activation.
  8. Press "OK" at the end of the test.
  9. The function is done.
  • If the function fails, check the test conditions and repair any faults.
