[1464]Activate/deactivate automatic low beam

With this function it is possible to activate/deactivate the automatic low beam function.

Note:

  • The regulations in each country must be followed according activation/deactivation of the automatic low beam function.

Test prerequisites:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

Procedure:

  1. Choose the function: "Automatic low beam function".

  2. The actual status for the function is presented. "Activate/deactivate is presented. Confirm with YES.

    • Press NO to abort the function.

  3. The new actual status for the function is presented.

  4. Confirm with OK to exit the function.

  5. Exit the function.
