Block and release central locking
This function is used to:
  • Block a key.
  • Release a blocked key.
The EWS control unit can manage up to. 10 keys paired with the control unit, which means that a maximum of. 6 spare keys are available. The control unit can identify individual keys, allowing keys to be blocked and released individually. If all 10 keys are lost, the EWS control unit must be replaced.
Blocking is recommended if a key has been lost or stolen. The engine cannot be started using a blocked key.
Any new key ordered is always released for the car, however central locking will not be possible remotely. The remote control keys must then be initialised. See function "Initialise remote control keys".
Note:
  • To check which keys can be blocked, use the function "Read out key status".
  • To block or release a key, the key in the ignition switch must be released and transmitting valid data.
  • The active key (in the ignition switch) cannot be blocked.
  • Never block all the keys; at least two must always be released.
  • Do not block new, undelivered keys.
Preconditions for the test:
  • All existing keys must be handed over with the vehicle.
  • Ignition on.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. Function complete.
