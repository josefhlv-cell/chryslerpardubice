Read learned clutch parameters
This function is used to read a wear value from the four-wheel drive control unit.
Perform this function before replacing the control unit.
Note:
The wear value is a stress value for the four-wheel drive clutch and differs from the vehicle's total driving distance, shown on the instrument panel.
You will be asked to enter the wear value after replacing the control unit, write down the value and save it in an appropriate place.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Note the wear value.
  3. The function is complete.
