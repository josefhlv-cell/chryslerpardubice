Reset adaptation values
This function is used to reset adaptation values in the control module after, e.g., replacement or adjusting components in the engine system.
Note:
After completed function, the following must be performed if the vehicle is equipped with manual transmission: Press the clutch pedal, engage the first gear and start the engine. With this procedure the engine control unit learns that the vehicle is equipped with a manual transmission.
Test conditions:
  1. Ignition on.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. If the function fails, check the test conditions and repair any faults.
