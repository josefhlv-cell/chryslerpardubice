[1124] Add / remove remote controls

Have all remote controls to the car present.

Erase all existing remote controls first.

Then program wanted remote controls.

Remove: Start by pressing “Erase all remote controls” button.

Erase all 4 remote control memory positions, by pressing each button.

Store erasing with “Exit button”.

Add remote controls:

Start the function by pressing “Add remote controls” button.

Add remote control 1 by pressing “Remote control 1”.

Press and hold a remote control button when command is sent.

Add remote control 2 by pressing “Remote control 2”.

Press and hold a remote control button when command is sent.

Same for remote 3. If you have 3 remote controls.

Store adding by pressing “Exit button”.

See status of programmed remote controls in data list.
