Commissioning HSR
This function is used for commissioning of the motor position sensor for the rear axle oblique angle regulation (HSR).
Note:
The commissioning must be performed in the following cases:
  • When replacing HSR-control unit.
  • When replacing HSR-actuator.
  • At removal and installation of HSR-actuator.
Test prerequisites:
  • Ignition on.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Function complete.
