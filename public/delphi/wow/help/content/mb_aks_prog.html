[205]Basic setting of position range sensor

When repairing or replacing transmission parts as well as clutch parts it is important to teach-in the gear selector's position sensor to obtain correct shifting function.

You are guided through the following steps:

Program the component (Position range sensor) in gear selector position 1-5.

Program the component (Position range sensor) in gear selector position R.

Program the component (Position range sensor) in gear selector position N.

  • It must be possible to start the engine.

  • Correct programming of the position range sensor must be run at least once for the clutch to work.

  • Teach-in of the clutch's friction point may be needed after programming to obtain satisfactory function.

Test conditions:

  • Engine off.

  • Clutch bled.

  • Climate system off.

  • Service brake and parking brake applied during the whole sequence.

Procedure:

  1. Start the function.

  2. Follow the instructions in the dialogue box. Move the gear selector to the stated position and press "OK".

  3. A dialogue box shows if the operation was successful or failed when the function is finished.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
