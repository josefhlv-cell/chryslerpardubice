[1478]Hill hold function

When an ABS control unit is changed or re-coded, the hill hold function shall be activated if the function is supported by the vehicle´s equipment and control units.

Note:

This function is only supported on vehicles from year model 2006 and forward. It is only possible to activate the hill hold function on control units that support the function.

Test prerequisites:

  • Ignition on

  • Battery voltage above 12 volt

  • No fault codes stored

Procedure:

  1. Choose the function: 'Hill hold function'.

  2. A dialog box presents the actual adaption value for the hill hold function. Confirm with yes to change the value. If the value should not to changed, the function is aborted with "Abort".

    The following learning values shall be used:

    • 0= Hill hold function deactivated

    • 1= Hill hold function activated

  3. Write the actual value for the vehicle. Confirm with "OK".

  4. A dialog box presents the new value.

  5. Confirm with "OK" to store the new value.

    • If the dialog box "Operation failed" is presented, the function is not supported and the old value resumes automatically.
