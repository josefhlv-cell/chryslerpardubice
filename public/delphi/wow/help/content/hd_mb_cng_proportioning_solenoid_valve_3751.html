Test of proportioning solenoid valve
This function checks the first proportioning solenoid valve duty cycle for the exhaust turbo charger.
Note:
Let a person observe the inlet to the turbocharger during the activation.
Test conditions:
  • Ignition on, engine off.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. Check test conditions.
  3. Press "OK".
  4. Press "START to start the activation.
  5. Press "STOP" to stop the activation.
  6. Press "OK" to exit the function.
  7. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
