Functional test of components with engine turned off
This test are performing a functional check of the selected component.
Note:
After completed test a dialogue box shows "The test has been successful" or "The test has been unsuccessful". Has the test been unsuccessful, a status of the fault that was detected during the test is displayed.
Test prerequisites:
  • Ignition on, engine off.
Procedure:
  1. Press OK to start the function test.
