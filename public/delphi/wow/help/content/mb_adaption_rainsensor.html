[209]Configure rain and light sensor

This function is used when the windshield has been replaced to configure sensor version and to obtain correct function of the rain sensor. After finished configuration, calibration of the rain and light sensor should be performed.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Select version of rain sensor, press "OK".

  3. A data list parameter shows selected rain sensor/windshield version.

    • If the function fails, check the test conditions and repair any faults.
