[329]Code parking assistance

If the vehicle is equipped with several functions on the same position it is necessary to add these values hexidecimally (see procedure and code example below).

Position: 1Function:Position: 2Function:Position: 3Function:

01With trailer hitch (manually removable)01Automatic transmission02Tiguan track & field, A3 3-door

0AGolf VI, S3 5-door
0BGolf Plus

Procedure:

  1. Open the calculator that you find via start/program/accessories.

  2. Open the tab "show" on the calculator and select "advanced".

  3. Select alternative "Hex" to do the calculation.

  4. Add the values for each function found on the same position.

  5. Do the same procedure for remaining positions if necessary.

    Code example:

    Position 1:With trailer hitch (manually removable), with optic parking system, with back-up camera = 01+10+20 = 31

    Position 2:Automatic transmission, with start/stop function = 01+02 = 03

    Position 3: Touran = 01

    • With these functions in the vehicle, the code becomes: 31 03 01

  6. Click on desired position in the read-off code and enter the new value for the relevant position.

  7. The function is done.
