[186]Reset adaptation values for engine control module and power control module

The engine control module learns and corrects deviations for, e.g., lambda control and stores this in the adaptation memory. This function is used when some component in the engine management system has been replaced or a leaking exhaust or inlet system has been repaired. The function resets old adaptation values, also fault codes and other diagnostics-related data will be erased.

Note:

After completed function the engine operation may be rough and idle low, let the engine idle for 10 minutes at normal working temperature to learn new adaptation values.

Test conditions:

  • Ignition on, engine off.

  • Transmission in neutral.

  • Parking brake applied.

Procedure:

  1. Start the function.

  2. Press "OK" to erase adaptation values in engine control module and power control module.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
