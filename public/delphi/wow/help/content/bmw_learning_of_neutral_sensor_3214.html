Learning the neutral position sensor
This function is used to learn the neutral position sensor for MSA (automatic engine start/stop), and should be done when the engine control module has been replaced. A learning is required to compensate the tolerances in the mechanics and the electrical system. In relation to the gear lever's learned zero point, the engine control module evaluates the maximal ranges where the engine may start when the clutch is operated.
Note:
During learning of the neutral position sensor, a CC-message will appear in the combination instrument, which disappears after the clamp change in the function.
Preconditions for the test:
  • Engine idling.
  • Vehicle stationary.
  • Gear in neutral position.
  • Clutch unaffected.
Procedure:
  1. Start the function.
  2. Deactivate MSA manually with the MSA-button or by opening the engine hood.
  3. Perform learning of the neutral position sensor.
  4. At the end of the function MSA is activated again, after completed clamp change.
  5. The function is done.
