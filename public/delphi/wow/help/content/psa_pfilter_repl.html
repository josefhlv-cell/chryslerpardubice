[1452]Cleaning or replacement of particle emission filter

This function must be used when the particle emission filter is cleaned or replaced. The function resets the parameter for the total quantity of diesel additive that has been injected into the particle emission filter.

Test prerequisites:

  • Engine cold and not started for at least 10 minutes.

  • Ignition on, engine off.

  • No faults stored.

  • All electrical loads should be switched off.

  • Battery voltage above 12 Volts.

Procedure:

  1. Start the function, press OK.

  2. A dialog box presents: operation succeeded/failed.

    • If the function fails, check the test prerequisites and repair possible fault codes.

  3. Exit the function.

  4. Switch off the ignition for 15 seconds.
