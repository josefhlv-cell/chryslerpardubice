Presentation mode
This function is used to activate/deactivate the presentation mode.
Note:
Don't forget to restore to normal mode after completed test.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. When presentation mode is activated. press the accelerator pedal to lower the headlights, release the accelerator pedal to raise the headlights. Turning the steering wheel causes the headlights to turn in the direction of the steering wheel.
  3. Restore to normal mode.
