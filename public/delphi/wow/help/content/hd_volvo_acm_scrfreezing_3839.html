Monitoring SCR freezing
This function is used to check and reset the counter for frozen cycles.
Note:
The reset must be performed when the dosing valve has been replaced.
The counter increases by one when the latest driving cycle didn't have a complete blow-out and the exhaust temperature sensor is below 10 °C at startup.
Test conditions:
  • Battery voltage above 20V.
  • handbrake applied.
  • Engine off.
Procedure:
  1. Check conditions.
  2. Start the function.
  3. The counter is shown.
  4. Select to reset the counters or cancel the function.
  5. The function is done.
  • If the function fails, check the test conditions and repair any faults.
