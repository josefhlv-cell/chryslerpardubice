[328]Regeneration of particle filter

This function cleans the particle filter from soot particles by burning them off using an increase in the exhaust temperature. In certain driving conditions, the particle filter can not be cleaned automatically, e.g., in continuous city driving. Then this function is used to force a regeneration. This only has to be done if the particle filter's degree of filling is more than 15% and no regeneration has been run automatically.

Note:

  • If degree of filling is more than 90%, no regeneration should be run due to risk of fire in the particle filter. The degree of filling for the particle filter can be read out in data list parameters.

  • Regeneration is cancelled automatically if driving stops.

Test conditions:

  • Engine on.

  • Engine oil temperature at least 70 °C.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. A data list parameter with current degree of filling for particle filter is shown.

  3. Drive the car in fourth or fifth gear at approx. 2,000 rpm until the degree of filling for the particle filter is below 15%.

  4. Check that no fault codes are stored in the control unit.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
