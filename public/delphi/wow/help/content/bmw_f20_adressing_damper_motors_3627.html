Addressing damper motors
Each damper motor has a specified address. The address determines what function the damper motor has in the system. Via this address each damper motor knows which messages that are addressed to it (eg. open throttle). Via this address also the IHKA control unit knows from which damper motor it has received an error message.
This function is used to perform an addressing of the damper motors. This may be necessary when the IHKA control unit hasn't succeeded with the auto addressing.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. The function is done.
