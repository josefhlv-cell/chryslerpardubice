Vehicle speed offset 65 mode
This function is a test to allow the system to enter the warning monitor status (standby mode), when the vehicle is stationary with a simulated vehicle speed of 65km/h.
Note:
The following times for simulated vehicle speed can be selected.
  • Simulated vehicle speed for 1 minute.
  • Simulated vehicle speed for 10 minutes.
  • Simulated vehicle speed for 30 minutes.
  • Simulated vehicle speed for 60 minutes.
By selecting a time as described above, a simulated vehicle speed of 65km/h will be set within the set time. If the vehicle is driven during this conditions, the simulated speed of 65km/h will be added to an actual speed.
Preconditions for the test:
  • Ignition on.
Procedure:
  • Select the function and follow the instructions in the program.
