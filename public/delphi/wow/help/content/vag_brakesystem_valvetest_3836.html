Hydraulic unit, test
This function is used to check that the solenoid valves in the hydraulic unit is working correctly, and to ensure that the brake lines are correctly connected to the hydraulic unit.
Note:
Warning lamps for the brake will flash when the function is activated.
Test conditions:
  • Co-worker.
  • Battery voltage above 12 Volts.
  • Ignition on.
  • Gear in position P/N.
  • Vehicle raised so that the wheels can rotate freely.
  • No fault codes stored, concerning components in the system.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. If the function fails, check the test conditions and repair any faults.
