[158]Initiate window lift

This function is used when a window lift has been replaced or lost its memory if the car has experienced a power failure. During initiation the window lifts will move up and down until they are calibrated, when initiating rear window the front window goes first to open position.

Test conditions:

  • Windows closed.

  • Doors closed.

  • Ignition on.

Procedure:

  1. Start the function.

  2. Follow instructions.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
