Regeneration diesel particle filter
This function is used to burn soot particles in the particle filter.
Note:
Burning of soot particles (regeneration) shall be done outdoors. The particle filter gets very hot, leave the vehicle on a non-flammable ground surface. To avoid subsequent damage, only perform regeneration once! The burn process may take up to 40 minutes.
Test conditions:
  • Engine idling.
  • Coolant temperature at least 80 °C.
  • No pedal may be activated.
Procedure:
  1. Start the function.
  2. A dialogue box shows status for coolant temperature, wait for correct temperature, see test conditions.
  3. Press "OK" to start the regeneration.
  4. A dialogue box shows status for regeneration, if burn has to be cancelled, select "Cancel".
  5. When the combustion is complete, the function continues automatically.
  6. Follow the instructions in the program.
If the burn fails or is cancelled, check test conditions, the particle filter may need to be replaced.
