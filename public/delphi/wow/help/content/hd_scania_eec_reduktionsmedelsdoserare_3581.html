Reductant doser
This function is used to activate the reductant doser.
Note:
After completed test, the valve automatically returns to 0%.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. A dialogue box shows the test conditions; check these and press "OK".
  2. Select how many percent the valve should be opened.
  3. Press "Start" to activate or "Stop" to deactivate the valve.
  4. Press "OK" to exit the function.
  • If the function fails, check the test conditions and repair any faults.
