[1703]Configure rain sensor

If the rain sensor is replaced or a new type of windscreen fitted, the rain sensor must be configured with the correct variant code in the control unit. If the variant code is stored incorrectly, the rain sensor may not function properly.

If possible, read the existing variant code in the basic data for the rain sensor before replacing it. Valid codes are also listed in the workshop manual or similar documents.

Test conditions:

  • Ignition on.

  • Battery voltage above 12 V.

  • No faults in the system.

Procedure:

  1. Select the "Rain sensor" function.

  2. A dialogue box shows the current code. Press "OK" to change the code.

  3. Enter the current code. Confirm with "OK".

  4. A dialogue box displays the new code. Press "OK".

  5. Exit the function.
