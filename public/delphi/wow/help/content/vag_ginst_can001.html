[1282]Gateway, code control unit.

Test condition:

  • Battery voltage above 11.5 V.

  • Ignition on.

  • All electrical loads switched off.

Note:

  • Use when control unit is replaced or when change of configuration is desired.

Procedure:

  • Start the function.

  • Add together the code numbers you want to use. Control units for engine and comfort doesn´t need to be coded.

    Example:

    ABS + Airbag + Electric power steering = Code

    00002 + 00004 + 00008 = 00014

  • Enter correct code number (5 digits).

  • Press OK.

  • Coding performed, read datalist to control the coding number after ignition off/on.

    Control unitCode
    None00000
    Automatic gearbox00001
    ABS00002
    Airbag00004
    Electric power steering00008
