Calibrating xenon headlights
This function is used to calibrate the xenon headlights.
Note:
The headlights must be adjusted after calibration.
Test conditions:
  • Battery voltage above 11.5 V.
  • Ignition on, engine off.
  • No faults stored.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Confirm with "OK". The adaptation starts and is done when "Function done" is shown.
