[250]Initiation of glow plugs

This function is used to adapt new glow plugs after they have been replaced.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. Confirm with "OK". The adaptation starts and is done when "Function done" is shown.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
