[61]Injector programming

Since individual injectors have different properties the engine's electronic control unit corrects the injection time for each cylinder to improve injection accuracy. Corrected data is converted to an identification code containing 6 digits/letters stamped on the top of the injector.

Note:

Fault at registration of injector identification code will entail rough idling, abnormal engine noise, and poorer emissions.

Test conditions:

  • Ignition on.

Procedure:

  1. Ignition on.

  2. Select the function, "Injector programming".

  3. The old registered codes are shown.

  4. Select the cylinder on which the injector is replaced.

  5. Enter the 6-digit code from the new injector, see figure.

  6. The new registered code is shown.

  7. When replacing more than 1 injector, select "Yes", otherwise "No".

  8. In the next step, a zero quantity calibration and a fuel adaptation will be performed.

  9. Start the engine.

    • Calibration is done automatically when the following conditions are fulfilled.

      1. Engine rpm between 1900 - 2500 rpm.

      2. Accelerator pedal not pressed down.

      3. Brake pedal not pressed down.

    • Fuel adaptation is done automatically when the following conditions are fulfilled.

      1. Engine started.

  10. Erase any fault codes.
