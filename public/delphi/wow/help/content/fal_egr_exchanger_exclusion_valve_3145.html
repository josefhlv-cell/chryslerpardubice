Test of EGR heat exchanger's exclusion valve
This function is used to check the function in the EGR heat exchanger's exclusion valve. The valve will be operated to its end-positions several times.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. The valve is operated for approx. 20 seconds.
  3. The function is done.
