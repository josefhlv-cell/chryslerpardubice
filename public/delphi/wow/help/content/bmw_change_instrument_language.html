[1553]Change of language in combination instrument IKE

This function is valid for the models: E38, E39 and E53 with combination instrument IKE.

Test prerequisities:

  • Ignition on, engine off.

Procedure:

  1. Press "OK" to start the function.

  2. Choose desired language in the list.

  3. Press "OK" to continue or Cancel to quit.

  4. When the function is completed the ignition must be shut off for 10 seconds.
