Recall service message
This function recalls the service indication message.
Test prerequisites:
  • Ignition on, engine off.
Procedure:
  1. Choose function: "Recall service message", and follow the instructions.
  2. After the operation a dialog box is shown: "Operation succeeded" or "Operation failed".
  3. Check if the function for adjusting the estimated oil level/oil quality in the engine is available? If so must also this function be performed!
If the operation failed check and repair any faults that may be in the system.
