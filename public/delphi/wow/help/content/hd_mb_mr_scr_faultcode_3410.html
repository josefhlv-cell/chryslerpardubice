Fault memory indication
Extra memory for accumulating faults.
This fault code is shown for a statutory accumulated fault.
In case of a fault in the SCR exhaust aftertreatment system, an entry is generated in the fault memory, and also another entry in the memory for accumulating faults.
This fault code is saved for at least 400 days or 9600 engine operating hours, and it can be read by governing authorities.
Note:
This function can only be used for Euro 4 and later Euro versions of engine. This means that the function only works on the diagnostic version 35 and later versions of the control module.
Test conditions:
  • Ignition on.
  • Engine off.
Procedure:
  1. Select the function "Reading of additional information for SCR fault codes".
  2. Press "OK".
  3. A matrix is shown with fault codes and the engine operating time since it was set.
