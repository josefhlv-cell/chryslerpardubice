[451]Initiating xenon system

This function is used when replacing the xenon lights' control unit or height sensor for body.

Test conditions:

  • Ignition on.

  • Vehicle stationary.

  • No faults in the system.

  • The vehicle must stand on level ground.

  • Vehicle must be without load.

  • Transmission in neutral.

Procedure:

  1. Start the function.

  2. When initiation is done, turn off the ignition and wait until the control light for start inhibitor starts to flash.

  3. Check data list parameter no.:10. Status shall be "done".

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
