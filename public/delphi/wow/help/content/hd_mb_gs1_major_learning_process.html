[123]Major programming for control unit GS 1 gear control

Major programming should only be performed if another transmission type / engine type has been installed.

In case of major programming, transmission type, road sensors' movement values for clutch, split, range, gate, or gear are calculated again.

During programming, instructions must be followed for pressing down the clutch completely and releasing it completely to avoid transmission breakdown due to incorrect programming data from the clutch.

In vehicle with electric drive control (EAS), clutch operation is automatic.

On the display the split arrows will flash alternately during the entire programming.

The neutral button is located on the passenger side of the gear selector lever.

The function button is located on the passenger side of the gear selector lever.

If indication "N" (Neutral) is shown on the display, programming has been finished correctly.

If programming is cancelled by a fault, the fault code number is shown on the instrument's display. For explanation of fault code, se list below.

Test conditions:

  • Ignition on, engine off.

  • All power consumers disconnected.

Procedure:

  1. Turn off ignition.

  2. Parking brake applied.

  3. Press down the clutch pedal completely and hold it down (Does not apply to EAS-vehicle).

  4. Press in the Neutral button and the Function button, keep them pressed in during the whole programming.

  5. Turn on the ignition.

  6. Start the engine when Neutral (N) flashes on the display.

  7. Let up the clutch completely at the first sound signal (Does not apply to EAS-vehicle).

  8. Press down the clutch pedal completely at the second sound signal (Does not apply to EAS-vehicle).

  9. Let up the clutch completely at the third sound signal (Does not apply to EAS-vehicle).

  10. Press down the clutch pedal completely at the fourth sound signal (Does not apply to EAS-vehicle).

  11. Programming is finished after the fifth sound signal.

  12. If indication "N" (Neutral) is shown on the display, programming has been finished correctly.

    If programming fails: Repeat programming, repair any faults in control unit GS 1.

    Control unit GS 1 fault messages on instrument's display (fault at learning and operation):

    GS 01 Button for emergency shifting is not in start position

    GS 02 Emergency shifting is active

    GS 09 Programming error: Neutral position.

    GS 10 Programming error: Programming values for split are incorrect.

    GS 11 Programming error: Programming values for gear are incorrect.

    GS 12 Programming error: Programming values for gear are incorrect.

    GS 13 Programming error: Programming values for gate are incorrect.

    GS 16 Programming error: Programming values for gate are incorrect.

    GS 17 Programming error: Programming values for range are incorrect

    GS 18 Failure of a solenoid valve or movement sensor.

    GS 19 Programming error: Vehicle rolling.

    GS 20 Programming error: Undervoltage or overvoltage.

    GS 21 Programming error: Clutch operation.

    GS 22 Programming error: Neutral setting cancelled.

    GS 23 Programming error: Transmission type not valid.

    GS 24 Programming error: Parking brake not applied.

    GS 26 Programming error: Engine on.

    GS 27 Programming error: Engine torque missing or not valid.

    GS 28 Programming error: Engine is not started.

    GS 29 Programming error: Engine rpm missing.

    GS 30 Programming error: Idle.

    GS 31 Programming error: Clutch distance.

    GS 32 Programming error: Intermediate shaft rpm.
