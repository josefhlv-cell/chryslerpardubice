[274]Configuration of running lights

This function is used to configure the running lights' function when light switch is in position 0.

There are 5 versions of status for the light switch in position 0:

  • Version 1:

    Status ignition on - Parking lights, tail lights & license plate lights on.

    Status engine on - Low beams, parking lights, tail lights & license plate lights on.

  • Version 2:

    Status ignition on - Low beams, parking lights, tail lights & license plate lights on.

    Status engine on - Low beams, parking lights, tail lights & license plate lights on.

  • Version 3:

    Status ignition on - All lights off.

    Status engine on - All lights off.

  • Version 4:

    Status ignition on - Low beams, tail lights & license plate lights on.

    Status engine on - Low beams, tail lights & license plate lights on.

  • Version 5:

    Status ignition on - All lights off.

    Status engine on - Low beams, tail lights on.

  • Inactive:

    Status ignition on - All lights off.

    Status engine on - All lights off.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.
