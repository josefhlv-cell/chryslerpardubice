[761]Refilling hose with additive

Description:

If components in the additive system has beenchanged or repaired.The hose between the additive tank and the injector(mounted on The main fuel tank) could be empty.

Conditions:

- Ignition on.

- Activate refilling

- Start the engine

- Check that refilling starts: Lock at the parameter ”Additive pump, activated”, the status should change to ”Yes.”

- When refilling is finished should the status change to ”No”.
