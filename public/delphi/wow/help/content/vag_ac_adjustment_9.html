[414]Basic setting of climate control system

When the control module for the climate control system has been replaced or a new actuator has been installed a basic setting of the climate control system must be performed. During basic setting the control unit teaches in the actuators' end-positions.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. A dialogue box shows: "Basic setting active" and switches to "Basic setting complete" when the function is done.

  3. Press "OK" to exit the function and finish communication with the system. Turn off the ignition for 30 seconds, then turn on ignition for 30 seconds to store the new values.

  4. Re-establish communication with the car and check that no fault codes are stored.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
