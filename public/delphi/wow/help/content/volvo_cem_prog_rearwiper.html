[1646]Configuring wiper function

This function configures the rear window's wiper function.

It is possible to program two variants for the rear window wiper function:

  • The rear window's wiper can only be activated manually.

  • The rear window's wiper can be activated automatically when reverse gear is selected and the front windshield's wiper is activated.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the function: "Programming wiper function, rear window", press "OK".

  2. A dialogue box with present wiper function is shown.

  3. Press "OK" to proceed.

  4. Select desired function: "ON" or "OFF", press "OK" to start programming.

  5. After successful programming, the programmed wiper function is shown.

  6. Press "OK" to exit the function.
