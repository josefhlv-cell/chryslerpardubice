Bleeding the cooling system
This function is used to bleed the cooling system. The bleeding routine can also be activated through a specific actuation sequence in the vehicle, refer to the manual activation under "manually performance" later in the text. The bleeding is active for 10 minutes.
Note:
If any of the conditions are not met, the bleeding routine will be canceled. It may also be that there is no need for bleeding in the actual vehicle. Bleeding is only needed if any of the following equipment exists:
  • Shut-off valve for the coolant expansion tank (turns off the pipeline between the radiator and the expansion tank).
  • Extended intercooler (coolant-cooled intercooler).
  • Low temperature AGR cooling (the AGR cooler is connected to the coolant system's low temperature side).
Test conditions:
  • Gear selector set to P/N.
  • Engine idling.
  • Speed lower than 3 km/h.
  • Coolant temperature below 50 °C.
Procedure:
Bleeding via diagnosis:
  1. Start the function and follow the instructions in the program.
  2. Function complete.
Bleeding manually performance:
  1. Turn on the ignition.
  2. Fully depress the accelerator for 10 seconds.
  3. Start the engine within 30 seconds, the bleeding starts.
  4. The bleeding is active for 10 minutes.
Note:
At clamp change, the time counters will be reset and allows for a new attempt to start bleeding.
