[1734]Calibrate level sensors

This function is used to calibrate the vehicle's level sensors.

Calibration of level sensors shall be performed when:

  • Any level sensor has been replaced.

  • Work has been done on level sensor.

  • The control unit has been replaced.

  • The control unit has been reprogrammed.

  • If any of the bellows have been replaced.

Note:

The vehicle will move up and down when the level sensors are calibrated. Therefore it is extremely important that no persons or equipment remain in the area around or under the vehicle's frame to prevent crushing injuries!

The test "Level sensor test" shall be performed with set values (see table below) for calibrating level sensors.

Test conditions:

  • Parking brake applied.

  • Primary tank pressure above 800 kpa.

  • Control rods fastened between level sensors and axles.

  • Bellows are intact.

Procedure:

  1. Start the engine and fill the system with air until the compressor cuts out.

  2. Press "OK" to start calibrating.

  3. All level sensors shall be "OK".

  4. The function is done.

    • If any level sensor is not "OK", fault code "MID150" is stored and a new calibration is to be performed, check test conditions and take action to repair any faults.
