[178]Reprogram EEPROM

This function is used in case the control unit's EEPROM-memory is lost. The function performs a new read-out of calibration values, and using these, enters new values in EEPROM.

Programming must be run if any of the following internal faults are stored in the engine control unit.

  • DDE 3.0: Error code 42, DDE-control unit (EEPROM and configuration).

  • DDE 4.0: Error code 1640, DDE-control unit (EEPROM and configuration).

  • DDE 4.1: Error code 1640, DDE-control unit (EEPROM and configuration).

  • DDE 4.1 Slave: Error code 1641, DDE-control unit (EEPROM and configuration).

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.
