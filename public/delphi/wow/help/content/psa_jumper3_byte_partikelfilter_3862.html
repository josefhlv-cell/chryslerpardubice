Replacement of particle filter
This function must be performed when the particle filter has been replaced. This procedure updates parameters in the control unit and resets the number of incorrect regenerations.
Test conditions:
  • Ignition on, engine off.
  • Battery voltage above 12V.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. The function is done. If the function failed, check test conditions and resolve any error codes.
