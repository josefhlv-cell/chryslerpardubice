Configure idle speed
This function is used to change the idle rpm. The rpm can only be adapted within predetermined limit values.
Test conditions:
  • Engine idling.
  • Coolant temperature above 70°C.
Procedure:
  1. Start the function.
  2. The current correction value for the idle speed is shown, press "Yes" if you want to change the value.
  3. Enter the idle speed correction value, between 1 rpm - 128 rpm. Press "OK".
  4. The adaptation is performed.
  5. A dialogue box presents "Current correction value idle speed" and "Desired idling speed".
  6. "Is the new idle speed satisfying?", Press "Yes" to exit the function or "No" to correct the speed further.
  7. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
