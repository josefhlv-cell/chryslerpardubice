[284]Valve test

This function activates the valves in a test cycle.

Test conditions:

  • Ignition on.

  • Full air pressure in the brake system.

  • Parking brake released.

Procedure:

  1. Start the function.

  2. Follow the instruction to release the parking brake.

  3. The test is run automatically.

  4. Follow the instruction to apply the parking brake.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
