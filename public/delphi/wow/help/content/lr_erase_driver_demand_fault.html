[1637]Resetting faulty driver demand

If the driver presses down the brake and accelerator pedals at the same time the control unit registers this as a fault (but no error code). This function resets the counter for the data list parameter "Faulty driver demand" which indicates odometer reading when the malfunction occurs.

Note:

Resets only this parameter.

Conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

  • Brake and accelerator pedal unaffected.

Procedure:

  1. Select function: "Erase faulty driver demand", press "OK".

  2. A dialogue box shows: "successful" or "failed".
