[604]Initialisation steering column

Note:

The function must be performed after the following work:

  • Replacement of steering column.

  • Changing centre console's connection module (SZM).

Test conditions:

  • Ignition on, engine off.

  • Battery charger connected to vehicle.

Procedure:

Manual initiation (with switch for steering column adjustment):

  1. For tilt adjustment, move the button to the upper and lower end-position.

  2. For fore-aft adjustment, move the button to the front and rear end-position.

Initiating via diagnosis:

  1. Start the function.

  2. Follow the instructions in the program.
