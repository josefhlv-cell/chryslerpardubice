[506]Reset adaptation values for catalytic converter

This function is used to reset the catalytic converter memory in the control unit for thermal breakdown in DPNR (Diesel Particles and NOx Reduction) when replacing catalytic converter.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. Memory is reset.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
