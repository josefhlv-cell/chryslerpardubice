[1109]Particle filter

Dismantle:

Dismantle the hoses for the pressure sensor.

Dismantle the temperature sensor cautiously.

Dismantle the rubber suspension.

Loosen rear clip.

Dismantle the three nuts from the front pipe.

Dismantle the particle filter rear holder.

Dismantle the particle filter.

Assembly:

Assemble particle filter.

Assemble particle filter rear holder.

Fasten to the front with a new gasket and three new nuts.

Assemble rear clip.

Assemble the rubber suspension.

Lubricate the temperature sensor threads.

Assemble the temperature sensor.

Assemble the hoses for the pressure sensor.

When a new particle filter is assembled use the function ”Particle filter replaced”.
