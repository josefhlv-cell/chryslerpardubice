Initialization procedure for diesel particle system (Euro 5)
This function is used to reset the values for the diesel particulate filter.
Note:
The engine control unit stores the change of the DPF system caused by the various driving conditions as the learning value and uses it for assumption of the accumulated particle quantity value or for the acceptance/rejection criteria of the DPF system. For this reason, the learning value is necessary to be initialized when the parts related to the DPF system are replaced.
Used for resetting at:
  • Replacement of particulate filter.
  • Replacing differential pressure sensor.
  • Replacing catalytic converter.
Test conditions:
  • Ignition on, engine off.
Procedure:
  • Start the function and follow the instructions in the program.
