Read out and register starter motor replacement
This function can be used to:
  • Read out information from the starter motor counter. This reveals whether a previous replacement of the starter motor has been registered. The information includes the mileage, engine starts and auto restarts.
  • Register starter motor replacement. The starter motor counter is reset.

Test conditions:
  • Ignition on.
Execution:
  1. Start the function.
  2. Follow the instructions in the program.
  3. Function done.
