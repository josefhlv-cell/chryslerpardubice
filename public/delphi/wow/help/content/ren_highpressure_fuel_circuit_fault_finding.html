[316]Detecting leakage in fuel system

This function is used to search for leakage in the fuel system. During the function the engine rpm will increase and the fuel pressure will increase to max. level.

Note:

During the function the fuel pressure will increase to max. level, close the engine hood to avoid fuel splashes.

Test conditions:

  • Engine on.

  • Vehicle stationary.

  • Parking brake applied.

  • Transmission in neutral.

  • Do not touch any controls or pedals while the function is in progress.

  • Coolant temperature between 70 and 90 °C.

  • Fuel temperature between 30 and 60 °C.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
