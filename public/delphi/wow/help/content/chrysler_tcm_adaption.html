[44]Reset adaptation values for transmission

This function is used to reset the stored adaptation values in the transmission's control unit.

The function is used when the transmission or any component has been replaced.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the function and follow the instructions.

  2. The function is done.

    • If the function fails, check the test conditions and repair any faults.
