Release active transport mode
This function is used to release active transport mode on new vehicles.
Note:
If the vehicle is new and the control module is in active transport mode, a list will be shown of the control modules that can be released to normal operating mode. With normal operating mode you get full functionality of the vehicle's control module.
If the vehicle already is in normal operating mode the function will be ended without any action.
Test conditions:
  • Transport mode active.
  • Ignition on, engine off.
Procedure:
  1. Start the function and follow the instructions in the program.
