[730]Key programming

This function is used to program keys. When programming, you must have all keys available. In order to perform the programming you need to enter a security code.

Note:

All keys must be reprogrammed.

You must have the key programming code available.

Old keys will be erased.

A maximum of 5 keys can be programmed

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • All keys to be programmed.

  • The vehicle's security code.

Procedure:

  1. Start the function.

  2. A dialogue box displays "Enter security code". The code contains the letters "o" or "i".

  3. Turn off the ignition.

  4. Turn the ignition key within 15 seconds to program the key.

  5. If programming is successful, you will see "Key programmed. Do you want to program a new key?".

  6. If multiple keys are to be programmed, the function is repeated until all keys have been programmed.

  7. Communication is restarted to conclude the programming.

  8. Function complete. Run the dedicated function in order to synchronise the remote controls.

  9. After concluding the function attempt to start the vehicle with each key.
