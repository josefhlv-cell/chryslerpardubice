Regeneration of particle filter
In certain driving conditions, the particle filter can not be cleaned automatically, e.g., in continuous city driving. Then this function can be used to force a regeneration of the particle filter. The function cleans the filter from soot particles by increasing the exhaust temperature and thus burn off soot particles. Increase of the exhaust temperature takes place automatically during the regeneration procedure.
Note:
  • The exhaust temperature is very high during the procedure. Therefore, perform the regeneration outdoors, without connected exhaust hose.
  • The regeneration procedure may take between approx. 5-40 min.
  • The gas pedal or brake pedal may not be pressed down during the sequence.
  • The regeneration can be cancelled at any time by pressing down the clutch and brake pedal.
Test conditions:
  • Engine idling.
  • Coolant temperature above 80°C.
  • No flammable materials near the exhaust pipe.
  • Fuel level at least 1/4.
  • Gear selector in position P.
  • Parking brake applied.
  • Engine hood open.
  • Turn on the light switch, high beams on.
  • Turn on fan, set to max. power.
  • Turn on the A/C.
  • Vehicle stationary.
  • No error codes in the system.
Procedure:
  1. Start the function.
  2. Confirm with "OK". Regeneration starts with an increase of the engine rpm.
  3. During regeneration a dialogue box shows current values that are related to the regeneration. The function is done when this can be read from the status for regeneration.
    • Regeneration can be cancelled at any time with the function or by turning off the ignition.
  4. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
