Change language
This function is a description of a manual procedure that is performed in the main instrument.
There are 3 push-buttons on the lower right side, one to access the menu and two to navigate in the menu.
Description of function for each button, starting from the top:
  1. Menu (+).
  2. Menu/ESC.
  3. Menu (-).
When menu/ESC (2) is pressed for more than 1 second the change is saved, confirm with a brief press. If no button is pressed within 60 seconds, the display returns to a standard display.
The display can show the following languages: Italian, English, German, Portuguese, Spanish, French, Dutch, and Polish.
Note:
The setup menu can be activated in 2 ways with a brief press (< 1 sec) on menu/ESC (2).
  • Full menu (stationary vehicle).
  • Basic menu (moving vehicle).
Test conditions:
  • Ignition on.
Procedure:
  • Navigate to the language menu.
  • Briefly press (< 1 sec) menu/ESC (2), now the display flashes with the latest selected language.
  • Press +(1)/-(3) to select a new language, confirm with a long press on +(1) or -(3) (> 1 sec).
  • Press menu/ESC (2), brief press (< 1 sec) returns to the menu, or long press (> 1 sec) to access the standard display without saving.
