[822]Coding headlight range control unit Audi TT

Coding:

The headlight range control unit must be recoded if the control unit has been renewed.

Code:

For coding headlight range control unit on Audi TT the following codes are valid:

  • Vehicles with front wheel drive:00009

  • Vehicles with four-wheel drive:00010

To perform coding:

  • Write the current code in the coding headlight range control unit field.

  • Click on the OK-button.

  • A dialogue box confirms: Operation succeeded / Operation failed.

  • Read the control unit basic data to check that the new code is programmed.

  • Check that no fault codes are stored.
