Enter clutch parameters
This function is used to enter the clutch wear value to the four wheel control unit.
Run this function after replacing the control unit.
Note:
The wear value differs from the vehicle's total driving distance, shown on the instrument panel.
Read the wear value with associated function before this function is performed.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Enter the read and saved wear value.
  3. The function is complete.
