[1311]Instrument cluster, code control unit.

Test condition:

  • Battery voltage above 11.5 V.

  • Ignition on.

  • All electrical loads switched off.

Note:

  • Use when control unit is replaced or when change of configuration is desired.

Procedure:

  • Read, repair and erase eventual fault codes.

  • Start the function.

  • Put together the code numbers you want to use.

    Add together the mounted equipment to create the first two digits.
