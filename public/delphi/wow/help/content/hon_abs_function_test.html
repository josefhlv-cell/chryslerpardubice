[89]Test of solenoid valves

This function runs a function test of the ABS-system's solenoid valves.

During the test, when the brake pedal is pressed down, the pedal will vibrate.

Test conditions:

  • Ignition on.

  • Brake pedal pressed down.

  • Gear in neutral position

  • No faults in the system.

  • Fault codes erased.

Procedure:

  1. Start the test for the selected solenoid valve with "OK".

  2. The test stops automatically after approx. 5 seconds.

    • If the function fails, check the test conditions and repair any faults.
