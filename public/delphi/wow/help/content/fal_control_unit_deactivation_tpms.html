[31]Deactivation control unit

This function deactivates the control unit from working in normal mode.

Note:

The function can be used to deactivate the control unit, if the vehicle is located in a garage where you do not want to cause interference with vehicles that are located nearby.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function and follow the instructions in the program.
