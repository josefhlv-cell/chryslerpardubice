Fuel metering solenoid valve
This function is used to select a specified value to component Y628 (Fuel metering solenoid valve).
Test conditions:
  • The engine idling.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. Select specific value to be activated to the component.
  3. A dialogue box shows test conditions, check these and press "Start".
  4. Start and stop the activation for the selected value.
  5. Repeat the procedure for the values to be tested.
  6. At the end of the test press "OK".
  7. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
