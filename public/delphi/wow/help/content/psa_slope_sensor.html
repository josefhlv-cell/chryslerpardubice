[1453]Slope sensor calibration

This function adapts the slope sensor to the electric parking brake control unit. Carry out a calibration when:

  • A fault code regarding calibration of the slope sensor is present.

  • The slope sensor is refitted or replaced

  • The electric parking brake control unit is replaced.

Note:

During calibration, the ignition must not be switched off.

Test prerequisites:

  • Ignition on, engine off.

  • The slope sensor connected and installed correctly.

  • The tyre pressure must be correct and the vehicle must not be overloaded (only the driver should be seated in the vehicle)

  • Battery voltage above 12 Volts.

  • All electrical loads should be switched off.

Procedure:

  1. Position the car on a flat and level surface.

  2. Start the function, press OK.

  3. The calibration is carried out. A dialog box presents: operation succeeded/ failed.

    • If the function fails, check the test prerequisites and repair possible fault codes.

  4. Exit the function, clear possible fault codes and disconnect the diagnostic tool.

  5. Switch off the ignition for 30 seconds, and then switch it on for 30 seconds.

  6. The calibration is now completed.
