[468]Test of starting operation of SCR

The function is used to check that the SCR-system can deliver Adblue by building up a pressure, that the non-return valve works, and that the pressure drops when the cooling valve opens.

  • The connector on the dosing module must be disocnnected to prevent serious damage to the aftertreatment system.

Test conditions:

  • Parking brake applied.

  • Engine off.

  • Ignition on.

  • Dosing module connector disconnected.

  • Adblue in reservoir.

  • Battery voltage above 20V.

Procedure:

  1. Start the function.

  2. Check conditions.

  3. Select to start or cancel the test.

  4. Check the working pressure while the test is in progress.

  5. Check status of the test.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
