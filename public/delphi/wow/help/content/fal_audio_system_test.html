[400]Testing the audio system

This function is used to check that the convergence microphone works and that the connection between radio and convergence is intact. For a positive result a beep will be heard from the convergence microphone.

In case of a negative result, proceed as follows:

Begin by restarting the system using the "Restart convergence control unit" function. Then retest using "Test the audio system". If the result is still negative, check as follows:

  • If you can hear a beep from the radio: The problem is in the microphone, which may either be faulty or incorrectly connected.

  • If you cannot hear a beep from the radio: Check the connections (cables, contacts, etc.) between convergence and the radio.

Test conditions:

  • Ignition on

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is complete.
