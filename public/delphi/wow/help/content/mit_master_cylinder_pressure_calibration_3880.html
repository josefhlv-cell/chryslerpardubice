Master cylinder pressure calibration
This function is used to calibrate the master cylinder offset values for pressure and should be used when the "ASC" control unit has been replaced. Always perform calibration with unaffected brake pedal.
Test conditions:
  • Ignition on.
  • The vehicle must stand on level ground.
  • No faults in the system.
  • Brake pedal unaffected.
Procedure:
  1. Start the function.
  2. Follow instructions.
  3. The function is done.
    • If the function fails, check the test conditions and repair any faults.
