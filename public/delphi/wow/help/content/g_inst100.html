[851] Setting the throttle wire

Preconditions for the test:

  • Ignition on.

Note:

  • For checking and setting the throttle wire.

Procedure:

  • Set the throttle wire by means of the locking ring on the throttle wire attachment, so that the throttle arm reaches the full throttle position.

  • Choose the function. Setting the throttle wire

  • Fully depress the throttle pedal and keep it in that position for at least five seconds. Read off the value in the throttle opening column. Required value: 170-175.

  • Release the throttle pedal (the throttle control unit goes to its basic position). Read off the value in the throttle opening column. Required value: 10-11.

  • If the required values are not achieved, repeat the throttle wire setting procedure.
