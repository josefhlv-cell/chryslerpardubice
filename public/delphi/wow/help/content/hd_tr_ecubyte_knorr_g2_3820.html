Read out configuration data from ECU and save to a file
This function is used to save configuration data from ECU to a specific file for the relevant trailer.
Note:
See tables of compatible ECUs. Part numbers from TABLE#1 can only be replaced with part numbers from TABLE#1. Part numbers from TABLE#2 can only be replaced with part numbers from TABLE#2.
Test conditions:
  • The trailer shall be supplied with voltage with either a truck or another external voltage source.
  • The trailer is secured and cannot roll away.
Procedure:
  1. Start the function.
  2. Read the information about procedure under the information button.
  3. Select number of axles on the trailer in a scroll list.
  4. Select number of modulators on the trailer in a scroll list.
  5. Select number of sensors on the trailer in a scroll list.
  6. Check that the VIN-code in the VIN-code box matches.
  7. Press the "OK" button.
  8. Select the file directory where the file is to be saved and press save.
  9. Press "OK" to save the configurations to a file.
  10. The configuration file will receive a name from your selections and the VIN-code.
  11. Your selections and the VIN-code are only used as identification of the file and do not affect the configuration.
  12. The function is done.
