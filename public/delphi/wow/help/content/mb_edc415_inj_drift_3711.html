Smooth running measurement
This function is used in case of complaints of unsmooth engine operation.
The smooth running system control, is optimized during this function.
Engine smoothness control is balancing the speed variation for each individual cylinder caused by variable injection amount and each cylinder´s efficiency. This is obtained by an application that sends an exact fuel amount for each cylinder at each injection time.
Test conditions:
  • Engine idling.
  • Engine temperature above 70°C.
Note:
Unsmooth engine operation and noise may occur, during the procedure.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. The engine speed will be fluctuating during the test, and after the test it returns to normal idle running.
  3. If the function fails, check the test conditions and repair any faults.
