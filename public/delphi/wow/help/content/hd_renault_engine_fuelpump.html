[1673]Replace fuel pump

This function is used when replacing the fuel pump to adapt it to the engine control unit.

Test conditions:

  • Ignition on, engine off.

  • No faults in the system.

  • Battery voltage above 11.5 V.

Procedure:

  1. Select the "Replace fuel pump" function

  2. "Function complete" is displayed when learning is complete.

  3. Exit the function.
