[230]Code cruise control

This function is used to code or decode the cruise control function in the engine control module. On certain models recoding is required for several control modules in the vehicle for correct function, see manual for cruise control.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. Follow the instructions shown in the function.

  3. A dialogue box shows: "coding OK", press "OK" to exit the function.

  4. Turn off the ignition and exit communication with the car for 30 seconds.

  5. Turn on the ignition, re-establish communication with the car, and check that no fault codes are stored.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
