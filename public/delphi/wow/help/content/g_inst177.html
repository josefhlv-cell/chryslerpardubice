[933]Basic ignition position

Preconditions for the test:

  • Engine idling.

  • Engine temperature above 80 °C.

  • No faults stored.

Note:

  • To check and adjust basic ignition timing.

Procedure:

  • Choose the function: Basic ignition position

  • The ignition will now be locked, making adjustment possible.

  • Check the basic ignition setting with the ignition timing lamp. Prescribed value 2-7 ° before TDC.

  • If necessary, set the required value by turning the distributor. Setting value: 5 ±1° before TDC.
