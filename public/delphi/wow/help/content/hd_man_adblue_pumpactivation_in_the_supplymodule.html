[485]Test of pump in supply module

The test determines the pump's function in the supply module.

To avoid incorrect diagnosis it is very important that the pressure has been minimized via activation of "Breather valve AdBlue" before this test is run.

AdBlue-pressure shall reach 3 bar within 2 minutes.

Test procedure if above is not reached:

* Breather valve defective.

* Suction line clogged or leakage.

* Return line clogged or leakage.

* Filter clogged.

* Pump activated 40/week. (Max. volume of supply module)

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
