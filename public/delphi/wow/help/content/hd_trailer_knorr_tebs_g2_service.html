[90]Change service interval

This function is used to state desired service interval in km and date.

Test conditions:

  • Trailer supplied with electric power.

Procedure:

  1. Start the function.

  2. Enter the new service interval in km, press "OK".

  3. Enter the new date interval, press "OK".

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
