Transfer of VIN number
This function is used to transfer the VIN number to a new control unit.
Test conditions:
  • Locate the vehicle's VIN number.
  • Ignition on.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. A dialogue box shows the VIN number that is stored in the control unit, check this and press "OK".
  3. Is the VIN number correct, there is no need to perform this function. Press "Abort".
  4. A dialogue box shows where you can enter the vehicle's VIN number.
  5. Enter the vehicle's correct VIN number, press "OK".
  6. A dialogue box shows the new VIN number, press "OK".
  7. The function is done.
  • If the function fails, check the test conditions and repair any faults.
