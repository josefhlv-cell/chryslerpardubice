[26]Bleeding brakes

This function is used to bleed the brakes.

Note:

  • The bleeding is running for about 2 minutes but can be aborted if necessary.

Test prerequisites:

  • Battery voltage over 12V.

  • Ignition on, engine off.

Procedure:

  1. Start the function and follow the instructions in the program.

  2. If required, repeat the function.
