[1761]Reset adaptation values for rain sensor

This function is used to reset the adaptation value for the rain sensor. This shall be done when replacing windshield, rain sensor, control unit, or when incorrect adaptation value is suspected.

Test conditions:

  • Ignition on.

  • No faults in the system.

  • Switch windshield wiper in position "Off".

  • Well cleaned and dry windshield in the area around the rain sensor.

Procedure:

  1. Select the function: "Rain sensor adaptation". press "OK".

  2. Adaptation values are shown, press "OK".

  3. Adaptation is performed.

  4. New updated adaptation values are shown, press "OK".

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
