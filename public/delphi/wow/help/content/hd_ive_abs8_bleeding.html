[707]Bleeding the brake system

The brakes must be bled if air has entered the ABS system's hydraulic unit, or if brake function has deteriorated. The function takes around 350 seconds.

Note:

The test is performed automatically in the following order:

  • Left rear.

  • Left front.

  • Right front.

  • Right rear.

  • Before tightening,the brake nipples, check that the function is ready and the brake fluid does not contain air bubbles.

  • If you need to repeat the bleed, you must wait 5 minutes to cool the valves, or the system may be damaged.

Test conditions:

  • Ignition on.

  • Brake pedal depressed.

  • Brake nipples opened.

Procedure:

  1. Open the brake nipples.

  2. Start the function.

  3. Depress the brake pedal.

  4. Follow the instructions.

  5. The function is complete.

  6. Tighten the brake nipples.

    • If the function fails, check the test conditions and repair any faults.
