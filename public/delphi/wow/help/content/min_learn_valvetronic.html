[714]Learning of Valvetronic appropriation

This function performs learnin of the variable valve control's setting mechanism.

The function must be run after the following operations:

  • After all repairs of the variable valve control.

Test conditions:

  • ignition on, engine off

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is complete.
