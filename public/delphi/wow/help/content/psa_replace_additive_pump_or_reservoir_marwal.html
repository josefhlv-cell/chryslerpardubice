[336]Reset counter for additive

This function is used to reset the counter for total injected amount from the additive reservoir. The function shall only be done after replacing metering pump or additive reservoir according to the service instructions for the car.

Test conditions:

  • Ignition on, engine off.

  • All power consumers disconnected.

  • Battery voltage above 12V.

  • Additive reservoir filled or metering pump replaced.

Procedure:

  1. Start the function.

  2. A dialogue box shows if the function succeeded or failed.

  3. Complete the function and disconnect the diagnostic tool.

  4. Open the tank cap within the following minute for at least 5 sec. and close the tank cap again.

  5. The metering pump is now configured for start, and the system start takes place the next time the engine is started.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
