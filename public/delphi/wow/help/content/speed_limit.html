[1217]Disconnecting vehicle speed limit

Note:

The communication with ABS/ESP control unit is automatically aborted if the vehicle speed exceeds 10 km/h by a speed limitation.

It is possible to disconnect the vehicle speed limitation with this function and read the parameters when vehicle speed is over 10 km/h.

Observe:

  • Vehicle must be stationary when disconnecting.

  • ESP function is not active when the vehicle speed limitation is disconnected.

  • ABS function is always active.

  • Vehicle speed limitation is automatically reactivated when you exit communication with the ABS/ESP system.

Performance:

  1. Choose function: Disconnecting vehicle speed limit.

  2. A dialog presents: Operation succeeded/ failed.

  3. Press OK.

  4. The vehicle speed limitation is now activated.
