[669]Programming richness regulation

This function is used to program richness regulation for injectors.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. When the function is done, turn off the ignition for 30 seconds to store new values.

  3. Turn on the ignition.

  4. Check values of Data list Adapted lambda value; offset & and Increase of adapted lambda value.

  5. Test function of the injectors.
