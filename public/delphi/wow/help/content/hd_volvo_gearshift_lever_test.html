[1728]Testing electromagnet gearshift selector

This function is used to check the electromagnets in the lever carrier.

Start the test by checking that electromagnet "SOX1" is "Active" and that electromagnet "SOLF" is "Inactive", when the gear lever is in position "N". Status active/inactive is shown during the test.

Test conditions:

  • Parking brake applied.

  • Battery voltage above 20 V.

  • Engine off.

  • Gear lever in position N.

Procedure:

  1. Select the function, press "OK".

  2. A dialogue shows the test conditions, check these.

  3. Check that electromagnet "SOX1" is "Active".

  4. Check that electromagnet "SOLF" is "Inactive".

  5. Move the gearshift lever to a gear position (does not apply to automatic transmission). Now check that electromagnet "SOX1" is "Inactive".

  6. Move the gearshift lever from "N" towards "Hold". Check that electromagnet "SOX1" is activated for a second or two. It should not be possible to reach the "Hold" position directly since "SOX1" locks out the position for a few seconds.

  7. When the "Hold" position is obtained, check that electromagnet "SOLF" reaches status "Active".

  8. Activate electromagnet "SOX1" with the diagnostics program and feel with the gearshift lever that the electromagnet locks out from "Automatic" towards "Hold". "SOX1"="Active".

  9. Deactivate electromagnet "SOX1" with the diagnostics program and feel with the gearshift lever that the electromagnet does not lock out "Automatic " towards "Hold". "SOX1"="Inactive".

  10. Activate electromagnet "SOLF" with the diagnostics program and feel with the gearshift lever that the lever carrier is locked out. It is not possible to select or deselect a gear. "SOLF"="Active".

  11. Deactivate electromagnet "SOLF" with the diagnostics program and feel with the gearshift lever that the lever carrier is no longer locked out. "SOLF"="Inactive".

  12. The function is done.

    • If the function fails, check the test conditions and repair any faults.
