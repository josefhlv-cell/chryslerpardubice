[61]Speed limitation

This function is used to change the highest permitted speed for the vehicle.

Note:

  • Highest speed that can be programmed is 161 km/h.

  • Speed is written as km/h.

  • 1 mph = 1.6 km/h.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function, press "OK".

  2. Enter desired speed limit, press "OK".

    • A dialogue box shows: operation succeeded/failed.

    • If the function fails, check the test conditions and repair any faults.
