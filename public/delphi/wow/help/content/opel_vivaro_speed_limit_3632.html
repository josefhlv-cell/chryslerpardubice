Configure max. speed limitation
This function is used to configure the speed limitation.
Note:
The different alternatives for the speed limitation are:
  • 90 km/h
  • 100 km/h
  • 110 km/h
  • 120 km/h
  • 130 km/h
  • 250 km/h
  • Max vehicle speed.
Preconditions for the test:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. A dialogue box shows the current speed limitation.
  3. Press "OK" to change or select "Abort" to exit the function.
  4. Select desired speed limitation in the dropdown list and press "OK".
  5. After configuration is finished, the current speed limitation is shown.
