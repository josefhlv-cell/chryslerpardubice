[413]Basic setting of Haldex coupling

Basic setting adapts the control module for four-wheel drive to the valve for controlling the Haldex coupling. Adaptation shall be performed when valve for controlling Haldex coupling has been replaced.

Test condition:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. Basic setting starts and is done when the text "OK" is shown.

  3. Exit communication with the vehicle.

  4. Turn off the ignition for 50 seconds to store new values.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
