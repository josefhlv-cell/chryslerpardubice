[170]Code control module for parking assistance

When installing a new control unit or modified equipment in the car, the control unit for parking assistance must be coded for existing equipment. With this function it is possible to do the following:

  • Alt. 1: Read off and save old version code when replacing control unit.

  • Alt. 2: Possibility to change version code in existing control unit.

Note:

  • Incorrect version coding may reduce the car's safety / function.

  • Optic parking system is shown via radio display and is activated via reverse gear.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Alt. 1: With the defective control unit still installed. Start the function "Code control unit".

  2. Existing version code in the control unit is read out and shown. Select "Save to file" to save read-out version code. Name the file as desired and select a location where it is to be saved, press "Save". It may be suitable to name the file using the car's registration number and choose to save on the computer's desktop. Press "Cancel", exit the function, and exit communication with the car.

  3. A dialogue box with the text "Saved" confirms that the read version code is saved, press "OK".

  4. Existing version code shown in byte.

  5. Click on desired byte and enter the new value for current byte (see code table below), press "OK".

    Code number:Function:
    0 X X X X XWithout optic parking system, without back-up camera
    3 X X X X XWith optic parking system, with back-up camera
    1 X X X X XWith optic parking system, without back-up camera
    2 X X X X XWithout optic parking system, with back-up camera
    X X X X 0 XWithout trailer hitch
    X X X X 1 XWith trailer hitch (manually removable)
    X X X X 2 XWith trailer hitch (electric folding)
    X X X 0 X XManual transmission
    X X X 1 X XAutomatic transmission
    X X X X X1Multivan
    X X X X X2Commercial vehicles
    Coding example:

    With optic parking system, without back-up camera, trailer hitch (manually removable), manual transmission, Multivan= 110001

  6. You are asked if you want to code the system, press "YES" to perform coding, press "NO" to cancel.

  7. Version coding in progress. The new stored code is shown.

    • If coding fails, check that the version code is valid for the control unit in question.

  8. Press "OK" to exit the function and turn off the ignition for 30 seconds to save the new code.

  9. The function is done.
