[722]Accelerator calibration

This function must be performed if the accelerator has been replaced or repaired.

Note:

Check whether the accelerator pedal has a "kickdown" position. The "kickdown" position is when you can depress the pedal past a resistance position (full speed position), to the fully floored position.

If there is a fault in the function it is because the accelerator has not been in the correct position according to the instructions, or the accelerator is faulty.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 20V.

Procedure:

  1. Start the function.

  2. A dialogue box shows the test conditions; check these and press "OK".

  3. A dialogue box stating "Does the accelerator have a kickdown position?" is displayed. Press "Yes" or "No".

  4. A dialogue box stating "Release the accelerator pedal to idle position" is displayed. Press "OK".

  5. A dialogue box stating "Depress the accelerator to full speed position" is displayed. Press "OK".

  6. A dialogue box stating "Release the accelerator pedal to idle position" is displayed. Press "OK".

  7. A dialogue box stating "Depress the accelerator to full speed position" is displayed. Press "OK".

  8. A dialogue box stating "Release the accelerator pedal to idle position" is displayed. Press "OK".

  9. A dialogue box stating "Depress the accelerator to full speed position" is displayed. Press "OK".

  10. A dialogue box stating "Release the accelerator pedal to idle position" is displayed. Press "OK".

  11. A dialogue box stating "Depress the accelerator to the kickdown position" is displayed. Press "OK".

  12. A dialogue box states "Accelerator pedal learned" and live data is displayed.

  13. A dialogue box states "Function complete". Press "OK".

  14. The function is complete.

    • If the function fails, check the test conditions and repair any faults.
