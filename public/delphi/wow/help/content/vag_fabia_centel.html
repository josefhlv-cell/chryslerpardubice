[1272]Central electronic system configuration

When configurating vehicle systems you are refered to adaption channels in control unit. Each channel correspond to a function in control unit, channels and function vary depending on type of control unit. By changing the stored value in a channel you also affect its characteristic. When entering some channels a short text can be read out as help for configuration.

Note:

  • Faulty configuration can reduce car safety and/or performance.

  • See workshop manual for complete information on configuration.

  • On control units without index (ex. 6Q0937049) and with index B (ex. 6Q0937049B) must a login procedure be performed before configuration. The valid login code is 21343.

  • On control unit with index C (ex. 6Q0937049C) must not a login procedure be performed.

Test prerequisite:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • All electrical loads switched off.

  • Valid login performed for control units without index and control units with index B.

Procedure:

  1. Start the function 'Central electronic system configuration'.

  2. Enter channel from table in presented input field, confirm with 'OK'.

    • Function will be aborted if not valid channel is entered.

  3. Current channel value will be presented.

    • If current value is ok, the function can be aborted with 'No'

  4. Press 'Yes'. Enter new channel value in presented input field, confirm with 'OK'.

  5. If presented channel value is correct, press 'Yes' to store value.

    • If presented channel value is not to be stored, press 'No' to abort change.

  6. Exit function.
