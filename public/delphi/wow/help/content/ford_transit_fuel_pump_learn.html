[217]Basic setting of fuel pump

This function is used if any of the following components have been replaced:

  • Fuel pump, high pressure.

  • Fuel metering valve.

To enable running of the function, a warm-up phase is performed to reach the required temperatures. After completed function error code P026B will be stored in the control module.

Test conditions:

  • Battery voltage above 12V.

  • No faults in the system.

  • Fuel pipe temperature 26 - 54 °C.

  • Cylinder head temperature 56 - 94 °C.

  • Idle rpm 700-1,000 rpm.

  • Fuel rail pressure 19 - 32 MPa.

Procedure:

  1. Start the function.

  2. Run a warm-up phase, press "OK" when test conditions are fulfilled.

  3. Teach-in takes place in two steps, first temporary teach-in and then permanent teach-in.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
