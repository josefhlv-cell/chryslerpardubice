[557]Reset adaptation values for pressure sensor particle filter

This function is used to reset the adaptation values for the pressure sensor for the particle filter. Shall be performed if the particle filter has been replaced.

Test conditions:

  • Ignition on, engine off.

  • Transmission in neutral.

  • Parking brake applied.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Press "OK" to teach in new adaptation values.

  3. After the function has been run the ignition shall be off for at least 60 sec, follow instructions in the function.

  4. Function done.

    • If the function fails, check the test conditions and repair any faults.
