[532]Update the central data memory

This function updates the central data memory in the control unit ZDS and shall be used after a parameter setting has been changed in a control unit.

If the control unit is not updated after changing a parameter setting, a fault code is indicated in control unit ZDS' central data memory.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. A dialogue box shows test conditions, check these and press "OK".

  3. Update starts, follow instructions.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
