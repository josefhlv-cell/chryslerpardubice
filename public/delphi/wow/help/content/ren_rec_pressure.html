[1172]Enter recommended pressures

Test condition:

  • Engine off

  • Ignition on

Procedure:

  • Read from the table below which code is valid for the car.

  • Desired pressure is per axle(back/forth) and for high/low speed

  • Write the required code in the coding field(see e.g. below) and press the “OK” button

  • For example. If you want 2,0bar on front axle and 2,1bar on rear axle at low speed, 2,1bar on front axle and 2,2bar on rear axle at high speed Type: 919898A0 Thus: Front low(91), Rear low(98), Front high(98) and rear high(A0)

  • A dialogue box confirms: Operation succeeded / Operation failed

  • Front axle low speed recommended pressure

  • Rear axle low speed recommended pressure

  • Rear axle high speed recommended pressure
