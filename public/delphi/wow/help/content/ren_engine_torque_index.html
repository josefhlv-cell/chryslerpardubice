[1157]Programming of engine torque index

Conditions:

-Engine off

-Ignition on

This commando is used for configuration of the index of torque and brake definition.

Procedure:

-Type the code for which engine you want to configure the ECU for.

Ex. 4A01 if you wish to configure for a K4M.

Possible configurations:

  • K4M = 4A01

  • F4P = 5401

  • F4R/F5R = 5F01

  • F4Rt = 7D02

  • L7X = 9102

OBS! Use capital letters (A-F) and the figures 0-9.
