[681]Replace hydraulic kit

The function resets certain parameters in the controller that relate to the component being replaced.

The function must be performed when replacing the hydraulic kit.

When this function is performed fault code P290D (End of line / service self-calibration) is generated. In order to reset the fault codes, the "End of line / service self-calibration" function must be performed".

Note:

Perform the following functions in the following order!

  • Before replacing the hydraulic kit:

    1. Accumulator depressurisation.

  • After replacing the hydraulic kit:

    1. Replace hydraulic kit.

    2. Bleeding clutch.

    3. End of line/service self-calibration.

    4. Clutch self-calibration.

    5. Longitudinal acceleration signal learn.

Test conditions:

  • Ignition on.

  • Stop&Start function disabled.

Procedure:

  1. Start the function and follow the instructions in the program.
