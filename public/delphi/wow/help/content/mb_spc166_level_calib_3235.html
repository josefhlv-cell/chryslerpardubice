Calibrating level sensor
This function is used to calibrate the vehicle's level sensors.
Note:
Calibration only needs to be run after the following events:
  • A level sensor is replaced.
  • The control unit is replaced.
  • After an incorrect calibration.
Test conditions:
  • Ignition on, engine off.
  • Calibration shall be performed on a wheel alignment rig.
  • "Romess"-tool to measure chassis angle.
Procedure:
  1. Start the function.
  2. A dialogue box shows current levels for the chassis. Use the dialogue box to adjust the level of the four measuring points to the approved range between ±20 mm.
  3. Continue in the function when the level is approved.
  4. Read the four levels with the "Romess"-tool and enter the values in the dialogues that are shown. Approved angle for front axle is 8,4-10,8°, and for rear axle 1,3-3,6°.
  5. Save the new values to exit the function.
If the function fails, check the test conditions and repair any faults.
