[1736]Programming remote control

When replacing a defective remote control or increasing number of remote controls, these must be adapted to the control unit. It is also necessary if the code in the remote control and control unit no longer match, which may occur if the transmitter button is pressed in often when outside the system's operating range.

  • All remote controls must always be adapted again, even the existing ones.

  • Time to adapt all remote controls may not be longer than fifteen seconds.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

  • All power consumers disconnected.

Procedure:

  1. Select the function "Adaptation of remote control", press "OK".

    • Note that old transponders are now erased.

  2. A dialogue box is shown, enter the number of remote controls to be adapted (including existing ones).

  3. Press "OK" and press within 15 seconds and hold in the unlock button for at least one second in order on each remote control to be adapted.

    • A flashing indicator confirms that the remote control is adapted.

  4. Adaptation is cancelled when:

    • The number of remote controls to be adapted is reached.

    • A button is pressed down several times on the same remote control.

    • Time for adaptation exceeds 15 seconds.

  5. Press "OK" to exit the function.

  6. Turn off the ignition, remove the key, and check function of all remote controls.

  7. The function is done.

    • If the function fails, check the test conditions and repair any faults.
