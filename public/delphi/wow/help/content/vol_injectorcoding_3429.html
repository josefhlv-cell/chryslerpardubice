Injector programming
This function is used to recode the injectors after replacement.
Note:
There are three different classes of injectors. All cylinders must have the same class at all injectors!
The control unit must be programmed with the same class that is written on the injector!
Test prerequisite:
  • There is an independent number on the top of the injectors, indicating which class the injectors have.
Procedure:
  • Ignition on, engine off.
  • Start the function and follow the instructions in the program.
