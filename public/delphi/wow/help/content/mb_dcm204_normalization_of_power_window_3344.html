Initiate window lift
This function describes how to manually initiate the window lift.
  • To initiate the window lift, the following steps must be done:
    • Open the window fully with the window lift switch "Down".
    • Close the window fully with the window lift switch " Up".
    • If the window reverses at the upper stop, release the window lift switch and then close the window with the window lift switch within 2 seconds, run the window to the upper stop.
    • When the window is at the upper stop position, the window lift switch must remain in position "Up" for another 2 seconds.
There is a data list that presents if the window lift is initialized or not.
Test prerequisites:
  • Ignition on.
  • Battery voltage above 12V.
Procedure:
  1. Start the function, press OK.
  2. A data list presents status for the window lift.
  3. Initialize the window lift as described above.
    • If the function fails, check the test conditions and repair any faults.
