[1253]Climate regulation

If the climate control unit has been replaced, or a new position motor for the temperature damper has been installed, a basic setting must be performed. When the climate regulation basic setting is performed, the control unit learns the positioning motor end positions.

Test prerequisites:

  • The battery voltage should be above 11.5 V.

  • Ignition on, engine off.

  • No fault codes should be stored in the fault memory.

Performance:

  • Choose function: Climate regulation.

  • The temperature damper position motors drive to their end positions during the basic setting. The text: "motoren lernen" is presented and changes after a while to: "endanschlage lernen".

  • Wait about 20 seconds (the climate control unit registrates the position motors new values and store them).

  • End the function. Switch OFF/ON the ignition, wait about 15 seconds for possible fault codes to be stored.

  • Re-establish the communication and check if any fault codes have been stored.
