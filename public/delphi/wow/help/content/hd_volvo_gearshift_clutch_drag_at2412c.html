[1742]Testing clutch drag

This function is used to check clutch drag.

Test conditions:

  • Parking brake applied.

  • The air pressure in the transmission shall be 650-1,000 kPa.

  • Engine on.

  • Battery voltage above 20 V.

  • Gear lever in position N.

Procedure:

  1. Select function, press "OK".

  2. A dialogue box shows test conditions, press "OK".

  3. A dialogue box with values from the test is shown, check that they are within min. and max. values, press "OK".

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
