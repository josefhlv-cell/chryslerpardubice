[300]Basic setting of throttle body and EGR

This function is used for basic setting of throttle body (ETB) and EGR. The function is used when any of the components have been replaced or reinstalled after repair.

The engine should be at operating temperature before running this function.

Test conditions:

  • Ignition on.

  • Engine temperature between 60 °C - 95 °C.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
