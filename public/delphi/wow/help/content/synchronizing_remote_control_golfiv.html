[1221]Synchronising a remote control

Synchronisation:

Synchronisation of a remote control (transponder) is necessary when replacing a faulty remote control or when increasing the number of remote controls (maximum four). It is also necessary if the code of the remote control and the control unit no longer agree. This may happen if the transmit button is frequently pressed when out of range.

Note:

New ignition keys must also be adapted to the immobiliser control unit.

Method:

  1. Insert one of the ignition keys in the ignition lock and turn on the ignition.

  2. Choose the function. Delete remote controls (all programmed remote controls are deleted).

  3. Choose the function. Synchronise remote control. Press OK.

  4. A dialog box presents: Operation succeeded/failed.

  5. Within 15 seconds, press one of the buttons on the remote control that is to be adapted for at least one second.

  6. Confirm with the OK button.

  7. Repeat from step 3 until all remote controls have been synchronised.

  8. Switch off the ignition and remove the ignition key.

  9. Check the operation of all the remote controls.

  10. Synchronisation is terminated automatically when the maximum number of remote controls that can be adapted is reached (four).
