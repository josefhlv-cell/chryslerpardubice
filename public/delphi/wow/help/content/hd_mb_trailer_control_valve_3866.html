Trailer control valve
This function is used to test the brake pressure to the trailer control valve.
Test conditions:
  • Connect pressure gauge to coupling head (yellow) for brake pressure of trailer.
  • Compare the pressure gauge pressure values against the actual values shown.
  • The engine at idle to reach enough air pressure.
  • Parking brake released.
Procedure:
  1. Start the function.
  2. Press the "OK" button.
  3. The test is run automatically.
  4. The function is done.
    • If the function fails, check the test conditions and repair any faults.
