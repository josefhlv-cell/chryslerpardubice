Replacing UniAir module
This function is used to reset the adaption values for "UniAir" in the engine control module, after replacing of the UniAir module.
Note:
If this procedure has not been run the control unit cannot estimate exact air and gasoline flow and the following consequences are likely to occur:
  • Possible that unmotivated diagnostic requests for all components related to the throttle body and throttle control's position may occur.
  • Very poor driveability.
The function must be performed after following operations:
  • Replacing UniAir module.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function and follow the instructions in the program.
