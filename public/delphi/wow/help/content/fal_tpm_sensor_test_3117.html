TPM sensor test
This function is used to check communication between tire pressure sensors and TPM ECU. The function should be run after new sensors are programmed.
Note:
A driving sequence should be performed in the function, so that the sensors start sending out signals. During the driving sequence it is important that the speed is above 35 km/h for at least 30 seconds.
Note that a signal shall be received from all four (4) tire pressure sensors to pass the test.
In case of a failed test, check the following:
  • That correct sensor-ID is stored in the TPM ECU using a TPM tool, compare with a reading from the diagnostic tool.
  • Check that the sensors work.
  • Identify and replace damaged sensors. Then perform new programming of sensor-ID using the function "Programming tire pressure sensors".
If a TPM tool is not available:
Let the vehicle stand stationary with the ignition off for more than 20 minutes, then drive the vehicle for at least 20 minutes at a speed not below 25 km/h. Then read error codes with diagnostic tool.
Test conditions:
  • Ignition on, engine on.
  • A driving cycle shall be run in this function.
Procedure:
  • Start the function, press "OK".
  • Sensor test is run.
  • Perform driving cycle according to instructions.
  • Press "OK" to continue.
  • Sensor data is retrieved.
