[1075] Zero compensation of the lateral acceleration sensors

This basic setting is used to zero-compensate the value from the lateral acceleration sensor.

This must be done if:

  • The ABS control unit has been replaced.

  • The lateral acceleration sensor has been replaced.

  • An error code that requires zero compensation is stored in the ABS control unit.

Note:

The basic setting can only be done after entering a login code. This is done in the programming menu, using the function: Login

During basic setting, the ignition must not be switched off.

Method:

  • Position the car on a flat and level surface.

  • Choose the basic setting: Zero compensation of the lateral acceleration sensor.

  • The text: ”Adaption correct” confirms that zero compensation has been done.

  • If the value for the lateral acceleration sensor is too high, zero compensation will not be accepted (adaption not possible). The value is presented in data list four.
