[263]Regeneration of particle filter

This function cleans the particle filter from soot particles by burning them off using an increase in the exhaust temperature. In certain driving conditions, the particle filter can not be cleaned automatically, e.g., in continuous city driving. Then this function is used to force a regeneration. This only has to be done if the particle filter's degree of filling is more than 40 %. A regeneration in progress is indicated in the instrument panel with the control light for particle filter being lit.

Note:

  • If degree of filling is more than 90 % no regeneration should be done manually due to risk of fire in the particle filter. The degree of filling for the particle filter can be read out as data list parameter.

  • Regeneration can be cancelled if the ignition is turned off.

Test conditions:

  • Engine on.

  • Engine oil temperature above 70°C.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Follow the instructions shown in the following dialogue boxes.

  3. Press "OK" to exit the function.

    • If the function fails, check the test conditions and repair any faults.

  4. Drive the car in fourth or fifth gear at approx. 2,000 rpm until the control light for particle filter turns off.

  5. Check and solve any fault codes stored in the system.

  6. The function is done.
