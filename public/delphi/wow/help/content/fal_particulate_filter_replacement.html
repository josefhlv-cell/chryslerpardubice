[651]Replacement particulate filter

Note:

This procedure should be run when the particulate filter is replaced. The command updates the parameters in the ECU and resets the number of incorrect regenerations.

After this procedure is finished the particulate filter should be regenerated.

Test conditions:

  • Ignition on.

Procedure:

  1. Select the function 'Replacement particulate filter' and follow the instructions.

  2. When this action is finished, select the function for particulate filter regeneration and run it.
