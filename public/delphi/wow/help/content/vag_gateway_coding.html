[69]Configure gateway

To enable the car's different control units connected to the CAN-bus to communicate with each other they are connected in a control unit called gateway. The gateway control unit communicates with all control units in the car. When reading out the gateway coding, control units that are programmed in the car are shown as "coded". Others are shown as "Not coded". If a control unit for trailer is to be retrofitted, it requires that the status for this control unit is changed to "coded" in the gateway control unit to enable the other control units to exchange information with the control unit. It is also possible to decode control units from the gateway.

Note:

  • Incorrect coding may reduce the car's function.

  • Coding of the gateway control unit takes place according to a procedure in several steps that is possible to cancel/abort.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

  • All power consumers disconnected.

Procedure:

  1. Select the function.

  2. A dialogue box with scroll list shows the control units that are possible to connect to the car. Control units that are programmed are designated as "Coded" and non-programmed as "Not coded".

  3. To program or deprogram a control unit, select the relevant control unit in the scroll list, press "OK".

  4. Coding is performed.

  5. "Coding OK" is shown if coding is successful.

  6. Press "OK" to exit the function.

  7. Check that no fault codes are stored in any of the relevant control units.
