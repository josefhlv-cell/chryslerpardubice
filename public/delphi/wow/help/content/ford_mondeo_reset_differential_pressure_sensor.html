[199]Reset adaptation values for differential pressure sensor

This function is used when the differential pressure sensor has been replaced. Learned values for the sensor will be reset in the engine's control unit.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function.

  2. Follow the instructions in the programme.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
