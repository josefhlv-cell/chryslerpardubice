[1564]Self test

This function is a self test of the system, where a number of components selected by the control unit are loaded (activated). If the control unit detects an unreasonable value on any component a fault code is stored in the system. The function finishes with a reading of fault codes where possible fault codes stored in the system are displayed.

Note:

  • Erase fault codes before the self test to avoid that historical fault codes are displayed.

  • Do not activate switches or controls during the test.

Test prerequisites:

  • Battery voltage above 12V.

  • Vehicle stationary.

  • Engine idle running.

  • Parking brake applied.

  • Gear selector in P position.

  • Vehicles with diesel engine - exhaust gas temperature higher than 100 °C (212 °F).

  • Vehicles equipped with sport/economy-button may need to be pushed on/off during the self test.

Procedure:

  1. Choose the function: "Self test".

  2. The self test starts and the components are activated one by one.

    • The self test can be aborted by "Abort".

  3. When the self test is finished a reading of fault codes is automatically performed.
