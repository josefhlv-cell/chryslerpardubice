[1733]Testing gears

This function is used to check that the engaged gear matches the selected gear.

A noise is heard from the transmission when a gear is activated. Check that the engaged gear matches the selected gear. If the engaged gear does not match the selected gear, it may be because the pinions in the transmission are not meshing correctly. In this case, try to move the vehicle slightly and reactivate. The system air pressure can also be seen during activation; it should drop slightly with each activation.

Test conditions:

  • Parking brake applied.

  • Air pressure in transmission between 550-1,000 kPa.

  • Engine off.

  • Battery voltage above 20 V.

  • Oil temperature in transmission above 15°C.

  • Gear lever in position "N".

Procedure:

  1. Select the function, press "OK".

  2. Select the gear to be activated.

  3. Listen for the activation noise and check that the engaged gear matches the selected gear.

  4. Repeat steps 2 and 3 for the other gears.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
