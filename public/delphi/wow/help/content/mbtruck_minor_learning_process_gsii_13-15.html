[1541]Minor programming for control unit GS II gear control.

The minor programming has to be carried out if the transmission (same transmission type) or one of the position sensors for clutch, splitter, range, gear or gate has been replaced.

The minor programming must be carried out if the clutch has been replaced or if work has been done on the clutch, clutch actuator, clutch booster or clutch travel sensor.

Note:

On vehicles with EAS, the clutch graph must be erased in control unit FR.

The minor programming will recalculate the position values of the position sensors for clutch, splitter, range, gear and gate.

During the programming it is essential that the instructions to fully depress and fully release the clutch pedal are followed, in order to avoid damaging of the transmission due to incorrect learned data of the clutch.

On vehicles with EAS, the clutch operation is done automatically.

On the display the splitter arrows will flash alternately during the entire programming.

The neutral pushbutton is located on the passenger side of the gear lever.

If the programming is interrupted by a fault, a fault code is presented on the display. For explanation of the fault code see the list below.

Test prerequisties:

  • Ignition on, engine off.

  • No consumers active.

Procedure:

  1. Ignition off.

  2. Parking brake applied.

  3. Depress the clutch pedal fully and hold (Not relevant for EAS vehicles).

  4. Press the neutral pushbutton and hold it during the entire programming.

  5. Switch on ignition.

  6. Start engine when Neutral (N) flashes on the display.

  7. Release the clutch pedal fully when the buzzer sounds for the 1:st time. (Not relevant for EAS vehicles)

  8. Depress the clutch pedal fully and hold when the buzzer sounds for the 2:nd time. (Not relevant for EAS vehicles)

  9. If the readout N (Neutral) appears on the display, the programming has been successfully completed.

    If the programming failed: redo the programming, adjust possible faults in the control unit GS II.
