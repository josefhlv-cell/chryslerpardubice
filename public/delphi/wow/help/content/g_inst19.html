[947] Idling contact

Cars 10.94 >

Test condition:

  • Ignition on.

  • No faults stored.

Note:

  • Setting is only necessary when replacing the throttle unit or the lower part of the injection unit.

  • The idling contact can only be set when the pushrod of the throttle unit is fully extended.

  • If the throttle is opened to gain access to the stop screw, the control unit moves the throttle pushrod back. To push the pushrod out again, the basic adjustment function must be chosen again.

  • When correcting the stop screw, the operation of the idling contact must be checked.

  • On quitting basic setting, the throttle unit pushrod must return to its initial position.

Check the idling contact:

  • Choose the basic setting requirements function.

  • Check that these requirements are met.

  • Choose the idling contact function.

  • Note the throttle sensor value, track 1. Prescribed value 196-200.

  • If the prescribed values are not reached, remove the induction air cover.

  • Correct the setting with the stop screw. Setting value: 198 ± 1.
