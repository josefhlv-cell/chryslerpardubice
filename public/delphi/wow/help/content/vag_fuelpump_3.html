[1277]Fuel system venting

If there is air in the fuel system after a repair has been performed, it is possible to ventilate the system with this function by activating the fuel pump. This function activates the fuel pump for 30 seconds.

Note:

  • This function shall only be performed on a sealed fuel system.

Test prerequisities:

  • Ignition on. Engine off

  • No faults stored.

  • Battery voltage above 12 V.

  • No leakage in the fuel system.

Procedure:

  • Choose the function: Fuel pump activation. The fuel pump starts (the value for the fuel pump status changes to: "Pump on") and runs for 30 seconds.

  • The fuel pump stops and shuts off for 30 seconds and the status for the fuel pump changes to "Pump off".

  • Exit the function.
