[1737]Testing PWM-valves and clutch

This function is used to check the clutch cylinder, air leakage, and clutch performance.

Values are shown for the PWM-valves during the test. Check that they are within min. and max. values.

Test conditions:

  • Parking brake applied.

  • Air pressure in transmission 650-1000 kPa.

  • Engine off.

  • Battery voltage above 20 V.

Procedure:

  1. Press "OK" to start the function.

  2. A dialogue with test conditions is shown, press "OK".

  3. A dialogue with values from the test is shown, check that they are within min. and max. values, press "OK".

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
