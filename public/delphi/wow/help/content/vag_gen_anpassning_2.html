[1281]General-purpose configuration

When configurating vehicle systems you are refered to the adaption channels in the control unit. Each channel correspond to a function in the control unit. Channels and functions vary depending on the type of control unit. By changing the stored value in a channel you also affect its characteristic. When entering some channels a short text can be read out as a help for configuration. Channels and values are availible in a workshop manual or similar.

Note:

  • The workshop manual with channels and values should be available.

  • Faulty configuration can reduce car safety and/or performance

Test prerequisites:

  • The battery voltage should be above 12V.

  • Ignition on, engine off.

  • All the electrical loads should be switched off.

Performance:

  1. Start the function 'General-purpose configuration'.

  2. Enter the channel in the presented input field, confirm with 'OK'.

    • The function will be aborted if a valid channel is not entered.

  3. The current channel value will be presented.

    • If the current value is ok, the function can be aborted with 'No'

  4. Press 'Yes'. Enter the new channel value in the presented input field, confirm with 'OK'.

  5. If the presented channel value is correct, press 'Yes' to store value.

    • If the presented channel value is not to be stored, it is possible to change the value with "No" (from step 3).

  6. If the value is stored, a dialog box presents: "Stored in memory".

  7. Confirm with OK to exit the function.
