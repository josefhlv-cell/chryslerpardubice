[1371]Tyre pressure monitoring (RKA)

When a basic setting of the tyre pressure monitoring (RKA) is performed, the ABS control unit is reset to delivery condition. The basic setting must be performed when:

  • A system fault is indicated ( the RKA lamp lights continuously) and the fault code 2214 is stored in the ABS/ESP control unit.

Note:

  • After the basic setting, a manual calibration of the tyre pressure monitoring must be performed.

  • The basic setting can only be done after entering a login code. Use the function: Login.

Test prerequisites:

  • Ignition on, engine off.

  • The battery voltage should be above 12V.

Performance:

  • Choose the function: Login. Enter the login code: 40168, press OK.

  • Choose the function: "Tyre pressure monitoring".

  • When the basic setting is performed, "Adaption succedded" / Adaption not possible is indicated.

  • Exit the function.

  • Perform a manual calibration by pressing the ASR/ESP and the tyre pressure monitoring buttons simultaneously for at least 2 seconds. After a succedded calibration a receipt tone is heard.
