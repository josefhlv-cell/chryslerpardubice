[1421]Climate regulation

If the climate control unit has been replaced, or a new position motor for the temperature damper has been installed, a basic setting must be performed. When the climate regulation basic setting is performed, the control unit learns the positioning motor´s end positions.

Test prerequisites:

  • The battery voltage should be above 11.5 V.

  • Ignition on, engine off.

  • No fault codes should be stored in the fault memory.

  • Correctly installed and connected.

Performance:

  • Choose the function: Climate regulation.

  • The temperature damper position motors drive to their end positions during the basic setting. The text: "Adaption in progress" is presented and changes after a while to: "Adaption OK".

  • Wait about 20 seconds (the climate control unit registrates the position motor´s new values and stores them).

  • End the function. Switch OFF/ON the ignition, wait about 15 seconds for possible fault codes to be stored.

  • Re-establish the communication and check if any fault codes have been stored.

    • If the function fails, check test prerequisites and repair possible fault codes.
