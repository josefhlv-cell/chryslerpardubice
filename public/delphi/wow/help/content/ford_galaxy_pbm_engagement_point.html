[362]Reset engagement point for clutch

This function is used to erase stored engagement point for the clutch. The function is used when the clutch has been replaced to enable adaptation of the new clutch.

Test conditions:

  • Ignition on.

  • Battery voltage above 12V.

  • Vehicle stationary.

  • The vehicle must stand on level ground.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
