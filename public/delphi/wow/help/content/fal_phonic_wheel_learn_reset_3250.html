Calibrate rpm sensor
This function is used to learn the new calibration values to the control unit after work has been done or if the inductive rpm sensor has been replaced (See procedures in service manual). Before adjusting, the adaptation values shall be reset with the function "Resetting self-adaptation parameters".
After calibration, fault code ”P1300 Phonic wheel adaptation” may appear. To erase the fault code the diagnostic instrument must first be disconnected. Engine temperature must be above 85 °C and rpm should be above 5500 rpm 3-5 times. Press down the accelerator pedal until the engine rpm is above 5500 rpm and then release the pedal and let the engine go to idle.
Note:
Turn off the ignition for at least 60 seconds to store the new values.
Test conditions:
  • Ignition on.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. The function is done.
    • If the function fails, check the test conditions and repair any faults.
