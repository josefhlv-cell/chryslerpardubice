Bleeding the cooling system
To bleed the coolant circuit, the coolant pump may be activated briefly.
This function is used to start the coolant pump briefly.
Test conditions:
  • Engine idling.
  • Place the vehicle on a level surface.
  • Parking brake applied.
  • Gear selector in position P.
  • Refrigerant compressor turned off.
  • Check that the steering wheel is straight and the front wheels point straight ahead.
  • The throttle pedal and brake pedal should not be operated.
  • Transmission temperature 30-100 C°.
Procedure:
  1. Start the function.
  2. The coolant pump starts and runs for max. 2 minutes.
  3. The function can be aborted at any moment during the process.
  4. The function is ended after 2 minutes.
