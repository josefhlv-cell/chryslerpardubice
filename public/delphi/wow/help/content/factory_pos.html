[837]Reset factory mode

Conditions:

- Ignition On. - Enter “Security access” mode before reading or programming.

Description:

In vehicle manufacturing the vehicle is set to factory mode.

Or when a new ECU is installed. Some functions are disabled.

The reason is to limit battery usage. First read status of factory mode.

If the vehicle is set to factory mode, use the ”Reset factory position” programming to

set the vehicle in normal mode.
