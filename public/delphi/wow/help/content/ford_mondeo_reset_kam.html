[149]Reset adaptation values in control module

This function resets the engine control module to its nominal values and is used when any component in the engine management system has been replaced.

Test conditions:

  • Ignition on, engine off.

  • Vehicle stationary.

Procedure:

  1. Start the function.

  2. Follow the instructions.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
