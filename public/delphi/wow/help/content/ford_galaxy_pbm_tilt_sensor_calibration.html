[358]Calibrate tilt sensor

This function is used to calibrate the tilt sensor.

Test conditions:

  • Ignition on.

  • Battery voltage above 12V.

  • Vehicle stationary.

  • The vehicle must stand on level ground.

  • When the function is in progress, no vibrations are permitted.

  • Vehicle unloaded without driver or passengers.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
