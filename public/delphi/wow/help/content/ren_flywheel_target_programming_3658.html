Initiation flywheel sensor
This function is used to initiate the sensor for the flywheel top dead center.
Note:
Only perform this function if the sensor has been replaced. After the function has been completed, the following procedure must be performed during driving:
Decelerate, with all the pedals released, between 1800 rpm to 1400 rpm on the third gear for manual transmission and on the second gear for automatic transmission, for at least 3 seconds with a coolant temperature above 35°C.
Then make another deceleration, with all the pedals released, between 3500 rpm to 3000 rpm on the third gear for manual transmission and on the second gear for automatic transmission, for at least 14 seconds with a coolant temperature above 35°C.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Press "OK" to start the function.
  2. After completed function, perform the procedure as described above.
