Configuration of AUX input on Haldex EB+
This function is used to configure the selected AUX input. If the input already has a configuration, it will be overwritten.
Test conditions:
  • The trailer is energised.
  • The trailer is secured and cannot start to roll.
Procedure:
  1. Press "OK" to start the function.
  2. Select the function to be configured to the AUX input.
  3. Answer the different pop-up boxes that appears and press the "OK" button.
  4. Some functions are only to answer by pressing the "OK" button.
  5. Exit by pressing the "OK" button in the box.
  6. Configuration of trailer lamp, service lamp, AUX power and retarder, requires no further information, except that you confirm with "OK" button.
  7. Configuration of Colas (manual air suspension actuation), requires activation time and activation/deactivation speed.
  8. Configuration of steer axle lock requires lock/unlocking speed, if it is lift axle depending and if you want it to be inverted.
  9. Configuration of ILAS-E front/rear (lift axle) requires at which % of the air suspension pressure it shall go down or up. Select which sensors that is connected to the axle. Select if the axle shall have a speed depending raising or lowering. Select the speed that you want it to raise to and the speed it shall lower to. Have you selected the axle not to be speed depending, will it not be raised or lowered by the speed. Configure the traction assist axle at which % of overload you want it to go down and at which speed it shall go down. The last choice is lifting axle button function when pushing it for 5 sec., if the axle shall have a permanent up and down raising or turn off the lifting axle function. If you choose to turn off the lifting axle function, the function is back at the next startup.
