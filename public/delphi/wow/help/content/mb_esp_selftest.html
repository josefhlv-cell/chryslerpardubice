[1498]ESP driving test

This driving test is used to check the sensor signals from: steering angle, lateral acceleration, brake pressure and the yaw rate sensor. The test must be done if any of the components of the ESP (Electronic Stability Program) system has been removed or replaced.

Note:

  • Once activated, the ESP driving test can not be interrupted.

  • If the ESP driving test has been activated, but not performed correctly, fault codes will be stored in the fault memory.

  • During the ESP driving test, the ignition must not be switched off.

Test prerequisite:

  • The engine should be running.

Performance:

  1. Choose the function: ESP driving test, press OK.

  2. Exit the function and diagnosis. The ABS indicator lamp is turned on and the ASR indicator lamp is flashing.

  3. Depress the brake pedal until the ASR indicator lamp is given light. (The driving test is now activated.)

  4. Perform the test drive within 30 seconds, with a speed over 7 km/h through a left curve. Note: There must be no ABS/ESP regulation during the test drive.

  5. The ESP driving test has been performed correctly if the ABS and ASR indicator lamps go out.

    If the ABS/ASR indicator lamp is still turned on, the ESP driving test has not been done. Re-activate the test by continuing from step 3.
