[478]Adblue circuit test with injection

This test is automatic and consists of 4 phases flushing phase, pressurizing phase, dosing phase, and pressure reduction phase. The purpose of the test is to check the amount of AdBlue that the system delivers within a certain time, in addition to controlling the amount so that the test can be used to trace mechanical faults in the dosing module and Adblue hoses. The test runs for 400 seconds. The first time the test is run the result may be lower due to air bubbles in the system.

Approved result is 129 ml +/- 10%.

Test conditions:

  • Ignition on, engine off.

  • Voltage above 20V.

  • AdBlue tank temperature above -5 °C.

  • Air pressure above 8,000 mbar.

  • Loosen the dosing line by the injector and place in a measuring beaker.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. Function done.

  4. Reinstall the dosing line.

    • If the function fails, check the test conditions and repair any faults.
