Code control unit
This function is used to reset the teach-in variant coding for the ESP-system. Coding is done if the ESP-unit or control unit has been replaced or if fault code C1702 is active with the MIL-light on. When the function is run the new variant coding will be programmed.
If the function is cancelled or fails, check fault codes and test conditions.
If the vehicle is equipped with Smart parking assist system (SPAS), the button to this is placed in the centre of the instrument panel.
Test conditions:
  • Ignition on, engine off.
  • Battery voltage above 12V.
  • No fault codes should be stored in the fault memory.
  • Position the car on a flat and level surface.
  • Wheels in a straight-ahead position.
  • Correct air pressure in tires.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. The function is done.
