Self-test of climate control unit
This function is used to test certain components in the climate control.
Test prerequisites:
  • Engine running.
  • Warm engine.
  • Fan control to maximum.
  • If the function fails, check test conditions and repair any faults.
Procedure:
  1. Start the function.
  2. Follow the instructions shown in the dialogue boxes.
  3. Check the function of the component.
  4. A dialogue box shows: Function done/failed.
