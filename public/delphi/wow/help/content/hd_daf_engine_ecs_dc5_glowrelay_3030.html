Checking the glow relay
This control is used to activate/deactivate the glow relay.
Note:
When the remaining activation time is 0 seconds, activation is terminated automatically.
Test conditions:
  • Ignition on.
  • Engine off.
Procedure:
  1. Check test conditions.
  2. Start the function.
  3. Activate/deactivate the glow relay.
  4. Check the status.
  5. Press "OK" to exit the function.
  6. The function is complete.
