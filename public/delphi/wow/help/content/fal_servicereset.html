[1493]Reset service message

Note:

  • When a service message is reset, the current kilometre value is saved for countdown to the next service.

  • When a service reset is performed the service counter is decreased by 1 and can not be reset to the old value.

Test prerequisities:

  • Ignition on, engine off.

Procedure:

  1. Press OKto start the function.
