[626]Basic setting of steering angle sensor

This function is used to adapt steering angle sensor to the control unit. This should be done when:

  • The control unit for ABS has been replaced.

  • The steering angle sensor or control unit for steering wheel electronics has been replaced.

  • Work that affects the chassis geometry has been done.

  • Error code 00778 is stored in the control unit.

Note:

Check that the steering angle sensor is in zero position before removing (this value can be read out via data list).

Test conditions:

  • Engine on.

  • Control unit correctly coded.

Procedure:

  1. Start the engine.

  2. Turn the steering wheel approx. 30° to the right and left, turn back the steering wheel to horizontal position (tolerance +/-5°).

  3. Start the function.

  4. When the text "Adaptation steering angle sensor in order" is shown the basic setting is finished, press OK to exit.

  5. Exit communication with the car and turn off the ignition for 30 seconds.

  6. Turn on the ignition, re-establish communication with the car, and check that no fault codes are stored.

  7. The function is done.

    • If the function fails, check the test conditions and repair any faults.
