Control after completed main battery capacity automatic measurement
This function should be used after the function "Main battery capacity automatic measurement" has been completed.
Note:
Check that the data list "Execution status" has the status "Completed" and that the data list "Fault status" has the status "No fault".
Also check that the data lists "Automatic capacity measured result history 1" and "Automatic capacity measured odometer result history 1" has been updated to current values.
Unless the data lists have been updated according to the above description, the function "Main battery capacity automatic measurement" must be restarted.
Preconditions for the test:
  • Ignition on.
Procedure:
  1. Start the function and follow the instructions in the program.
