Adaptation of torque converter
This function is used to run an adaptation of the torque converter and shall be performed in case of complaints about the torque converter's engagement.
Note
The adaptation consists of two steps:
  1. Adaptation via cold-start.
  2. Adaptation via torque ranges.
Test conditions:
  • Engine idling.
  • Gear selector in position "D".
  • Coolant temperature < 20 °C.
Procedure:
  1. Start the function.
  2. A dialogue box shows which coolant temperature shall be reached during driving.
  3. After the temperature is reached, the vehicle shall be stopped according to the dialogue box.
  4. Driving cycle is run for the following temperatures: 20, 40, 60, 80 °C.
  5. The function ends after completed driving cycles.
