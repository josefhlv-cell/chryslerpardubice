[169]Reset adaptation values for air filter

This function resets the adaptation values for air filter. This shall only be done at:

  • Air filter replacement.

Test conditions:

  • Battery voltage at least 12 V.

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Confirm with "OK". The adaptation starts and is done when "Function done" is shown.

  3. Press "OK" to exit the function.

    • If the adaptation failed, check test conditions.

  4. The function is done.
