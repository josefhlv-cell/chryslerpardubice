Activating electro-mechanical power steering
This function must be run if work has been done on the steering. The function will automatically assess and perform correct activation.
Note:
This function must be performed if the control unit or the electric motor for the electro-mechanical power steering has been replaced.
Test conditions:
  • Engine idling.
  • The vehicle must stand on level ground.
  • The steering wheel stands straight and the front wheels point straight forward.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
