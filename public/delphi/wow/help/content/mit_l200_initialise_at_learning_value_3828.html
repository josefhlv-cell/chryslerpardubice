Reset learning value
This function is used to reset the learned values in the automatic transmission control module.
Note:
The function must be run following replacement or repair of the following:
  • Replacing the automatic gearbox
  • Replacing valve housing
  • Installing engine
  • Replacing solenoid valve
This reset will also initialize the INVECS-2 learning value.
Preconditions for the test:
  • Ignition on, engine off.
  • Gear selector in position P.
Procedure:
  1. Select the function and follow the instructions.
