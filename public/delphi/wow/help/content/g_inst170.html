[926]Tank ventilation system

Preconditions for the test:

  • Engine idling.

  • No faults stored.

  • Engine temperature above 60 °C.

  • Induction air temperature below 60 °C.

  • All electrical loads switched off.

  • Gear selector set to ”P/N”.

Note:

  • To check the tank venting system.

Procedure:

  • Choose the function: Tank ventilation system.

  • The diagnostic status field changes from ”Test off” to ”Test on”.

  • Let the engine idle until the tank ventilation system changes from ”Test on” to ”TVV OK / TVV not OK”.
