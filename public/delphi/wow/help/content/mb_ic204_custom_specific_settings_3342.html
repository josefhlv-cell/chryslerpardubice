Coding navigation
This function is used to encode the navigation at retrofit.
If special tool navigation 20 and/or Navigation is installed, the coding must be set to installed.
Note:
On vehicles newer than 2009/1 (code 800) retrofit coding is performed via SCN, which is available through Mercedes on-line service.
Preconditions for the test:
  • Ignition on.
Procedure:
  1. Start the function and follow the instructions in the program.
