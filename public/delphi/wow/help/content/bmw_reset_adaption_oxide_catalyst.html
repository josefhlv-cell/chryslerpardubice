[614]Reset adaptation values for the nitrogen oxide catalyst

Note:

This function must be run after changing the nitrogen oxide catalyst.

Adaptations values for the nitrogen oxide catalyst may only be reset if the nitrogen oxide catalyst has been changed!

Test conditions:

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.
