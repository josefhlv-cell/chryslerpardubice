[ 1173]Programming of valve codes

Conditions:

-Engine off

-Ignition on

Procedure:

-After ”OK” button has been pressed a pop-up window appears with request to activate a valve code with the activator, put the activator against the tyre as shown in the picture.

-After the valve activation the user is supposed to chose if it is a summer or winter tyre.

–Next step is to choose placement for the tyre. After this is done the programming is finished.
