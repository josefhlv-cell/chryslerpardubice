Basic setting of mechatronic
This function performs a basic setting of the transmission's control unit. At basic setting, the gear positions are synchronized. This must be done:
  • When the mechatronic unit has been replaced.
  • After clutch replacement.
  • When fault code 18115 or 1087 is stored.
The following functions must be performed in correct order:
  1. Basic setting of mechatronic.
  2. Mechatronic adaption value resetting.
  3. Test drive after basic setting.
Note:
  • Basic settings shall be performed in the order according to the above.
Test conditions:
  • Engine idling.
  • Transmission temperature between 30 and 100 °C.
  • Gear selector in position P.
  • Brake pedal pressed down.
  • Gas pedal not pressed down.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. The following basic settings are performed:
    • Gear shift unit/position sensor
    • Syncronization positions
    • Clutch values
    • Main pressure, zero values
  3. Continue with the function "Mechatronic adaption value resetting".
