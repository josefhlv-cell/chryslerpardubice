[448]Start sequential control of control unit

This function is used to start sequential control in transmission control unit and return to normal position. The function is used after doing certain work on the clutch and transmission.

This is a component activation and shall only be used if the car is configured and equipped with the component. An activation may take up to a minute, during that time a window with the text "Please wait" is shown.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function.

  2. Wait for "Function done".

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
