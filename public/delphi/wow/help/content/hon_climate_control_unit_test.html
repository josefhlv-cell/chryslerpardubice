[201]Self-test of climate control unit

This function is used to check the climate control unit's function. Fan motor and dampers are operated to their end-positions in a sequence and lasts for approx. 1 minute. If any defect is detected during the test, fault codes will be generated and instructions issued to troubleshoot these.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function.

  2. Follow the instructions in the programme.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
