[392]Initiating rain sensor

An initiation of the rain sensor shall be performed:

  • After changing the windshield.

  • If the rain sensor's electronic part has been replaced.

  • If there are malfunctions of the rain sensor.

Test conditions:

  • Ignition on, engine off.

  • No faults in the system.

  • Ambient temperature between 15 and 35 °C.

  • Windshield clean and undamaged in the area for the optic unit.

Procedure:

  1. Start the function.

  2. Press "YES" to start initiation.

  3. After initiation has been run the rain sensor's nominal values are shown, at least two of three values shall be 1200 +/-50 digits and the other rain sensor values greater than 850 digits for initiation of rain sensor to be OK.

  4. The function is done.

    • If reference values are not reached, run the initiation again.
