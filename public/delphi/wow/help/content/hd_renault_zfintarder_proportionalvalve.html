[259]Test of proportional valve

This function is used to check the proportional valve's function.

The difference between requested current and actual current should not exceed 5 mA.

  • 0% = 0 mA

  • 50% = 212 mA

  • 100% = 425 mA

Test conditions:

  • Engine off, ignition on.

  • Parking brake applied.

  • Battery voltage above 20V.

Procedure:

  1. Start the function.

  2. Select degree of opening for the valve.

  3. Check the difference between requested and actual current.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
