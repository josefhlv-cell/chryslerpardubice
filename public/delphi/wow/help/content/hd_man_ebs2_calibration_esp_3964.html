ESP Calibration
This function is used to calibrate the ESP system.
Note:
The calibration must be performed if:
  • The steering angle sensor or yaw rate sensor has been replaced or removed/worked with.
  • An accident that involves components of the steering has occurred.
  • The fault codes 3706, 3707 and 3732 have been active.
After completed calibration, the vehicle must be driven on a straight road about 250 m. Avoid steering movements if possible.
The calibration starts when the vehicle is driven faster than 20 km/h.
The calibration is complete when the yellow warning lamp turns off.
You don't need to use the diagnostic tool for the last part of the calibration.
Test conditions:
  • Ignition on, engine off.
  • The vehicle must stand on level ground.
  • Set the front axle completely straight (0° +/- 0,05°) using the steering wheel (check with wheel alignment test).
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. Calibration is performed.
  4. You don't need to use the diagnostic tool for the last part of the calibration.
  5. Erase any fault codes.
