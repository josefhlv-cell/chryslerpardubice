[458]Reset adaptation values for catalytic converter

This function enables reset of the catalytic converter's adaptation values. This should be done if:

  • The catalytic converter has been replaced.

  • The engine control unit has been replaced.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. When the function is done, exit communication with the car and turn off the ignition for 30 seconds.

  4. Turn on the ignition again, re-establish communication with the car, and check that no fault codes are stored.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
