[1694]Parking brake start-up

The system must be started up if the handbrake shoes have been replaced. This is to ensure the best possible setting against the drum and optimise conditions for the bedding-in operation, which is the next step. When start-up is complete, the "Bed in brakes" function is run.

Test conditions:

  • Engine off, ignition on.

  • No faults in the system.

Procedure:

  1. Select the "Parking brake start-up" function and follow the instructions.

  2. Depress the brake pedal to begin the start-up procedure.

  3. When the function is complete, a faint noise will be heard from the rear brakes as the shoes are adjusted against the drums.

  4. The function is complete.
