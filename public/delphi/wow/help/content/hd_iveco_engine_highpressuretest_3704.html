Troubleshooting of high pressure fuel system
This function is used to test the efficiency in the high pressure fuel pump and checks that there are no leaks in the fuel circuit.
Note:
Do not depress the brake pedal during the test.
Test prerequisites:
  • Vehicle stationary.
  • Parking brake applied.
  • Gear selector set to P/N.
  • Engine idling.
Procedure:
  1. Press "OK" to start the function.
  2. Follow the instructions in the program.
  3. When the test is complete, the result is shown in a dialogue box.
