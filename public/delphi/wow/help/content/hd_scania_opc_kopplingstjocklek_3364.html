Adjusting the clutch disk thickness
This function should be performed after replacing the clutch disc, OPC ECU and after replacing the clutch actuator.
If a new OPC ECU has been installed, or if you have changed to a used clutch disc, then in the function you must enter the total clutch disc thickness.
The minimum value that can be programmed is 7,0 mm and the maximum value is 10,6 mm.
The function only works on vehicles without clutch pedal.
Test prerequisites:
  • Ignition on, engine off.
  • Transmission in neutral.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. Select in the scroll list what you want to program, press "OK".
  3. Enter the thickness of the disc (only if you select "Replaced OPC" or "Used clutch disc"), press "OK".
  4. The function is done.
  • If the function fails, check the test conditions and repair any faults.
