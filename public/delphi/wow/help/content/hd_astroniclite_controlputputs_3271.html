Control outputs
This function is used to control the transmission's electric outputs.
Note:
The transmission should emit sounds when you select to activate an output.
Test conditions:
  • Engine off.
  • Ignition on.
  • Vehicle stationary.
  • Parking brake applied.
  • Transmission in neutral.
Procedure:
  1. Start the function.
  2. Check conditions.
  3. Select which one of the outputs that should be controlled.
  4. Check that the selected output reacts and listen for sounds.
  5. Press "Cancel" to return to the original selection.
  6. Repeat steps 3-5 for the other outputs.
  7. Function complete.
  • If the function fails, check the test conditions and repair any faults.
