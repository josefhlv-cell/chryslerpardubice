Reset service message
This function is used to reset service message. It shall be done at engine oil change.
Test conditions:
  • Ignition off.
Procedure:
  1. Press and hold down the button "REAR FOG LIGHT".
  2. Ignition on.
  3. Let up the button "REAR FOG LIGHT".
  4. Press and hold down the "TRIP"-button (located on the direction indicator lever).
  5. Press and hold down the button "REAR FOG LIGHT".
  6. If the dialogue "Resetting service mode" does not appear in the display after the steps 1-5 has been performed, repeat those steps.
  7. Hold down both buttons until the message "SERVICE MODE RESET" is shown.
