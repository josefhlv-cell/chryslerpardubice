[1240]Zero compensation of the longitudinal acceleration sensor

This basic setting is used to zero-compensate the value from the longitudinal acceleration sensor. This must be done if:

  • The ABS control unit has been replaced.

  • The electromechanical parking brake has been replaced

  • The longitudinal acceleration sensor has been replaced.

  • A fault code that requires a basic setting is stored in the ABS control unit.

Note:

During basic setting, the ignition must not be switched off.

Test prerequisite:

  • The battery voltage should be >12V.

  • Ignition on, engine off.

  • No fault code should be stored.

Performance:

  1. Position the car on a flat and level surface.

  2. Choose the basic setting: Zero compensation of longitudinal acceleration sensor.

  3. Value 0,0 confirms that the zero compensation has been done. If the value for the longitudinal acceleration sensor is too high, zero compensation will not be accepted (adaption not possible).

  4. Exit the function.
