Configure front fog lamps
This function is used to configure the front fog lamp.
Possible configurations:
  • Present.
  • Not present.
Test prerequisites:
  • Ignition on, engine off.
  • Access to safety code existing with other codes in a Car Pass (see image).
Procedure:
  1. Start the function.
  2. A data list presents the current configuration. Press "Yes" to change the configuration.
  3. Select desired configuration in the displayed scroll list.
  4. Press "OK" and follow the instructions.
  5. The new configuration is displayed once programming is complete.
If the function is cancelled or fails, check fault codes and test conditions.
