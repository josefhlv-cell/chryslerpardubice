[348]Deactivate economy mode

This function is used to get the car to exit economy mode, economy mode is deactivated 30-60 minutes. This function is only available on certain BSI-versions.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12.1 V.

Procedure:

  1. Start the function.

  2. A dialogue box shows that activation is in progress.

  3. A dialogue box shows if the function succeeded or failed.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
