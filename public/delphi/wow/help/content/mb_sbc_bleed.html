[180]Bleed brake system / change brake fluid

This function is used to bleed the brake system. In connection with bleeding all brake fluid will be replaced.

  • Battery charger must be connected during the entire sequence.

  • The container must have a capacity of at least 3 litres of fluid.

  • Filling and bleeding unit must be filled sufficiently. Approx. 2-3 litres of brake fluid is needed to finish the sequence.

  • The wheels will be bled in the following order: right rear, left rear, left front, and right front.

Note:

High pressures will be generated, therefore the bleeder hose must be secured so that it cannot slide off the bleed nipple.

Test conditions:

  • Engine off.

  • Battery charger connected to vehicle.

  • The container must be empty.

  • The brake fluid reservoir may not become empty during the sequence (if it becomes empty the function must be restarted).

Procedure:

  1. Start the function.

  2. Dialogue boxes guide the sequence.

  3. A dialogue box shows if the operation was successful or failed when bleeding is finished.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.

    • If the function is cancelled, the SBC-system may need to be activated via separate function.
