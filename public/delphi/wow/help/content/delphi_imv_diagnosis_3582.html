IMV diagnosis
This function is used to test the function for the fuel metering valve IMV.
Note:
During the test will the engine rev. up 5 times to approx. 3000 rpm.
Test conditions:
  • Ignition on, engine on.
  • Coolant temperature at least 70 °C.
  • Do not touch the accelerator pedal during the test.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. The test starts, the engine will now rev. up 5 times to approx. 3000 rpm. A number of parameters is presented during the test and when the functional test status presents "complete", the test is performed.
  3. If the function fails, check the test conditions and repair any faults.
