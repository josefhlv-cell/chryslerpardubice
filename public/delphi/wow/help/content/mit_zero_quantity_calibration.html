[62]Injector calibration

Injector calibration shall be performed in connection with injector replacement, this is to optimize the injection quantities.

Test conditions:

  • Ignition on.

Procedure:

  1. Select the function "Zero quantity calibration", press "OK".

  2. Start the engine.

  3. Calibration is done automatically when the following conditions are fulfilled:

    • Engine rpm between 1900 - 2500 rpm.

    • Accelerator pedal not pressed down.

    • Brake pedal not pressed down.

  4. Erase any fault codes.
