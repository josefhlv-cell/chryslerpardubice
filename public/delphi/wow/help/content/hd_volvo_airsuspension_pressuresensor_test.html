[238]Checking pressure sensors

This function is used to check that the signals from pressure sensors connected to ECS are received and interpreted correctly by the control module.

Voltage feed pressure sensors should be approx. 5.0V.

A pressure gauge should be connected to the pressure sensor that is to be tested.

Test conditions:

  • Parking brake applied.

  • Working pressure in air system.

  • Battery voltage above 20V.

  • Pressure gauge connected.

Procedure:

  1. Start the function.

  2. Choose the axle to be raised or lowered.

  3. Check that the value on the screen for the relevant sensor and the value on the pressure gauge match.

  4. Repeat the test for the other sensors.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
