[37]Calibrate start fuel quantity

This function is used to adjust the start fuel quantity's offset (injection start).

Adjustment shall only be performed if the engine is difficult to start even if the preheating system is OK.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the function.

  2. A dialogue box shows status for "Offset start fuel quantity". Press "OK", and follow the instructions.

  3. After finished adjustment the current offset value for start fuel quantity is shown.

    • If the function fails, check the test conditions and repair any faults.
