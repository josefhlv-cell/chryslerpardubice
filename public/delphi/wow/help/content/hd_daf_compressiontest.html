[100]Compression test

Compression test is used to decide how good the cylinder compression is. The engine is not started for this test. The test results are shown as percentages (0-100%).

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Turn on the ignition, the values from the compression test are shown.

  3. Turn off ignition, press "OK".

  4. Wait 6 seconds.

  5. Turn on the ignition, press "OK".

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
