[144]Basic setting of light beam length

This function is used to adjust zero point for the light beam controls. Adjustment of zero point should be done after repair or replacement of parts in the light beam control.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • Vehicle must be without load.

  • The vehicle must stand on level ground.

  • Actual values for the level sensors shall be within the valid range.

Procedure:

  1. Start the function.

  2. A dialogue box shows current values for the level sensors and the valid range.

    • Note that the values for the level sensors must be within the valid range.

  3. Choose if the zero point adjustment should be performed in the dialogue box.

  4. A dialogue box shows if the function succeeded or failed.

    • If the function fails, check the test conditions and repair any faults.
