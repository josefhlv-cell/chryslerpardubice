[1710]Configure wiper motor

The wiper motor control unit is fitted with the windscreen wiper motor in a single unit. The control unit is a slave system to the electrical control unit and has several functions, e.g. variable park position and after-wiping. When the wiper motor is replaced, it must be configured with the correct variant code to operate correctly. The existing variant code for certain models can be read from the basic data.

  • At every second wipe, the wiper motor moves to the bottom park position then slightly higher (variable park position). The bottom park position must be used when setting the wiper unit.

  • During configuration, the function is activated for the variable park position and the wiper motor moves automatically to the bottom park position.

  • The variable park position is activated automatically after 100 wiper strokes.

Note:

The bonnet must be closed during activation, otherwise the power supply to the wipers will be cut.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

  • Bonnet closed.

  • Wiper motor replaced.

  • If possible, read and note the existing code.

Procedure:

  1. Select the "Encode wiper motor" function.

  2. A dialogue box shows the current code. Press "OK" to change the code.

  3. Enter the desired code (see below). If the item number is not listed, use the old existing code. Confirm with "OK".

    Item number: 1Z1955119AVariant code
    Without after-wiping63477
    With after-wiping65525
    Item number: 1Z1955119CVariant code
    Without after-wiping55223
    With after-wiping57271

  4. A dialogue box displays the new code. Confirm with "OK".

  5. Exit the function.
