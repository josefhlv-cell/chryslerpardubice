[1443]Configuration of BSI

With this function it is possible to activate / deactivate some of the BSI functions according to the following instructions.

Test prerequisites:

  • Correct BSI version.

  • Correct vehicle equipment.

  • Ignition on, engine off.

  • No faults stored.

  • All electrical loads should be switched off.

  • Battery voltage above 12 Volts.

Procedure:

  1. Start the function, press OK.

  2. A dialogue box will present the value stored in the control unit.

    • To change the value choose "Yes".

    • To exit the function without changing the value choose "No".

  3. Enter the new value with 2 digits in the presented input field.

    • To store the value choose "OK".

    • To exit the function without changing the value choose "Cancel".

  4. A dialogue box confirms: Operation succeeded / Operation failed.
