[1302]EGR system

Test condition:

  • Ignition on.

  • No faults stored.

  • Battery voltage above 11.5 V.

  • All electrical loads switched off

  • Engine temperature above 80 °C.

Note:

  • To check the EGR system.

Procedure:

  • Choose the function: EGR system.

  • Revs up five times to max engine speed.

  • The value in the diagnostic status field must change from "Test off" to "Test on".

  • Let the engine idle until the value changes to "System OK! / System not OK!".

  • If the specifications are not attained, interrogate fault memory.

  • Exit function.
