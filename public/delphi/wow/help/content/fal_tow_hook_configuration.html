[1495]Tow hook assembly

This function is used to configure the parking assistance system, when a tow hook is assembled.

Note:

  • It is possible to read the present status in data list.

Test prerequisites:

  • Ignition on, engine off.

Procedure:

  1. Press OK to start the function.

  2. Choose fitted or not fitted in the list.

  3. Press OK to continue or Cancel to quit.
