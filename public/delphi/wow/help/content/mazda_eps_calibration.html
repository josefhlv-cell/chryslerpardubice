[1563]Steering wheel calibration

Calibration is performed after removal or replacement of components that can affect the steering wheel angle.

Note:

Check that there are no fault codes stored in the EPS before proceeding with the process.

Test prerequisites:

  • No faults in the system.

  • Engine idle running.

Procedure:

  1. Choose the function: "Steering wheel calibration", press "OK".

  2. Dialog box shows: "Start engine and allow to idle".

    • Press "OK" to start the calibration or "Cancel" to quit.

    • The EPS warning light will begin to flash.

  3. Dialog box shows: "Turn the steering wheel from end to end position, then turn it back to the center position (at least 3 times) until the EPS warning lamp goes off". Then press "Ok".

  4. Dialog box shows: "Turn ignition off and on".

    • Press "OK" to finish the calibration.

  5. Dialog box shows: "Operation succeded".
