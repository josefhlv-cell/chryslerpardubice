[1396]Adjusting of headlights with xenon lamps

Before the adjustment of the headlights is performed on vehicles with xenon lamps, a basic setting of the automatic headlight range control must always be carried out. The basic setting disconnects the control mechanism to make headlight adjusting possible. If a basic setting is not performed, the headlight range control device will be damaged.

Note:

  • The vehicle must not be moved during the adjustment; to open/close doors or lean on the vehicle is not allowed. When headlights, vehicle level senders or headlight range control unit are renewed, a basic setting must be performed.

  • If the fault code 1539 is stored, a basic setting must be performed.

Test prerequisities:

  • The battery voltage above 12 V.

  • Ignition on, engine off.

  • No faults stored in the fault memory.

  • Headlamp lenses unbroken and clean.

  • Reflectors and bulbs ok.

  • Tyre pressure ok.

  • Handbrake released and no gear selected.

  • Wheels in a straight-ahead position.

  • Vehicle correctly loaded and springs settled.

  • Vehicle and headlight adjuster on a level surface and aligned.

Procedure:

  1. Read and check the inclination. The inclination value is embossed in trim above the headlight. It is stated in percentage and based on a projection distance of 10 metres. A value of for example 1,2 % corresponds to 12 centimetres.

  2. Select the basic setting: "Adjust light setting".

    • The headlights will now be moved into the adjustment position. This is confirmed with the text: "Activate".

  3. Adjust the headlights according to the national legislation and regulations.

  4. Exit the basic setting.

  5. Select the basic setting: "Store setting".

    • The new headlight setting is stored and the values from the front and the rear level sensors are stored as new starting values. This is confirmed with the text: "Control position learned".

  6. Exit the basic setting.

  7. Turn the ignition off and on to initialize the system.

  8. Read the fault codes and check that no faults are stored.
