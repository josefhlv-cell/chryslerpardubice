[1568]Calibration of steering angle sensor

This function is used to zero-compensate the value from the steering angle sensor.

This funktion is used when:

  • The ABS control unit, steering angle sensor or the steering column sensor has been replaced.

  • Bodywork that affects the wheel alignment has been done.

  • The steering angle sensor has been disconnected.

Note:

  • After each time the ignition is switched on the calibration can only be implemented once.

  • Tolerance for the calibration is ±15°.

Test prerequisites:

  • Battery voltage higher than 12V.

  • Ignition on, engine off.

Procedure:

  1. Move the front axle into straight ahead position.

  2. Choose the function, press "OK".

  3. A dialog box shows the steering angle position.

    • To be able to perform a calibration the steering angle sensor must be within ±15°.

  4. To perform calibration, press "OK".

  5. The calibration takes 10 seconds, do not rotate the steering wheel.

  6. A dialog box shows the steering angle position, if the calibration succeeded.

    • If the function fails, check the test prerequisites and adjust possible fault codes.

  7. Press "OK".
