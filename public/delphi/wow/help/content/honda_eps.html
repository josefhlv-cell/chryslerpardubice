[341]Calibrate torque sensor

This function is used to calibrate the torque sensor for electric power steering (EPS) that is stored in the control unit.

The function shall be used after the following components have been replaced:

  • Transmission.

  • Sensor torque (EPS) Electric power steering.

  • Control unit for electric power steering (EPS) or variable steering angle (VGS).

  • Sensor ratio (If vehicle is equipped with variable steering angle system (VGS).

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • No faults in the system.

  • Vehicle raised at the front so that the wheels can rotate freely.

  • The steering wheel stands straight and the front wheels point straight forward.

Procedure:

  1. Turn the steering wheel 10 degrees to the left and then to the right.

  2. Centre the steering wheel with the wheels pointing straight forward.

  3. Press "OK" to start the function.

  4. Follow the instructions in the program.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
