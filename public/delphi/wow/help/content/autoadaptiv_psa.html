[763] Clearing adaption memory

Clearing the adaption memory is a function that resets all learned adaption values. This must be performed in event of work with the fuel system. (Injectors or fuel pump)

Observe:

After clearing the adaption memory it is necessary to follow a learning procedure.

Test prerequisites:

  • Ignition on.

  • Battery voltage min 12 V.

Performance:

  • Choose function: Clear adaption memory.

  • A dialog presents: Operation succeeded/ failed.

  • Press OK.

  • Follow the instructions below to perform learning procedure.

Learning procedure for adaption memory.

1. Learning of throttle position.

Test prerequisites:

  • Coolant temperature between 5°C and 100°C.

  • Intake air temperature above 5°C.

  • Accelerator pedal not depressed.

Performance:

  • Switch on ignition, wait 30 seconds.

  • Switch off ignition, wait 30 seconds.

2. Learning accelerator pedal position sensor.

Performance:

  • Switch on ignition and press accelerator pedal fully.

  • Release accelerator pedal.

  • Start the engine without pressing accelerator pedal.

3. Mixture learning. (Idling)

Test prerequisites:

  • Gear selector in P/N position.

  • Coolant temperature above 80°C.

Performance:

  • Engine idling for 5 minutes.

4. Mixture learning. (Load)

Test prerequisites:

  • Coolant temperature above 80°C.

Performance:

  • Urban driving for 5km.
