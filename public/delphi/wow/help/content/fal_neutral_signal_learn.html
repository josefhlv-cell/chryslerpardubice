[355]Calibrate neutral signal

This function is used if any of the following components have been replaced.

  • Control unit.

  • Transmission

  • Clutch.

  • Re-connection and selector potentiometer control unit.

  • Throttle potentiometer.

  • Transmission links.

Test conditions:

  • Ignition on.

  • Transmission in neutral.

  • Pedals may not be pressed during basic setting.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
