[922]Basic setting requirements

Preconditions for the test:

  • Engine idling.

  • No faults stored.

  • No leaks in the exhaust system.

  • Engine temperature above 85 °C.

  • Induction air temperature below 60 °C.

  • All electrical loads switched off.

  • Gear selector set to ”P/N”.

  • Throttle cable adjustment OK.

Note:

  • Used to check basic setting requirements.

  • These basic setting requirements must have been met when checking the idling.

Procedure:

  • Choose the function: Basic setting requirements.

  • Check the block of digits in the basic setting requirements column. Prescribed value 111 111.

Quit the basic setting requirements function and continue with the idling check.
