Bleed brake system
This function is used to bleed the brake system. Make sure that the brake fluid level does not drop below the minimum marking on the brake fluid reservoir during bleeding.
Test conditions:
  • Ignition on, engine off.
  • Gear selector in position P.
  • Parking brake applied.
  • A co-worker is needed to assist with the bleeding method.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. The function is done.
    • If the function fails, check the test conditions and repair any faults.
