[352]Reset vehicle configuration

This function shall only be used in case of fault in the configuration or if used control unit has been installed with wrong configuration. Reset is performed for transmission, climate control, cruise control, ABS, and electric control. After resetting, new configuration is read in to control unit.

Fault code "P1302 transmission identification" may appear in the system when reset is performed. To reset it, drive the vehicle forwards and backwards then switch the ignition off/on. Then clear the trouble codes.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.
