Version number
This function is used to learn the right combination of the engine and tire size in a new control unit.
Note:
A list is presented in the function, with four choices. Select the right configuration in the table below:
Adaptation No. 0
  • D4F with 175/65 R14
  • D4F, D4FT, K9K GT with 185/55 R15
Adaptation No. 1
  • D4F, D7F, K9K with 165/65 R14
Adaptation No. 2
  • K9K, D4FT with 175/65 R14
  • K9K with 185/55 R15
Adaptation No. 3
  • Renault Sport with 195/45 R16
  • Renault Sport with 195/40 R17
Test conditions:
  • Ignition on, engine off.
  • No fault codes in the system.
Procedure :
  • Press "OK" to start the function.
