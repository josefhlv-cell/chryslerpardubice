[680]Replacing the automatic gearbox

The function resets certain parameters in the controller that relate to the component being replaced.

The function must be performed if the gearbox is replaced.

Note:

Perform the following functions in the following order!

  • Before replacing the automatic gearbox:

    1. Accumulator depressurisation.

  • After replacing the automatic gearbox

    1. Replace automatic gearbox.

    2. End of line/service self-calibration.

    3. Clutch self-calibration.

Test conditions:

  • Ignition on.

  • Stop&Start function disabled.

Procedure:

  1. Start the function and follow the instructions in the program.
