[489]Basic setting of pilot injection

This function shall be run after one or several injectors have been replaced.

When all values are fulfilled and the "OK" button is pressed, the glowing light will start to flash, which indicates that teach-in mode has started. The light stops flashing when the function is done.

After correctly run function, check for any fault codes in the system and erase all. Fault code "P1601" may be stored. To erase any fault codes, the function must be run correctly.

The teach-in procedure may have to be repeated up to 10 times per injector.

Test conditions:

  • Engine idling.

  • All values must be fulfilled.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. Click on "OK" when all values are fulfilled.

  4. Increase engine speed to 3,000 rpm, then let up the accelerator pedal completely and quickly. (The accelerator pedal must be let up within 2 sec. of starting to press it down.)

  5. When the engine speed has returned to idle, repeat the procedure again. (Up to 10 times per injector.)

  6. Turn off the ignition and wait 10 seconds before turning on the ignition again.

  7. After turning on the ignition again, check if there are any fault codes in the system. Erase all fault codes!

  8. The function is done.

    • If the function fails, check the test conditions and repair any faults.
