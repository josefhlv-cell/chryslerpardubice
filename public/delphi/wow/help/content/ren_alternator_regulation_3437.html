Alternator regulation
This function is used to regulate the alternator charge.
Note:
  • The UPC puts a preset voltage on the alternator when this function is performed.
  • The function takes approx. 1 minute.
  • The function must not be aborted. If the function is aborted, it must be run again until it is fully completed.
Test conditions:
  • Engine idling.
Procedure:
  1. Press "OK" to start the function.
