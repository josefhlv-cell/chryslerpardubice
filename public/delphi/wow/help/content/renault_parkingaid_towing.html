[372]Calibrate reversing sensors

This function is used to adjust sensitivity of the reversing sensors. The function shall be used if the reversing sensors generate sporadic alarms or constanly when towing or pulling a trailer.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Increase the distance one centimetre at a time until the sensors do not generate an alarm.

  3. The function is done.
