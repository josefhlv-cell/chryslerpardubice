[1197]Reset oxygen sensor adaptions

Engine off, ignition on.

Battery voltage min 11 V.

If one or more of the following components have been renewed or rectified the adaption must be performed:

  • Oxygen sensors

  • Catalytic converter

  • Exhaust system

  • Coolant temperature sensor

  • Any induction system components

  • Cylinder head

  • Engine control unit connections

  • Engine control unit sensor ground
