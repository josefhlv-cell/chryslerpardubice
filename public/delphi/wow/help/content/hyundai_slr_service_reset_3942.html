Reset service message
This function is used to reset the service message.
Note:
If you select not to change the interval for the service message, the current settings will remain.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. The interval for the service message is shown.
  3. Select if you want to reset the service message.
  4. Select if you want to change the interval for the service message.
  5. The function is done.
