[409]Activate service mode on parking brake

This function shall be used for the following jobs on the parking brake:

  • After replacing parking brake module.

  • After replacing parking brake button.

  • Before replacing brake calipers' actuators.

  • Before replacing brake calipers or brake pads rear.

NOTE! after above jobs have been done, the function "Operation start, parking brake" must be run.

Test conditions:

  • Ignition on.

  • No faults in the system.

Procedure:

Select below which job has been done on the vehicle:

  • Replacing parking brake's control module:

    1. Start the function.

    2. Select in the list the job that is to be processed.

    3. Follow the instructions in the program.

    4. The function is done.

    5. Run the function "Operation start, parking brake".

  • Replacing parking brake's button:

    1. Start the function.

    2. Select in the list the job that is to be processed.

    3. Follow the instructions in the program.

    4. The function is done.

    5. Run the function "Operation start, parking brake".

  • Replacing the brake calipers' actuators:

    1. Start the function.

    2. Select in the list the job that is to be processed.

    3. Follow the instructions in the program.

    4. The function is done.

    5. Then replace the brake calipers' actuators.

    6. Run the function "Operation start, parking brake".

  • Replacing the brake calipers or brake pads rear:

    1. Start the function.

    2. Select in the list the job that is to be processed.

    3. Follow the instructions in the program.

    4. The function is done.

    5. Then replace the brake calipers or brake pads rear.

    6. Run the function "Operation start, parking brake".
