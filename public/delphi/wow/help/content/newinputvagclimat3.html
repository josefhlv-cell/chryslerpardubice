[1094] CLIMATRONIC

Coding control unit

Volkswagen Polo IV

Coding and basic setting of Climatronic must be performed when:

  • Change of Climatronic control unit

  • Not correct values are achieved from datalist

  • The display is flashing after the ignition is turned on and no fault code is stored in the memory

Procedure:

  1. Read, repair and erase eventual fault code

  2. Choose function write to ECU

  3. Edit correct code number

  4. Press OK.

  5. Coding performed, read ”Datalist 9” to control the coding number
