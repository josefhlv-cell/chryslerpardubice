[1720]Programme keys

This function is used when the new keys need to be programmed and stored in the system.

Note:

All trouble codes in the immobiliser system must be dealt with and erased before programming can be carried out. No other transponder keys must be near the ignition switch during programming. The distance must be at least 10 cm! A security code must be entered in order to programme (see image 1). The valid security code can be found, along with other codes, in the vehicle's Car Pass (see image 2).

If an incorrect security code is entered three or more times, a safety delay is activated (see parameter in the data list). During this safety delay, no codes may be entered. The safety delay is doubled each time an incorrect code is entered. If the immobiliser's control unit has been replaced or is incorrectly programmed, it must be programmed before the keys can be programmed. Programming is not possible if the battery voltage is low.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • No faults in the system.

Procedure:

  1. Insert the key to be programmed in the ignition switch (Other keys must be at least 10 cm from the ignition switch) and switch on the ignition.

  2. Press "OK" to start the function.

  3. A dialogue box shows the status of transponders 1-5. Press "OK" to proceed and follow the instructions.

  4. Once programming is complete, the current transponder status is displayed.
