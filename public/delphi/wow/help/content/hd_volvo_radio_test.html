[315]Button test

This test checks the function of the buttons. Press in a button and check that status in the test matches with selected button.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Press in a button.

  3. Check that status in the test matches with selected button.

  4. Repeat the procedure for the remaining buttons.

  5. Finish the test.

  6. The function is done.
