Forced regeneration
This function is used to run a forced regeneration.
Note:
This is a two-person job and the diagnostic tool must be connected during the time that the regeneration is run.
The vehicle must be driven over 60 km/h and the function will take approximately 30 minutes.
The vehicle speed must be over 60 km/h during the whole operation, if it is lowered for more than 3 minutes, the function must be restarted.
Test conditions:
  • Engine temperature above 65 °C.
Procedure:
  1. Start the function and follow the instructions in the program.
