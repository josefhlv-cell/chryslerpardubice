Activate run-in protection climate compressor
This function is used to run-in the climate compressor after replacement, and refilling the refrigerant system. Run-in is necessary to ensure the lubrication. At run-in, the climate compressor must be run at a predetermined engine speed range (300-1500 revolutions/min). The manufacturer refilled amount of oil, is then evenly mixed with the liquid refrigerant.
Note:
When the engine speed exceeds the predetermined speed range 300-1500 revolutions / min., run-in is canceled automatically. The run-in procedure must be repeated completely.
Test prerequisites:
  • Engine idling.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Function complete.
