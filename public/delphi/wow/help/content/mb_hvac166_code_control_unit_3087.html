Coding the control unit
This function is used to change the coding in the control unit as desired.
Test conditions:
  • Ignition on.
Performance:
  1. Start the function.
  2. A list shows the current coding.
  3. Proceed with the function.
  4. Select the parameter to be changed.
  5. Choose the selection to be stored from the list shown.
  6. The chosen option will be stored and the newly updated list is shown.
