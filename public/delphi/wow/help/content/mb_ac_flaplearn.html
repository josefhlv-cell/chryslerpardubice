[111]Initiate flap motors

This function initiates flap motors for the control unit after work or replacement of one or several flap motors.

  • After finished function, basic setting of flap motors should be performed with separate function.

  • The ignition must not be turned off during the function.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • Flap motors correctly installed and connected.

Procedure:

  1. Start the function.

  2. The function starts, adaptation is run. The function may take up to 2 minutes to finish.

  3. A dialogue box shows if the function was successful or failed.

    • If the function fails, check the test conditions and repair any faults.
