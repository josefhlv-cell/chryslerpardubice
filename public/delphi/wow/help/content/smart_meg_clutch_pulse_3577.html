Pulsate the clutch after replacement
This function is used to pulsate the clutch after replacement.
Test Prerequisites:
  • Ignition on, engine off.
  • Vehicle stationary.
  • Battery voltage above 12V.
  • Gear selector in neutral position.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. The clutch will now run between open and closed (pulsate).
  3. A dialogue box shows "Operation successful/failed".
  4. If the function fails, check the test prerequisites and repair possible fault codes.
  5. The function should be run twice for the best result.
