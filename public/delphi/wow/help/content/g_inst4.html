[994] Idling control

Preconditions for the test:

  • Engine idling.

  • No faults stored.

  • No leaks in the exhaust system.

  • Engine temperature above 80 °C.

  • All electrical loads switched off.

  • Automatic gearbox set to ”P/N”.

Note:

  • Used to check idling.

  • Idling, ignition advance/retard and CO value are not adjustable.

  • The idling speed is set by the control unit.

  • The position of the distributor has no effect on ignition advance/retard.

  • The CO value is controlled by the lambda regulation.

  • In the basic setting mode, the carbon canister valve is closed.

Procedure:

  • Choose the idling check function.

  • Rev up the engine and let it idle for two minutes.

  • Read off the engine speed signal. Prescribed value 800-880 rpm.

  • Read off the lambda correction factor. Prescribed value 1.00 ± 0.3 (oscillates).

  • Read off the ignition advance setting. Prescribed value 1-15 < ° before TDC.
