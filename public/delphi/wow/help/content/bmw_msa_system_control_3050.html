MSA System control
This function is used to read out the history from the MSA system and to reset the history memory.
The function of the MSA Automatic engine start/stop is to reduce carbon dioxide emissions. Fuel consumption is reduced, as the engine automatically switches off when the vehicle is at a standstill. The engine automatically restarts when the connection conditions are fulfilled. Second generation MSA enables vehicles to be fitted with either manual or automatic transmission.
This function can be used to:
  1. See an overview of MSA (number of engine stops and number of MSA engine stops).
  2. See an overview of the history (disconnection lock and connection requests), and reset the history memory.
  3. See an overview of the 10 most recent start hindrances.
Note:
If the history memory is reset, the overview of the 10 most recent start hindrances is also reset.
Vehicle conditions: MSA only works under certain conditions.
MSA stop
The engine switches off under the following conditions:
  • Speed lower than 3 km/h.
  • Engine speed is close to idle speed.
  • A minimum speed of approx.10 km/h must be reached following start-up.
  • No gear engaged (manual transmission).
  • Clutch not engaged (manual transmission).
  • Brake engaged (automatic transmission).
  • Steering wheel is not turned.
MSA start
The engine starts automatically when:
  • No gear engaged (manual transmission).
  • The clutch pedal is depressed (manual transmission).
  • The brake pedal is released (automatic transmission).
Disconnection lock
The following conditions prevent an MSA stop:
  • Engine adjustments, e.g. cylinder equalisation.
  • Regeneration of diesel particle filter.
  • Regeneration of active carbon filter (petrol vehicles).
  • Engine fault.
  • Engine temperature too low.
  • Engine temperature too high.
  • Outside temperature below 3°C.
  • Air conditioning requirements such as: heating and climate controls operational, IM sensor active.
  • Insufficient knock-resistance (petrol).
  • Automatic transmission not ready.
  • Road gradient too steep.
  • Help system active (active cruise control, parking assist).
  • Traffic congestion operation.
  • MSA stopped for too long.
  • Comfort break conditions not met.
Hybrid vehicle
  • High voltage power management: temperature too low or too high.
  • Mains load too high.
  • Charge level of high voltage battery too high or too low.
  • Fault in hybrid system.
Connection request
The following conditions are required for an engine start:
  • The vehicle begins to roll.
  • Steering wheel is turned, engine starts again.
  • Insufficient brake vacuum.
  • Power management requires a running engine.
Hybrid vehicle
  • High voltage power management: temperature too low or too high.
  • Mains load too high.
  • Charge level of high voltage battery too high or too low.
  • Fault in hybrid system.
Safety requirements
The following conditions will deactivate MSA:
  • Bonnet open.
  • Driver leaves the vehicle, securing the door switch, seatbelt buckle, brake pedal.
  • Vehicle is towed.
  • Ignition key not recognised.
  • MSA button.
  • Battery not recognised.
Test conditions:
  • Ignition on.
Execution:
  • Start the function and follow the instructions in the program.
  • See table of explanations below.
Table of explanations for overview of history memory:
  • Number: total disconnection locks since the last wipe of the history memory.
  • FROM km: disconnection lock was last active prior to XX kilometres. Only relevant if there is a number total.
  • TO km: disconnection lock was last active prior to XX kilometres. Only relevant if there is a number total.
  • Active: current status of disconnection lock.
