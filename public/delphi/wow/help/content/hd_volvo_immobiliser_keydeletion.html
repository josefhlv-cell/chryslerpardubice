[658]Erase keys

This function erases all stored key codes and resets the key counter in the control unit.

Test conditions:

  • Parking brake applied.

  • Engine off.

  • Ignition on.

Procedure:

  1. Start the function.

  2. Check conditions.

  3. Check the status for the function.

  4. Function done.

    • If the function fails, check the test conditions and repair any faults.
