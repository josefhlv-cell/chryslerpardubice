[321]Adapting service interval

With this function it is possible to adapt service interval data to fixed oil change interval or flexible oil change interval by changing value for oil quality. Values that can be selected are shown below:

  • Oil quality 1 = fixed oil change interval

  • Oil quality 2 = flexible oil change interval

Vehicles that are to be adapted to flexible service interval must support this function, see service book. Oil of approved standard must be used when adapting to flexible service interval.

Adaptation may only take place in connection with performed service and reset service indication.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage 12 V.

Procedure:

  1. Start the function.

  2. A dialogue box with current adapted service interval data is shown.

  3. Press "Yes" to change value.

  4. The new stored adaptation value for service interval data is shown.

  5. Press "OK" to exit the function.

    • If the function fails, check the test conditions and repair any faults.
