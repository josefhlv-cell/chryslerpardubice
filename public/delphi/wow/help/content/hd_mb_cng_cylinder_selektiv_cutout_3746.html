Cylinder deactivation
This function is used to temporarily deactivate the ignition/intake on one cylinder at a time.
Note:
This function should be performed with engine at idle!
The engine sound should change when a cylinder is deactivated.
Test conditions:
  • Engine idling.
  • Engine temperature above 75°C.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. Check test conditions.
  3. Select the cylinder to be deactivated.
  4. Press "OFF".
  5. Check the "live" data list.
  6. Press "ON".
  7. Repeat the test for each cylinder.
  8. Press "OK" to exit the function.
  9. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
