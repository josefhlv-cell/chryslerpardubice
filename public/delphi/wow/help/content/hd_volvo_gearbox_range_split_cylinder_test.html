[1712]Test split/range cylinder

This function is used to check the integrity of the split/ range cylinder's solenoid valves, and that the air cylinder's piston and position sensor are functional.

A noise should be heard when a valve is actuated. The cylinder stroke length values are displayed at the end of the test. The current value must be between the minimum and maximum values.

  • Possible faults:

    1. Air faults: Dirt/oil in the air ducts, piston jamming in the cylinder, solenoid valve jamming or leakage from the air connections.

    2. Mechanical faults: Worn shift levers, coupling sleeves or brass pins.

Test conditions:

  • Parking brake applied.

  • Air pressure in transmission between 550-1,000 kPa.

  • Engine off.

  • Battery voltage above 20 V.

  • Oil temperature in transmission above 15°C.

Procedure:

  1. Select the function for the cylinder to be tested.

  2. A dialogue box appears showing the test conditions. Check these.

  3. Activate/deactivate the cylinder's solenoid valve; a noise should be heard. Press "OK".

  4. The cylinder stroke length value is displayed.

  5. The function is complete.
