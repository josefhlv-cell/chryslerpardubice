[1765]Version coding of control unit

When replacing or retrofitting a control unit it has to be version-coded to function correctly. The control unit must be of the correct type to approve the version code.

Note:

Incorrect version coding may reduce the car's safety and function.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • No faults in the system.

Procedure:

  1. Select the function: "Version coding", press "OK".

  2. Current version is shown, press "OK" to change version.

  3. A scroll list with possible versions is shown. Select desired version, press "OK".

  4. The new version is shown, press "OK" to save the new value.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
