[1450]Gearbox oil change.

When changing the gearbox oil it is possible to clear the oil deterioration counter.

Test prerequisites:

  • Ignition on, engine off.

  • Gear in neutral position.

  • No faults stored.

  • All electrical loads should be switched off.

Procedure:

  1. Start the function, press OK.

  2. The function starts, the oil deterioration counter is now cleared. A dialog box presents: operation succeeded/ failed.

    • If the function fails, check the test prerequisites and repair possible fault codes.

  3. Exit the function.
