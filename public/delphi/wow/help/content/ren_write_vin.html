[452]Program VIN-code

This function is used to enter new VIN-number in vehicle's control unit when it has been replaced.

Note:

The function cannot be cancelled, also it cannot be used on an old control unit or an already programmed.

Test conditions:

  • Ignition on, engine off.

  • Check that data list "VIN-code" is blank or shows 00000000000000000.

  • Read off the vehicle's VIN-code on the manufacturer plate on right door pillar or under windshield on left side.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.
