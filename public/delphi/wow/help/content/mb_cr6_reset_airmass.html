[140]Reset adaptation values for mass airflow sensor

This function is used after any of the following components have been replaced:

  • Mass airflow sensor left or right.

  • Air filter.

The ignition must not be turned off during the function. If the function is cancelled or fails, check fault codes and test conditions.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

Procedure:

  1. Start the function.

  2. When the function is done, a dialogue box will be shown with instructions to turn the ignition off and on to end the function.

    • If the function fails, check fault codes and test conditions.

  3. Exit the function.
