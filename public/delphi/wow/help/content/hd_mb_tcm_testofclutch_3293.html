Activation of components
This function is used to check the control unit's signals to the selected component.
Test conditions:
  • Ignition on.
  • Transmission in neutral.
  • Gear sequence is not active.
  • Learning process for transmission is not active.
  • Clutch activation learned.
  • Transmission learned.
  • Oil temperature between 20-80 °C.
  • Select the component to be activated.
  • Battery voltage OK.
  • Working pressure in air system.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. Select the component to be activated.
  3. A dialogue box shows the test conditions, check these and press "OK".
  4. Start and stop activation of the selected component.
  5. Repeat the procedure for the components to be tested.
  6. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
