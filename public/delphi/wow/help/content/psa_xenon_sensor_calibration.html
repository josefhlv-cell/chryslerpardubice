[476]Calibrate level sensor for Xenon lights

The function adapts the body's level sensor to the control unit for correct level control of the headlights.

This function shall be performed after replacing or adjusting level sensor or after work on the wheel suspension.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • All power consumers disconnected.

  • Sensors and control unit correctly installed and adjusted.

  • The vehicle must stand on level ground.

  • Correct air pressure in tires.

  • The steering wheel stands straight and the front wheels point straight forward.

  • The car shall be unloaded and without driver.

  • Low beams on (economy mode inactive).

  • Released parking brake and car in neutral.

Procedure:

  1. Start the function.

  2. A dialogue box shows "Calibration in progress".

  3. A dialogue box shows if the function succeeded or failed.

    • If the function fails, check the test conditions and repair any faults.

  4. After successful calibration, adjust the headlights with the usual adjustment tool.

  5. Erase any fault codes.

  6. Finish and turn off the ignition for 30 seconds.

  7. The function is done, apply the parking brake.

    • If the function fails, check the test conditions and repair any faults.
