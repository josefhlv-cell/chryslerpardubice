Function check QMVH
This function is used to perform a function check of the rear axle stabilizer torque distribution (QMVH).
QMVH controls the extra control elements on the rear axle and distributes the drive torque targeted between the two wheels on the rear axle. In PR-situations the system also has the name "Dynamic Performance Control".
Note:
If the rear axle stabilizer torque distribution does not work the control/warning lights for DSC and X-Drive are turned on. If a malfunction occurs an associated symbol shows a check-control message in the LCD.
Test conditions:
  • No active error memory may be stored in the control unit.
  • Ignition on.
  • The battery voltage should be >12V.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Function complete.
