System status gateway
In vehicles where diagnostic communication takes place using a gateway, it is possible with this function to get a list over the systems in the vehicle and their current status. Very useful for service work, etc. The following status can be shown:
No fault codes.
The control unit participate in the data bus communication, no faults stored in the control unit.
Fault code stored.
The control unit participate in the data bus communication, one or more fault codes are stored in the control unit.
Coded, mounted.
The control unit is coded and mounted.
Coded, not mounted.
The control unit is coded, but not mounted.
Mounted, not coded.
The control unit is mounted, but not coded.
Test conditions:
  • Battery voltage above 12 V.
  • Ignition on.
Procedure:
  1. Select the function: "System status gateway", press "OK".
  2. A list with the systems in the vehicle and their current status is shown.
    • If the operation failed, check car selection and test conditions.
  3. Note if any system(s) has fault codes stored.
  4. Press "OK" to exit the function and return to the car selection.
  5. Select the relevant system to check and solve stored fault codes.
  6. The function is done.
