[447]Activate service mode on parking brake

This function is used to set the parking brake in service mode. The function shall be run before work on, e.g., replacing brake discs, pads, or brake calipers rear. After work is done the service mode shall be deactivated.

Test conditions:

  • Ignition on, engine off.

  • Parking brake released.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
