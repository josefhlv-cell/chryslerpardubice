Injector programming
This function is used to program new injector codes to the control unit after injector replacement. The injector code is printed on the injector's main part. The code consists of 30 characters.
Test conditions:
  • Ignition on, engine off.
  • Battery voltage above 12V.
Procedure:
  1. Press "OK" to start the function.
  2. A dialogue box confirms the programmed injector code.
  3. Confirm with "OK" to reprogram the injector code.
  4. Edit injector code and press the OK button to perform the programming.
  5. After succeded programming the old and new codes are displayed.
  6. Confirm with "OK" to finish the programming.
  7. CAUTION: If the programming failes, check the fault codes and that the right injector code is entered.
