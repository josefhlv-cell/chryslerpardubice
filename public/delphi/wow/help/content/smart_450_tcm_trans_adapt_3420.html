Learning of shift fork
This function is used to program the different gear positions for the gear module.
Note:
If the function fails, another try must be performed.
With difficulties to complete the function, you can rotate the drive wheels to get the gearbox to change position.
The gear selector may not be touched during the function.
Test Prerequisites:
  • Battery voltage above 12V.
  • Vehicle stationary.
  • Ignition on, engine off.
  • Gear selector in neutral position.
Procedure:
  • Start the function and follow the instructions in the program.
  • The gearbox now learns the new values for the different gears positions.
  • A dialogue box shows "Operation successful/failed".
  • If the function fails, check the test prerequisites and repair possible fault codes.
