[41]Reset adaptation values for particle filter

This function is used to reset the adaptation value for soot quantity and soot volume in the engine control unit.

Reset shall only be performed if the particle filter has been replaced.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

Procedure:

  1. Select the function.

  2. Confirm with "OK", the function starts.

  3. Follow the instructions shown on the screen during the adaptation sequence.

  4. The adaptation is done.

  5. Turn off the ignition and exit communication with the car for 30 seconds.

  6. Turn on the ignition, re-establish communication with the car, and check that no error codes have been stored.

  7. The function is done.

    • If the function fails, check the test conditions and repair any faults.
