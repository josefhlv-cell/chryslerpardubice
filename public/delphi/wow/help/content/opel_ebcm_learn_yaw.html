[252]Calibrate yaw angle sensor

This function is used to calibrate the yaw angle sensor. Teach-in of yaw angle sensor after certain service jobs:

  • Replacement of electronic brake control module (EBCM).

  • Replacement of anti-roll sensor.

Calibration should be performed in the following order.

  1. Select "Yaw angle rate sensor, reset" in the sensor module for multiple acceleration measurement (IMU)

  2. Select "Yaw angle rate sensor teach-in" in the sensor module for multiple acceleration measurement (IMU)

  3. Select "Yaw angle rate sensor teach-in" in the brake control module (EBCM).

Test conditions:

  • Ignition on, engine off.

  • The vehicle must stand on level ground.

  • Parking brake applied or gear selector in position P.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
