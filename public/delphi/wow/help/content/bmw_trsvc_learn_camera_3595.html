Learning the around-view-camera
This function is used to learn the different cameras (rear view camera, exterior mirror camera right and left, bumper camera right and left). After completed learning of the cameras, calibration is automatically performed, during travel, of rear view camera and exterior mirror camera. Bumper camera isn't possible to calibrate.
Note:
If a replacement of the control unit TRSVC has been done, it must be coded before the function can be performed.
Preconditions for the test:
  • Cameras connected.
  • Ignition on, engine off.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Function complete.
