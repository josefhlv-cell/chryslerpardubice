[1684]Steering angle calibration

This function is used to calibrate the steering wheel angle sensor. Before calibrating, the wheels must be set.

Note:

If three or more incorrect safety codes are generated, a safety delay is activated. During this safety delay, it is not possible to enter a code. The safety delay is doubled for each incorrect safety code generated.

Test conditions:

  • Ignition on, engine off.

  • The vehicle must be on level ground.

  • Access to safety code existing with other codes in a Car Pass (see image).

Procedure:

  1. Turn the steering wheel more than 5 degrees to the left or right.

  2. Turn the steering wheel so that the wheels are straight.

  3. Start the function and enter the safety code.

  4. Follow the instructions. Do not move the steering wheel during calibration.

  5. Clear any trouble codes after calibration.

  6. The function is complete.

    • If the function fails, check the test conditions and repair any faults.
