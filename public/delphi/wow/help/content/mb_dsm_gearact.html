[120]Test of gear positions

This function is used to test the different gear positions when troubleshooting.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • Parking brake and service brake applied.

Procedure:

  1. Start the function.

  2. The function starts, the gear module moves the controls to selected position.

    • A warning signal and warning text may be active during the process.

  3. When the gear controls have reached correct position, a dialogue box will be shown where you are instructed to turn the ignition off and on to finish the function.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
