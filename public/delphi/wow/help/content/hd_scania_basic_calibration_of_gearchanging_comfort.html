[1738]Basic setting of gearshifting comfort

This function is used to reset the adaptation values in the control system for the transmission. Basic setting shall be done after replacement of the "OPC" control unit, the engine, or parts included in the injection system.

Basic setting may reduce gearshifting comfort for a certain time.

Test conditions:

  • Ignition on.

  • Engine off.

  • Propeller shaft rpm = 0.

Procedure:

  1. Select the function, press "OK".

  2. Exit the function and exit communication with the car by returning to the car selection.

  3. Turn off the ignition for at least 5 seconds.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
