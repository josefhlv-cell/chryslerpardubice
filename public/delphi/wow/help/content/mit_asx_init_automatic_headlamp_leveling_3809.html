Initialization automatic headlamp levelling
This function is used to initialize the ECU for automatic headlamp levelling.
Note:
The function must be run after the following operations:
  • Replacing of the automatic headlamp levelling ECU.
  • When removing/installing the front height sensor.
  • When removing/installing the rear height sensor.
  • When removing/installing suspension related components.
Check that the fault codes B2511, B2512, B2514, B2515, B2516 is not set to the automatic headlamp levelling ECU. If it is set, perform troubleshooting before the initialization.
Test conditions:
  • Ignition on, engine off.
  • Position the car on a flat and level surface.
  • If the fuel tank isn't filled up, put weight in the luggage compartment to make up for the fuel shortage so that the weight will become 90% of full-state weight or heavier. (0.8 kg per litre).
  • The vehicle's driver seat should be loaded with one person (approx. 75 kg).
Procedure:
  1. First perform the function "Height sensor initial position clear".
  2. The headlamp automatic levelling warning is displayed on the multi information display in the combination meter.
  3. Then select the function "Height sensor initial position learning".
  4. Start the function and follow the instructions in the program.
  5. The headlamp automatic levelling warning on the multi information display in the combination meter will turn off.
  6. The function is done.
  7. After the function is completed, perform a headlamp adjustment.
