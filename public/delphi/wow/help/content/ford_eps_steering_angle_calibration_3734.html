Calibration of steering angle sensor
This function is used to zero-compensate the value from the steering angle sensor.
Note:
Calibration should be done if:
  • The ABS control unit has been replaced.
  • The steering angle sensor has been replaced.
  • The steering column has been replaced.
  • Bodywork that affects the wheel alignment has been done.
  • The steering angle sensor has been disconnected.
  • An error code that requires zero compensation is stored in the ABS control unit.
Test prerequisites:
  • Battery voltage above 12V.
  • Ignition on, engine off - the engine is started during the procedure.
  • The vehicle must be placed on a flat surface.
Procedure:
  1. Check that the steering wheel is in the correct position when the front wheels are straight ahead.
  2. Start the function and follow the instructions in the program.
  3. Start the engine.
  4. Turn the steering wheel to end position in both directions.
  5. Make sure that similar angle is reached on both sides. At deviation over 20%, must the steering angle sensor center position and wheel alignment be checked.
  6. The function is done.
  7. Turn off the ignition for at least 10 seconds.
  8. Perform a self test and erase any fault codes.
