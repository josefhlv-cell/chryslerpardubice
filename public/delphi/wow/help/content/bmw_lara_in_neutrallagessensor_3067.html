Learning the neutral position sensor
This function is used to learn the neutral position sensor, and should be done when the engine control module has been replaced. Learning is required to compensate the tolerances in the mechanics and the electrical system. In relation to the gear lever's learned zero point, the engine control module evaluates the maximal ranges where the engine may start when the clutch is operated.
Note:
MSA is deactivated during the function, and is activated again when the function is done.
During learning of the neutral position sensor, a CC-message will appear in the combination instrument, which disappears after the clamp change in the function.
Test conditions:
  • Engine idling.
  • Vehicle stationary.
  • Gear in neutral position.
  • Clutch unaffected.
Execution:
  1. Start the function and follow the instructions in the program.
  2. The function is done.
