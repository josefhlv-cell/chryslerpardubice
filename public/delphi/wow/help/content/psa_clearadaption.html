[1119]Clear adaption memory

The engine control unit learns and corrects possible deviations, in for example the lambda regulation system. These deviations are stored in the adaption memory. This function erases all the adaption values in the engine control unit. If a faulty lambda sond has been replaced, or a leaking exhaust system has been repaired, it is possible to clear the old and faulty adaption values with this function.

Test prerequisite:

  • Engine cold and not started for at least 10 minutes.

  • Ignition on, engine off.

  • No faults stored.

  • All electrical loads should be switched off.

Procedure:

  1. Choose the function: Clear adaption memory.

  2. When the function starts, the adaption values are cleared. A dialog box presents: operation succeeded/ failed.

  3. Exit the function and disconnect the diagnostic tool.

  4. Switch off the ignition for 15 seconds, and then switch it on for 30 seconds.

  5. Start the engine and let it idle until fully warm.

  6. Drive the vehicle in a various mode to complete the learning process of the new adaption values
