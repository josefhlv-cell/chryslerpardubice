Resetting information battery monitoring sensor (BMS)
This function is used to reset the information after replacing battery or battery monitoring sensor (BMS).
Note:
Applies only cars equipped with start/stop function.
Resetting shall only be performed after battery or battery monitoring sensor (BMS) has been replaced.
The battery monitoring sensor (BMS) needs 4-6 hours to calculate correct charging state after replacement.
Park the vehicle with removed key and locked doors for the stated time.
If the charging state still is low, brake energy regeneration and start/stop will not be permitted! The battery needs to be charged!
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function and follow the instructions in the program.
