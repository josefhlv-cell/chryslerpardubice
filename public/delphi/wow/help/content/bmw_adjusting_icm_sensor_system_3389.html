Adjusting ICM sensor system
This function is used for startup of ICM sensor system. Turn speed sensors and acceleration sensors are adjusted via the diagnosis.
The function must be performed in the following cases:
  • Change of ICM control unit.
  • At every dismounting and remounting of an ICM control unit.
Note:
If the vehicle body is tilted so that it is visible, it may lead to incorrect sensor values. This may cause loss of function, including fault memory registrations during driving. Follow the instructions carefully.
Test prerequisites:
  • Ignition on.
  • The vehicle must be on a flat and solid surface. Adjustments on the vehicle lift is not allowed.
  • The vehicle may not be fully loaded during the adjustment.
  • EHC and level sensors must be removed from service.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Function complete.
