[828]Coding headlight range control unit Sharan

Note:

Sharan has one control unit for the left headlight and one control unit for the right headlight. Both control units have the same code, but they are coded separately. After coding shall adjustment of headlight setting allways be performed.

Coding:

The headlight range control units must be recoded if the control unit has been renewed.

Code:

For coding headlight range control units on Sharan the following code is valid: 00005

To perform coding:

  • Write the current code in the coding headlight range control unit field.

  • Click on the OK-button.

  • A dialogue box confirms: Operation succeeded / Operation failed.

  • Read the control unit basic data to check that the new code is programmed.

  • When both control units are coded, continue with basic setting: Adjust light setting (left headlight).
