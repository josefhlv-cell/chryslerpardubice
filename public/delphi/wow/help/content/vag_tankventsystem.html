[1758]Testing tank ventilation system

This function is used to test the tank ventilation system. By alternately letting the coal canister valve be closed or active ("active" approx. 220-900 seconds open and approx. 70 seconds closed) it is possible to assess the tank ventilation system.

Test conditions:

  • Engine idling.

  • No faults in the system.

  • Engine temperature above 80°C.

  • Gear in position P/N.

Procedure:

  1. Select the function: "Tank ventilation system", press "OK".

  2. Switch between coal canister closed or active using the buttons in the function.

  3. When finishing, the coal canister valve is activated automatically.

    • If the function fails, check the test conditions and repair any faults.
