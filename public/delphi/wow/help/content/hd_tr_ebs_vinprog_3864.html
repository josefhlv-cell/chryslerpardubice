Program vehicle identification number
This function is used to program the vehicle identification number.
Test conditions:
  • The trailer shall be supplied with voltage with either a truck or another external voltage source.
  • The trailer is secured and cannot roll away.
Procedure:
  1. Start the function.
  2. Check the current vehicle identification number.
  3. Enter the new desired vehicle identification number (Between 5-17 characters).
  4. Check the new vehicle identification number.
  5. Function done.
  • If the function fails, check the test conditions and repair any faults.
