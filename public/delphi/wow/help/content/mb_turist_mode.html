[1700]Configure control unit for tourist lights

This function is used to adjust the headlights from left-hand traffic to right-hand traffic, or vice versa.

Set the tourist light in position "ON" in the following cases:

  • Car with right-hand drive is driven in country with left-hand traffic.

  • Car with left-hand drive is driven in country with right-hand traffic.

Set the tourist light in position "OFF" in the following cases:

  • Car with right-hand drive is driven in country with right-hand traffic.

  • Car with left-hand drive is driven in country with left-hand traffic.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

Procedure:

  1. Select the function and press "OK".

  2. A dialogue box shows: "Ignition on". Press "OK".

  3. A dialogue box shows if the operation was successful or failed.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
