[204]Calibrate the clutch's friction point

This function is used to calibrate the clutch's friction point.

Test conditions:

  • Ignition on, engine off.

  • Clutch bled.

  • Programming of the selection range sensor correct.

  • Climate system off.

  • Service brake and parking brake applied during the whole sequence.

Procedure:

  1. Start the function.

  2. Dialogue boxes appear to guide you through the entire sequence.

    • After finished calibration of the clutch's friction point, a dialogue box will show the teach-in value as well as the approved range for the clutch's friction point.

    • If the the clutch's friction point is outside the approved range, bleeding may be needed, or a clutch replacement.

  3. A dialogue box shows if the operation was successful or failed when the function is finished.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
