[237]Steering angle calibration.

This function is used if the control unit is replaced or bodywork that affects the wheel alignment has been done.

Test prerequisites:

  • Ignition on, engine off.

  • The vehicle must be placed on a flat surface.

  • Check that the steering wheel is in the straight ahead position.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. If the function fails, check the test conditions and repair any faults.
