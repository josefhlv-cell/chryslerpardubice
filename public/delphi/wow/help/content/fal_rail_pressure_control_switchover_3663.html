Rail pressure control switchover
This function is used for rail pressure control and to diagnose the high pressure system.
Note:
At the start of the function, current status is shown followed by a drop down list where you can select which diagnostic mode to be tested:
  • Pressure control valve.
  • Measuring unit.
  • Connected pressure regulation.
  • Exit routine.
Always exit the diagnostic mode by selecting "Exit routine".
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function and follow the instructions in the program.
