Service information
This function is used, before a service is performed, to read relevant service information from the control unit.
Test prerequisites:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. The relevant service information is displayed. The information can be saved or printed.
  3. Information on service items can be read from the list below.
  4. Press "OK" to exit the function.
