[1363]Throttle control unit

The basic setting matches ("adapts") the throttle control unit to the engine control unit. An adaption must be done when:

  • The throttle control unit has been removed or replaced.

  • The electric power to the engine control unit has been disconnected.

Test prerequisites:

  • Ignition on, engine off.

  • The battery voltage should be above 11.5 V.

  • The throttle pedal should be inactive.

  • The cooling temperature should be between 5-105 °C.

  • The intake air temperature should be between 5-143 °C.

  • If the cruise control is fitted, it must be working properly.

Procedure:

  • Chose the function: Thottle control unit.

  • During the adaption "Adaption running" shows in the adaption status field.

  • When the adaption has been performed, "Adaption OK" / "Adaption ERROR" is displayed.

  • The basic setting is finished. Exit the function

  • Switch off the ignition and wait at least 50 seconds to store the values.
