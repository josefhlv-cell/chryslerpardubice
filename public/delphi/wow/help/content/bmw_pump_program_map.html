[593]Adjusting pump curve

This function is used to reset the pump curve's values.

Used when:

  • Injection pump has been replaced.

  • Two or more injectors have been replaced.

Test conditions:

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.
