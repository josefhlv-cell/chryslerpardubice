[1524]Calibrate sensors for pad wear

After changing brake pads on the selected axle, the sensors for pad wear must be calibrated. Calibration may only be performed if new brake pads are installed on selected axle(s) and any fault codes are resolved.

Test conditions:

  • Parking brake released.

  • Wheels blocked.

  • Engine speed 1000 rpm, or constant air supply (12 bar) to air dryer.

  • New brake pads installed.

Procedure:

  1. Press down and let up the foot brake 10 times with the start key in running position.

  2. Start the function.

  3. When the function is done, turn off and on the ignition to save the change.

  4. Read out thickness of the brake pads after calibrating via test brake pad thickness. Thickness should be approx. 100%.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
