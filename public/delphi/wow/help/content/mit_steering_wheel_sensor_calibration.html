[1766]Calibrate steering angle sensor

This function is used to store the neutral position in the steering angle sensor.If the steering angle sensor's neutral position should be lost or has not been calibrated after repair, the steering angle sensor's warning light will indicate that the steering angle sensor is missing neutral position.This may also be caused by faults in the car's CAN-bus or that the battery has been disconnected.

When the function is done, perform steering angle calibration in the ABS/ACS control unit as well. NB! Turn off the ignition for 10 seconds after communication with the control unit for steering angle has ended, before communication with the ABS/ACS control unit is started.

The steering angle sensor must be calibrated after the following work:

  • The steering angle sensor has been replaced.

  • ABS/ASC control unit has been replaced.

  • A wheel alignment has been done on the vehicle.

Test conditions:

  • Ignition on, engine off.

  • The steering wheel stands straight and the front wheels point straight forward.

  • The vehicle must be on level ground.

Procedure:

  1. Start the function and read out calibration status for the steering angle sensor.

    • In case of "Not done", only a calibration of the steering angle sensor will be performed.

    • In case of "Done", first an initiation will be performed and then a calibration of the steering angle sensor.

  2. The function is done.

    • If the function fails, check the test conditions and repair any faults.
