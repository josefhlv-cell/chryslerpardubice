End of line test
This function is used to check the installation of the control unit.
Test conditions:
  • The trailer is anchored and standing on a level surface.
  • The constant air supply is connected.
Procedure:
  1. Raise the trailer.
  2. Start the function.
  3. Apply brake pressure to the trailer, run the brake pressure test until the "OK" button is displayed.
  4. Release the brake pressure.
  5. Confirm with the "OK" button.
  6. Release the parking brake.
  7. Rotate the wheel indicated by the test.
  8. The wheel should turn faster than 3 km/h for the test to continue.
  9. If the wrong wheel is rotated, or if the sensors are incorrectly connected, the test will be stopped.
  10. Confirm with the "OK" button.
  11. Check that the warning lamp lights.
  12. Confirm with the "OK" button.
    • If the function fails, check the test conditions and repair any faults.
  13. Print out a test report.
