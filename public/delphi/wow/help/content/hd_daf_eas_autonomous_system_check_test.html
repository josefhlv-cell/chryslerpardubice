[477]Automatic system test

This function is used to check EAS. Electrical and mechanical connections and components are checked during the test. The test runs for max. 220 seconds.

Test conditions:

  • Ignition on.

  • Air pressure above 8,000 mbar.

Procedure:

  1. Start the function.

  2. Wait until the result is shown, press "OK".

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
