[1469]Coding steering wheel electronics

To make all functions work correctly, the control unit must be coded according to the corresponding equipment.

Note:

  • A faulty coding can reduce the car´s safety/performance.

  • The control unit must be of a correct version to accept the code.

Test prerequisites:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • Electrical consumers switched off.

Procedure:

  1. Choose the function: "Code control unit".

  2. The actual code in the control unit is presented. "Change value is presented". Confirm with YES.

  3. Enter the new code (see below) in the presented input field, confirm with OK.

    Code number:Function:
    0 X X X X XLeft hand drive
    1 X X X X XRight hand drive
    X 0 X X X XWithout electrical steering column adjustment
    X 1 X X X XWith electrical steering column adjustment
    X X 0 0 X XStandard steering wheel without multifunction, Tiptronic control and steering wheel heating function
    X X 1 1 X XSport steering wheel with Tiptronic control
    X X 2 0 X XMultifunction steering wheel without Tiptronic control and steering wheel heating function
    X X 2 1 X XMultifunction steering wheel with tiptronic control, without steering wheel heating function
    X X 2 2 X XMultifunction steering wheel with steering wheel heating function, without Tiptronic control
    X X 2 3 X XMultifunction steering wheel with Tiptronic control and steering wheel heating function
    X X X X 0 XWithout trip computer, cruise control and adaptive cruise control
    X X X X 1 XWith trip computer, without cruise control and adaptive cruise control
    X X X X 2 XWith cruise control, without trip computer
    X X X X 3 XWith adaptive cruise control, without trip computer
    X X X X 4 XWith trip computer and cruise control
    X X X X 5 XWith trip computer and adaptive cruise control
    X X X X X 1Limousine
    X X X X X 2Avant (with rear window wiper)
    Coding example:

    Left hand drive vehicle with: multifunction steering wheel (without Tiptronic control, without steering wheel heating function), trip computer, cruise control and Avant = 002042

  4. A dialog box will confirm: code stored (with the new value) in memory.

    • If the coding operation fails, check if the code is valid.

  5. Confirm with OK to exit the function.

  6. Switch off the ignition for 60 seconds to store the new code.

  7. Re-establish contact with the system. Read and check the fault codes and the new code.

  8. Exit the function.
