[672]Accumulator depressurisation

Note:

This function reduces the pressure in the hydraulic unit and must always be performed before removing hydraulic pipes. The pressure in the system is normally around 45 bar.

Note! Remove the pump's electrical connection after the function has concluded. If the key is turned to 'ignition on' the pressure in the circuit will return to 45 bar.

Test conditions:

  • Engine off.

  • Stop&Start function disabled.

  • Actuator connection OK.

  • Clutch position sensor OK.

  • Brake pedal depressed during the whole function.

Procedure:

  1. Start the function and follow the instructions in the program.

  2. When the function has been performed. Turn the ignition off and remove the electrical connection to the pump.
