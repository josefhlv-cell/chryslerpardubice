[40]Basic setting of differential pressure sensor

This function is used to adapt the engine control unit after the differential pressure sensor for particle filter has been replaced.

The adaptation shall be run when the differential pressure sensor has been replaced.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The adaptation is done.

  4. Turn off the ignition and end communication for 30 seconds.

  5. Turn on the ignition, re-establish communication, and check that no fault codes are stored.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
