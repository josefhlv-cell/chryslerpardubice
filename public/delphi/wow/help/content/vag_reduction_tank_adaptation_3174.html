Adapting tank level reduction agent
This function is used to adapt the tank level for reduction agent to full in the engine control module. This shall be done if:
  • Work with the system for reduction agent has been done, which as a result requires that the reduction agent tank is topped up to full.
  • The engine control unit has been replaced.
Note:
The reduction agent tank must be full.
Test conditions:
  • Battery voltage above 12V.
  • Ignition on, engine off.
Procedure:
  1. Start the function and follow the instructions in the program.
    • If the function fails, check the test conditions and repair any faults.
