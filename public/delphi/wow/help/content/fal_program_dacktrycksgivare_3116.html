Programming of tire pressure sensors
This function shall be run when a new TPM ECU or new tire pressure sensors have been installed. After the function has been performed, run the function "TPM sensor test", to check the communication between the sensors and ECU.
Note:
Before the function is run, make sure that the 7-digit ID-codes are available. The codes are found on a label on the back of the wheel sensors or they can be read out using a TPM-tool.
Test conditions:
  • Ignition on.
  • Sensor's 7-digit ID-code available.
Procedure:
  1. Start the function and follow the instructions in the program.
