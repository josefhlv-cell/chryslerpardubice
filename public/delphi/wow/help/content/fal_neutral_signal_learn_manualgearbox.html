[398]Calibrate neutral signal

This function is used to teach the transmission its neutral position (only models with manual transmission). Faults in carrying out this procedure will affect function in the Start & Stop system.

The function must be run if any of the following is done.

  • Work on the transmission.

  • Neutral position sensor is replaced.

  • Transmission control module is replaced.

  • Engine control module is replaced.

Test conditions:

  • Engine off, ignition on.

  • Transmission in neutral.

  • Pedals may not be activated during the function.

  • No fault status (engine rpm, vehicle speed, and clutch sensor).

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
