Resetting the frequency counter
This function resets the frequency counter following the replacement of selected components.
The ignition must not be switched off during the reset.
Test conditions:
  • Ignition on.
  • Battery voltage above 12 V.
  • The components are replaced.
Procedure:
  1. Start the function.
  2. The current value is shown and the user has the option to reset the frequency counter.
  3. The frequency counter is reset and the new value is shown.
  4. The function is complete.
