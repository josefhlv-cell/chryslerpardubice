[542]Checking lambda sensor

This function is used to check that the lambda sensors before and after the catalytic converter works correctly. Shall be performed if one or both lambda sensors have been replaced.

Test conditions:

  • Engine started at idle (800 rpm +/-25).

  • Lambda sensors working.

  • Coolant temperature above 80 °C.

  • Fault codes erased.

Procedure:

  1. Start the function and follow the instructions in the program.
