[200]Self-test of combination instrument

Functions that are tested:

  • Control drive circuit buzzer.

  • Control indication circuit.

  • Test input switches.

  • Control LCS segment.

  • Control drive circuit gauges.

During the self-test the instrument panel's light control will work normally with the light on. The "SELECT" or "TRIP RESET"-button can be used to start drive circuit for buzzer and gauges. The self-test will be cancelled if the vehicle's speed exceeds 2 km/h or if the ignition is turned off.

Test conditions:

  • Ignition on

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.
