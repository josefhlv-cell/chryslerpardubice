[646]Calibration of position sensors

When replacing the headlight module or any of the position sensors, these have to be recalibrated.

Note! When changing to a new control module, the error code B104154 is generated. After calibrating position sensors the error code is erased.

Test conditions:

  • Ignition on.

  • Vehicle stationary.

  • Vehicle unloaded.

  • The vehicle must stand on level ground.

  • One person in the driver's seat.

  • Reverse gear (R) may not be engaged.

Procedure:

  1. Start the function and follow the instructions in the program.

  2. The function is done.

    • If the function fails, check the test conditions and repair any faults.
