[1749]Code steering wheel electronics

The control unit must be coded according to the corresponding equipment in order for all functions to work correctly. Correct code can be read from the list below. The control unit must be of the correct type to approve the code.

Code example: 002042

  • Left-hand drive

  • Without electric steering column adjustment, without lane keeping assist

  • Multi-function steering wheel without control for Tiptronic, without steering wheel heating

  • With trip computer, with cruise control

  • Avant (with rear window wiper)

Note:

Incorrect coding may reduce the car's safety and function.

Test condition:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • All power consumers disconnected.

Procedure:

  1. Select the function: "Code control unit".

  2. Existing code in control unit is shown.

  3. Question about changing value is shown.

  4. Enter the desired code (see below) in the displayed entry field, confirm with "OK".

  5. A dialogue box shows: code stored (with the new value) in the memory.

    • If coding failed, check that the code is valid.

  6. Confirm with "OK" to exit the function.

  7. Turn off the ignition for 60 seconds to store the new code.

  8. Establish contact with the system. Read out and check any fault codes and the new code.

  9. Exit the function.
