Calibration for opening the liftgate
This function is used to perform a calibration for complete opening of the liftgate. The function must always be performed after replacing the ECU or liftgate.
Preconditions for the test:
  • Ignition on.
  • The liftgate must be fully closed.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Function complete.
