[346]Reset immobilizer

This function is used, when necessary, to temporarily reset the immobilizer in case of reduction agent shortage. This makes it possible to drive the car to the closest workshop, the range is limited to approx. 50 km after performed reset, then reduction agent must be filled. Cars equipped with an SCR-system (Selective Catalytic Reduction) use a urea ammonia nitrate-based reduction agent, also called AdBlue, which is injected in the exhaust system in small doses to reduce exhaust emissions. In cars equipped with an SCR-system, reduction agent must be used according to legislation. In case of system malfunction or shortage of reduction agent, the car cannot be started. The reduction agent is stored in a separate tank, it is not mixed with the diesel fuel.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. Reset is run.

  4. The function is done.

  5. Exit the function and start the car.
