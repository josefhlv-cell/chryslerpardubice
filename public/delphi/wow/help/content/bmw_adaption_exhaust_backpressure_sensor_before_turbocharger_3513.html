Adaption exhaust back pressure sensor before turbocharger
This function is used to reset the adaption values. When this is done, the original values are restored in the control unit. The characteristic curve of the exhaust back pressure sensor is then adapted during driving.
The function must be run after the following operations:
  • After replacement of the exhaust back pressure sensor before turbocharger.
  • After replacement of boost pressure sensor.
Test conditions:
  • Ignition on.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Function complete.
