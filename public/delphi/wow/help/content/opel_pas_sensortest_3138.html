Parking aid sensor test
This function is used to test the parking sensors.
Test conditions:
  • Vehicle positioned so that there are no objects within the parking sensors' operating range.
  • Parking sensors cleaned and free from snow, ice, mud, etc.
  • Ignition on, engine off.
Procedure:
  1. Press "OK" to start the function.
  2. The function is complete; check that no trouble codes are stored.
