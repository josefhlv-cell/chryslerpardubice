[390]Glow plug replacement

This function is used to reset the adaptation values for the glow plugs. During driving, values are stored for the individual glow plugs in the glow plug module, if one or several glow plugs have been replaced the values must be reset. The values may only be reset for the cylinder(s) where a glow plug has been replaced.

The function has two alternatives:

  • Resetting values for all cylinders - if all glow plugs have been replaced.

  • Resetting values for individual cylinder - if glow plug for an individual cylinder has been replaced.

Test conditions:

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Select the cylinder for which the glow plug has been replaced or select "All cylinders" if all glow plugs have been replaced.

  3. Press "OK" to reset the values.

  4. If additional glow plugs have been replaced, select "YES" to reset values for the next cylinder, of no other values are to be reset, select "NO" to exit the function.

  5. The function is done

    • If the function fails, check the test conditions and repair any faults.
