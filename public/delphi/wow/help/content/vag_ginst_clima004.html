[1297]Climatronic, basic setting.

Test conditions:

  • Battery voltage above 11.5 V.

  • No faults stored.

  • Ignition on.

Note:

  • Basic setting must be performed when one off the following are replaced: Control unit, position motor fresh/recirculation or position motor temperature damper.

  • During basic setting the positioning motors values will be presented in the datalist. When both positioning motors are presenting 0, the basic setting is completed.

Procedure:

  • Start the function.

  • Check the values of the positioning motors.

  • When both positioning motors are presenting 0, the basic setting is completed.

  • Exit the function.
