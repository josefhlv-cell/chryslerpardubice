Temperature correction of engine fan
This function is used to adjust the temperature dependent limit for start of the electrical fan to the combustion engine or the air conditioning.
Note:
A positive temperature correction allows the fan to start earlier.
A negative temperature correction allows the fan to start later.
The limit can be reached earlier than minimum/maximum value, depending on the control unit conditions.
Test conditions:
  • Ignition on, engine off.
Procedure:
  • Start the function.
  • Use +/- buttons to increase/decrease.
  • Adjust to the desired value or until the limit is reached.
  • Exit the function with "OK".
