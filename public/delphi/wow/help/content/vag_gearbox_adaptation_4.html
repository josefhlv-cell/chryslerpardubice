[292]Basic setting of DSG transmission

When the direct transmission's (DSG) shifting unit (mecatronic unit) has been replaced or if any of the fault codes 1078 or 18115 are stored in the control unit, it is necessary to perform a basic setting.

The following basic settings shall be performed in the following order:

  1. Gear selector position sensor.

  2. Synchronization positions.

  3. Main pressure, zero positions.

  4. Resetting tiptronic switches in the steering wheel.

Note:

Basic settings shall be performed in the order according to the above. During the whole basic setting procedures, the engine should idle and the brake pedal should be pressed down.

Test conditions:

  • Engine idling.

  • Transmission temperature between 30 and 100 °C.

  • Gear selector in position P.

  • Brake pedal pressed down.

  • Gas pedal not affected.

Procedure:

  1. Select the function: Gear selector/position sensor.

    • Prescribed value: Gear selector, index should count up from 0 to 4.

  2. Select the function: Synchronization positions.

    • Prescribed value: Index, synchronization should count up from 0 to 4.

  3. Select the function: Main pressure, zero values.

    • Prescribed value: All parameters should show 0.00 bar.

  4. Select the function: Resetting tiptronic switches in the steering wheel.

    • Prescribed value: All displayed digits should change to 0 or 1.
