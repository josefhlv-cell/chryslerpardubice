Recall service message
This function is used to reset the service message.
Note:
To recall service message maybe a security code needs to be entered (picture 1). The valid security code can be found in a Car Pass among other codes (picture 2). The security code is a safety measure to protect the vehicle from unauthorised tampering.
Picture 1
Picture 2
Resetting service message may be possible to perform without security code. In the function, you can choose to try to perform the reset without security code.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. A dialogue box shows "Do you want to try without security code?. Press "YES" to try without security code. Press "NO" to use the security code.
  3. Follow the instructions in the program.
  4. The function is complete.
Incorrect input of the security code three times or more will lead to a security waiting period. During this waiting period it is not possible to enter the code. The security waiting time will be doubled for every incorrect input.
