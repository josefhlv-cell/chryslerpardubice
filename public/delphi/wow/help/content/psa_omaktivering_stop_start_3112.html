Reactivation of the function Stop & Start
This reactivation is used to check the Stop & Start function and should be run after the battery has been disconnected.
Test prerequisites:
  • The battery's charging state should be above 75%.
  • Ignition on, engine off.
  • No faults stored.
Performance:
  1. Start the function.
  2. A dialogue box shows the result.
  3. Exit the function.
