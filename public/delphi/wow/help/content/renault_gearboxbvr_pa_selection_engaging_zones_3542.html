Programming of gear selector sensor
This function is used to reset the adaptation values in the control unit for the transmission.
When repairing or replacing transmission parts as well as clutch parts it is important to learn the gear selector's position sensor to obtain correct shifting function.
Note:
When replacing or programming the control unit, always use the command "Reset: Shutdown of hydraulics during work", before performing programming of gear selector sensor.
Test conditions:
  • Engine off.
  • Gear selector in N.
  • handbrake applied.
  • Coolant temperature below 50 °C.
Procedure:
  1. Start the function and follow the instructions in the program.
