[380]Reset adaptation values for swirl flap

This function resets adaptation values for swirl flap, the function is used when swirl flap has been replaced. When the swirl flap has been replaced new values are taught into the engine control unit when the engine starts.

Test conditions:

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Adaptation values are reset in the control unit.

  3. Turn off the ignition.

  4. Replace swirl flap.

  5. Wait at least 3 minutes.

  6. Turn on the ignition.

  7. The function is done.

    • If the function fails, check the test conditions and repair any faults.
