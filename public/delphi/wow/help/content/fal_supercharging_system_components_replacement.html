[585]Replacement components supercharging system

This function is used to reset all adaptive parameters for the compressor/turbo group and boost pressure counter in the control unit.

Note:

Shall be performed after:

  • Turbo replacement.

  • Turbo actuator replacement.

  • Turbo vacuum valve replacement.

If this is not done the following consequences may occur:

  • Possible reduced performance.

  • Unmotivated diagnostics.

  • Very poor driveability.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function and follow the instructions in the program.
