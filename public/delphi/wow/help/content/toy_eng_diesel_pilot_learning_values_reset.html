[430]Reset adaptation values for pilot injection volume

This function is used to reset teach-in value for pilot injection volume to the injectors. The function is run after injectors have been replaced.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. Repeat the function until all replaced injectors have been reset.

  4. The function is done.
