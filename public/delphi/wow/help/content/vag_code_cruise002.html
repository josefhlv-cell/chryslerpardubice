[1262]Activate and deactive cruise control system

When installing cruise control it is necessary to activate the cruise control function in the engine control unit. You can also deactivate the function if cruise control is removed.

  • Some models require recoding of the control unit for steering wheel electronics for correct function, see manual for cruise control.

Test condition:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Enter code number (5 digits) and press "OK".

    Coding numberStatus
    11463Activate cruise control system
    30903Activate cruise control system with automatic distance adjustment
    16167Deactivate cruise control system

  3. A dialogue box shows "Stored in memory", press "OK".

  4. Exit the function and turn off and on the ignition to store the change.

  5. After activating the cruise control system, check the function by test-driving.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
