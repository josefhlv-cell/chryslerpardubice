[222]Basic setting of inlet valves

With this function it is possible to perform a basic setting of the inlet valves. This should be done when the control module for ABS has been replaced.

Note:

  • The ignition must not be turned off during the adaptation.

  • If a basic setting of inlet valves is done, a basic setting of the abs valves must be performed.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • Do not touch the brake pedal during basic setting.

Procedure:

  1. Start the function.

  2. A dialogue box with the text "Status for basic setting" shows "In progress" and changes to "Done" when basic setting is finished.

  3. Press "OK" to exit the function.

  4. Exit communication with the system and turn off the ignition.

  5. Turn on the ignition again and re-establish communication with the system and continue with the function "Basic setting abs valves".

    • If the function fails, check the test conditions and repair any faults.
