[474]Programming of gear lever sensor

This function is used to program the selection and engaging zones of the gearlever sensor.

Note:

This configuration should only be done if the vehicle is equipped with this component. The configuration could take up to one minute, and in the meantime, a window appears with the text "Please wait".

Test prerequisites:

  • Gearlever in position P.

  • Ignition on.

  • Engine off.

  • Brake pedal released.

Procedure:

  1. Start the function

  2. Wait for "Function complete"

  3. If the function fails, check the test prerequisites.
