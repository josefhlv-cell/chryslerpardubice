[1494]Learning throttle adaptation

This function program the throttle with new adaptation values.

Note: This function should be performed:

  • After replacing the throttle.

  • If the vehicle has unreasonable fuel consumption.

If the learning completes incorrectly, fault code 1687 (throttle, learning faults) will be registered, check the following possible causes:

  • Engine started.

  • Coolant temperature out of range.

  • Signal out of range.

  • Air temperature signal.

  • Incorrect contacts or cables.

  • Throttle potentiometer fault.

  • Engine ECU fault.

Test conditions:

  • No faults in the system.

  • Ignition on, engine off.

Procedure:

  1. Press OK to start the function.

  2. The throttle's learning phase takes around 10-15 seconds.
