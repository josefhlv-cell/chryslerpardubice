Key programming
This function is used to erase and program keys. All fault codes in the immobiliser system must be dealt with and erased before programming can be carried out .
Note:
Keys can be programmed in several ways:
  • Erase keys: This procedure erases all remote control keys from the control unit's memory. Ensure that all the remote control keys to be added exist.
    1. Start the function.
    2. Select the remote control key to be added. Press and hold the lock and unlock buttons together on the remote control key. The "Programmed" parameter is displayed when the key has been added to the control unit.
    3. Repeat step 2 until all the keys have been learned.
    4. Stop when the process is complete.
  • Next available memory location: This procedure adds remote control keys which are programmed to the first free location in the control unit.
    1. Start the function.
    2. Select the remote control key to be added. Press and hold the lock and unlock buttons together on the remote control key. The "Programmed" parameter is displayed when the key has been added to the control unit.
    3. Repeat step 2 until all the keys have been learned.
    4. Stop when the process is complete.
  • Remote control key 1: This procedure replaces a previously learned remote control key with a new remote control key in memory location 1.
    1. Start the function.
    2. Select the remote control key to be added. Press and hold the lock and unlock buttons together on the remote control key. The "Programmed" parameter is displayed when the key has been added to the control unit.
    3. Stop when the process is complete.
  • Remote control key 2: This procedure replaces a previously learned remote control key with a new remote control key in memory location 2.
    1. Start the function.
    2. Select the remote control key to be added. Press and hold the lock and unlock buttons together on the remote control key. The "Programmed" parameter is displayed when the key has been added to the control unit.
    3. Stop when the process is complete.
  • Remote control key 3: This procedure replaces a previously learned remote control key with a new remote control key in memory location 3.
    1. Start the function.
    2. Select the remote control key to be added. Press and hold the lock and unlock buttons together on the remote control key. The "Programmed" parameter is displayed when the key has been added to the control unit.
    3. Stop when the process is complete.
  • Remote control key 4: This procedure replaces a previously learned remote control key with a new remote control key in memory location 4.
    1. Start the function.
    2. Select the remote control key to be added. Press and hold the lock and unlock buttons together on the remote control key. The "Programmed" parameter is displayed when the key has been added to the control unit.
    3. Stop when the process is complete.
Test conditions:
  • Ignition on, engine off.
  • No faults in the system.
Procedure:
  1. Start the function.
  2. A dialogue box displays the remote control key status. Press "OK" to proceed.
  3. Select desired alternative in the dropdown list and press OK. Then follow the instructions shown in the function.
