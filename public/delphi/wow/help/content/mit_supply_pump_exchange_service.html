[282]Basic setting of feed pump

The engine's control unit learns the relationship between the suction valve for the feed pump and the fuel injection volume. The value is calculated using values from the suction valve's current and the output voltage on pressure sensor fuel rail. For this reason, this function should be run when the feed pump has been replaced. New teach-in takes place when the engine is idling after the function has been run. Time to run the initiation is between 5-10 minutes.

Using data list 48 "High-pressure pump learned status" it is possible to follow the initiation's status.

  • New initiation: 255

  • Started initiation: 1

  • Finished initiation: 2

Test conditions:

  • Ignition on, engine off - the engine is started during the procedure.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. After finished initiation, start the engine and let it idle according to the following conditions:

    • Accelerator pedal fully released.

    • Engine coolant temperature: 60 °C or higher.

    • Fuel temperature: 30 °C or higher.

  4. Initiation is finished when data list 48 "High-pressure pump learned status " has status 2.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
