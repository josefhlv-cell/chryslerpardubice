[7]Adapting transmission

This function is used to reset the adaptation values in the control unit for the automatic transmission. After resetting it is necessary to program new adaptation values by driving in reverse and forward.

Note:

Adaptation should be performed if:

  • The control unit for the transmission has been replaced.

  • Coding of the control unit for the transmission has been performed.

  • The transmission has been replaced.

  • The hydraulic control unit has been replaced.

  • The input shaft has been replaced.

Test conditions:

  • Transmission's oil temperature between 80°C - 95°C.

  • Engine on.

  • No faults in the system.

  • Engine speed during programming of new adaptation values should be max. 1500 rpm.

  • Vehicle speed during programming of new adaptation values should be max. 15 km/h.

Procedure:

  1. Start the function and follow the instructions in the program.
