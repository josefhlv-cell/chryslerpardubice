[622]Resetting ECT-memory

This function is used to reset the learned memory in the ECT control unit.

Note:

A memory reset is necessary after replacing the valve housing or the automatic transmission.

When the function is done, perform the following steps:

  1. Turn off the ignition for 5 sec., and turn it on again.

  2. Drive the vehicle in a stop/start pattern for approx. 15 min.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Adaptation is performed.

  3. The function is done.
