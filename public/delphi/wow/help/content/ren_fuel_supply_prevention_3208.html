Fuel shut-off
This function is used to lock the injectors and shut off the fuel flow regulators so that the engine cannot be started as well as to check cylinder compression without risk of fuel injection.
Note:
Fuel shut-off is active until the function "Disable fuel shut-off " has been performed. If this function is not available for the vehicle, the ignition may have to be turned off for up to 30 minutes to manually disable fuel shut-off.
Test conditions:
  • Ignition on and engine off.
Procedure:
  1. Start the function.
