[1367]Adjusting headlights with xenon lamps

Before the adjustment of the headlights is performed on vehicles with xenon lamps, basic setting of the automatic headlight range control must always be carried out. The basic setting disconnects the control mechanism to make headlight adjusting possible. If basic setting is not performed the headlight range control device will be damaged.

Note:

  • The vehicle must not be moved during the adjustment; to open/close doors or lean on the vehicle is not allowed. When headlights, vehicle level senders or headlight range control unit are renewed, a basic setting must be performed.

Test prerequisities:

  • The battery voltage should be above 12 V.

  • Ignition on, engine off.

  • No faults should be stored in the fault memory.

  • Headlamp lenses unbroken and clean.

  • Reflectors and bulbs ok.

  • Tyre pressure ok.

  • Handbrake released and no gear selected.

  • Wheels in a straight-ahead position.

  • Vehicle correctly loaded and springs settled.

  • Vehicle and headlight adjuster on a level surface and aligned.

Procedure:

  1. Read and check the inclination. The inclination value is embossed in trim above the headlight. It is stated in percentage and based on a projection distance of 10 metres. A value of for example 1,2 % corresponds to 12 centimetres.

  2. Select the basic setting: "Adjust light setting".

    • The headlights will now be moved into the adjustment position and the fault code "01539" is stored. This is confirmed with the text: "Headlight adjustment".

  3. Exit the basic setting.

  4. Adjust the headlights according to the national legislation and regulations.

  5. Select the basic setting: "Adjust light setting" again.

    • The new headlight setting is stored. This is confirmed with the text: "Control position learned".

  6. Exit the basic setting.

  7. Turn the ignition off and on to initialize the system.

  8. Read the fault codes and check that no faults are stored.
