[1249]Zero compensation of the lateral acceleration sensor

This basic setting is used to zero-compensate the value from the lateral acceleration sensor. This must be done if:

  • The ABS control unit has been replaced.

  • The lateral acceleration sensor has been replaced.

  • A fault code that requires a basic setting is stored in the ABS control unit.

Note:

During the basic setting, the ignition must not be switched off.

Test prerequisites:

  • The battery voltage should be >12 V.

  • Ignition on, engine off.

Performance:

  1. Position the car on a flat and level surface.

  2. Choose the basic setting: Zero compensation of lateral acceleration sensor.

  3. The text: ”Adaption correct” confirms that zero compensation has been done. If the value for the lateral acceleration sensor is too high, zero compensation will not be accepted (adaption not possible).

  4. Exit the function and check the lateral acceleration sensor value in the datalist meny.
