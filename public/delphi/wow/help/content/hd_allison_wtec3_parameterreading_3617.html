Parameter reading
This function is used to read out parameters from the control unit.
Test conditions:
  • Ignition on.
Procedure:
  1. Start the function.
  2. Wait until the parameter values are presented.
  3. Check the parameter values.
  4. Press the "OK" button.
  5. Turn off the ignition and press OK.
  6. Wait 10 seconds.
  7. Turn on the ignition. Press "OK".
  8. Function done.
  • If the function fails, exit the diagnosis, turn the ignition off for 10 seconds and then try again.
