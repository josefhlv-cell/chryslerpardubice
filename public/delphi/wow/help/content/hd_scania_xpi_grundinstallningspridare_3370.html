Basic setting of injectors
This function is used to perform a basic setting of all the injectors. The function ensures that the engine gets the best possible fuel economy and performance.
Note:
The function should be performed after that one or several injectors are programmed.
Test prerequisites:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Press "OK", basic setting is performed.
  3. The function is done.
