[738]Service warning on the display

This function is used to turn the service warning for the various types of service on the display on or off.

Note:

If the display service warning is deactivated, the vehicle will never warn you of an imminent need for service.

Test conditions:

  • Ignition on.

  • Engine off

  • Parking brake applied.

Procedure:

  1. Start the function.

  2. Check test conditions.

  3. Select service type.

  4. Check current status.

  5. Select other status or exit function.

  6. Select which status the service warning should have.

  7. Check the new current status.

  8. Select to make more changes or exit function.

  9. If you wish to make more changes, repeat from step 3.

  10. Function complete.

    • If the function fails, check the test conditions and try again.
