[1061]Calibration of headlight range control (Xenon)

The automatic headlight range control system works towards a front and a rear level sensor. This function compensates the light adjustment automatically depending of load. When a calibration of the headlight range control system is performed an eventual deviation of the starting position will be compensated. The starting position can be read in the data list parameters as front/rear level sensor start value.

Note:

When calibration is performed the level sensors actual value is compared with the starting values. If the values do not match is the current value stored as a new value and the headlights will be adjusted with the change.

Test prerequisites:

  • Engine idling.

  • Bonnet open.

  • No fault codes stored.

  • Dipped headlights unbroken and lamps ok.

  • Dipped headlights on.

  • Correct tyre pressure.

  • Handbrake released and gear in neutral position.

  • The vehicle correctly loaded.

  • The vehicle on a level surface.

Performance:

  1. Choose function: ”Automatic calibration”

  2. A dialog box present: Calibration in progress.

  3. Then the calibration is finished a dialog box present: operation succeeded.
