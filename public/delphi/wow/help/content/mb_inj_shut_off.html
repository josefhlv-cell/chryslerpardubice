[318]Cylinder shut-off

This function is used to shut off fuel injection for a limited time. Turning off the fuel injection enables, among other things, compression test. A time indication shows how long the injection is shut off, during this time the starter motor can be run without the engine starting. The function takes approx. 20 seconds.

Test conditions:

  • Engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. A time indication shows how long the injection is shut off.

  3. A dialogue box is shown with the instruction to turn off the ignition and then turn it on again to finish the function.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
