[502]Test of urea injection

The purpose of the test is to check the function of the urea injector.

Sound should be heard from the urea injector during the test.

Test conditions:

  • Parking brake applied.

  • Engine off.

  • Ignition on.

  • "Starting SCR operation, test" must be finished.

  • Adblue in reservoir.

  • Battery voltage above 20V.

Procedure:

  1. Start the function.

  2. Check conditions.

  3. Select to start or cancel the test.

  4. Check the working pressure while the test is in progress.

  5. Check status of the test.

  6. Turn off the ignition and press OK.

  7. Wait 10 seconds.

  8. Turn on the ignition and press OK.

  9. The function is done.

    • If the function fails, check the test conditions and repair any faults.
