[1648]Change time delay for locking tank hatch

This function changes the time delay from the vehicle being locked to locking of the tank hatch.

There are two time alternatives to choose between:

  • Time delay 10 minutes.

  • Time delay 0 minutes.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the function: "Programming time delay, locking tank hatch", press "OK".

  2. A dialogue box with present configuration is shown.

  3. Press "OK" to continue.

  4. Select desired value, press "OK" to start programming.

  5. Programmed value is shown after successful programming.

  6. Press "OK" to exit the function.
