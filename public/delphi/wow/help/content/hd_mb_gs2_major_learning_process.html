[122]Major programming for control unit GS II gear control

Major programming should only be performed if another transmission type / engine type has been installed or if Telma retarder has been retrofitted.

Note:

In vehicle with electric drive control (EAS), the clutch curve must be erased in control unit FR.

In case of major programming, transmission type, road sensors' movement values for clutch, split, range, gate, or gear are calculated again.

During programming, instructions must be followed for pressing down the clutch completely and releasing it completely to avoid transmission breakdown due to incorrect programming data from the clutch.

In vehicle with electric drive control (EAS), clutch operation is automatic.

On the display the split arrows will flash alternately during the entire programming.

The neutral button is located on the passenger side of the gear selector lever.

The function button is located on the driver side of the gear selector lever.

If indication "N" (Neutral) is shown on the display, programming has been finished correctly.

If programming is cancelled by a fault, the fault code number is shown on the instrument's display. For explanation of fault code, se list below.

Test conditions:

  • Ignition on, engine off.

  • All power consumers disconnected.

Procedure:

  1. Turn off ignition.

  2. Parking brake applied.

  3. Press down the clutch pedal completely and hold it down (Does not apply to EAS-vehicle).

  4. Press in the Neutral button and the Function button, keep them pressed in during the whole programming.

  5. Turn on the ignition.

  6. Let up the clutch completely at the 1st sound signal (Does not apply to EAS-vehicle).

  7. Press down the clutch pedal completely at the 2nd sound signal (Does not apply to EAS-vehicle).

  8. Start the engine when Neutral (N) flashes on the display.

  9. Let up the clutch completely at the 3rd sound signal (Does not apply to EAS-vehicle).

  10. Press down the clutch pedal completely at the 4th sound signal (Does not apply to EAS-vehicle).

  11. Let up the clutch completely at the 5th sound signal (Does not apply to EAS-vehicle).

  12. Press down the clutch pedal completely at the 6th sound signal (Does not apply to EAS-vehicle).

  13. If indication "N" (Neutral) is shown on the display, programming has been finished correctly.

    If programming fails: Repeat programming, repair any faults in control unit GS II.

    GS II 11 Programming error: Programming values for gear are incorrect.

    GS II 12 Programming error: Programming values for gear are incorrect.

    GS II 13 Programming error: Programming values for gate are incorrect.

    GS II 17 Programming error: Programming values for range are incorrect
