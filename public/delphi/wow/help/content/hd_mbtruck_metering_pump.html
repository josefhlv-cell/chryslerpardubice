[571]Checking/filling, metering pump

The test checks that the pump works.

Can also be used to fill lines when commissioning.

Note:

The test can only be started when the fan has stopped.

It may continue for up to 3 min.

When filling lines, run the pump for 30 sec.

Test conditions:

  • Ignition on.

  • Engine off.

Procedure:

  1. Start the function.

  2. The fan's condition is checked.

  3. Perform check/filling.

  4. Press "OK" to finish.
