Resetting gearshift unit's engagement point
This function is used to reset the adaptation value for the gearshift unit's engagement point to a prescribed value.
The function shall be performed if:
  • Repair has been performed on gearshift unit's pistons.
Preconditions for the test:
  • Ignition on, engine off.
  • Gear selector in position P.
Procedure:
  1. Start the function and follow the instructions in the program.
  • If the function fails, check the test conditions and repair any faults.
