Resetting values diesel particulate filter
This function is used to reset the values for the diesel particulate filter.
Note:
Used for resetting at:
  • Replacement of particulate filter.
  • Replacement of differential pressure sensor.
  • Replacement of nitrogen oxide catalyst.
  • Replacement of emission-relevant engine component.
  • Resetting diesel particulate filter at frequent particle filter replacement.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Select the function and follow the instructions.
