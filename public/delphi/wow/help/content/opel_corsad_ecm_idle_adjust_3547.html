Configure idle speed
This function is used to adjust the idle speed.
Test conditions:
  • Engine idling.
  • Coolant temperature above 70°C.
Procedure:
  1. Start the function.
  2. A dialogue box presents "Requested idle speed", "Engine speed" and "Idling speed offset".
  3. Correct the idle speed using the +/- buttons.
  4. When the idle speed is satisfying, press "OK" to complete the programming or press "Abort" to cancel the programming.
  5. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
