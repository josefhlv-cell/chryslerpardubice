[1604]Filling fuel system

This function is used to fill the fuel line after replacing or repairing components in the fuel system.

Note:

  • Filling takes approx. 3 minutes.

Test conditions:

  • Ignition on, engine off.

  • Parking brake applied.

Procedure:

  1. Select the function: "Filling fuel line".

  2. A dialogue box is shown, confirm with "OK" to start the function.

  3. After approx. 3 minutes the following is shown: "function done", confirm with "OK".
