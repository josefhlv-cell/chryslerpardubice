[526]End of line test

This function is used to check the installation of the control unit.

Test conditions:

  • The trailer is anchored and standing on a level surface.

  • The constant air supply is connected.

Procedure:

  1. Start the function.

  2. Check the warning lamp.

  3. Confirm with the "OK" button

  4. Raise the trailer.

  5. Rotate the wheel indicated by the test.

  6. The wheel should turn faster than 3 km/h for the test to continue.

  7. If the wrong wheel is rotated, or if the sensors are incorrectly connected, the test will be stopped.

  8. Confirm with the "OK" button.

  9. Confirm calibration of the inclination sensor with the "OK" button.

  10. Should calibration of the inclination sensor fail, it may be due to the trailer not standing on level ground or the control unit not being installed correctly.

  11. Conclude the test by confirming with the "OK" button.

  12. The function is complete.

    • If the function fails, check the test conditions and repair any faults.

  13. Print out a test report.
