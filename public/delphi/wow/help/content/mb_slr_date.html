[1499]Setting of service date

This function is used when the service date needs to be changed.

Note:

During this function, the ignition must not be switched off.

Test prerequisites:

  • Ignition on, engine off.

  • Battery voltage above 12 Volts.

Procedure:

  1. Start the function, press "OK".

  2. A dialogue box will present the value (date) stored in the control unit.

    • To change the value press "Yes".

    • To exit the function without changing the value press "No".

  3. Enter the new value with 4 digits in the presented input field (MMYY).

    Example: June 2008, enter 0608.

    Example: December 2011, enter 1211.

    • To store the value press "OK".

    • To exit the function without changing the value press "Cancel".

  4. A dialogue box confirms: Operation succeeded / Operation failed.

  5. The function is now completed.
