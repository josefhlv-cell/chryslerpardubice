Adaptation of the clutch's slip point
This function is used to program the clutch's slip point after replacement.
Note:
During this function, the engine will start automatically.
Test Prerequisites:
  • Ignition on, engine off - the engine is started during the procedure.
  • Vehicle stationary.
  • Parking brake applied.
  • Battery voltage above 12V.
  • Gear selector in neutral position.
  • The control unit shall be approved by the start inhibitor system.
Procedure:
  1. Start the function.
  2. The engine will start and idling during the function.
  3. The clutch will now detect the slip point.
  4. A dialogue box shows the result of the calibration when it is done.
  5. The engine must be turned off after completed function.
  6. If the function fails, check the test prerequisites and repair possible fault codes.
