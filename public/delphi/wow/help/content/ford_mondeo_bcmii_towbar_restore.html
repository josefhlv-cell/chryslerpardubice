[66]Restore configuration from back-up

This function is used to restore a control unit's configuration from a back-up.

Note:

There must be a back-up of the configuration from the control unit in question for the function to work.

Restoring takes up to 2 minutes, during that time the diagnostic equipment may not be disconnected.

Test conditions:

  • Battery charger connected to vehicle.

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. A dialogue box is shown, where the file with the back-up is to be selected.

    • Restoring takes up to 2 minutes, during that time the diagnostic equipment may not be disconnected.

  3. The function is done.

    • If the function fails, exit the diagnosis and turn off the ignition for 30 seconds before trying again.
