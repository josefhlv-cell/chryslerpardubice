[38]Calibrate max. fuel quantity

This function is used to adjust the fuel quantity's offset to max. (injection quantity).

Adjustment shall only be performed if engine torque is too low or too high.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the function.

  2. A dialogue box shows status for "Offset max. fuel quantity". Press "OK", and follow the instructions.

  3. After finished adjustment the current offset value for max. fuel quantity is shown.

    • If the function fails, check the test conditions and repair any faults.
