[814]Coding central locking control unit on Sharan up to 07.97

Coding:

The central locking control unit must be recoded if the control unit has been renewed.

Note:

  • If a faulty code for the control unit is entered the old code will remain.

  • When there is no fixed connection between the actual central locking motor position and the inside lock control lever, the doors can be locked and unlocked without that the central locking motor moves. If a door is unlocked with the inside lock control lever can it not be electrically locked before it is fully opened. Depending on how the control device is coded this is always done or on command through a synchronising cycle.

Always:

All the motors unlock and after that locks in proper order.

On command:

Then the unlocking cycles are only done when:

  1. A door is opened when the car is locked (except the boot lid).

  2. The front passenger door and a rear door are opened at separate unlocking of the front door.

  3. The driver door is opened at separate unlocking of the passenger door (rear door is localized – common terminal in the control device.

If another door is unlocked from the inside with the lock control lever without that the door is opened, this door will not be locked at the next locking sequence. The electrical locking will not be performed until the door is opened.

To perform coding:

  • Read from the table below which code is valid for the car.

  • Write the current code in the coding central locking control unit field.

  • Click on the OK-button.

  • A dialogue box confirms: Operation succeeded / Operation failed.

  • Read the control unit basic data to check that the new code is programmed.

  • Check that no fault codes are stored.
