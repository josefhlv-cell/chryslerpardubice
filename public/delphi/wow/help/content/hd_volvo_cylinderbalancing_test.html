[618]Cylinder balancing

This function is used to evaluate if any or some injectors deviate too much in fuel injection so that engine properties are affected.

If the test shows plus compensation for an injector, it means that the relevant injector in question gives too little fuel to the cylinder. Injection time is increased for the injector that gives too little fuel to obtain a smoother running engine. In case of low engine power, check the injectors that are 'plus-compensated'.

If the test shows minus compensation for an injector, it means that the relevant injector in question gives too much fuel to the cylinder. Injection time is reduced for the injector that gives too much fuel to obtain a smoother running engine. In case of smoke problems, check the injectors that are 'minus-compensated'.

If any cylinder is compensated more than the others it may lead to malfunctions under different driving conditions. If the test indicates this, check that the programming codes on the injectors match those programmed in the control unit.

Note:

If any or some cylinders are compensated more than the others it does not necessarily mean that there is something wrong with an injector. For a correct assessment, also run the tests for cylinder compression and cylinder shut-off.

Test conditions:

  • Coolant temperature shall be above 70° C.

  • Idle rpm.

    • 7 litre engine 600-750 rpm.

    • 9 litre engine 600-750 rpm.

    • 11 litre engine 600-750 rpm.

    • 12 litre engine 500-1100 rpm.

    • 13 litre engine 500-1100 rpm.

    • 16 litre engine 500-1100 rpm.

  • Accelerator pedal let up.

  • Parking brake applied.

  • Power take-off not active.

Procedure:

  1. Start the function.

  2. Check test conditions.

  3. Select to continue or abort the test.

  4. Run balancing until the cylinder balancing data becomes stable.

  5. Check the balancing data.

  6. Function done.

    • If the function fails, check the test conditions and try again.
