[114]Adaptation of the key's remote control

When replacing a defective remote control or increasing number of remote controls, these must be adapted to the control unit. It is also necessary if the code of the remote control and control unit no longer match. This may occur if the transmitter button is pressed when outside the system's operating range.

Note:

  • All remote controls must always be adapted again, even the existing ones.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

  • All power consumers disconnected.

Procedure:

  1. Select the function "Adaptation of remote control", press "OK".

    • Note that old remote controls are now erased.

  2. A "drop-down list" is shown, select number of remote controls that are to be adapted (including the existing), press "OK".

  3. You are now instructed to press the unlock button for at least one second in order on each remote control to be adapted.

    • A flashing indicator confirms that the remote control is adapted.

    • Time to adapt all remote controls may not exceed fifteen seconds.

  4. The adaptation finishes automatically when the number of remote controls to be adapted is reached.

  5. Press "OK" to exit the function.

  6. Turn off the ignition and check the function of all remote controls.
