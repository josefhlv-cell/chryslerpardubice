[270]Test of lift axle switch

This function is used to check that the signals from the lift axle switch work correctly.

Test conditions:

  • Parking brake applied.

  • Battery voltage above 20V.

Procedure:

  1. Start the function.

  2. Change the position of the lift axle switch.

  3. Check that the position of the lift axle switch and status of the signal match.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
