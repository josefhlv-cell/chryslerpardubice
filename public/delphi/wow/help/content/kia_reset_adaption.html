[1072]Clear adaption memory

The engine control unit learns and corrects possible deviations, in for example the lambda regulation system. These deviations are stored in the adaption memory. This function erases all the adaption values in the engine control unit. If a faulty lambda sond has been replaced, or a leaking exhaust system has been repaired, it is possible to clear the old and faulty adaption values with this function.

Test prerequisite:

  • Ignition on, engine off.

  • All electrical loads should be switched off.

Procedure:

  1. Choose the function: Clear adaption memory.

  2. The function starts, the adaption values are cleared. A dialog box presents: operation succeeded/ failed.

  3. Press OK to exit the function.
