[1242]Bleeding the brake system

This basic setting is used when bleeding antilock brake systems (ABS). The basic setting is only needed when at least one of the chambers in the brake fluid reservoir has been emptied, or when changing the brake fluid.

Note:

Bleeding is done in an automatic sequence of several steps, with prompts to the user as described below.

Test prerequisite:

  • The battery voltage should be above 11.5V.

  • Ignition on, engine off.

Procedure:

Choose the basic setting: Bleed the brake system. The bleeding sequence has now been activated and the following check steps and prompts will be displayed:

  1. Please wait (10 seconds).

  2. Depress and hold down the brake pedal ->Press OK

  3. Please wait (10 seconds). The hydraulic pump runs.

  4. Release the pedal ->Press OK

  5. Bleeding screw open x wheel ->Press OK

  6. Please wait (10 seconds). The hydraulic pump runs and the bleeding of each respective wheel is performed.

  7. Bleeding screw close x wheel ->Press OK

  8. The procedure continues from step 2 until all the wheels have been bleeded one time each. There after from step 9.

  9. Please wait (10 seconds).

  10. Bleeding screw open x wheel ->Press OK

  11. Please wait (10 seconds). The hydraulic pump runs and the bleeding of each respektive wheel is performed.

  12. Bleeding screw close x wheel ->Press OK

  13. The procedure continues from step 2 until all the wheels have been bleeded a second time each. There after from step 14.

  14. Finished. ->Press OK
