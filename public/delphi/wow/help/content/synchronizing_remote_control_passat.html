[1222]Synchronising remote control

Synchronising:

Synchronisation of a remote control (transponder) is necessary when replacing a faulty remote control or when increasing the number of remote controls (maximum four). It is also necessary if the code of the remote control and the control unit no longer agree. This may happen if the transmit button is frequently pressed when out of range.

Note:

All remote controls must always be re-synchronised, including the existing ones.

New ignition keys must also be synchronised to the immobiliser control unit.

The time taken to synchronise all remote controls must not exceed fifteen seconds.

Method:

  1. Insert one of the ignition keys in the ignition lock.

  2. Choose the function:Delete remote controls (all programmed remote controls are deleted).

  3. Enter the number of remote controls to be synchronised in the field:Enter number of remote controls (1-4). Press OK.

  4. Press a button on each remote control for at least one second.

  5. Switch off the ignition and remove the ignition key.

  6. Check the operation of all the remote controls.

  7. Synchronisation is terminated automatically when:

    • the number of remote controls to be synchronised is reached.

    • A button is pressed more than once on the same remote control.
