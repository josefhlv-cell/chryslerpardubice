[1634]Basic setting of throttle control unit

At basic setting, the throttle control unit is adapted to the engine control unit.

The adaptation shall be done when:

  • Voltage to the engine control unit has been disconnected.

  • The throttle has been removed or replaced.

  • Engine control unit has been replaced.

Test conditions:

  • Ignition on, engine off.

  • Coolant temperature between 10-95 °C.

  • All power consumers disconnected.

  • Battery voltage above 11.5 V.

  • Accelerator pedal not pressed down.

  • No fault in the system.

Procedure:

  1. Select the function: "Throttle control unit".

  2. At adaptation, "Test active" is indicated in the field "status for basic setting".

  3. When the adaptation is done, "Has finished" is indicated in the field "status for basic setting" + "system test finished, system OK" in the field "control conditions".

  4. If the adaptation should fail, the cause is shown in the field "control conditions".

  5. Exit the function with "OK".

  6. Check that no error codes are stored in the engine control unit.
