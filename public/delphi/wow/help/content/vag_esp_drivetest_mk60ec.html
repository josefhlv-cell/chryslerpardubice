[1617]Driving test of anti-spin system ESP

This driving test is used to check the signals from the sensors: steering angle, sudden acceleration, brake pressure, and angular velocity. The test shall be done if any components in the anti-spin system has been changed or removed.

Note:

  • "ESP driving test" can not be interrupted once it has been started.

  • Calibration of the steering angle sensor must be in order, this can be read out in the data list menu.

Test conditions:

  • Engine on.

  • Access to road section that meets requirement as stated in point 4 below.

Procedure:

  1. Select the function: "ESP driving test", press "OK".

  2. Exit the function and exit communication with the car by returning to the car selection. Control lights for "ESP" and "ABS" should be on.

  3. Press down the brake pedal forcefully until control light for "ABS" starts to flash (driving test is now activated and error code 1486 is stored).

  4. Within 50 seconds, drive at a speed of 20 to 30 km/h through a curve with steering angle more than 90°. No "ABS/ESP" control may take place.

  5. "ESP" driving test has been finished correctly if control lights for "ABS" and "ESP" turn off.

  6. If control lights do not turn off, then "ESP" driving test has not been finished correctly. Reactivate the driving test by continuing from point 3.
