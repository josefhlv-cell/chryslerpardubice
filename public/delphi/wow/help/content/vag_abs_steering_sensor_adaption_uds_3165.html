Initialise steering angle sensor
This basic setting is used to initiate the steering angle sensor. This must be done if:
  • The ABS control unit has been replaced.
  • The steering angle sensor has been replaced.
  • A fault code that requires zero compensation is stored in the ABS control unit.
Test prerequisites:
  • Battery voltage above 12V.
  • The ABS control unit correctly coded.
  • Access to a stretch of road that fulfils the conditions set out below.
Method:
  1. Drive the car straight ahead on a flat surface at not more than 20 km/h to check that the car does not pull to one side when the steering wheel is held in the straight ahead position.
  2. Stop the vehicle while driving in a straight line and ensure that the steering wheel has not turned.
  3. Start the function and follow the instructions in the program.
