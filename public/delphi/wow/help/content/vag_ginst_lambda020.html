[1333]Lambda adaption

Test condition:

  • Engine idling.

  • No faults stored.

  • Coolant temperature above 75 °C.

  • No leaks in the exhaust system.

  • All electrical loads switched off.

  • Automatic gearbox set to ”P/N”.

  • Inlet air temperature below 90 °C.

Note:

  • Used to see the lambda adaption value.

Procedure:

  • Choose the function: Lambda adaption.

  • Read off additive lambda adaption. Prescribed value -6.0 % to 6.0 %.

  • Read off the multiplicative lambda adaption. Prescribed value -10.0 % to 10.0 %

  • If the specifications are not attained, interrogate fault memory.

  • Exit function.
