[1507]Reinitialise programming

With this service the adaption values in the engine control module will be cleared. This is necessary to do after repair of the following component's:

  • Egr valve.

  • Damper valve.

  • Particle filter.

Test prerequisities:

  • No faults in the system.

  • Ignition on, engine off.

Procedure:

  1. Press OK to start the function.
