Zero compensation of the brake pressure sensor
This basic setting is used to zero-compensate the value from the brake pressure sensor. This must be done if:
  • The ABS control unit has been replaced.
  • The brake pressure sensor has been replaced.
  • An error code that requires zero compensation is stored in the ABS control unit.
Note:
During basic setting, the ignition must not be switched off.
Do not touch the brake pedal during basic setting.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. After completed function flashes the ABS-lamp, this turns off after an ignition cycle.
