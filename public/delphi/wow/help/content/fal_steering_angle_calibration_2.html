[666]Steering angle reset

This procedure should be run when the control unit or the component that is checked shall be replaced.

Note:

Control unit self-learning of the steering wheel's position. The front wheels must stand straight ahead to calibrate correctly.

The procedure must only be run on vehicles with ABS/ESP without electric steering. If "Not available" run the corresponding procedure available in the control unit for electric steering if the vehicle is equipped with this.

Test conditions:

  • Ignition on.

  • The steering wheel stands straight and the front wheels point straight forward.

  • Vehicle stationary.

  • Calibration missing.

Procedure:

  1. Start the function and follow the instructions in the program.
