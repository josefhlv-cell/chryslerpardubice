[51]System test during operation

This function is used to test the transmission's different signals.

Note:

When the function checks the transmission's output speed signal the vehicle should be driven at approx. 20 km/h.

Test conditions:

  • Engine on.

Procedure:

  1. Start the function.

  2. Test engine speed signal.

  3. Test transmission's turbine speed signal.

  4. Drive the vehicle at 20 km/h.

  5. Test transmission's output speed signal.

  6. Stop the vehicle.

  7. Check status of the different signals.

  8. The function is done.

    • If the function fails, check the test conditions and repair any faults.
