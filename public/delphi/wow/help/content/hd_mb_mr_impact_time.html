[117]Injection time

This function is used to read the injection time.

The read-in values are only initiation values, and cannot be used to check the injection time.

Test conditions:

  • Parking brake applied.

  • Engine idling.

Procedure:

  1. Select the function: "Injection time".

  2. A dialogue box shows "Start the engine and let it idle". Press "OK" to continue or "Cancel" to cancel the function.

  3. A dialogue with values from the injection time is shown. Press "OK".

  4. A dialogue shows "Function done". Press "OK".

  5. Function done.
