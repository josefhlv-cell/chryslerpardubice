Reset service message
If service has been performed on a maintenance component it must be confirmed in the service system. This function is used to reset the service message for the component.
Note:
After confirmed completed service, the following is updated in the maintenance system for selected component:
  • The service interval number for current service increases by one.
  • Calculations for next service date are restarted.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. A dialogue box shows test conditions, check these and press "OK".
  3. Select component to confirm completed service and press "OK".
  4. A dialogue box shows the current service interval.
  5. Confirm completed service, press "YES" to continue in the function. Otherwise press "NO".
  6. A dialogue box shows new service interval and that service is confirmed.
  7. Press "OK".
  8. The function is done
