[1391]Trailer coding

When an aftermarket installation or a removal of a trailer module has been performed, it is necessary to code/decode the function into/from the system to make it work correctly.

Note:

  • A faulty coding can reduce the car´s safety/performance.

  • The control unit must be of a correct version to accept the code.

Test prerequisites:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • Electrical consumers switched off.

Procedure:

  • In an aftermarket installation of a trailer module, the value 16384 shall be deducted from the read out code.

  • At a removal of a trailer module, the value 16384 shall be added to the read out code.

  1. Choose the function: "Trailer coding".

  2. The actual code in the control unit is presented. "Change value is presented". Confirm with YES.

  3. Enter the new code in the presented input field, confirm with OK.

  4. A dialog box will confirm: code stored (with the new value) in memory.

    • If the coding operation fails, check if the code is valid.

  5. Confirm with OK to exit the function.

  6. Switch off the ignition for 60 seconds to store the new code.

  7. Re-establish contact with the system. Read and check the fault codes and the new code.

  8. Exit the function.

    Example for an aftermarket installation:

    • Code before a trailer module installation: 21330 - 16384=4946.

    • Enter the code 4946 in the presented input field.

    Example for removal:

    • Code before a trailer module removal: 4946 + 16384=21330.

    • Enter the code 21330 in the presented input field.
