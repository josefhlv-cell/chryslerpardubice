Vehicle configuration for the electric parking brake
This function is used to activate or deactivate automatic application of the electric parking brake when the engine is turned off.
Note
Always check that the parking brake works before the vehicle is returned to the customer.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Select between the position "normal" to activate or the position "extreme cold" to deactivate automatic application of the parking brake.
