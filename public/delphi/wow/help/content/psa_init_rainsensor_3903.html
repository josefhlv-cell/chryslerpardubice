Rain sensor initialization
This function is used to adapt the rain sensor to the windshield.
Note:
An initiation of the rain sensor shall be performed:
  • After replacing the rain sensor.
  • After changing the windshield.
Test conditions:
  • Ignition on, engine off.
  • Windshield clean and undamaged in the area for the optic unit.
  • The sensor is correctly mounted on the windshield.
  • The vehicle must not be in economy mode.
Procedure:
  1. Start the function.
  2. A dialogue box shows the result.
  3. The function is done. If the function failed, check test conditions and resolve any error codes.
