[1602]Configure control unit

This function is used to reset the control unit's (vehicle's) configuration. E.g., if the vehicle is equipped with or is not equipped with: AC, cruise control, transmission, ABS, etc. This is necessary when the control unit has been replaced.

Trouble code P1302 'gearbox identification' may be displayed when the reset has been performed. To reset it, drive the vehicle forwards and backwards then switch the ignition off/on. Then clear the trouble codes.

After resetting, the control unit registers which functions the vehicle is equipped with via activation of each function or via the CAN net (each ECU/function sends information via the CAN net).

The following functions will be affected by the reset:

  • Air conditioning. The function is registered when activating the air conditioning.

  • Cruise control. The function is registered when activating the cruise control.

  • Manual transmission. The function is registered when the clutch pedal is depressed.

  • Selespeed transmission. The function is registered via the vehicle's internal communication network.

  • ABS/VDC/ASR. The function is registered via the vehicle's internal communication network (only if these are connected to the CAN net).

Note:

  • The reset takes approx. 60 seconds.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the "Self-learning functions reset" function and press "OK".

  2. Follow the instructions.
