[1446]Injector programming

This operation only relates to SID 803A ECUs with type M injectors (engraved on the injector). Carry out programming when one or several injectors are replaced. The injector programming status can be seen as a datalist parameter.

Test prerequisites:

  • SID 803A engine control unit.

  • Type M injector connected and installed correct.

  • Engine cold and not started for at least 10 minutes.

  • Ignition on, engine off.

  • No faults stored.

  • All electrical loads should be switched off.

  • Battery voltage above 12 Volts.

Procedure:

  1. Start the function, press OK.

  2. When the function starts, the old adaption values are cleared. A dialog box presents: operation succeeded/failed.

    • If the function fails, check the test prerequisites and repair possible fault codes.

  3. Exit the function and disconnect the diagnostic tool.

  4. Switch off the ignition for 15 seconds, and then switch it on for 30 seconds.

  5. Drive the vehicle in variable driving conditions to complete the programming.
