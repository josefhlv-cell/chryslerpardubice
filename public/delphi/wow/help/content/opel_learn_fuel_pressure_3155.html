Programming fuel pressure sensor
When replacing certain components, a teach-in procedure is needed for a complete repair and correct function of the system.
This function is used to program the fuel pressure sensor.
Test conditions:
  • Ignition on, engine off - the engine is started during the procedure.
  • Battery voltage above 12 V.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
If the function fails, check the test conditions and repair any faults.
