Driving test of anti-spin system ESP
This driving test is used to check the signals from the sensors: steering angle, sudden acceleration, brake pressure, and angular velocity. The test shall be done if any components in the anti-spin system has been changed or removed.
Note:
  • "ESP driving test" can not be interrupted once it has been started.
  • If "ESP driving test" has been activated but not completed correctly, error code is stored in the error memory.
Preconditions for the test:
  • Steering angle within ±10°.
  • Vehicle stationary.
  • Access to road section that meets requirement as stated in point 5 below.
Performance:
  1. Select function: "ESP driving test", press "OK".
    • A dialogue box shows: "Operation successful" or "Operation failed". Check test conditions and error codes if the function failed.
  2. Exit the function and exit communication with the car by returning to the car selection. Control light for "ABS" is on constantly.
  3. Press the "ESP OFF" button once so that the "ESP" light starts to flash.
  4. Within 10 seconds, drive through a curve at a speed over 10 km/h and with a steering angle greater than 90 degrees.
  5. "ESP driving test" has been performed correctly if the control lights for "ABS" and "ESP" go off.
    • If the control light for "ABS/ESP" has not gone out, then "ESP driving test" has failed.
    • If the driving test failed, check test conditions and error codes.
    • Reactivate the driving test by continuing from point 3.
