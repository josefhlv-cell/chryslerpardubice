Identifying of components on the LIN network
This function is used to identify components on the LIN network after eg. replacement of throttle position motor:
  • Actuators have been replaced or reinstalled.
  • Components for the climate control system have been replaced or reinstalled.
Note:
  • To perform this function, there must be no fault codes in the system and the throttle position motors must be unbroken and correctly mounted.
Test prerequisites:
  • Connect a battery charger! Since it can take up to 30 seconds to perform this function.
  • Ignition on, engine off.
  • The vehicle should have normal room temperature during calibration.
Procedure:
  • Start the function and follow the instructions in the program.
