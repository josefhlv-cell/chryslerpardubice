[242]Status test of control buttons

This function is used to check signals to and from switches.

Sensors are not checked in this test.

Test conditions:

  • Engine off.

  • Parking brake applied.

  • Battery voltage above 20V.

Procedure:

  1. Start the function.

  2. Check that status of switches matches with the test. Activate buttons on the control box. Check status on the screen that they match with the buttons that have been activated.

  3. Finish by pressing "OK".

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
