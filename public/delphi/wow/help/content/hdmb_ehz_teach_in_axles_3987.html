Control and learning of additional axle
This function tests and calibrates the front axle and the additional axle, by controlling the steering wheel to each end position.
Note:
  • Lift up the front axle and the additional axle with a jack or a lift.
Test conditions:
  • Engine off, ignition on.
  • handbrake applied.
Procedure:
  1. Start the function.
  2. Answer the questions and follow the instructions in the different boxes.
  3. The function is done.
    • If the function fails, check the test conditions and repair any faults.
