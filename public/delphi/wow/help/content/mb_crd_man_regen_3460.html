Regeneration of particle filter
In certain driving conditions, the particle filter can not be cleaned automatically, e.g., in continuous city driving. Then this function can be used to force a regeneration of the particle filter. The function cleans the filter from soot particles by increasing the exhaust temperature and thus burn off soot particles. Increase of the exhaust temperature takes place automatically during the regeneration procedure.
Note:
  • The exhaust temperature is very high during this procedure. Therefore, perform the regeneration outdoors, without connected exhaust hose.
  • The regeneration procedure may take up to 40 minutes.
  • The gas pedal or brake pedal may not be pressed down during the sequence.
  • Regeneration can be cancelled at any time via the function or by turning off the ignition.
Test conditions:
  • Engine idling.
  • Coolant temperature above 60 °C.
  • Exhaust temperature above 200 °C.
  • Fuel level at least 1/4
  • Gear in position P.
  • Parking brake applied.
  • Engine hood closed.
  • Turn on high beams, fog lights, and rear window heating.
  • Turn on fan, set to max. power.
  • Set the climate system to max. cooling at ambient temperature above 0 °C, otherwise max. heat.
Procedure:
  1. Start the function.
  2. Confirm with "OK". Regeneration starts with an increase of the engine rpm.
  3. The regeneration lasts for approximately 40 min. When the engine is back to idling the regeneration is completed.
    • Regeneration can be cancelled at any time via the function or by turning off the ignition.
  4. The function is done.
    • If the function fails, check the test conditions and repair any faults.
