[406]Write configuration data from file to ECU.

Procedure:

  1. Select number of axles on the trailer in a scroll list, 1,2,3, etc.

  2. Select number of modulators on the trailer in a scroll list. 1 m, 2 m, or 3 m.

  3. Select number of sensors on the trailer in a scroll list. 2 s or 4 s.

  4. Type in the VIN code of the trailer in the VIN code field.

  5. Press "Ok" button.

  6. Select the directory where the file is saved and select the file that appears.

  7. The file name is based on the choice from the dropdown lists and the VIN code.

  8. Press the "Open" button.

  9. The configuration data is written to ECU.

  10. Press "Ok" button to end the function.

  11. If the configuration file do not appear in the folder it may depend on wrong axle, modulator or sensor choice or wrong VIN code typing.

  12. If the write to ECU procedure fail it may depend on wrong vehicle selection or a corrupt configuration file.

  13. Make sure by using the available functions or by other appropriate manner that the function of the trailer is correct.

  14. Perform a testdrive of the vehicle before it is returned to the customer.
