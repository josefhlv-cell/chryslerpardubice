[1145]Configuration A/C

Test conditions:

-Engine off

-Ignition on

Possible configurations:

-VAR. capacity

-Fixed capacity -Cold loop

-Without A/C

Code number:

Var. capacity = 2

Fixed capacity = 1

Cold loop = 3

Without A/C = 0

Procedure:

Edit your configuration 3, 2, 1 or 0 and then push OK
