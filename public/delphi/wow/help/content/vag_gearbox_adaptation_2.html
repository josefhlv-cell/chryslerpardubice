[1732]Basic setting of transmission

This function performs a basic setting of the transmission's control unit. At basic setting, the gear positions are synchronized.This must be done:

  • When replacing the clutch.

  • If work has been done on the transmission.

Test conditions:

  • Ignition on, engine off - the engine is started during the procedure.

  • Gear in position P.

  • Transmission temperature 30-100 C°.

  • Accelerator pedal fully released.

Procedure:

  1. At ignition on and engine off, select the function: "Basic setting" and press "OK".

    • Prescribed value:"Adaptation status" shall count to value "4" and "Index synchronization" to value "0".

  2. Start the engine (basic setting continues).

    • Prescribed value: "Index synchronization" starts to count again. The basic setting is done when it has counted down to value "0".

    • If basic setting fails, check the test conditions and repair any faults.
