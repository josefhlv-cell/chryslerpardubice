Auxiliary brake lever, test
This function is used to control the lever for the retarder.
Test conditions:
  • Battery voltage above 20 V.
  • Ignition on.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. Check that the lever status matches the test.
  3. Exit by pressing the "OK" button in the box.
  4. The function is done.
If the function fails, check the test conditions and try again.
