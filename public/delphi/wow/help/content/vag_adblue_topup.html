[347]Reset counter for additive level

This function is used after topping up reduction agent (AdBlue) to reset the indicated reduction agent reservoir's level to full. Cars equipped with an SCR-system (Selective Catalytic Reduction) use a urea ammonia nitrate-based reduction agent, also called AdBlue, which is injected in the exhaust system in small doses to reduce exhaust emissions. In cars equipped with an SCR-system, reduction agent must be used according to legislation, in case of system malfunction or shortage of reduction agent the car cannot be started. The reduction agent is stored in a separate reservoir, it is not mixed with the diesel fuel.

The function should only be run when the reduction agent reservoir is completely full.

Test conditions:

  • Ignition on.

  • Additive reservoir filled.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. Reset is run.

  4. Exit the function and turn off the ignition for 30 seconds to save the new value.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
