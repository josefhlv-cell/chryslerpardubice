[1263]Coding gateway

The different CAN bus systems and control units are connected in a control unit called gateway to exchange information. All the control units that are possible to program into the car are stored in the gateway control unit. When reading the gateway coding, the control units that are programed to the car are displayed as "Coded". The other control units are displayed as "Not coded". If for example a trailer control unit is installed it is necessary to change the status of this control unit in Gateway control unit to "Coded", so the other control units in the car can exchange information with the trailer control unit. It is also possible to decode control units from the gateway if a control unit is dismounted from the car.

Note:

  • A faulty coding can reduce the security/ functionality of the car.

  • The coding of the gateway control unit is performed according to a multi step procedur that is possible to abord/ regret.

  • It is the same procedure to deprogramme a control unit, the only difference is that the buttons are called "Decode" instead of "Code".

Testprerequisites:

  • The batteyi voltage should be above 12 V.

  • Ignition on, engine off.

  • All electrical consumers should be switched off.

Performance:

  1. Choose the function: Code control unit.

  2. A dialog box with "drop down list" displays the control units that are possible to connect to the car. Programmed control units are mentioned as "Coded" and not programmed control units as "Not coded".

  3. Mark the current not coded control unit in the dialog box to program it to the gateway. (Mentioned as "Not coded")

  4. Confirm with the button: "Code".

  5. A dialog box presents the choosen control unit. Confirm to store coding.

  6. A dialog box presents: Operation succeeded/ failed. Confirm with OK.

  7. Check that no fault codes are stored in any of the concerned control units and test the mounted control unit.
