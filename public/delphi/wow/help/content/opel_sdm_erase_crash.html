[1698]Erase registered crash

When an airbag has been deployed, it is registered in the control unit. This function is used to erase the registered airbag deployments.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the "Erase registered crash" function

  2. Press "OK" to start erasing.

  3. Exit the function.
