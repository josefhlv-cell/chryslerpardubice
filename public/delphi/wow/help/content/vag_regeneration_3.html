[1482]Forced regeneration

Regeneration of the particle emission filter is a function that can be started with the diagnostic equipment. This function burns particles present in the particle emission filter in order to clean it. Some driving conditions are unfavourable to automatic regeneration, e.g. urban driving. In these cases the forced regeneration procedure can be used to avoid clogging of the particle emission filter. During the regeneration procedure the engine speed is raised to 1500 rpm. The procedure can last for up to 40 minutes. It is possible to read out the status and time for the regeneration in the datalist parameters.

Observe:

This operation results in very high exhaust temperatures. Perform the operation outdoors and without exhaust gas extraction take-off.

Test prerequisites:

  • Engine idling.

  • Engine at operation temperature.

  • Fuel level above ¼ full.

  • Gear in P/N.

  • Do not operate the clutch, brake or gas pedal during the regeneration.

Procedure:

  1. Choose the function: Regeneration.

  2. Enter the valid code in the input field: 10016. Press OK.

  3. A dialog box presents: operation succeeded/ failed.

    • If the function fails, check test prerequisites.

  4. The engine speed is automatically raised to 1500 rpm and the regeneration procedure is started.

    • Shut off the engine to abort the regeneration procedure.

  5. It is possible to read out the regeneration status in the datalist parameters according to the following:

    • Regeneration total time: Counts from 0 to 255 and returns to 0 when the procedure is finished.

    • Regeneration phase: When the regeneration starts 001 is presented, and shifts after a while to 010 and 100, to return to 000 when the procedure is finished.

  6. The engine speed returns automatically to normal idling when the procedure is finished.
