[187]Calibrate clutch switch

There are two types of clutch switch, analogue/digital. If the vehicle is equipped with digital clutch switch, the engine control unit will be taught (learn), after the clutch has been pressed down all the way. This function is used to teach-in analogue clutch switch, after August 2008 only analogue clutch switch is available.

If it was not possible to teach-in clutch switch, fault code P1750 will be stored.

Test conditions:

  • Ignition on.

  • Equipped with analogue clutch switch.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
