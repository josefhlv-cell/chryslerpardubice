[539]Oil change

This function is used to reset all adaptive parameters in the UniAir-module from the control unit after an engine oil change.

Note:

If the reset is not performed, the control unit cannot estimate exact air and gasoline flow and the following consequences may occur:

  • Unmotivated diagnostic requests for all components that are related to the throttle body and throttle control's position may occur.

  • Very poor driveability.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function and follow the instructions in the program.
