[11]Crankshaft position variation learning

This function is used to activate the algorithm for crankshaft position variation learning, which calculates correction factors reference pulse for misfire diagnostics.

Test conditions:

  • Engine on.

  • Place the gear lever in park or neutral.

  • Parking brake applied.

  • Lock the drive wheels.

  • Engine temperature above 40°C.

  • Air conditioning off.

Procedure:

  1. Start the function.

    • If the function fails, check the test conditions and repair any faults.
