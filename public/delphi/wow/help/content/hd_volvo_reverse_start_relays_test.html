[1729]Testing relay reverse light and immobilizer

This function is used to check the function of reverse lights and immobilizer relay.

When the gear selector is in position "N", relay reverse light should be "Inactive" and relay immobilizer "Active". You can see status of relay reverse lights and immobilizer during the test.

  • Relay immobilizer ="Active" Engine can be started.

  • Relay immobilizer ="Inactive" Engine cannot be started.

  • Relay reverse light ="Active" reverse light on.

  • Relay reverse light ="Inactive" reverse light off.

Test conditions:

  • Parking brake applied.

  • Ignition on.

  • Engine off.

  • Battery voltage above 20 V.

  • Gear in position "N".

Procedure:

  1. Select the function, press "OK".

  2. A dialogue shows test conditions.

  3. Check that relay reverse light is "Inactive".

  4. Check that relay immobilizer is "Active".

  5. Move the gear selector to position "R". Check that relay reverse light is "Active" and that the reverse light is on. Check that relay immobilizer is "Inactive".

  6. Activate with the diagnostics program relay reverse light. Check that status is "Active" and that the reverse light is on.

  7. Deactivate with the diagnostics program relay reverse light. Check that status is "Inactive" and that the reverse light is off.

  8. Activate with the diagnostics program relay immobilizer. Check that status is "Active".

  9. Activate with the diagnostics program relay immobilizer. Check that status is "Active".

  10. The function is done.

    • If the function fails, check the test conditions and repair any faults.
