[1445]Clutch pedal sensor calibration

This function adapts the clutch pedal sensor to the ABS control unit. Carry out an calibration when:

  • A fault code regarding calibration of clutch pedal sensor is present.

  • The clutch pedal sensor is replaced.

  • The ABS control unit is replaced.

Note:

During calibration, the ignition must not be switched off.

Test prerequisite:

  • Ignition on, engine off.

  • The clutch pedal sensor connected and installed correct.

  • Battery voltage above 12 Volts.

  • All electrical loads should be switched off.

Procedure:

  1. Position the car on a flat and level surface. Do not operate the clutch pedal during the calibration.

  2. Start the function, press OK.

  3. The calibration is carried out. A dialog box presents: operation succeeded/failed.

    • If the function fails, check the test prerequisites and repair possible fault codes.

  4. Exit the function, clear possible fault codes and disconnect the diagnostic tool.

  5. Switch off the ignition for 15 seconds, and then switch it on for 30 seconds.

  6. The calibration is now completed.
