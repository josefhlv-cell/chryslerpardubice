[349]Basic setting of air conditioning

If the control unit for the AC has been replaced or a new actuator has been installed, a basic setting of the AC must be performed. At basic setting, the control unit learns the actuators' end-positions and stores these.

Test conditions:

  • Ignition on, engine off - the engine is started during the procedure.

Procedure:

  1. Start the function.

  2. Start the engine.

  3. Start the air conditioning.

  4. Turn off the ignition when instructed.

  5. Turn on the ignition when instructed.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
