[302]Test of pressure tank valve

This function is used to check the function of the solenoid valve for the pressure tank.

Test conditions:

  • Ignition on.

  • Working pressure in air system.

  • Parking brake applied or wheels blocked.

Procedure:

  1. Start the function.

  2. Test the valve with the buttons.

  3. Press "OK" when the function is complete.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
