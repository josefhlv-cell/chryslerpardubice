Key programming
This function is used to erase and program new keys (max. 4 pcs.).
Note:
All keys, new and original, must be programmed during one and the same shift. Otherwise the original keys will not be recognized after programming of a new key.
A 12-digit security code has to be entered in order to program. The security code and new keys (non-programmed) are ordered from an Opel dealer.
Test conditions:
  • Ignition on, engine off.
  • Battery voltage above 12 V.
  • New (non-programmed) keys and original keys.
  • No faults in the system.
Procedure:
  1. Original key in the ignition.
  2. Start the function and follow the instructions in the program.
  3. After finished programming, check in the data list that the correct quantity of keys is programmed.
  4. Try to start the car.
If the function fails, check the following:
Fault symptom
Possible causes
Solution
Programming of security code failed.
The system's security code does not match the entered security code.
Use correct security code in relation to the system, ordered from an Opel dealer.
Key programming failed.
The key has another security code or is defective.
Use correct keys: The new (non-programmed) ordered keys and the original keys.
