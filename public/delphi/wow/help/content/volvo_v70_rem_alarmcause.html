[1640]Reading alarm cause

Every time the alarm is triggered, information is saved which facilitates determining the cause of the alarm being triggered. The information states which alarm was triggered and when it occurred.

  • Data list parameter: "Global time", indicates current time for how long the central electronic module's internal clock has counted, shown in days. "Global time" gives a reference value that can be used to calculate number of days since alarm occurred.

  • Data list parameter: "Time alarm cause", indicates how long the central electronic module's internal clock has counted until the alarm was triggered. Highest number of days means latest alarm occurrence.

  • Data list parameter: "Alarm cause", indicates which component in the car has caused the alarm.

To calculate the number of days since an alarm occurred, take the value in "Global time" minus the value "Time alarm cause" for desired alarm cause.

Test conditions:

  • Ignition on.

Procedure:

  1. Select the function: "Alarm cause", press "OK".

  2. Alarm causes and times are shown, press "OK" to finish.
