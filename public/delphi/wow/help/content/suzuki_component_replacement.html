[611]Reset adaptation value for component

This function is used when some component has been replaced.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • Check that no fault codes are stored in the control unit.

  • Parking brake applied.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.
