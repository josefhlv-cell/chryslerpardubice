[815]Coding convenience control unit on Beetle –99>

Coding:

The convenience control unit must be recoded if the control unit has been renewed.

Note:

If a faulty code for the control unit is entered the old code will remain.

To perform coding:

  • Read from the table below which code is valid for the car.

  • Write the current code in the coding convenience control unit field.

  • Click on the OK-button.

  • A dialogue box confirms: Operation succeeded / Operation failed.

  • Read the control unit basic data to check that the new code is programmed.

  • Check that no fault codes are stored.
