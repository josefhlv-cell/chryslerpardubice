Activation of traction control solenoid valves
This function performs a function test of the traction control valves.
Note:
During the test you will be instructed to depress the brake pedal while rotating the wheel. It will be easier if you are two persons.
Test conditions:
  • Ignition on, engine off.
  • Transmission in neutral.
  • Lift the vehicle.
Procedure:
  1. Start the function and follow the instructions in the program.
