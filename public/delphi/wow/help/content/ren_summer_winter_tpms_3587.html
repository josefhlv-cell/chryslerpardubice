Replacing summer/winter tyres
This function is used to change the vehicle configuration when you have shifted from summer to winter tyres or the opposite.
Note:
In the control unit are the programmed valve codes, for both the summer and the winter tyres, saved. This function may only be used when a set of wheels, where the valve codes is already programmed to the vehicle, is mounted. However, it is important that the correct valve ends up in that position to which it is programmed, otherwise must the function "Programming wheel valve codes" be performed.
Preconditions for the test:
  • Engine off.
  • Ignition on.
Procedure:
  1. Start the function.
  2. Select "Summer tyre" or "Winter tyre" in the list.
  3. Press "OK" to change the configuration.
