[764] Bleeding the brake system

This basic setting is used when bleeding antilock brake systems (ABS) on vehicles fitted with electronic differential lock (EDL).

The basic setting is only needed when at least one of the chambers in the brake fluid reservoir has been empty, or when changing the brake fluid.

Note:

Bleeding is done in an automatic sequence of several steps, with prompts to the user, as described below. Each sequence is repeated eight times (two bleeding operations per wheel).

The recommended sequence when bleeding the brake system is as follows:

  • RH rear

  • LH rear

  • RH front

  • LH front

Method:

  • Check that the vehicle battery voltage is above 11.5 volts

  • Choose the basic setting: Bleed the brake system

The bleeding sequence has now been activated and the following check steps and prompts will be displayed:

  1. Depress and hold down the brake pedal.

    (The hydraulic pump starts and builds up pressure)

    ->Press OK

  2. Release the pedal and open the bleed screw.

    -> Press OK

  3. Wait (ten seconds).

    (The hydraulic pump runs)

    -> Press OK

  4. Depress the brake pedal ten times. Close the bleed screw.

    -> Press OK

  5. See 1. (X8)

  6. Partial bleeding is complete.

->Press OK

Some systems do not include item 3, but the procedure is the same in other respects.
