[1513]Coding of steering wheel electronics

To make all functions work correctly, the control unit must be coded according to the corresponding equipment.

Note:

  • Faulty coding can reduce the car's safety/performance.

  • The control unit must be of a correct version to accept the code.

Test prerequisites:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • Electrical consumers switched off.

Procedure:

  1. Choose the function: "Code control unit".

  2. The actual code in the control unit is presented. "Change value is presented". Confirm with YES.

  3. Enter the new code (see below) in the presented input field, confirm with OK.

    Code number:Function:
    0 X X X XManual gearbox
    1 X X X XAutomatic gearbox
    X 0 0 X XSteering wheel without multifunction and Tiptronic control
    X 1 1 X XSteering wheel with Tiptronic control, without multifunction
    X 2 0 X XMultifunction with radio function, without Tiptronic control
    X 3 0 X XMultifunction with radio/phone function, without Tiptronic control
    X 4 0 X XMultifunction with radio function, prepared with mobile functions, with voice control, without Tiptronic control
    X 5 0 X XMultifunction with radio/voice control, without Tiptronic control
    X 2 1 X XMultifunction with radiofunction, with Tiptronic control
    X 3 1 X XMultifunction with radio/phone function, with Tiptronic control
    X 4 1 X XMultifunction with radio function, prepared with mobile functions, with voice control, with Tiptronic control
    X 5 1 X XMultifunction with radio/voice control, with Tiptronic control
    X X X 0 XWithout trip computer and cruise control
    X X X 1 XWith trip computer, without cruise control
    X X X 2 XWith cruise control, without trip computer
    X X X 4 XWith trip computer and cruise control
    X X X X 1Vehicle variant TT
    Coding example:

    Vehicle with: Automatic gearbox, multifunction with radiofunction, with Tiptronic control, with trip computer, and cruise control, vehicle variant TT= 12141

  4. A dialog box will confirm: code stored (with the new value) in memory.

    • If the coding operation fails, check if the code is valid.

  5. Confirm with OK to exit the function.

  6. Switch off the ignition for 60 seconds to store the new code.

  7. Re-establish contact with the system. Read and check the fault codes and the new code.

  8. Exit the function.
