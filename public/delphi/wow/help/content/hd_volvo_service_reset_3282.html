Service warning system
This function is used to adjust the service interval.
Note:
There are three values that can be changed to indicate when the service reminder shall take place; engine hours, driving distance, and number of days since last reset.
If more than one service interval is used, that which occurs first will activate the service reminder.
Enter value 0 to deactivate the service reminder for one or more intervals.
Test conditions:
  • Engine off.
  • Ignition on.
  • Battery voltage above 20 V.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. Current service interval is shown.
  3. Choose if existing service interval is to be kept or if a new interval shall be programmed.
  4. Programming is performed.
  5. New service parameters are shown, press "OK".
  6. Function complete.
  • If the function fails, check the test conditions and repair any faults.
