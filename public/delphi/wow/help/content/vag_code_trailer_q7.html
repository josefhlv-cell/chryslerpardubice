[421]Code trailer module

When installing trailer hitch and control module for trailer, the control module for trailer must be coded for all functions to work correctly. New control unit may have code 0 stored.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Existing code in control unit is shown, press "YES" to change value.

  3. Enter the desired code (see below) in the displayed entry field, press "OK".

    Code number:Market:
    X X X X X 0 XFixed trailer hitch
    X X X X X 1 XElectronically folding trailer hitch
    X X X X X 2 XManually folding trailer hitch
    X X X X X X 1Other
    X X X X X X 2USA, Canada

    • Code example: Electronically folding trailer hitch, other = 0000011

  4. A dialogue box shows that the code is stored (with the new value) in the memory.

  5. Press "OK" to exit the function.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
