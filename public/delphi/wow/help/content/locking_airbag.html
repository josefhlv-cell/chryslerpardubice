[1076]Locking/unlocking airbag PSA

Note:

It is possible to lock the airbag ECU to prevent triggering of the airbag components. This permits safe handling of the ECU with no risk of unwanted inflation.

Locking the airbag ECU results in lightning of the airbag warning light without storing a fault.

Observe:

This function only prevent the trig signal to the squibs, the airbag system components shall still be handled carefully.

Once the operation is completed, the ECU must be unlocked by selecting the unlocking function.

Performance:

To lock:

  1. Choose function: Locking airbag.

  2. A dialog presents: Operation succeeded/ failed.

  3. Press OK.

  4. Choose data list menu. Data list number 4.

  5. Verify that the airbag locking parameter shows: Locked

To unlock:

  1. Choose function: Unlocking airbag.

  2. A dialog presents: Operation succeeded/ failed.

  3. Press OK.

  4. Choose data list menu. Data list number 4.

  5. Verify that the airbag locking parameter shows: Unlocked
