[40]CTP relay

This function is used to activate a function and check that output signals are correct.

Activation is not continuous, it takes place in several cycles.

Test conditions:

  • Engine off.

  • Ignition on.

  • Immobilizer inactive.

  • Air control should not be at 0.

Procedure:

  1. Start the function.

  2. Press "Start" to activate the component.

  3. Press "Stop" to deactivate the component.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
