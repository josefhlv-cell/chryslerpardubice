[930]Idling check

Preconditions for the test:

  • Engine idling.

  • No faults stored.

  • No leaks in the exhaust system.

  • Engine temperature above 80 °C.

  • All electrical loads switched off.

  • Gear selector set to ”P/N”.

Note:

  • Used to check idling.

  • Idling, ignition advance/retard and CO value are not adjustable.

  • The CO value is controlled by the lambda regulation.

Procedure:

  • Choose the function: Idling check.

  • Read the operating condition. Prescribed value 1100 0010, where the second digit from the left in the block of digits corresponds to the idling contact (1=closed).

  • Read off the engine speed signal. Prescribed value 750-850 rpm.
