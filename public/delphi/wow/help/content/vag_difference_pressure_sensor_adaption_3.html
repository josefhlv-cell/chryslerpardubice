[291]Reset adaptation values for differential pressure sensor

This function enables reset of the differential pressure sensor's adaptation values. This should be done when:

  • The differential pressure sensor has been repaired or replaced.

  • The particle filter has been replaced.

  • The engine control unit has been replaced.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. After finished adaptation, exit communication with the car and turn off the ignition for 30 seconds.

  4. Turn on the ignition again, re-establish communication with the car, and check that no fault codes are stored.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
