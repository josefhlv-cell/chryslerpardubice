Key programming
This function copies the start key's code to the control unit and presents the key number.
Note:
Other keys shall not be in the vicinity of the transponder.
If several keys shall be programmed, repeat the procedure for the non-programmed keys.
Up to 8 keys can be programmed.
Test conditions:
  • Parking brake applied.
  • Engine off.
  • Start the function.
  • An already programmed key must first be presented to validate the matching process.
  • When programming a new key, you have 30 seconds to change key and turn on the ignition.
Procedure:
  1. Start the function.
  2. Check conditions.
  3. Turn off the ignition and then turn it on again within 30 seconds with an already programmed key. Then press "OK".
  4. Check key number.
  5. If you want to program a new key, insert it and turn on the ignition within 30 seconds. Then press "Yes".
  6. Check key number.
  7. If you want to program several keys, repeat steps 5 and 6.
  8. If you are done with programming, press "No".
  9. Turn off the ignition.
  10. Wait 30 seconds.
  11. Turn on the ignition.
  12. The function is done.
  13. If the function fails, check the test conditions and repair any faults.
