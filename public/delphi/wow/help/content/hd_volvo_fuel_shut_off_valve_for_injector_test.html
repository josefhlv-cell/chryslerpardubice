[558]Cylinder shut-off

This function is used to temporarily shut off an injector at a time to check the injectors' function.

Note:

The function shall be run with the engine on, at the rpm where any misfiring occurs.

The engine sound should change when an injector is turned off.

Test conditions:

  • Engine idling.

  • Engine temperature above 75°C.

  • Parking brake applied.

Procedure:

  1. Start the function.

  2. Check test conditions.

  3. Select cylinder where the injector is to be shut off.

  4. Press "Start".

  5. Check that the engine sound changes.

  6. Check fuel consumption and engine rpm.

  7. Press "Stop".

  8. Repeat the test for the other cylinders.

  9. Press "OK" to exit the function.

  10. The function is done.

    • If the function fails, check the test conditions and repair any faults.
