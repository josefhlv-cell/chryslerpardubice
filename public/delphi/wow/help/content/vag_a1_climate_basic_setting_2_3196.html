Basic setting of air conditioning system
This function is used to activate operation of the climate compressor in the control module for the climate control system. This should be done if:
The air conditioning system control unit has been replaced.
Note:
  • A started basic setting shall not be cancelled, then a fault code is stored in the fault memory and operation of the AC will not work. If this happens, repeat the basic setting.
  • If basic setting cannot be finished correctly due to, e.g., high outdoor temperature, increase engine rpm to approx. 2000 rpm and repeat the function.
Test conditions:
  • Engine idling.
  • Climate system off.
  • Air vents in instrument panel fully open.
  • No faults in the system.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. After the function is completed, check any error codes.
    • If the function fails, check the test conditions and repair any faults.
  3. Then continue with the function "Learning end position damper motors".
