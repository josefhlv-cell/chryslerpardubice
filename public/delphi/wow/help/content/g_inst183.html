[940]Basic ignition position

Preconditions for the test:

  • Check program version (Datalista 04), up to 1083.

  • Engine idling

  • Engine temperature above 80 °C

  • No faults stored

Note:

  • To check and adjust basic ignition timing.

Procedure:

  • Choose the basic ignition timing function. The numbers on the screen are not relevant for the measurement

  • Check ignition timing at 2000 – 2500 rpm with the ignition timing lamp. Prescribed value 4-8 ° before TDC.

  • Set the required value by turning the distributor. Setting value 6 ± 1 ° before TDC.
