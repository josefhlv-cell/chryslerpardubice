[17]Reprogram engine ECU

This function is necessary to perform when changing to another control unit.

Note:

  • Original ECU MUST be reset prior to removal.

  • To perform this function, it is necessary to have access to manufacturer's 4-digit security code.

    This is obtained from IM Groups I.M.O.L.A site.

    If the wrong vehicle code is entered too many times the system will go into security wait time.

    IM Group provide a Technical support help line to access this information, phone 0121 747 4000.

Test prerequisites:

  • Battery voltage over 12V.

  • VCI connected to vehicle with ignition on engine off.

Procedure:

  1. Start the function and follow the instructions in the program.

  2. After completed function, choose the function "Write VIN".
