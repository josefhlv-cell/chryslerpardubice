[1298]Climate control, basic setting.

Test condition:

  • Battery voltage above 11.5 V.

  • No faults stored.

  • Ignition on.

Note:

  • The basic setting must be performed when the control unit or one of the step motors has been replaced.

Procedure:

  • Start the function.

  • The parameter diagnosis status presents the step motor values.

  • The basic setting is finished when the diagnosis status presents "finished".

  • Exit the function.
