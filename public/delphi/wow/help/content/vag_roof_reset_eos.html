[46]Basic setting motor for sunroof

This function is used to perform basic setting of the sunroof's motor, after repair.

Note:

Risk of crushing at the windshield's frame when the sunroof is closed during basic setting.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function and follow the instructions in the program.

    • If the sunroof is open at the start of the function, close it and the end-position is programmed.

    • If the sunroof is closed at the start of the function, the closed position is programmed as end-position.

  2. The function is done, run a function test of the sunroof.
