[511]Code control unit

When replacing a control unit, it needs to be version-coded to function correctly.

  • Incorrect version coding may reduce the car's safety and function.

  • The control unit must be of the correct type to approve the version code.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • All power consumers disconnected.

Procedure:

  1. Start the function.

  2. The vehicle's coding data is checked.

  3. Press "YES" to code the new control unit.

  4. Turn off the ignition for 10 seconds.

  5. The function is done.

  6. Check the function.

    • If the function fails, check the test conditions and repair any faults.
