Reset counter learned variable line pressure (VLP)
This function is used to perform a reset of the counter for variable line pressure (VLP).
Note:
It is possible in the function to reset several counters, according to the list below:
  • Resetting variable line pressure, 2-3 shift counters in open loop.
  • Resetting variable line pressure, open loop output tooth counter.
  • Resetting both.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function and follow the instructions in the program.
    1. If the function fails, check the test conditions and repair any faults.
