[1175]Programming of vehicle parameters

Conditions:

-Engine off

-Ignition on

Procedure:

-Type the code for which engine you want to configure the ECU for.

Ex. 5F04 if you wish to configure for a F4R .

Possible configurations:

  • F4R = 5F04

  • F4Rt = 7D04

  • F9Q 754 = 7D04

  • G9T = A005

  • F9Q 750 = 8704

  • P9X = AF05

  • V4Y = A805

OBS! Use capital letters (A-F) and the figures 0-9.
