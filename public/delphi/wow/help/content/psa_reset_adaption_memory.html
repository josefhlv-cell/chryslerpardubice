[360]Reset adaptation values for engine control unit

This function is used to reset the adaptation memory in the engine control unit. The engine control unit learns to correct any deviations for, e.g., heated oxygen control, and stores this in the engine control unit. For example, if a defective heated oxygen sensor has been replaced or a leaking exhaust system has been repaired, the faulty adaptation values can be reset with this function.

Test conditions:

  • Ignition on, engine off.

  • The engine should be cold (below 30 °C), and not started for at least 10 minutes.

  • No faults in the system.

  • All power consumers disconnected.

Procedure:

  1. Start the function.

  2. A dialogue box shows that activation runs.

  3. A dialogue box shows if the function succeeded or failed.

    • If the function failed, check test conditions and resolve any error codes.

  4. Finish and disconnect the diagnostics instrument.

  5. Turn off the ignition to reset the adaptation values.

    • Wait 15 seconds.

  6. Turn on the ignition.

    • Wait 15 seconds.

  7. Turn off the ignition to save stored values and wait until "Power-latch" function turns off (display in main instrument turns off (approx. 15 sec.)).

  8. Turn on the ignition.

    • Wait approx. 10 seconds.

  9. Start the engine and let the engine idle without touching the accelerator pedal until the engine is warm - cooling fans start.

  10. For teach-in of misfiring the engine shall be revved up once from idle to 5000 rpm.

  11. Drive the vehicle variably to finish teach-in of the new adaptation values.

  12. The function is done.
