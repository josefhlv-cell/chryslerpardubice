[1675]Calibrate sensor group

This function is used to reset the sensor group.

Clear any trouble codes after calibration.

Test conditions:

  • Ignition on, engine off.

  • The vehicle must be on level ground.

  • Turn the steering wheel at least 10°.

Procedure:

  1. Select the "Calibrate sensor group" function.

  2. Press "OK" to start calibrating.

  3. Exit the function.

    • Clear any trouble codes after calibration. If the function fails, check the test conditions.
