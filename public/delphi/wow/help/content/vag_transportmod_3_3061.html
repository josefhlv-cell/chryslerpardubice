Activation/deactivation of transport mode
This function is used to activate or deactivate "Transport mode". Transport mode is intended to minimise power consumption in the car by limiting the car's functionality or completely disconnecting certain functions.
Test prerequisites:
  • Ignition on.
  • Battery voltage OK
Procedure:
  1. Choose the function: Activate/deactivate transport mode.
  2. A dialog box confirms: Operation succeded/failed.
  3. Exit the function and check the activation/deactivation.
