[1705]Reset system

This function is used to reset the system.

In some systems, the adaptive/stored values can be reset.

Test conditions:

  • Ignition on, engine off

  • Battery voltage above 12 V.

Procedure:

  1. Start function, press "OK".

  2. A dialogue box shows if the function succeeded or failed.

  3. The function is complete.
