[480]AdBlue filter leakage test

This test is used after service and repair of EAS for detecting leakage in the system. The test will flush and pressurize the AdBlue filter. The test is automatic and runs for 190 seconds.

Test conditions:

  • Ignition on, engine off.

  • Voltage above 20v.

  • AdBlue tank temperature above 5 °C.

Procedure:

  1. Start the function.

  2. Check that the AdBlue pressure increases and maintains the pressure.

  3. Check that there are no leaks.

  4. Function done.

    • If the function fails, check the test conditions and repair any faults.
