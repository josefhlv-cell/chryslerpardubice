[1696]Unlock additional heater

Trouble code 2251 (parking/additional heater locked) cannot be erased until the heater has been unlocked using this function.

The heater may lock for any of the following reasons:

  • The heater has failed to start after 3 starting attempts.

  • The same fault has been registered 3 times in succession.

  • The airbag control unit has registered a crash.

  • A component test has been carried out on the airbag control unit.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

Procedure:

  1. Select the "Unlock additional heater" function.

  2. Confirm with "OK" to simultaneously unlock the heater and erase the trouble codes.

  3. A dialogue box shows whether the operation has succeeded or failed. Confirm with "OK".

  4. Exit the function.

  5. Check that no trouble codes are stored in the heater.

    • If the function fails, check the test conditions and repair any faults.
