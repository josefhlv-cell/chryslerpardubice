[512]Configure central lock

This function is used to configure the central lock's function. These three settings of the central lock can be adjusted:

  • Automatic locking after driving off.

    The vehicle is locked automatically when you start driving. However, it can always be opened from the inside by operating the door's inner door lever twice. The first is to unlock the door and the second to open it.

  • Lock again two minutes after unlocking if no door has been opened.

    If the vehicle is locked and no door is opened within two minutes the vehicle will be locked again.

  • Selective central lock.

    With the first press of the key's unlock button only the driver door is unlocked. Only after the second press of the key button is the entire car unlocked.

Test conditions:

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. The current status for the function is shown, press "OK".

  3. Depending on the function's status, question is shown if the function should be activated or deactivated. Press "YES" to run the function and "NO" to finish.

  4. Turn off the ignition for 10 seconds.

  5. The function is done.

  6. Check the function.

    • If the function fails, check the test conditions and repair any faults.
