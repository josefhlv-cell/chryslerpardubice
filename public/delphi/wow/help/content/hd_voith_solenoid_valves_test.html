[49]Test solenoid valves

This function is used to detect any fault of the solenoid valves that have not been detected during normal operation.

Note:

The function can only be run on transmissions with software version E300.1-D5.0.0.0.

Test conditions:

  • Engine off.

  • Ignition on.

  • Vehicle stationary.

  • Parking brake applied.

  • Transmission in neutral.

Procedure:

  1. Start the function.

  2. Check test conditions.

  3. Select to activate the solenoid valves' coils or cancel the function.

  4. Select the solenoid valve to be tested and press "Start".

  5. Listen for sounds from the solenoid valve and wait for the status of the solenoid valve to be presented.

  6. Check the status.

  7. Repeat the procedure from step 4 to test the other solenoid valves.

  8. Select to continue the test by pressing "OK" or to cancel by pressing "Abort".

  9. Press "Yes" to measure the solenoid valve's coils.

  10. Select which solenoid valve's coil that is to be measured and press "Start".

  11. Wait for the status of the solenoid valve's coil to be presented.

  12. Check the status.

  13. Repeat the procedure from step 10 to test the other coils.

  14. Function done.

    • If the function fails, check the test conditions and repair any faults.
