[1241]Bleeding the brake system

This basic setting is used when bleeding antilock brake systems (ABS). The basic setting is only needed when at least one of the chambers in the brake fluid reservoir has been emptied, or when changing the brake fluid.

Note:

Bleeding is done in an automatic sequence of several steps, with prompts to the user as described below. Each sequence is repeated eight times (two bleeding operations per wheel). The recommended sequence when bleeding the brake system is as follows:

  • RH rear

  • LH rear

  • RH front

  • LH front

Test prerequisite:

  • The battery voltage should be above 11.5V.

  • Ignition on, engine off.

Procedure:

Choose the basic setting: Bleed the brake system. The bleeding sequence has now been activated and the following check steps and prompts will be displayed:

  1. Depress and hold down the brake pedal. (The hydraulic pump starts and builds up pressure) ->Press OK (If the brake pedal is not depressed immediately, the pump automatically starts).

  2. Release the pedal and open the bleed screw. ->Press OK within 5 seconds otherwise the hydraulic pump starts automatically.

  3. Wait (10 seconds). (Hydraulic pump runs) ->Press OK

  4. Depress the brake pedal ten times. Close the bleed screw. ->Press OK

  5. Continue the procedure from point 1-4 further 7 times.

  6. Partial bleeding is complete. ->Press OK

    Some systems do not include step 3, but otherwise the procedure is the same.
