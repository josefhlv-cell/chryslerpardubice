[1517]Dynamic pump adjustment

It is necessary to adjust the injector pump when:

  • The timing belt has been changed.

  • A fault code indicates that pump adjustment is required.

  • Other work which has affected the pump adjustment has been performed.

Note:

During the pump adjustment, the injection will be locked and the engine`s running will be changed depending on the pump`s adjustment requirements.

Test prerequisites:

  • Engine idle (read dialog box for more information).

  • The injector pump`s mechanical basic setting is in order.

  • Timing belt tension is in order.

  • No fault codes stored in the fault memory.

  • Engine temperature min 80-85 ºC.

  • Neutral gear.

  • Consumers off.

Performance:

  • Press OK to start the function and follow further instructions in the program.
