[858] Tank ventilation system

Preconditions for the test:

  • Engine idling.

  • No faults stored.

  • Engine temperature above 80 °C.

  • All electrical loads switched off.

  • Gear selector set to P/N.

  • Induction air temperature below 60 °C.

Note:

  • To check the tank venting system.

Procedure:

  • Choose the tank ventilation system.

  • The tank ventilation system changes from ”Test off” to ”Test on”.

  • Let the engine idle until the tank ventilation system changes to ”TVV OK / TVV nOK”.

Required values at test: Tank valve opening angle 13-25 % (varies about 6 % in test), tank valve self-test >25 %, induction manifold pressure 240-420 mbar.
