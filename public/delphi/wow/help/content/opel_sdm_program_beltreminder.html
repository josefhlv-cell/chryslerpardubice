[1699]Configure seat belt reminder

This function is used to configure the seat belt reminder.

Note:

WARNING! You are about to run a function that will affect the vehicle's safety. Disconnecting the vehicle's seat belt reminder system can compromise driving safety. The use of seat belts doubles the chance of surviving a crash. What is a seat belt reminder and how does it affect Euro NCAP crash safety test certification? A seat belt reminder system is a system which increases the driver's vigilance using lights and signals indicating the need to fasten a seat belt. The signal should be loud and clear but not irritating. The aim is to remind the occupants, who know the advantages of a seat belt, to fasten the belt. The points awarded to systems that fulfil the stated requirements are added to the total points score, which in turn leads to crash safety certification. The manufacturer of this diagnostic tool accepts no liability for damage which may result from a crash, irrespective of the cause.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the "Programme seat belt reminder" function then press "OK".

  2. A dialogue box with the present configuration is shown.

  3. Press "OK" to continue.

  4. Select the desired configuration, press "OK" to start programming.

  5. The new configuration is displayed once programming is complete.

  6. Press "OK" to exit the function.
