Injector programming
Due to tolerances when manufacturing the injectors, the actual injected fuel quantity may deviate minimally from the calculated fuel quantity. After manufacturing, these deviations are established and two adjustment values are developed for each injector. With these adjustment values the engine control module corrects the calculated injection quantity and thus improves exhaust emissions. With this function the installed injectors adjustment values can be changed or stored again in the engine control unit.
Note:
  • If an injector has been replaced you have to check that the marked adjustment value on the injector matches the value stored for that cylinder in the engine control unit.
  • If the engine control unit has been replaced, an injector quantity adjustment must be performed for all cylinders so that all installed injectors' adjustment values are stored in the new control unit. If this is not done it may lead to rough engine running or the engine not starting at all.
The adjustment value is marked with three digits on each injector. The marking is located on the middle of the injector's plastic casing.
The figure shows an example of where the adjustment value is marked on the injector's plastic casing.
If the adjustment values cannot be read when the injector is installed, the injector must be removed. The seals must be replaced before reinstalling the injector again.
Test conditions:
  • Ignition on, engine off.
  • No faults in the system.
Procedure:
  1. Read off the adjustment value on the injector.
  2. Start the function.
  3. The stored adjustment values for all cylinders are shown. The adjustment values are shown with several decimals but are only entered as a three-digit whole number.
  4. Select on which cylinder the value should be changed, enter the new value and press "OK" to save.
  5. Values for all cylinders are shown again. Check that the new value for the selected cylinder is saved.
  6. NOTE! Due to recalculations in the engine control unit, the adjustment values may deviate slightly after the new values have been saved. There is no entry error or control unit failure.
  7. If no other values should be changed, select "NO" to exit the function.
