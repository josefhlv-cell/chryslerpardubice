Sensor rotor adaptation
This function is used after any of the following components have been replaced:
  • Camshaft sensor.
  • The starter motor ring gear.
  • Engine mounts.
Note:
The function, reset values for sensor rotor adaptation, must in some cases be completed before this function can be performed.
Test conditions:
  • Engine idling.
  • Coolant temperature above 70°C.
  • Exhaust temperature below 900°C.
Procedure:
  1. Start the function.
  2. When the test conditions have been reached, press "OK" to start the adaptation.
  3. Drive the car in 3rd gear, increase the engine speed to 3500 rpm and start the deceleration.
  4. Repeat step 3 until the data list "Sensor rotor adaption completed" shows "Yes".
