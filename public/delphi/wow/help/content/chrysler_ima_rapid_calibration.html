[23]Injector calibration

This function initiates zero-position calibration and normal voltage calibration. This function is used when the engine's control unit has been replaced and all injectors are still the same. Injector programming shall be done before you continue with this function.

Note:

Program the injectors before the function is performed.

Test conditions:

  • Ignition on, engine off.

  • Injectors programmed.

Procedure:

  1. Select the function and follow the instructions.

  2. The function is done.

    • If the function fails, check the test conditions and repair any faults.
