[1122]Forced regeneration

Regeneration of the particle emission filter is a forced operation by request from the diagnostic equipment. This function burns particles present in the particle emission filter in order to clean it.

Some driving conditions are unfavourable to automatic regeneration, e.g. urban driving. I this cases the forced regeneration procedure can be used to avoid clogging of the particle emission filter.

Observe:

This operation results in very high exhaust temperatures. Perform the operation outdoors and without exhaust gas extraction take-off.

The operation proceeds automatically according to following sequence:

  1. Two minutes timer function.

  2. Increase in engine speed to 4000 rpm.

  3. Return to idle for 30 seconds.

  4. Increase in engine speed to 3000 rpm to create a balance.

Test prerequisites:

  • Engine idling.

  • Coolant temperature above 60°C.

  • Fuel level above ¼ full.

Performance:

  1. Choose function: Regeneration.

  2. A dialog box presents: Regeneration in progress.

  3. When the regeneration procedure is finished the dialog box presents: Operation succeeded
