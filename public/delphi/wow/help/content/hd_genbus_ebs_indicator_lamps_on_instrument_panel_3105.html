Control lights in instrument panel
This function is used to check the EBS-system's various control lights and indicator lights.
Test conditions:
  • Engine off.
  • Ignition on.
  • Transmission in neutral.
  • Make sure that the vehicle cannot start to roll.
Procedure:
  1. Start the function.
  2. Check test conditions.
  3. Select the light that is to be tested.
  4. Check that the selected light turns on for approx. 5 seconds and then turns off.
  5. Select to run additional tests or exit the function.
  6. Repeat steps 3-5 to test additional lights.
  7. Function complete.
  • If the function fails, check the test conditions and repair any faults.
