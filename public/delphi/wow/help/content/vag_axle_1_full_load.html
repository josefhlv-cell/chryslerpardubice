[1455]Target pressure axle 1 at full load

With this function it is possible to change the target tyre pressure value for axle 1 (front axle) at full load. It is possible to read the actual value as a datalist parameter.

Observe:

The actual value is presented and entered with factor 0,1 (27 = 2,7 bar).

Test prerequisites:

  • Battery voltage above 11.5 V.

  • No faults stored.

  • Ignition ON.

Procedure:

  1. Choose the function: Target pressure axle 1 at full load

  2. A dialog box presents the actual adaption value for the target tyre pressure value for axle 1 (front axle) at full load. Confirm with yes to change the value.

    • If the value is ok, the function can be aborted with "Abort"

  3. Enter the new value with factor 0,1 (27 = 2,7 bar). Confirm with "OK".

  4. A dialog box presents the new value.

  5. Confirm with "OK" to store the new value.

    • Check the test prerequisites if the dialog box "Operation failed" is presented.
