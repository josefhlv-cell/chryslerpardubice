[592]Checking static setting of injection pump

This function is used to automatically check the injection pump's basic setting.

Note:

If reference values are not reached and the pump's static basic setting is correct, there may be the following faults:

  • Feed pressure is too low.

  • Injection pump is defective.

As one step in troubleshooting, run the test "Check injection control's start and injection timing".

Test conditions:

  • Engine on.

  • Working temperature of engine reached.

  • Parking brake applied.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.
