[364]Calibrate power steering

This function is used to calibrate the power steering. Centring of the steering wheel angle sensor and teach-in of end-position shall be performed when these service jobs have been done:

  • Steering angle sensor replacement.

  • Replacing steering gear.

  • Replacement of power steering motor.

  • Replacement of steering column.

  • Replacement of steering linkage inner parallel rod.

  • Replacement of steering linkage outer parallel rod.

Centring of the steering wheel angle sensor must be performed before teach-in of end-position.

For centring the external steering wheel angle sensor, see calibrations in steering wheel angle sensor module (SAS) & Brake module (EBCM).

Calibration should be performed in the following order:

  1. Select function "Steering wheel angle, sensor centring".

  2. Select function "Power steering Softstop, reset".

  3. Select function "Power steering Softstop, teach-in".

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
