[699]Service data

.

Note:

The function retrieves mileage data from the last five stored services, and maintenance data.

If a negative result is returned from any of the services, this means that the service interval has been exceeded by the displayed distance.

If no data is shown, then no service has been saved or the function has not been activated.

Test conditions:

  • Ignition on.

  • Engine off.

  • No faults in the system.

  • Parking brake applied.

Procedure:

  1. Start the function.

  2. A dialogue box shows the service data.

  3. Function complete.

    • If the function fails, check the test conditions and repair any faults.
