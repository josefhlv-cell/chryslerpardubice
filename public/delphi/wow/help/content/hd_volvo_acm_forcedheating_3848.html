Test of warm-up valve
This function is used to open and close the warm-up valve for the AdBlue tank to check any electric problems in the valve.
Test conditions:
  • Parking brake applied.
  • Engine running.
  • Ignition on.
  • Gear selector in neutral.
  • Battery voltage above 20V.
Procedure:
  1. Start the function.
  2. Activate the valve.
  3. Listen for an audible click from the tank warm-up valve.
  4. Observe that the AdBlue tank temperature increases.
  5. The function is done.
    • If the function fails, check the test conditions and repair any faults.
