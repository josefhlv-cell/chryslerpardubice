[1479]Configuration of trailer function

When configurating vehicle systems, you are refered to the adaption channels in the control unit. Each channel correspond to a function in the control unit. It is necessary to adapt the instrument cluster control module correctly, to make the trailer module communicate with the instrument cluster control module.

Note:

  • When an aftermarket towbar/trailer module is mounted, the value 64 shall be added to the read out data.

  • When an aftermarket towbar/trailer module is dismounted, the value 64 shall be withdrawn from the read out data.

Test prerequisites:

  • The battery voltage should be above 12V.

  • Ignition on, engine off.

  • No fault codes in the system.

  • Towbar and trailer module correctly mounted and connected.

  • Trailer module function coded into central electronics control unit.

Performance:

  1. Start the function 'Configuration of trailer function (channel 61)'.

  2. The current channel value will be presented.

    • If the current value is ok, the function can be aborted with 'No'

  3. Press 'Yes'. Enter the new channel value in the presented input field, confirm with 'OK'.

  4. If the presented channel value is correct, press 'Yes' to store value.

    • If the presented channel value shall not be stored, it is possible to change the value with "No" (from step 3).

  5. If the value is stored, a dialog box presents: "Stored in memory".

  6. Confirm with OK to exit the function.
