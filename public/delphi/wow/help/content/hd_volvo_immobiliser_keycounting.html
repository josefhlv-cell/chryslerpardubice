[654]Key counting

This function is used to count the number of keys registered in the control unit.

The number of keys may be 0 to 6 keys.

Note:

The key shall be in driving position during the test.

Test conditions:

  • Parking brake applied.

  • Engine off.

  • Ignition on.

Procedure:

  1. Start the function.

  2. Check conditions.

  3. Check the number of keys.

  4. Function done.

    • If the function fails, check the test conditions and repair any faults.
