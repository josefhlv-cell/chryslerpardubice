[1645]Configuration of running lights

This function configures status for running lights' function.

There are three variants of status for light switch in position OFF:

  • "Always activated": Parking lights and running lights or Bi-Xenon lights are always activated with light switch in position OFF.

  • "Activated with sensor": lights activated depending on signal from the dusk sensor. For running light functions "Flexzero, "Flexstd", and "Flexlgt" to work in light switch position OFF, the running light status be set to "Activated with sensor".

  • "OFF": Parking lights and running lights or Bi-Xenon lights are not activated in light switch position OFF.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the function: "Programming status for running lights", press "OK".

  2. A dialogue with programmed status for running lights is shown.

  3. Press "OK" to proceed.

  4. Select desired status for running lights, press "OK" to start programming.

  5. After successful programming, the programmed status for running lights is shown.

  6. Press "OK" to exit the function.
