[1510]Climate regulation

If the climate control unit has been replaced, or a new position motor for the temperature damper has been installed, a basic setting must be performed. When the climate regulation basic setting is performed, the control unit learns the position motors end positions.

Test prerequisites:

  • The battery voltage should be above 11.5 V.

  • Ignition on, engine off.

  • No fault codes should be stored in the fault memory.

  • Correctly installed and connected.

Performance:

  • Choose the function: Climate regulation.

  • The temperature damper position motors runs to the end positions during the basic setting. A text present the damper position motors and changes to OK when it is finished.

  • Wait about 20 seconds (the climate control unit registrates the position motors new values and stores them).

  • End the function. Switch OFF/ON the ignition, wait about 15 seconds for possible fault codes to be stored.

  • Re-establish the communication and check if any fault codes have been stored.

    • If the function fails, check test prerequisites and repair possible fault codes.
