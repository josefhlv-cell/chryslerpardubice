Torque sensor calibration
This function is used to calibrate the torque sensor for electric power steering (EPS) that is stored in the control unit.
This funktion is used when:
  • The control unit is replaced.
Test prerequisites:
  • Battery voltage higher than 12V.
  • Ignition on, engine off.
  • Sensor / control unit connected and installed correct.
  • Check that the steering wheel is in the correct position when the front wheels are straight ahead.
  • Erase any fault codes.
Procedure:
  1. Start the function, press "OK".
  2. The calibration takes 10 seconds, do not rotate the steering wheel.
  3. If the calibration fails, the fault cause will be presented in a dialogue box.
  4. If the function fails, check the test prerequisites and adjust possible fault codes.
