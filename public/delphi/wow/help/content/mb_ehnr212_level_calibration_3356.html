Calibrating level sensor
This function is used to calibrate the rear level sensors on the vehicle.
Note:
If an approved calibration already is stored, it will be deleted and a fault code is set, until a new approved calibration has been performed.
A calibration needs to be performed only after the following events:
  • A level sensor is replaced.
  • The control unit is replaced.
  • After an incorrect calibration.
Reference values for the tilt angle on the rear axle is in the range: -1,3° - 0,8°.
Approved values for the height is +/- 20 mm.
  • The calibration could not be performed if the tilt angle or the height is outside the limits above.
Test conditions:
  • Ignition on, engine off.
  • Calibration shall be performed on a wheel alignment rig.
  • "Romess"-tool to measure chassis angle.
Procedure:
  1. Start the function.
  2. If an approved calibration already is stored, it will be deleted and a fault code is set, until a new approved calibration has been performed.
  3. Select left or right to get to the height adjustment. Current level for the height adjustment is shown in mm.
  4. When selecting increase (+) the selected side is raised for 5 seconds, when selecting decrease (-) the selected side is lowered for 3 seconds. Store approved values with the inclination measuring equipment, e.g. 'Romess CM-09606'.
  5. Continue in the function with "OK" when the level is approved.
  6. Enter the values that is stored in the inclination measuring equipment.
  7. Save the new values to exit the function.
If the function fails, check the test conditions and repair any faults.
