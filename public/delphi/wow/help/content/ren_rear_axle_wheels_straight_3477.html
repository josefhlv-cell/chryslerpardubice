Return to position: Rear axle wheels straight
This function is used to set the rear wheels straight.
Note:
The function should be applied before the toe-in adjustment (front wheel alignment).
The test must not be performed with the wheels on the ground. Lift the vehicle using the jacking points.
Test prerequisites:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Check that the rear end deflection angle is correct.
