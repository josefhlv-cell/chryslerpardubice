[534]Parameter setting

This function is used to change parameter setting.

The list only shows fuel quality with which the vehicle is powered.

Sulphur content ... - 0.1% corresponds to fuel quality 1.0.

Sulphur content 0.1% - 0.3% corresponds to fuel quality 1.0.

Sulphur content 0.3% - 0.8% corresponds to fuel quality 0.5.

Sulphur content ... 0.8% corresponds to fuel quality 0.2.

Environment-friendly diesel fuel (FAME) corresponds to fuel quality 0.3.

Environment-friendly diesel fuel (FAME) with benefit package (code MJ9) corresponds to fuel quality 0.5.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. A dialogue box shows test conditions, check these and press "OK".

  3. Select parameter setting and press "OK".

  4. A new dialogue box shows new parameter setting. Press "OK".

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
