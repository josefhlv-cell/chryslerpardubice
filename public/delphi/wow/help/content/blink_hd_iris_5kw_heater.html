Fault code reading

  • If the control unit detects a fault when the heater is turned on, or during operation, the active fault code is shown (F and 3 digits) within 15 seconds in the timer's display.

  • When reading fault codes: Press the button for heat, the heater starts. Press the button for clock, hold it in and press button P within 2 seconds. Press on the button right arrow once to show fault code 1, press twice to show fault code 2, etc.

  • When fault codes F015, F016, and F050 are shown, the control unit is put in blocked mode. In order to release the block, the fault codes must be erased.

  • Erasing fault codes and releasing the blocked mode: Press the heater button. F015, F016, or F050 is shown in the display. Press the button for clock, hold it in and press button P within 2 seconds. Turn on the ignition (15.00 hrs). When - –:- flashes in the display, the heater is to be turned on and off.
