[22]Reset adaptation values for the fuel system

This function is used to reset the stored fuel values in the engine's control unit. The function should only be used when all injectors have been replaced, but the engine's control unit remains the same. Make sure that all injectors are programmed before you continue.

Note:

Program the injectors before the function is performed.

Test conditions:

  • Ignition on, engine off.

  • Injectors programmed.

Procedure:

  1. Select the function and follow the instructions.

  2. The function is done.

    • If the function fails, check the test conditions and repair any faults.
