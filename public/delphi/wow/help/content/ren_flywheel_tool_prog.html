[453]Basic setting of flywheel

This function is used to reset the value for top dead centre and then a new test-drive procedure is run to teach in new values.

Test conditions:

  • Ignition on.

  • Coolant temperature above 35 °C.

  • Access to a stretch of road that fulfils the conditions set out below.

Procedure:

  1. Start the function.

  2. Reset of learned values takes place.

  3. Exit the function and prepare the test-drive procedure.

  4. Reduce speed with an injection shut-off (that is, let up the brake pedal, accelerator pedal, and clutch pedal) between 1800 and 1400 rpm, with 3rd gear for a manual transmission and in 2nd gear for an automatic transmission, for at least 3 seconds with coolant temperature above 35°C.

  5. Reduce speed a second time with an injection shut-off (that is, let up the brake pedal, accelerator pedal, and clutch pedal) between 3500 and 3000 rpm, with 3rd gear for a manual transmission and in 2nd gear for an automatic transmission, for at least 14 seconds with coolant temperature above 35°C.

  6. Check that the data list parameter "Teach-in ring gear engine flywheel" is "Done" - if the parameter is not done, repeat programming.

  7. The function is done.

    • If the function fails, check the test conditions and repair any faults.
