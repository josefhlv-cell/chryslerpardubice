[1060]Zero position adjustment (Xenon)

The automatic headlight range control system works towards a front and a rear level sensor. This function compensates the light adjustment automatically depending of load. When a calibration of the headlight range control system is performed an eventual deviation of the starting position will be compensated. The level sensors voltage value can be read in the data list parameters as front/rear level sensor. It is possible to read out the deviation of the chassi since last calibration in data list parameters (spring compression). The calibration should be performed after dismounting/change of head lights or level sensors.

Note:

There are tre different chassis (high, normal, low chassi). Each chassi has its own target value for the level sensors. At calibration choose corresponding chassi fo the car. If the zero position adjustment not could be performed, the actual values for the level sensors are out of range.

Target value for high chassi:

  • Front level sensor: 2900-3800mV

  • Rear level sensor: 1250-2450mV

Target value for normal chassi:

  • Front level sensor: 2700-3500mV

  • Rear level sensor: 1600-2800mV

Target value for low chassi:

  • Front level sensor: 2400-3200mV

  • Rear level sensor: 1900-3100mV

Test prerequisites:

  • No fault codes stored.

  • Batteri voltages ok.

  • Level sensors and headlights ok.

  • Ignition on.

  • Park vehicle on flat base.

  • No additional load or persons in the car.

Performance:

  1. Choose function: "Zero position adjustment". Confirm with Ok

  2. A dialog box present: Park vehicle on a flat base without any additional load, ignition on. Confirm with Ok

  3. A dialog box present chassi selection.

  4. Choose correct chassi for the car from drop-down list. Confirm with Ok

  5. A dialog box present actual values and target values for the level sensors. Then the calibration is performed, operation succeded presents

    • If the actual values for the level sensors is out of range, check the Test prerequisites.

  6. Finish with Ok.
