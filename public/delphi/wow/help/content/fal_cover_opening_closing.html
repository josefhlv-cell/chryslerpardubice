[5]Cover opening/closing

This function is used to run the top cover from closed to open or from open to closed.

Note:

Make sure that there is enough room (roof height) for the top cover before starting the test.

Check trunk closing.

Test conditions:

  • Ignition on.

  • Vehicle stationary.

  • Parking brake applied.

  • Battery voltage between 10V and 15V.

Procedure:

  1. Start the function and follow the instructions in the program.
