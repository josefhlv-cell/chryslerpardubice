[1046]Idling control

Preconditions for the test:

  • Engine idling.

  • No faults stored.

  • No leaks in the exhaust system.

  • Engine temperature above 80 °C.

  • All electrical loads switched off.

  • Automatic gearbox set to ”P/N”.

  • Pressure gauge not connected.

Note:

  • Used to check idling speed.

  • The idling speed is not adjustable.

Procedure:

  • Choose the idling check function.

  • Note the speed signal, idling. Prescribed value front-wheel drive 740-860 rpm, four-wheel drive 620-740 rpm.
