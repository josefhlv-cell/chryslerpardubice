[1244]Zero compensation of the brake pressure sensor

This basic setting is used to zero-compensate the value from the brake pressure sensor. This must be done if:

  • The ABS control unit has been replaced.

  • The brake pressure sensor has been replaced.

  • A fault code that requires a basic setting is stored in the ABS control unit.

Note:

During the basic setting, the ignition must not be switched off.

Test prerequisites:

  • The battery voltage should be >12 V.

  • Ignition on, engine off.

Performance:

  1. Do not depress the brake pedal.

  2. Choose the basic setting: zero compensation of the brake pressure sensor.

  3. The text: ”Adaption correct” confirms that zero compensation has been done. If the value for the brake pressure sensor is too high, zero compensation will not be accepted (adaption not possible).

  4. Exit the function and check the brake pressure sensor value in the datalist meny.
