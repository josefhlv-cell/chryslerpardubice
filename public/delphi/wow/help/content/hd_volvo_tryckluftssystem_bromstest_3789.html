Compressed air system test
This test is used to check the status of the pneumatic system. The air pressure from the different parts of the pneumatic system will be read from the vehicle.
Note:
EBS backup mode active = Electronic brake system not active.
Air tank, front and rear:
The air pressure must be below 1250 kPa.
Parking brake cylinder:
0-850 kPa when the parking brake is released or the brake pedal is pressed, otherwise 0 kPa.
Test conditions:
  • Battery voltage above 20 V.
  • Parking brake applied.
  • Ignition key in On position. Engine off.
Procedure:
  1. Start the function.
  2. Check that the air pressure sensor shows reasonable values.
  3. The function is complete.
If the function fails, check the test conditions and repair any faults.
