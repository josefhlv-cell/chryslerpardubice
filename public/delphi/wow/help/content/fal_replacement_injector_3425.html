Injector programming
This function is used to program one or several injectors after replacement of injector or control unit. The control unit performs an automatic measurement of the injectors regulation interval during programming.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. The function is done.
    • If the function fails, check the test conditions and repair any faults.
