[190]Testing variable intake manifold

This function is used to test the valve for variable intake manifold ("intake manifold tuning, IMT) (intake manifold runner control, IMRC)". Clicking sounds are heard in the engine compartment when the valve opens and closes. The engine coolant temperature should be above 80°C. To reach it, start the engine and run at an engine speed between 2,500-3,500 rpm until correct temperature is reached.

Test conditions:

  • Ignition on, engine off.

  • Do not touch the accelerator pedal during the test.

  • Coolant temperature above 80°C.

  • Parking brake applied.

Procedure:

  1. Start the function.

  2. Follow the instructions in the programme.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
