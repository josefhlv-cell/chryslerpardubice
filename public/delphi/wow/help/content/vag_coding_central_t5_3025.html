Code central electronics
This function is used to variant encode the control unit.
The control unit must be coded according to the corresponding equipment in order for all functions to work correctly. For example, when retrofitting/removing trailer hitch, you have to code/decode on/off function for trailer for it to work correctly.
Note:
  • Incorrect coding may reduce the car's safety/function.
  • The control unit must be of the correct type to confirm encoding.
  • If the control unit is to be replaced, it is recommended that the variant encoding from the defective control unit be read before replacement, see data list "Control unit variant encoding".
Test conditions:
  • Battery voltage above 12V.
  • Ignition on, engine off.
  • All power consumers disconnected.
To perform coding:
  • Start the function.
  • The actual code in the control unit is presented. "Change value is presented". Confirm with YES.
  • Enter the desired code (see below) in the displayed entry field, confirm with "OK".

  • A dialog box confirms: Code stored (with the new value) in memory.
  • Confirm with OK to exit the function.
