[4]Service work on transmission (DSG)

When removing the mechatronic, it is necessary to set it in removal position. This means that all gear controls are run in and clutch servos are run out.

After service work is done and everything is reinstalled, it is necessary to perform a basic setting and restore the assembly information for the mechatronic.

Note:

In some cases the gear control may jam. Then it is necessary to set the mechatronic in removal position by hand. See original documentation for this procedure.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

  • Gear selector in position P.

  • Brake pedal pressed down.

Procedure:

  1. Start the function.

  2. The text "Status for function" is shown and indicates "in progress" under the function that switches to "done" when it is finished.

  3. Exit the function and end communication with the car, and turn off the ignition.

  4. The function is done.
