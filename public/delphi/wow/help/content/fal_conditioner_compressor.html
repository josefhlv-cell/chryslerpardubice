[423]Self-test of cooling fan relay

The air conditioning's relay will be activated during the time this test is run. If the test is not started within 30 seconds it is cancelled automatically.

Test conditions:

  • Engine idling.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
