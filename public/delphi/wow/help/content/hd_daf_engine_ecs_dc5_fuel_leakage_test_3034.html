Fuel system, leak test
This test is used to check if there is an internal fuel leak in the feeder or injectors. If there is an internal leak, this will result in an increased fuel flow from the cylinder head return line. Before the test is carried out, it must be ensured that there is no external fuel leak.
Note:
During testing, the fuel system is under high pressure; therefore it is essential to wear protective goggles and maintain a safe distance from the engine.
During the test, error codes can occur on other systems, and must be erased after the test.
Special tools, ordered from a DAF dealer, must be used to carry out the test.
Special tool: DAF no. 1453195
Special tool: DAF no. 1453198
The first step is to check whether there is an internal leak. The fuel flow from the return line must not exceed 200 ml/min.
If the quantity of fuel exceeds this limit, it must be determined which cylinder has an internal leak.
Once the suspected internally-leaking cylinder has been plugged, the amount of fuel from the return line will reduce.

Test conditions:
  • Engine on.
  • Accelerator pedal let up.
  • The engine must idle for at least 1 minute before the test is started.
Procedure:
  1. Check using the test whether there is an internal fuel leak.
  2. Tilt the cab according to the manufacturer's instructions.
  3. Remove the return line from the cylinder head.
  4. Fit the test line with banjo screws and gaskets on the cylinder head (Part of special tool DAF no. 1453195).
  5. Plug the return line, use the accompanying banjo screws with gaskets, and fit the sealing cap (Part of special tool DAF no. 1453195).
  6. Place the free end from the test line into a container of at least 1000 ml.
  7. Check test conditions.
  8. Start the test.
  9. After the test has been carried out, check the amount of fuel from the return line.
  10. If the amount of fuel is less than 200 ml/min, there is no internal leak. The test is then complete, and the test equipment should be removed and the return line fitted at the correct tightening torque.
  11. If the amount of fuel is greater than 200 ml/min, there is an internal leak, and it must be located.
  12. Locating internal leaks.
  13. Remove the injection line from the rail outlet on cylinder 1.
  14. Plug the rail outlet for cylinder 1 with special tool DAF no. 1453198. Tightening torque 30 NM.
  15. Start the test.
  16. Check how many ml/min are coming from the return line.
  17. Remove special tool DAF no. 1453198, and fit the injector line to the rail outlet for cylinder 1.
  18. Repeat the test procedure for the other cylinders, and note all the values.
  19. Once the leaking cylinder has been plugged, the amount of fuel from the return line will decrease.
  20. Reset the vehicle.
  21. Function complete.
