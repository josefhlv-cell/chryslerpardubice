Activation of supply pump AdBlue
This function is a test and is used to pressurize and check the correct function of the valves in the supply pump.
This test must always be run when hoses have been disconnected, filters, or pump module have been replaced.
Note:
  • During start-up the AdBlue injection lines are pressurized. Where there are leaks AdBlue may run out on the vehicle.
Test conditions:
  • Ignition on, engine off.
  • Battery voltage above 20V.
  • All hoses and lines in the AdBlue-system must be connected before the test starts.
  • The AdBlue tank must contain a fluid volume of at least 10%.
  • AdBlue tank temperature above -5 °C.
  • Check that no fault codes are stored in the engine control unit.
  • The air pressure must be at least 8 bar when performing this test.
Procedure:
  1. Start the function.
  2. A dialogue box shows the test conditions, check these and press "OK".
  3. Communication will be established with the control system.
  4. Start activation of the pump.
  5. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
