[1116]Add key

Conditions:

- Pin Code “Immobilizer pin” is required.

- New key delivery documents contains the “Immobilizer pin”.

- No fault codes stored.

- Ignition on. - Maximum 6 keys can be programmed.

Description:

- Read “Programmed keys”, in the datalist.

- Change to the new key and establish connection.*

- Enter the car specific “PIN CODE”.**

- Press “Program key” button.***

- Read “Programmed keys”, in the datalist. 1 key added.

- Read faultcodes. Erase faultcodes if necessary.

- If you want to add another key, start procedure again.

Note:

* Every ignition off, new communication has to be established.

Stay in the datalist and wait for the dialog to establish connection.

** If wrong code is entered too many times, the system will be locked 5 minutes or more. See datalist “Security clock”.

*** After programming, new communication has to be established.

Go to the datalist and wait for the dialog to establish connection.
