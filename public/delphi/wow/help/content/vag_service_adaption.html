[18]Configure service interval data

On vehicle with flexible service interval, the service intervals are calculated, in addition to driven distance and time, also using fuel consumption and oil temperature. This calculation gives a value of the oil's degradation in relation to thermal loading. On vehicles with diesel engines the oil's degradation is calculated based on engine rpm, engine load, driven distance, and oil temperature. This gives values for thermal loading and soot deposits. Oil degradation is the decisive factor for when the next service shall take place. The shortest interval for service is 15,000 km or 12 months.

With this function it is possible to adapt service interval data using selected adaptation channel.

  • In some vehicles from model year 2008 and later, not only values for oil change interval are indicated, but also values for service/extra work (applies to channel 52-55).

  • Incorrect adaptation leads to incorrect calculation of future service.

  • Workshop manual with channel values should be available.

  • Oil of approved standard must be used when adapting to flexible service interval.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

Procedure:

  1. Select relevant channel for service interval data shown below and press "OK" to start the adaptation.

    These channels are relevant for fixed oil change interval:

    • 40 - Driven distance since last service.

    • 41 - Days since last service.

    • 45 - Oil quality, always value 1 for fixed interval.

    • 50 - Fixed value for distance to next service.

    • 51 - Fixed value for time in days to next service.

    These channels are relevant for flexible oil change interval:

    • 40 - Driven distance since last service.

    • 41 - Days since last service.

    • 42 - Lower limit value for driving distance to next service.

    • 43 - Upper limit value for driving distance to next service.

    • 44 - Upper limit value for time to next service.

    • 45 - Oil quality, always value 2 for flexible service interval.

    • 49 - Lower limit value for time to next service.

    These channels are relevant for time and distance-dependent service/extra work:

    • 52 - Fixed value for distance to next service.

    • 53 - Distance driven since last service.

    • 54 - Fixed value for time in days to next service.

    • 55 - Days since last service.

  2. Present value is shown. Press "Yes" to change value.

  3. Enter new value in shown entry field, confirm with "OK".

  4. The entered value is shown, press "Yes" to store the value.

  5. A dialogue box with "stored in memory" is shown.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
