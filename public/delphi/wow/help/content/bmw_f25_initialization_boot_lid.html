[598]Initiating tailgate opener

Note:

If the control unit for automatic operation of the tailgate identifies a fault, then drive for the automatic tailgate will be disconnected. Drive will remain disconnected even after the fault memory has been erased. A system reset for the automatic tailgate must be performed for the drive to work again.

This function must be run if one or both drives for tailgate opening has been changed.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.
