[436]Basic setting of solenoid valve

This function is used to adapt the solenoid valve for turbo 2 (VT2) to the engine control unit. Adaptation shall be done when the valve has been replaced. Teach-in is only possible with the engine running.

Test conditions:

  • Engine idling.

  • All power consumers disconnected.

  • Battery voltage above 12V.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. A dialogue box shows that activation is run.

  3. A dialogue box shows if the function succeeded or failed.

  4. Then let the engine idle for 1 minute to teach in low end-position.

  5. Then rev up the engine to at least 4000 rpm for 10 seconds to teach in high end-position.

  6. After teach-in, check status of teach-in in the parameter list.

  7. Finish and disconnect the diagnostics instrument.

  8. The function is done.

    • If the function fails, check the test conditions and repair any faults.
