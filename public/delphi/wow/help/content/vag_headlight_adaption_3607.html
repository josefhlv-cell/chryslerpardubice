Headlight adjustment
Before the adjustment of the headlights is performed on vehicles with xenon lamps, "Adjust light setting" of the headlight range control must always be carried out. This function disconnects the control mechanism to make headlight adjusting possible. If this is not performed the headlight range control device will be damaged.
This must be done if:
  • The control unit for the regulation of the headlight range has been re-coded or dismounted/assembled.
  • A new headlamp has been assembled.
  • The headlamp has been dismounted and assembled again.
  • The left front level sensor has been replaced.
  • The left rear level sensor has been replaced.
  • A new holder for the level sensor has been assembled.
  • The link arm or the frame of the level sensor has been dismounted/assembled, changed.
Note:
  • The vehicle must not be moved during the adjustment; to open/close doors or lean on the vehicle is not allowed. When headlights, level sensors or headlight range control unit are renewed, this function must be performed.
  • If the fault code 1539 is stored, this function must be performed.
Test prerequisites:
  • The battery voltage should be above 12 V.
  • Ignition on, engine off.
  • No fault codes stored.
  • No sensor or stepmotor faults.
  • The control unit for the regulation of the headlight range must be coded.
  • Headlamp lenses unbroken and clean.
  • Reflectors and bulbs ok.
  • Tyre pressure ok.
  • Handbrake released and no gear selected.
  • Wheels in a straight-ahead position.
  • Vehicle correctly loaded and springs settled (driver seat loaded with 75 kg).
  • Fuel tank at least 90% left.
  • The left front level sensor must have a value between 12,5-50%.
  • The left rear level sensor must have a value between 50-87,5%.
  • Vehicle and headlight adjuster on a level surface and aligned.
To perform adjustment:
  1. Read and check the inclination measurement, which is embossed in percentage on the hood above the headlight. The percentage information derives to a projection distance of 10 metres. A value of for example 1,0 % corresponds to 10 centimetres.
  2. Select the function: "Adjust light setting".
    • The headlights are now put in adjustment position. The values for the level sensors are erased and the fault code 1539 is stored. This is confirmed with the text: "headlight adjustment".
  3. Exit the function.
  4. Adjust the headlights according to the national legislation and regulations.
  5. Select the function: "Store setting".
    • The new headlight setting is stored and the values from the front and the rear level sensors are stored as new starting values. This is confirmed with the text: "Control position adjusted".
  6. Exit the function.
  7. Turn off the ignition for 60 seconds to store the new values.
  8. Re-establish diagnosis with the system. Read and check that no faults are stored.
  9. Exit the function.
