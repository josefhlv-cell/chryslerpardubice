[1730]Service mode parking brake

The electro-mechanical parking brake is integrated in the rear wheels' brake calipers. When repairing the rear wheel brakes, a diagnostics instrument must be used to open the parking brake by pulling back the pistons to expose the brake pads. After the repair is done, the parking brake shall be applied using a diagnostics instrument and the pads' new position is stored automatically.

The following work requires resetting of the brake pistons:

  • Removing and installing parking motors, brake calipers, brake discs, and wheel hubs.

  • Replacing brake pads.

After the repair is done and the parking brake is applied, a basic setting of the brake system needs to be performed.

Test conditions:

  • Ignition on and engine off.

  • Battery voltage above 12 V.

  • Parking brake not applied.

Procedure:

  • Resetting pistons (before service):

    1. Select the function: "Resetting pistons" (before service).

    2. Confirm with "OK".

    3. Now the stepping motors run in the pistons. The control light for parking brake is turned on.

    4. The function is done.

  • Run out pistons (after service):

    1. Select the function: "Run out pistons" (after service).

    2. Confirm with "OK".

    3. Now the stepping motors run out the pistons. The control light for parking brake is turned off.

    4. Exit the function.

    5. Perform the basic adjustment: "Basic setting of brake system".
