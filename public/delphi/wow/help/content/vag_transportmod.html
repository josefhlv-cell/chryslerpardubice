[1393]Activation/deactivation of transport mode

Transport mode is a function that is used to keep the battery capacity in the car. With the transport mode activated, discharging of the battery is limited. "Tra" is indicated on the dashboard when the transport mode is activated.

With the transport mode activated, the following functions/components are shut off:

  • Radio

  • Remote control function

  • Interior monitoring

  • Tilt sensor

  • Interior lighting is only active for 30 seconds

  • Radio controlled watch on the dashboard

  • SAFE indication on the instrument panel

Note:

On vehicles of year medel 2004 to 2006, the transport mode is automatically deactivated after 150 kilometres driving distance and can not be activated again. On vehicles of year model 2007 and forward, the transport mode is automatically deactivated after 50 kilometres driving and can be activated at any time.

Test prerequisites:

  • Ignition On

  • Battery voltage OK

Procedure:

  1. Choose the function: Activate/deactivate transport mode.

  2. A dialog box confirms: Operation succeded/failed.

  3. Exit the function and check the activation/deactivation.
