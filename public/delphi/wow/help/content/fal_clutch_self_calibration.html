[675]Clutch self-calibration

This function is used for fine adjustment of the clutch.

Note:

When the function is started the engine must be stopped in the ignition on position, but later in the function the engine is started in order for the fine adjustment to be performed. If the key is turned to the Stop position, the function must be restarted.

Test conditions:

  • Ignition on.

  • Stop&Start function disabled.

  • Gear in neutral position.

Procedure:

  1. Start the function and follow the instructions in the program.
