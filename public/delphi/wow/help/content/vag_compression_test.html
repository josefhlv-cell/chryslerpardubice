[324]Compression test

The engine control unit continuously monitors every individual cylinder's efficiency and compensates for any deviations by correcting the injection amount for the relevant cylinder, thus smooth engine operation is obtained.

In case of fault codes for injection control, the following function can be used to read out current correction of the injection amount for each cylinder. Major deviations may have several causes, for example:

  • Low compression.

  • Defective injector.

  • Air in fuel system.

The function should be regarded as help in troubleshooting. Manual checks of, e.g., compression are done for assured diagnosis.

Test conditions:

  • Engine idling.

  • Coolant temperature above 70°C.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program. Relevant reference values are shown in the function.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
