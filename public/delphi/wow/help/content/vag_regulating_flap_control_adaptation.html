[342]Basic setting of control unit for regulating flap

During basic setting, the control unit for regulating flap is adapted to the engine control unit.

Adaptation should be performed when:

  • Voltage to the engine control unit has been cut off.

  • Control unit for regulating flap has been removed or replaced.

  • Engine control unit has been replaced.

Test conditions:

  • Ignition on, engine off.

  • Ignition on for at least 10 seconds before the function is run.

  • Inlet air temperature between 5 and 100 °C.

  • Battery voltage above 12V.

  • All power consumers disconnected.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. A dialogue box with current status for the adaptation is shown.

  3. After completed adaptation, "Adaptation OK" is shown - The adaptation may in some cases proceed so quickly that "Adaptation OK" is shown immediately.

  4. Press "OK" when the function is complete.

  5. Exit communication with the vehicle.

  6. Turn off the ignition for 30 seconds to store new values.

  7. The function is done.

    • If the function fails, check the test conditions and repair any faults.
