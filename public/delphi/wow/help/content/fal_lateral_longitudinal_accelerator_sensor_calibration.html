[652]Calibrating the longitudinal and lateral acceleration sensor

This function is used when the control unit or the component being examined is replaced. Certain parameters and/or active diagnosis may be "Unavailable" depending on the version and options installed on the vehicle.

Note:

If a reset of the longitudinal and lateral sensor is performed, fault code C006A, lateral accelerator/gear sensors, is set to permanent. If this fault code remains this function will be processed as "Unavailable" by the controller. In order to reset the fault code, the vehicle must be in 'sleep mode': The key must have been removed and remain out for at least 1 minute.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. If the function ends with a negative result, check the test conditions and remedy any problem sources.
