Adaption of remote control
This function is used for adapting transponders (remote controls) when replacing a defect transponder or increasing the number of transponders (maximum four). This function is also necessary if the code of the remote control and control unit no longer match. This may occur if the transmitter button is pressed when outside the system's operating range.
Note:
  • All remote controls must always be re-synchronised, including the existing ones.
  • The time taken to synchronise all remote controls must not exceed fifteen seconds.
  • New ignition keys must also be adapted to the immobiliser control unit.
Test conditions:
  • The battery voltage should be at least 12V.
  • Ignition on, engine off.
  • All electrical loads should be switched off.
Method:
  1. Insert one of the ignition keys in the ignition lock.
  2. Start the function 'Adaption of remote control'.
    • All old remote controls are now deleted.
    • All remote controls must always be re-synchronised, including the existing ones.
  3. A dialogue box presents "Channel value: 1" if the transponder adaptation is possible, confirm with "Yes" to adapt new tranponders.
  4. Enter the total number of remote controls to be adapted in the presented input field, confirm with 'OK'.
  5. A dialogue box presents the number of remote controls to be adapted "channel value x", confirm with 'YES'.
  6. A dialogue box presents "stored in memory" if the system is ready for adaptation of new transponders, confirm with "OK".
    • The adaption time starts when the dialog box is presented.
  7. Press a button on each remote control for at least one second.
    • A flashing in the direction indicators alternatively a signal from the alarm horn confirms that the transponder is adapted.
  8. Synchronisation is terminated automatically when:
    • the number of remote controls to be synchronised is reached.
    • A button is pressed more than once on the same remote control.
    • The time taken to adapt all remote controls exceeds fifteen seconds.
  9. Switch off the ignition and remove the ignition key.
  10. Check the operation of all the remote controls.
