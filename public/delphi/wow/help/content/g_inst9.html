[1049] Basic ignition position

Preconditions for the test:

  • Engine idling.

  • Engine temperature above 80 °C.

  • No faults stored.

Note:

  • To check and adjust basic ignition timing.

Procedure:

  • Choose the basic ignition timing function.

  • The control unit increases the engine speed to 1150-1400 rpm.

  • Check that the block of numerals for the setting preconditions column are all zero.

  • Check the basic ignition setting with the ignition timing lamp. Prescribed value 3-8 ° before TDC.

  • Set the required value by turning the distributor. Setting value: 6±1° before TDC.
