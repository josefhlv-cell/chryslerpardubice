[1081]Test of compression

The compression test is used to determine how good the compression of each cylinder is. The engine will not start during this test. Test results will be presented in percentage (0-100%).

Test prerequisites:

  • Ignition on, engine off.

  • Battery voltage OK.

Procedure:

  1. Turn the ignition key into start position and keep it there until the start operation is switched off automatically.

  2. Wait until the actual values of the cylinder compression are correctly displayed.

  3. When you have finished the test, switch off the ignition for at least 7 seconds before it is switched on again.
