[492]UDST (Urea dosing system test)

In this test, the following information can be obtained:

  • Validation that correct components are installed in the system. (Tank, pump module, dosing module, pipes.)

  • Validation that the components work.

  • Validation of AdBlue dosing's components.

  • Check of sealing. Check of clogged pipes and hoses.

The test CANNOT give information about:

  • Correct injected AdBlue amount.

  • Heater's function.

  • Actual NOx-value.

Note:

When changing pump module or other components that open the circuit in the system the flushing phase shall be performed before other tests can be done.

Do not run more than two tests in a row.

If it is necessary to perform more than two tests the vehicle must first be warmed up until the catalytic converter has reached working temperature.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Press the "OK" button to start the test.
