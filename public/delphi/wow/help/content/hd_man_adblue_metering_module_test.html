[518]AdBlue dosing test

The test determines correct function in the dosing valve and its associated components.

The test can be run with three different dosing amounts.

  • Large amount. (Between 150 - 190 ml.) Test takes 90 seconds.

  • Medium amount. (Between 70 - 95 ml.) Test takes 180 seconds.

  • Small amount. (Between 35 - 55 ml.) Test takes 300 seconds.

All three tests should be run to enable a correct assessment of the dosing system. Do not perform the measurement without having removed the dosing valve. AdBlue injected in the catalytic converter can cause damage. The measurement can only be performed if the temperature sensor after the catalytic converter is disconnected and replaced with an 180 ohm resistor.

Test conditions:

  • Dosing valve removed from the exhaust pipe.

  • Air pressure in tanks shall be at least 8 bar.

Procedure:

  1. Remove the dosing module from the exhaust pipe.

  2. Use the adapter from AdBlue test kit (MAN 80.99607-6038) to connect the measuring line. Then the measuring line should be placed in the measuring beaker.

  3. Measured quantity is weighed after every test.

  4. If the measured values do not match the reference values, run test of the supply module.

  5. Ignition on, engine off.

  6. Press the "OK" button to start the test.
