ABS initialization
This function should be used if the ABS module, control unit for steering wheel electronics (SCCM) or dynamic sensor has been replaced.
Note:
To avoid serious or fatal injury, check that the brake capability is available before road tests.
The ABS system must be initialized when replacing the ABS module, control unit for steering wheel electronics (SCCM) or dynamic sensor. If initialization isn't performed, the ABS indicator will flash continuously. With this function, any fault codes will be reset on SCCM and dynamic sensor.
Perform a driving test after replacing the dynamic sensor, by turning the steering wheel between left and right in a billowing movement at a speed of 10 - 25 km/h (6 - 15 mph).
Test conditions:
  • Vehicle stationary.
  • The vehicle must stand on level ground.
  • Centre the steering wheel with the wheels pointing straight forward.
  • Brake pedal not pressed down.
Procedure:
  1. Start the function and follow the instructions in the program.
  • If the function fails, check the test conditions and repair any faults.
