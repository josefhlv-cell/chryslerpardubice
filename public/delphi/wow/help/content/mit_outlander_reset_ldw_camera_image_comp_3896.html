Decalibration: Image adjustment
This function is used if an image adjustment should be performed on a camera, where the image adjustment has already been performed.
Preconditions for the test:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. After the function is complete, fault code C1706 will be stored and the LDW warning indicator in the instrument will illuminate.
  3. The function is done.
