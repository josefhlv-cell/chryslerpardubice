[446]Deactivate service mode on parking brake

This function is used after work has been done on the parking brake. Deactivation is necessary for the parking brake to work again.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
