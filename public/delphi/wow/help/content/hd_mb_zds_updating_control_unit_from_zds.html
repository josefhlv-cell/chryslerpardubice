[603]Update control unit from central data memory, ZDS

This function transfers the control units' parameters, stored in the central data memory ZDS, to the control units.

If a fault code has occurred during transfer to the control modules, then you can read in extended fault code reading on ZDS which control unit is affected. The control units are stated in address name according to the list below. Perform a new update of the relevant control unit.

Addresses for control units

Control units=Address

  • WS=98

  • MSF=97

  • BS=A4

  • FM=3D

  • FR=02

  • GM=BA

  • GS=89

  • HM=91

  • INS=15

  • TMB=13

  • TMF=20

  • ZDS=32

  • HZR=1C

  • KOM=1A

  • RS=8F

  • EDW=2C

  • PSM=AE

  • SPA=85

  • SRS=2A

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. A dialogue box shows test conditions, check these and press "OK".

  3. Select to which control unit the transfer shall take place.

  4. Transfer starts, follow instructions.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
