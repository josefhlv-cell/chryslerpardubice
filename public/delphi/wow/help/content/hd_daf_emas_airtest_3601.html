Air test
This function checks if there is any air in the hydraulic system.
If air is detected, the EMAS system must be vented.
Note:
Be careful, during this function the trailing axle will be controlled automatically to its end positions.
Make sure that nobody can become trapped between the tires and chassis.
Test conditions:
  • Engine running.
  • handbrake applied.
  • Trailing axle lifted up.
Procedure:
  1. Start the function.
  2. Checking is performed by the system, this might take up to 265 seconds.
  3. Result is shown.
  4. The function is done.
  • If the function gets a fault code, check the test conditions and rectify the fault code.
