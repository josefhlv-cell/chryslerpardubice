[460]Reset service information after oil change

This function is used to reset all adaptive parameters in the UniAir-module from the control unit after an oil change in the engine.

If this procedure has not been run the control unit cannot estimate exact air and gasoline flow and the following consequences are likely to occur:

  • Possible that unmotivated diagnostic requests for all components related to the throttle body and throttle control's position may occur.

  • Very poor driveability.

The following conditions shall be fulfilled to run the procedure:

  • Gear lever in neutral.

  • Engine idling (Stop & Start function deactivated) NOTE!!! engine may not be started until instruction appears.

  • Let up brake and clutch pedal.

  • Air conditioning off.

  • Fault code P1305 may not be in the fault memory.

Test conditions:

  • Ignition on, engine off - the engine is started during the procedure.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
