[1161]ABS/ESP calibration

Conditions:

-Engine off

-Ignition on

Procedure:

-Type the code for which engine you want to configure the ECU for.

Ex. 01 if you wish to configure for a K4M.

-Start command

Possible configurations:

  • K4M = 01

  • F4P = 02

  • F4R/F5R = 03

  • F4Rt = 04

  • L7X = 08
