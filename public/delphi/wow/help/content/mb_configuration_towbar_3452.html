Configuration of towbar and country version
This function is used to configure the towbar control unit.
Note:
An incorrect configuration may cause that the control unit doesn't work properly together with the installed towbar.
Test conditions:
  • Ignition on.
Procedure:
  1. Start the function.
  2. A dialogue box with present configuration is shown.
  3. Press "OK" to proceed.
  4. Select country/region or manual locking.
  5. Select type of towbar.
  6. The function is done.
