[304]Reset adaptation values for the electric fuel pump

The electric fuel pump's power consumption is checked and saves an adaptation value in the engine control unit. This adaptation value is saved at minimal activation of the fuel pump's electric power consumption and a lower limit value for power consumption is calculated. This function must be run after replacement of the fuel system's high-pressure pump to reset the adaptation value, when the engine is started new adaptation values will be stored in the control unit.

Test conditions:

  • Ignition on, engine off.

  • The fuel pump shall be replaced.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Adaptation values are reset in the control unit.

  3. Start the engine and let it idle for a few minutes to teach in new adaptation values.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
