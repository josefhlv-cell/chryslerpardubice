[1232]Key programming

This function is used to registrate extra keys to the immobiliser system.

Note:

  • You must start with a registrated key.

  • Key code registration will fail if the time limit is exceeded.

  • Turn off any cell phone near the driver seat.

  • It is possible to registrate max. 4 keys.

Test prerequisites:

  • The battery voltage should be >12V.

  • Ignition on, engine off.

  • No stored fault codes.

  • A registrated key.

  • A new key to program.

Procedure:

  1. Choose the function: Key programming.

  2. Dialogue box: Engine off, ignition on, see help for further information. Press OK to continue.

  3. A dialogue box presents the number of programmed keys, to continue press OK.

    • If you want to cancel key programming, press abort.

  4. Dialogue box: Press OK and then touch the ignition switch with a registrated key within 30s, make sure that the emblem side is facing the switch.

    • Note: Programming will fail if the time limit is exceeded.

    • There will be a beep when the key touches the ignition switch.

    • If you want to cancel key programming, press abort.

  5. Dialogue box: Press OK and then touch the ignition switch with a key to be registrated within 30s, make sure that the emblem side is facing the switch.

    • Note: Programming will fail if the time limit is exceeded.

    • There will be a beep when the key touches the ignition switch.

  6. A dialogue box displays the number of programmed keys.

If the key programming has failed:

  • The time limits may have been exceeded.

  • Check the battery voltage.

  • Check that you have started this operation with a registrated key.

  • Check that no fault codes are stored.

Restart this function to try again.
