[434]Reset counter for gear selector, paddles, and electric pump

This function is used to reset counter for gear selector, paddles, and electric pump. The function is used when replacing gear selector, paddles, or electric pump.

Test conditions:

  • Ignition on, engine off.

  • Gear in P/N.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Counter is reset.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
