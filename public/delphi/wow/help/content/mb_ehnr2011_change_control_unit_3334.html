Control unit replacement
This function is used when the control unit should be replaced and it is still possible to communicate with the control unit.
Note:
If it is still possible to read out the old control unit, it is enough to perform the control unit replacement function.
Level calibration is not necessary in this case.
Test prerequisites:
  • Ignition on.
  • The old control unit is still fixed mounted.
  • The new control unit available.
Procedure:
  1. Start the function.
  2. Coding is read and stored in memory.
  3. Switch off the ignition, press "OK".
  4. Perform replacement of the control unit.
  5. Press "OK" to continue.
  6. Turn on the ignition, press "OK".
  7. A dialogue box shows: "Should coding starts?".
    1. At answer "Yes": Communication is established and the coding is retrieved from the memory and sent to the new control unit. At answer "No": Communication is established but no coding is sent.
  8. The function is done.
