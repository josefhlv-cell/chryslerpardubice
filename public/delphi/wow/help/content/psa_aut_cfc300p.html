Please take time to read the whole instruction before making any repairs on the gearbox.

Summary of the work sequences:

ADepressurize the hydraulic circuit.
BMechanical work.
CPressurize the hydraulic circuit.
DBleeding of the hydraulic circuit.
EReinitialisation of the auto-programming values.
FProgramming of the clutch biting point
GProgramming of the gearbox grid
HClear counters.

Explanation of the work sequences.

  1. Depressurize the hydraulic circuit.

    Note:

    During the function, the ignition must not be switched off.

    Test prerequisites:

    • Ignition on, engine off.

    • Gear in neutral.

    • All electrical loads should be switched off.

    • Battery voltage above 12 Volts.

    Procedure:

    1. Start the function.

    2. The system is now depressurized.

    3. A dialog box presents: operation succeeded/ failed.

      • If the function fails, check test prerequisites and repair possible fault codes.

    4. Exit the function.

  2. Mechanical work.

    • For the mechanical work we refer to manufacturer instructions.

  3. Pressurize the hydraulic circuit.

    Note:

    During the function, the ignition must not be switched off.

    Test prerequisites:

    • Ignition on, engine off.

    • Gear in neutral.

    • All electrical loads should be switched off.

    • Battery voltage above 12 Volts.

    Procedure:

    1. Start the function, press OK.

    2. The system is now pressurized.

    3. A dialog box presents: operation succeeded/ failed.

      • If the function fails, check the test prerequisites and repair possible fault codes.

    4. Exit the function.

  4. Bleeding of the hydraulic circuit.

    Note:

    During the function, the ignition must not be switched off.

    Test prerequisites:

    • Ignition on, engine off.

    • Gear in neutral.

    • All electrical loads should be switched off.

    • Battery voltage above 12 Volts.

    Procedure:

    1. Start the function, press OK.

    2. Bleeding of the hydralic unit is now performed.

    3. A dialog box presents: operation succeeded/ failed.

      • If the function fails, check the test prerequisites and repair possible fault codes.

    4. Exit the function.

  5. Reinitialisation of the auto-programming values.

    Test prerequisites:

    • Ignition on, engine off.

    • Gear in neutral.

    • All electrical loads should be switched off.

    • Battery voltage above 12 Volts.

    Procedure:

    1. Start the function, press OK.

    2. The auto-programming values are now reinitialised.

    3. A dialog box presents: operation succeeded/ failed.

      • If the function fails, check the test prerequisites and repair possible fault codes.

    4. Exit the function.

  6. Programming of the clutch biting point.

    Note:

    During the function, the ignition must not be switched off.

    Test prerequisites:

    • Engine on idle.

    • Gear in neutral.

    • All electrical loads should be switched off.

    Procedure:

    1. Start the function, press OK.

    2. The programming of the clutch biting point is now started.

    3. A dialog box presents: operation succeeded/ failed.

      • If the function fails, check the test prerequisites and repair possible fault codes.

    4. Exit the function.

  7. Programming of the gearbox grid.

    Note:

    During the function, the ignition must not be switched off.

    Test prerequisites:

    • Ignition on, engine off.

    • Gear in neutral.

    • All electrical loads should be switched off.

    • Battery voltage above 12 Volts.

    Procedure:

    1. Start the function, press OK.

    2. The programming of the gearbox grid is now started.

    3. A dialog box presents: operation succeeded/ failed.

      • If the function fails, check test prerequisites and repair possible fault codes.

    4. Exit the function.

  8. Clear counters.

    Note:

    When changing components in the gearbox, it is possible to clear the counter values for the corresponding part. This is done to get a correct usage history of the mounted parts. Current values can be seen in datalist tables. Clear only the counter for the charged component.

    Test prerequisites:

    • Ignition on, engine off.

    • All electrical loads should be switched off.

    • Battery voltage above 12 Volts.

    Procedure:

    1. Start the function, press OK.

    2. A dialog box presents: operation succeeded/ failed.

      • If the function fails, check the test prerequisites and repair possible fault codes.

    3. Exit the function.
