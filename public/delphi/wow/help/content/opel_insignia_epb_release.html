[280]Releasing parking brake

This function is used to release the parking brake.

Note:

The electric parking brake module releases the parking brake cable to detect any fault of the parking brake switch.

Test conditions:

  • Ignition on, engine off.

  • Gear in P/N.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
