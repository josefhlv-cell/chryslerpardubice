[1741]Reset adaptation values for particle filter

This function is used to reset the adaptation memory for the particle filter in the engine control unit.

Test conditions:

  • Engine on.

  • Gear in P/N.

  • Engine is at operating temperature.

  • Induction temperature between 15-65°C.

Procedure:

  1. Select the function: "Reset adaptation values, diesel particle filter", press "OK".

  2. Follow the instructions.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
