[1537]EAS clutch adjustment

This programming is only for vehicles with EAS (automatic gearbox).

The programming resets the characteristic values for the clutch position/torque transferred. This causes the control module to re-learn itself during the next trip.

Test prerequisites:

  • Ignition on, engine off.

  • No consumers active.

Procedure:

  1. Start the adjustment.

  2. The result of the programming will be presented.
