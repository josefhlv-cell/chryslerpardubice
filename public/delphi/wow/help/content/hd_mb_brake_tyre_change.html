[636]Configure tire size

This function is used to adjust the factory setting for tire size that is programmed in the control unit.

Note:

Only use tire size that is approved for the vehicle. Unreasonable values may lead to fault codes in the system.

  • The tire size's circumference is stated in mm.

Test conditions:

  • Ignition on, engine off.

  • Transmission in neutral.

  • Vehicle stationary.

  • Parking brake applied.

  • Battery voltage above 24V.

Procedure:

  1. Start the function.

  2. A dialogue box shows test conditions, check these and press "OK".

  3. Follow the instructions in the program.

    • If the function fails, check the test conditions and repair any faults.
