[938]Climatronic, Golf IV, Bora

If the display is flashing after the ignition is turned on and no fault code is stored in the memory, then coding and basic setting of Climatronic must be performed.

Test condition:

  • Ignition on

  • No fault code stored

  • Correct coding of Climatronic

Note:

When performing the basic setting will the four positioning motors values be presented in the datalist. When all four positioning motors are presenting 0 is the basic setting complete. During basic setting is it possible to hear the movement of the positioning motors.

Procedure:

  • Choose function: “Positioning motor”

  • Check the value of the four positioning motors
