[219]Basic setting of steering angle sensor

This function is used to adapt steering angle sensor to the control unit. Check that the steering angle sensor is in zero position before removing (this value can be read out via data list). This should be done if:

  • The control unit for ABS has been replaced.

  • The sensor has been replaced.

  • Work that affects the chassis geometry has been done.

Note:

  • The ignition must not be turned off during the adaptation.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • The steering wheel stands straight and the front wheels point straight forward.

Procedure:

  1. Start the function.

  2. A dialogue box with the text "Status adaptation" shows the steering angle sensor's adaptation status as well as current value.

  3. Press "OK" when the text "Adaptation in order" is shown to finish the function.

  4. Turn off the ignition and exit communication with the car for 30 seconds.

  5. Turn on the ignition, re-establish communication with the car, and check that no fault codes are stored.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
