[1477]Climatronic, basic setting.

If the climate control unit has been replaced, or a new damper positioning motor has been installed, a basic setting must be performed. When the climate regulation basic setting is performed, the control unit learns the positioning motors end positions.

Test prerequisites:

  • Battery voltage above 11.5 V.

  • No faults stored.

  • Ignition ON.

  • Climate control unit ON.

  • The damper positioning motor connected and correctly mounted.

Procedure:

  • Start the function: Positioning motor exchange.

  • Check the values of the positioning motors.

  • When all positioning motors are presenting 0, the basic setting is completed.

    • If any of the positioning motors don´t take on the correct value, check the test prerequisites and repair possible fault codes.

  • Exit the function.
