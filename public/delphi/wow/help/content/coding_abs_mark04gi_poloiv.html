[790]Coding ABS control unit Mark 04GI PoloIV –95 to -01

Coding:

The ABS control unit must be recoded if the vehicle relevant coding is not displayed in the system basic data or the control unit has been renewed.

Code:

For coding ABS Mark 04GI on Polo IV –95 to -01 the valid code is: 01901

Note:

If the control unit is incorrectly coded will the ABS check lamp and the brake system check lamp be permanently on.

If the control unit is not coded, the ABS check lamp and the brake system check lamp flashes once per second.

To perform coding:

  • Write the current code in the ABS coding field.

  • Click on the OK-button.

  • A dialogue box confirms: Operation succeeded / Operation failed.

  • Read the control unit basic data to check that the new code is programmed.

  • Check that no fault codes are stored.
