[1577]Adaption of component

With this function adaption in the engine control module (ECM) can be performed.

Note:

This adaption must be done after the component or system related components has been replaced or repaired.

Test prerequisites:

  • Ingnition on, engine off.

Procedure:

  1. Choose the function and follow the instructions.

If the operation failed check and repair any faults that may be in the system.
