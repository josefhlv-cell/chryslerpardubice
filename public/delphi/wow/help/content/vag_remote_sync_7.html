[720]Synchronising remote control

This function is used to synchronise remote controls that have already been adjusted for the vehicle.

Note:

Remote controls must be synchronised if the vehicle cannot be locked or unlocked, and error codes 00955 to 00958 have been stored.

  • All of the vehicle's remote controls must be synchronised following disconnection or replacement of the vehicle's battery.

  • Remote controls must also be resynchronised after the battery is replaced.

  • If the synchronisation process is not successful, the remote control must be adjusted using the "Remote control adjustment" function

Test conditions:

  • There are two synchronisation methods, depending on the control unit's version number. The version number is found on the last data list.

Procedure:

Method 1 (Version numbers up to 0999)

  1. Press a button on the remote control that does not work.

  2. Lock and unlock the vehicle within 30 seconds using the driver's door lock.

  3. Check the operation of the remote control.

Method 2 (Version numbers higher than 1000)

  1. If the vehicle is locked, open it manually using the driver's door lock.

  2. Press the unlock button on the remote control.

  3. Insert the key in the ignition and turn the ignition on for 2 seconds.

  4. Turn the ignition off and remove the ignition key.

  5. Press the unlock and lock buttons on the remote control.

  6. Check the operation of the remote control.
