[715]VANOS adaptation

A VANOS solenoid valve is used to activate the VANOS adjustment unit. The rpm and load signals calculate the position required for the intake and exhaust camshafts.

This function is used to reset adaptation values in the VANOS adjustment unit.

Test conditions:

  • Ignition on, engine off - the engine is started during the procedure.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is complete.

    • If the adaptation fails, check the fault memory in DME and remedy any faults. Then repeat the function.

    • If there are no faults stored in the control unit, you must carry out the following:

      1. Take a test drive with at least one fuel disconnection phase of 5 seconds and an engine speed of more than 2000 rpm.

      2. Then repeat the function.
