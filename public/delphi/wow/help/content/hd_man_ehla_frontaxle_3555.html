Calibration steering angle sensor front axle
This function is used to calibrate the steering angle sensors. Only calibrate the steering angle sensors if the sensors or sensor linkage has been disconnected or replaced, if the control unit has been replaced or axle geometry has changed.
Note:
Perform this calibration with the utmost care, incorrectly calibrated sensors will affect the driving performance.
Calibration must be performed completely and correctly. Incorrect, incomplete or aborted calibration leads to system fault and must be corrected!
Test conditions:
  • Engine on.
  • EHLA system must be oil-filled.
  • The rear axle must not be centered.
  • The differential lock must not be activated.
  • The suspension must be in normal driving mode.
  • Check the axle geometry using a measurement tool (axle offset, tilt, camber etc.)
Procedure:
  1. Press "OK" to start calibrating.
  2. Set the front axle completely straight (0° +/- 0,05°) using the steering wheel (check with wheel alignment test).
  3. Set the steering angle sensors as close as possible to 2,5 V (+/-0,15 V).
  4. Press calibrate.
  5. If the steerable rear axle already is calbrated, check the function at standstill before test driving. If not, calibrate the rear axle.
