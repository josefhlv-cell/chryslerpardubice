[510]Steering angle calibration

This should be done if: The ABS control unit has been replaced. The steering angle sensor has been replaced. The steering shaft has been replaced. Body work has been done that impacts wheel alignment. The steering angle sensor has been disconnected. Error code that requires calibration is stored in the ABS control unit.

Test conditions:

  • Ignition on, engine off.

  • The steering wheel stands straight and the front wheels point straight forward.

  • The vehicle must stand on level ground.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
