[1709]Calibrate clutch, transmission and bite point

This function is used to calibrate the clutch and transmission position sensors, and to find the clutch's bite point.

There are two types of calibration:

  1. "Clutch, transmission and bite point calibration, without clutch replacement".

    • Used when the clutch cylinder, transmission or control device housing has been replaced.

  2. "Clutch, transmission and bite point calibration, with clutch replacement".

    • Used when the clutch has been replaced.

Calibration takes place in 3 stages, with the result for each calibration displayed with a current calibration value for each component. The current calibration value must be between the minimum and maximum values which are also displayed. If the current calibration value is not between the minimum and maximum values, a trouble code will appear on the "MID 130" and calibration must be repeated. Trouble codes are inactive if calibration is performed correctly.

Note:

The engine must be switched off until a message to start the engine appears at "Calibration stage 3".

Test conditions:

  • Parking brake applied.

  • Air pressure in transmission between 550-1,000 kPa.

  • Engine off.

  • Battery voltage above 20 V.

  • Oil temperature in transmission above 15°C.

  • Gear lever in position N.

Procedure:

  1. Select the calibration version to be performed.

  2. A dialogue box appears showing the test conditions. Check these.

  3. Calibration stage 1: The clutch's stroke length and wear are calibrated.

  4. A dialogue box is appears with the result for stage 1.

  5. Calibration stage 2: The transmission is calibrated.

  6. A dialogue box is appears with the result for stage 2.

  7. Calibration stage 3: The bite point is calibrated, start the engine when the message appears.

  8. A dialogue box is appears with the result for stage 3.

  9. The function is complete.

    • If the function fails, check the test conditions and repair any faults.
