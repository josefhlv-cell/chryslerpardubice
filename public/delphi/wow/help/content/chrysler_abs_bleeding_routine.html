[1668]Bleed brake system

This function must be run after the brake system has been manually bled. Check that the brake fluid level is correct before starting the bleeding procedure.

The brake pedal must be depressed for the entire bleeding procedure.

Test conditions:

  • Battery voltage above 11.5 V.

  • Ignition on, engine off.

  • Correct brake fluid level.

  • Brake pedal depressed (for the entire procedure).

Procedure:

  1. Select the "Bleed brake system" function and press "OK". The bleeding procedure is now activated and the following requests and checking steps are shown.

  2. Depress the brake pedal and hold it down. Press "OK" to continue.

  3. Open the front right bleed valve. Keep the brake pedal depressed. Press "OK" to continue.

  4. Close the front right bleed nipple. Keep the brake pedal depressed. Press "OK" to continue.

  5. The procedure is now repeated in the same way for the next wheel (see steps 2-4).

  6. Press "OK" when the procedure ends.

  7. The function is complete.

    • If the function fails, check the test conditions and start again from point 1.
