[1211]Adjusting headlights with gas discharge lamps (Xenon)

Note:

On cars with one control unit for the left headlight and one control unit for the right headlight, the basic setting is only performed from the left headlight control unit (master).

Before adjustment of headlights is performed on vehicles with gas discharge lamps, basic setting of the automatic headlight range control always must be carried out. The basic setting disconnects the control mechanism to make headlight adjusting possible. If basic setting is not performed the headlight range control device will be damaged.

The vehicle must not be moved during the adjustment, to open/close doors or lean on vehicle is not allowed.

When headlights, vehicle level senders or headlight range control unit is renewed basic setting must be performed.

Test prerequisites:

  • Battery voltage min 11 V.

  • No fault codes stored.

  • Headlamp lenses unbroken and clean.

  • Reflectors and bulbs ok.

  • Tyre pressure ok.

  • Handbrake released and no gear selected.

  • Wheels in a straight-ahead position.

  • Vehicle correctly loaded and springs settled.

  • Vehicle and headlight adjuster on a level surface and aligned.

To perform adjustment:

  • Read and check inclination. The inclination value is embossed in trim above the headlight. It is stated in percentage and based on a projection distance of 10 metres. A value of for example 1,2 % corresponds to 12 centimetres.

  • Select the basic setting: Adjust light setting.

    The headlights will now be moved into the adjustment position and the fault code “headlights not adjusted” is stored.

    This is confirmed with the text: Headlight adjustment.

  • Adjust the headlights according to the national legislation and regulations.

  • Exit the basic setting.

  • Select the basic setting: Store setting.

    The new headlight setting is stored.

    This is confirmed with the text: Control position learned.

  • Exit the basic setting.

  • Turn the ignition off and on to initialize the system.

  • Read fault codes and check that no faults are stored.
