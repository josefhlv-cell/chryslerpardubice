[429]Code control unit

This function is used to reset the teach-in variant coding for the ESP-system. Coding is done if the ESP-unit or control unit has been replaced or if fault code C1702 is active with the MIL-light on. When the function is run the new variant coding will be programmed.

If the function is cancelled or fails, check fault codes and test conditions.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. Instruction to turn off and on ignition appears twice in a row.

  3. The function is done.
