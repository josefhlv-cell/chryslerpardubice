[713]Programming new wheel sensors

This function is used when programming new wheel sensors through magnetisation in the TPMS system.

The TPMS system can save max 9 wheel sensors (4 x main wheels, 5 x additional wheels, 1 of which is the spare wheel).

Note:

New wheel sensors are saved in the vacant spaces in the system.

If all of the spaces are occupied, the main wheels are overwritten.

In order to retain the current setting for the vehicle, it must be driven for at least 2 minutes at a speed of more than 40 km/h. After the drive, the additional wheels can be erased to create vacant spaces in the system.

The wheels to be programmed must be fitted to the vehicle when programming takes place.

Ensure that the other wheels are kept at a distance of around 3 metres from the vehicle to prevent them being programmed in error.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • Activation tool for wheel sensors.

  • Can pump tyres to 3.7 bar.

  • Access to all wheels that are to be programmed.

Procedure:

  1. Fit the new wheel set up to be programmed to the vehicle.

  2. Pump the tyres to 3.7 bar.

  3. Start the function and follow the instructions in the program.

  4. A dialogue box shows "Operation successful/failed".

  5. Function complete.

  6. Return to normal tyre pressure.
