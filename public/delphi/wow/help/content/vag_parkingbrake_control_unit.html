[705]Replace control unit

Following replacement of the control unit it is possible to perform basic setting of the parking brake using this function.

Note:

During basic setting the parking brake motors will be run backwards and forwards.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • Parking brake released.

  • No faults in the system.

Procedure:

  1. After replacing the control unit, start the function and follow the program instructions.

    • If the function fails, check the test conditions and repair any faults.
