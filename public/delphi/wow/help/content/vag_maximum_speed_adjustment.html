[326]Configure max. speed limitation

This function is used to adjust the factory setting for max. speed that is programmed in the engine control unit.

  • Max. speed can only be adjusted down.

  • Speed can only be adapted within certain limit values determined by the engine control unit, e.g., 80-190 km/h.

Test conditions:

  • Ignition on.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. Current value is shown. If current value is to be changed, press "YES".

  3. A scroll list is shown with the following choices:

    • "Adapt max. speed limitation" - Used when max. speed limitation shall be adjusted down from current value.

    • "Deactivate max. speed limitation" - Used when max. speed limitation shall be reset to the factory-set value.

  4. Selected desired alternative and follow instructions in the program.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
