[260]Reset adaptation values

This function is used to reset adaptation values in the control module after, e.g., replacement or adjusting components in the engine system.

Test conditions:

  • Ignition on, engine off.

  • No faults in the system.

  • All power consumers disconnected.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. Old adaptation values are erased.

  3. Complete the function and disconnect the diagnostic tool.

  4. Turn off the ignition for 30 seconds.

  5. Turn on the ignition for 30 seconds to store the new code.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
