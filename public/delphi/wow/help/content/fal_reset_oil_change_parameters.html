[1606]Reset service information after oil change

The engine control module contains a function that calculates contamination of the engine oil and recommends changing the same. This function updates parameters related to oil change in the control unit. When the function is run, parameter values are shown before oil change and after the oil change.

After the function has been run, any fault codes are erased automatically.

Explanation of parameters:

  • Service counter: This parameter counts up by 1 every time reset is performed.

  • Oil quality: Indication in % how long the engine oil's quality lasts. 100% means that oil change just has taken place and this value will decrease with number of driven km with the vehicle.

  • Driven km at latest oil change: Shows odometer reading at latest service reset.

  • Distance to next service: Shows kilometres to drive to next oil change.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.
