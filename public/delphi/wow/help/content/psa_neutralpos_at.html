[1484]Calibration neutral position

When replacing gerbox and/or control unit it is necessary to program the neutral position of the selection lever position sensor, to obtain a correct gearbox function.

Test prerequisites:

  • Ignition on, engine off.

  • Gear in neutral position.

  • No faults stored.

  • All electrical loads should be switched off.

Procedure:

  1. Start the function. Press OK.

  2. A dialog box present "Adaption in progress...".

  3. When the function is completed a dialog box present "Operation succeded / failed".

    • If the function fails, check the test prerequisites and repair possible fault codes.

  4. Exit the function and disconnect the diagnostic tool.
