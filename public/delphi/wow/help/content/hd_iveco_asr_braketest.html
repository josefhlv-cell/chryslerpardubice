[196]Checking ASR-system

This function is used to check the ASR-system's function. Values are read out with the diagnostic unit which is used to compare values from the brake tester. When the function is in progress the wheels on the axle in question will be locked/released with different pressures.

Test conditions:

  • The vehicle is placed with the relevant axle in a brake tester.

  • Parking brake released.

  • Engine on.

  • Brake pedal pressed down during the whole function.

Procedure:

  1. Start the function.

  2. Compare values in the diagnostic unit with relevant values on the brake tester (during checking the wheels on the axle in question will be locked/released with different pressures).

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
