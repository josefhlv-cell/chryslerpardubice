Regeneration of particle filter
This function cleans the particle filter from soot particles by burning them off using an increase in the exhaust temperature. In certain driving conditions, the particle filter can not be cleaned automatically. This function is used to force a regeneration.
Note:
  • The regeneration procedure is performed stationary with raised engine speed.
  • Due to the risk of fire, regeneration shall not be run if the soot quantity in the particle filter is above the relevant limit value shown in the function.
  • The regeneration procedure may take up to 40 minutes.
  • Regeneration can be cancelled by turning off the engine.
Test conditions:
  • Engine on.
  • No faults in the system.
  • Fuel level at least 1/4.
  • Correctly installed and working differential pressure sensor.
Procedure:
  1. Start the function.
  2. A dialogue box shows current soot quantity in the particle filter + upper limit value for running a regeneration.
  3. Criteria for successful start of regeneration are shown with current reference values.
  4. Press "OK" when all criteria are fulfilled to start a regeneration.
  5. An activated indication for the particle filter confirms that the regeneration procedure is active.
  6. Increase the engine speed to approx. 1500 rpm and hold it constant during the whole regeneration procedure.
  7. Exhaust temperature, differential pressure and soot content of the particle filter is presented during the whole regeneration.
  8. When the indication for the particle filter turns off or the soot content of the particle filter is less than 5 g, the regeneration is complete.
  9. Press "OK" to exit the function.
  10. The function is done.
    • If the function fails, check the test conditions and repair any faults.
