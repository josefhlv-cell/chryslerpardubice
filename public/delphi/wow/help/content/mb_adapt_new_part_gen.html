[382]Initiate component

This function is used after a component has been replaced or in case of defective function of a component.

Test conditions:

  • Ignition on.

  • Battery voltage above 12V.

  • All power consumers disconnected.

  • Do not touch the accelerator pedal during the test.

Procedure:

  1. Start the function.

  2. A dialogue box shows progress.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
