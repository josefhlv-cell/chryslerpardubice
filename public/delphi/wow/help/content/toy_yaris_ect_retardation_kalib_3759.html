Zero point calibration of deceleration sensor
This function is used when the gearbox, control unit or parts of the gearbox has been replaced.
Note:
If the deceleration sensor's zero point calibration isn't performed correctly or failed, it may be because the car shakes or vibrates during zero point calibration. Fault code P1589 may then be registered. If the function doesn't complete successfully after several attempts and all test conditions are met and fault code P1589 is registered, the deceleration sensor may be faulty.
Test conditions:
  • Vehicle at standstill on level ground.
  • Gear selector in position P.
  • Engine off, ignition on.
  • Do not start the engine, to prevent idling vibrations.
Procedure:
  1. Turn off the ignition.
  2. Move the selector lever to "P" and apply the parking brake.
  3. Turn on the ignition.
  4. Start the function and follow the instructions in the program.
