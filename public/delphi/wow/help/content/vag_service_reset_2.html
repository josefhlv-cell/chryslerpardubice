[1575]Reset service message

This function is used to reset the indication for:

  • Oil change

  • Inspection

    To reset these indications separately, select "Instrument - general-purpose configuration". For channels and channel values, follow the manufacturer's instructions.

Test prerequisites:

  • Ignition on, engine off.

Procedure:

  1. Press "OK" to start the function.

  2. Confirm with OK to recall the indication.

  3. Dialog box shows: "Operation succeeded" or "Operation failed". Confirm with "OK".

  4. If "Operation failed" is present, check the connection or the model selection.

  5. Exit the function.
