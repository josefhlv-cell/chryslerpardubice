[28]Install/remove relay box trailer

When retrofitting/removing control unit for trailer detection, the function for trailer has to be installed/removed for it to work correctly.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 Volt.

  • Control unit installed correctly.

Procedure:

  1. Start the function.

  2. A dialogue box shows "Function done/Operation failed!".

    • If the function failed, check test conditions and resolve any error codes.

  3. Exit the function.
