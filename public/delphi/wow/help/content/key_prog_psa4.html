Programming new keys

Citroën

When matching new keys to the car, all keys - old and new - MUST be to hand for programming. Every key needs to be re-programmed.

Coding the keys - step-by-step procedure:

  1. Read out, repair and delete possible fault codes.

  2. Collect together all the keys that are to be re-programmed/used with the vehicle.

  3. Scratch the card to reveal the security code

  4. Enter the security code as shown on the code card. Press OK and wait for acknowledgement.

  5. Enter the number of keys to be programmed for the system. Press OK and wait for instructions.

Programming of keys for the system ends with synchronisation of remote controllers for the central locking.

Synchronising the remote controls - step-by-step procedure:

  1. Carry out the above procedure to code keys for the system.

  2. When the last key has been programmed, leave the ignition switched on.

  3. Press and hold the lock button on the remote control for ten seconds. Do this for all keys that have remote control.

  4. Switch off the ignition.

  5. Wait for a few seconds.

  6. All the remote controls are now synchronised.
