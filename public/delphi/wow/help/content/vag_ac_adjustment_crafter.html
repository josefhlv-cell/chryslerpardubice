[264]Basic setting of climate control system

When the control module for the climate control system has been replaced or a new actuator has been installed a basic setting of the climate control system must be performed. At basic setting, the control unit learns the actuators' end-positions and stores these.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. A dialogue box shows: "Calibration in progress" and changes to "Function done" when basic setting is completed.

    • If the function fails, check the test conditions and repair any faults.

  3. Press "OK" to finish the basic setting. Exit communication with the system and turn off the ignition for 30 seconds.

  4. Turn on the ignition for 30 seconds to store the new code.

  5. Re-establish communication with the car and check that no fault codes are stored in the control module.

  6. The function is done.
