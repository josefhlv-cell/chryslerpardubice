[1615]Adapting EGR-system

Erase all error codes that do not involve the EGR-valve before programming. When the valve has been replaced the offset value in the memory shall be erased as well so that programming matches with the offset value on the new valve.

Test conditions:

  • Ignition on.

  • No error codes that do not involve the EGR-valve.

Procedure:

  1. Start the function: "Self-learning of EGR-system", follow the instructions that are shown. You can cancel at any time.

  2. After erasing is finished, check the following data list parameters

    "Feedback position EGR-valve": 0%

    "First offset EGR-valve": 0%

    "Last offset EGR-valve": 0%

  3. Exit the function and cancel communication by returning to the car selection. Turn off the ignition.

  4. Wait 30 seconds and turn on the ignition again.

  5. Turn off the ignition a second time, and wait 30 seconds.

  6. Turn on the ignition, re-establish communication and check the following data list parameters:

    "First offset EGR-valve": 15-30%

    "Last offset EGR-valve": 15-30%

  7. If parameters do not match, check if error code: "DF272", "EGR-valve, control" is stored.

  8. If this error code is not there, start the engine.

  9. Let the engine run at idle for 1 min., accelerate to 2,500 rpm for 5 seconds and return to idle, repeat 5 times.

  10. Check error codes as well as above data list parameters.

  11. If the malfunction occurs again, start over after having disconnected and then reconnected the valve.

  12. Change EGR-valve if the problem remains.
