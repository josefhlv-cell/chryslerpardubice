Replacing of sensor
This function is a description of what actions and in which order they should be performed when replacing the sensor.
Note:
It is important that they are performed in the following order below:
Before replacing the sensor, the following function must be performed:
  • Accumulator depressurisation.
After replacing the sensor, the following functions must be performed:
  • End of line/service self-calibration.
  • Clutch self-calibration.
Procedure:
  1. Select the function "Accumulator depressurisation" and follow the instructions.
  2. Perform replacement of sensor.
  3. Select the function "End of line/service self-calibration" and follow the instructions.
  4. Select the function "Clutch self-calibration" and follow the instructions.
  5. The sensor replacement is now complete.
