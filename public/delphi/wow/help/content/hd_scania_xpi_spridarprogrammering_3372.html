Injector programming
This function is used to enter new injector codes to the engine control unit.
If an incorrect injector code has been programmed, a fault code will be generated.
Note:
The function "Basic setting of injectors" must be performed, if one or several injectors has been programmed.
Test prerequisites:
  • Ignition on, engine off.
  • Transmission in neutral.
Procedure:
  1. Start the function.
  2. Current injector codes is shown, press "OK".
  3. Select in the scroll list the injector to be programmed.
  4. Enter the new injector code (9 characters). Press "OK".
  5. The injector is being programmed.
  6. Select if more injectors should be programmed.
  7. The function is done.
  • If the function fails, check the test conditions and repair any faults.
