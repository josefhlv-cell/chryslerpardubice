[1080] Test of brake pressure magnetic coil and brake switch.

This basic setting is used to check the signals from the brake pressure solenoid and the brake switch. These are fitted to the electronic brake assistance system on cars fitted with Electronic Stability Program (ESP).

This must be done if:

  • The brake assistance unit has been replaced.

  • An error code that requires checking is stored in the ABS control unit.

Note:

The check is done in an automatic sequence of several check points, as described below.

Method:

  • Start the engine.

  • Choose the basic setting: Brake pressure solenoid and brake switch test.

The check has now been activated and the following check steps and prompts will be displayed:

  1. Magnetic coil activated.

    ->Press OK

  2. Values for the brake pressure sensors in the master cylinder and the status of the brake switch are displayed.

    The values for the pressure sensors must be: 9 bar ±2 bar

    The value for the brake switch: Not operated

    ->Press OK

  3. Depress and hold down the brake pedal.

    Check that the brake light comes on.

    -> Press OK

  4. Values for the brake pressure sensors in the master cylinder and the status of the brake switch are displayed.

    The values for the pressure sensors must be: above 80 bar

    The value for the brake switch: Operated

    ->Press OK

  5. Release the pedal.

    ->Press OK

  6. Values for the brake pressure sensors in the master cylinder and the status of the brake switch are displayed.

    The values for the pressure sensors must be: 9 bar ±2 bar

    The value for the brake switch: Not operated

    ->Press OK

  7. Magnetic coil test complete

->Press OK
