[235]Status-check of control box

This function is used to check that the control box signals are received and interpreted correctly by the control module.

After the test is run the control box should be in MAN1 and driving mode.

Test conditions:

  • Parking brake applied.

  • Battery voltage above 20V.

Procedure:

  1. Start the function.

  2. Activate buttons on the control box. Check status on the screen that they match with the buttons that have been activated.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
