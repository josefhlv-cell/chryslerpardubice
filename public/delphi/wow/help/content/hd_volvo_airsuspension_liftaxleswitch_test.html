[243]Checking bogie switch

This function is used to check that signals sent from the bogie switch are received and interpreted correctly by the control module.

Test conditions:

  • Parking brake applied.

  • Battery voltage above 20V.

Procedure:

  1. Start the function.

  2. Activate different positions for the bogie switch and check status on the screen that the signal matches with the switch positions.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
