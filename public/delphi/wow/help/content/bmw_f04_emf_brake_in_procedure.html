[718]Bed-in brake procedure parking brake

The bedding-in procedure must be carried out following replacement of brake discs or rear brake linings, in order to improve the friction value of the parking brake.

This requires a preset blocking force to be applied to the parking brake while the vehicle is run on a brake tester.

Test conditions:

  • Engine on.

  • Access to a brake tester.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is complete.
