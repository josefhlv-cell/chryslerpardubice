[1686]Reset injector nozzle adaptation values

In order to compensate for the tolerances in the fuel injection system, a characteristic curve containing the specific values is stored in the engine control unit (fuel injection adaptation). The injection volume is calculated by the engine control unit and these values are adjusted while the engine is running to improve exhaust gas emissions.

This function must be run if two or more injector nozzles have been replaced, requiring the fuel injection adaptation to be reset.

Test conditions:

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Press "OK" to reset the fuel injection adaptation values.

  3. Switch off the ignition for 10 seconds to allow the new values to be stored in the engine control unit.
