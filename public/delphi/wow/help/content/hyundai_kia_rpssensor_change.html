[498]Reset adaptation values for fuel rail pressure sensor

This function is used to reset the adaptation value for the pressure sensor. This has to be done after replacing the pressure sensor.

When adaptation is done the ignition must be turned off for 10 seconds before it is turned on again.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. If the function fails, check the test conditions and repair any faults.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
