[240]Status-check of control module for air suspension

This function is used to check input and output signals for buttons and switches related to the air suspension.

Test conditions:

  • Battery voltage above 20V.

Procedure:

  1. Start the function.

  2. Activate buttons and switches related to the air suspension. Check status on the screen that they match with the buttons that have been activated.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
