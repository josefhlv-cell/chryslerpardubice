[726]Resetting the basic module parameters from the mirror memory

This function transfers parameters from the mirror memory to the virtual controller, and the central computer memory is updated from the external controller. You can also choose to read in servicing life data from the mirror memory to the controller WS.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. A dialogue box shows the test conditions; check these and press "OK".

  2. A dialogue box asks "Do you want to transfer the parameters in the basic module back from the mirror memory" Press "YES" if you want to continue the function. Press "NO" to cancel the function.

  3. Transfer begins, follow the instructions.

  4. A dialogue box asks if you want to transfer service life data from the mirror memory to the controller WS.

  5. The function is complete.

    • If the function fails, check the test conditions and repair any faults.
