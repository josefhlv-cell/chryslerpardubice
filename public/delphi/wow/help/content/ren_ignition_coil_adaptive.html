[671]Self-adjustment for ignition coils

Note:

Run this function if the ignition coils have been replaced.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Check test conditions.

  2. Start the function.

  3. When the function is done, turn off the ignition for 30 seconds.

  4. If the function fails, check the test conditions and repair any faults.
