Activation glow plug
This function is used to temporarily activate one glow plug at a time, to check the glow plug function.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Select desired glow plug in the dropdown list and press "OK".
  3. Press "OK" to start the activation, note that the value of the selected glow plug will be changed in the presented data list.
  4. Then press "OK" to cancel the activation.
  5. Then wait for 30 seconds before a new glow plug can be selected.
  6. The function is done.
    • If the function fails, check the test conditions and repair any faults.
