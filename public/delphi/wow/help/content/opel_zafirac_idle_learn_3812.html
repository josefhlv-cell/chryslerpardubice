Idle learn
When replacing certain components, a learning procedure is needed for a complete repair and correct function of the system.
This function is used to program the idle position sensor.
Note:
Only for vehicles with Stop/Start system!
Test conditions:
  • Ignition on, engine off - the engine is started during the procedure.
  • Gear in neutral position.
Procedure:
  1. Start the function and follow the instructions in the program.
If the function fails, check the test conditions and repair any faults.
