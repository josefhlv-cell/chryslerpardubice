[1466]Coding of the parking assistance control unit

When installation of a new control unit is performed, or if the vehicle equipment is changed, the parking assistance control unit must be coded for the existing equipment.

Note:

  • A new control unit can have code 0 stored.

Test prerequisities:

  • The battery voltage should be above 12 V.

  • Ignition on, engine off.

  • No faults should be stored in the fault memory.

Procedure:

  1. Start the function: "Code control unit".

  2. A dialog box presents the actual code and "Change value". Confirm with "Yes" to change.

    • The function can be aborted with "No" if the code is correct.

  3. Enter the new code (se below) in the presented input field, confirm with OK.

    Code number:Function:
    0 X X X XWithout towbar
    1 X X X XWith towbar
    X 0 X X XManual gearbox
    X 1 X X XAutomatic gearbox
    X X 0 X XEuropean countries
    X X 1 X XS-variant of european countries
    X X 2 X XUSA
    X X 3 X XS-variant of USA
    X X X 0 XLimousine
    X X X 1 XAvant
    X X X 2 XCabriolet
    X X X X 44 = A4
    Code example:

    A4 with towbar, manual gearbox, European countries, limousine = 10004

  4. A dialog box confirms: Code stored (with the new value) in memory.

  5. Confirm with OK to exit the function.
