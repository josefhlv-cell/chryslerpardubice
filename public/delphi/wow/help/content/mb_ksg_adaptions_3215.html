Adapting gear positions and/or clutch
This function is used to make adaptations of gear positions and/or clutch in case of malfunction after replacement.
Note:
The following adaptations should be performed when replacing control module or transmission:
  1. Transmission adaptation.
  2. Clutch, adaptation engagement.
  3. Program clutch position.
The following adaptations should be performed when replacing clutch:
  1. Replace clutch.
  2. Clutch, adaptation engagement.
  3. Program clutch position.
Test conditions:
  • Battery voltage above 12V.
  • Make sure that the vehicle cannot start to roll.
Procedure:
  • Start the function and follow the instructions in the program.
  • Certain functions require a test-drive to enable completion.
  • If the function fails, check the test conditions and repair any faults.
