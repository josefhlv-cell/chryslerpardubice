Set gear shift unit in neutral position
This function is used to change position of the gear shift unit to neutral position.
Note:
  • The function must only be used when dismounting the following component:
    • Mechatronic for transmission with double clutch.
Test conditions:
  • Battery voltage above 12 V.
  • Ignition on, engine off.
  • Gear selector in position P.
Procedure:
  1. Start the function and follow the instructions in the program.
    • If you are unable to set the dismounting position using the vehicle diagnostic system, move the mechatronic by hand to the dismounting position according to original manufacturer's recommendations.
