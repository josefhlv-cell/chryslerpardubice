Compression test
This function turns off the fuel injection system to perform a compression test.
Note:
An external compression tester must be connected to measure the engine compression.
Test conditions:
  • Ignition on, engine off.
  • Battery charger connected to vehicle.
  • Coolant temperature above 80°C.
Procedure:
  1. Connect the compression tester to the engine.
  2. Start the function.
  3. A dialogue box shows: Press "OK" to disable the injection.
  4. Measure the compression in each cylinder.
  5. Press "OK" to finish the test.
If the test fails, check test conditions and rectify any faults.
