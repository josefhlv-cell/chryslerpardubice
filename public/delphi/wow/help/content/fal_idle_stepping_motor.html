[1491]Idle stepping motor

With this function you check that the idle stepping motor functions correctly.

Note:

  • The engine must be running in order to run the active diagnosis.

  • The engine speed will be fluctuating during the test, and after the test it returns to normal idle running.

Test prerequisities:

  • No faults in the system.

  • Engine running.

Procedure:

  1. Press OKto start the function.
