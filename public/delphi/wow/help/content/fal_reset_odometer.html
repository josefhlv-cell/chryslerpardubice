[1492]Resetting the odometer

This function resets the odometer to 0 km. For example with a new vehicle delivery.

Note:

  • The odometer can only be zeroed if the total distance does not exceed 200 km and the symbol "H" is displayed before the total distance.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.
