[51]Basic setting of flap motors

This function is used to activate the different flap motors on the air conditioning unit via a data cable (LIN-BUS). This data cable connects the different flap motors to the control unit. Depending on the repair, one or several basic settings of the system have to be performed.

There are the following three basic adjustments for the climate control unit:

  1. "New addressing flap motors"

  2. "Teach-in end-position flap motors"

  3. "Check cooling performance / compressor run-in"

This function is used when:

  • Flap motor has been replaced or the position of the flap has changed, then basic setting 1 and 2 shall be performed in mentioned order.

  • Control unit for the air conditioning has been replaced, then basic setting 2 and 3 shall be performed in mentioned order.

    During basic setting the flap motors are run to their end-positions and the control unit stores these values.

Note:

If a flap motor has been replaced or its position on the flap has been changed, then the function "new addressing flap motors" must be performed before the basic setting is done.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. When the basic setting is in progress "activated" is shown in the field "status for basic setting" at the same time as the control light in the AC-button, or the AC display (depending on equipment), flashes.

  3. "Done" is shown when the basic setting is finished. The control light in the AC-button, or the AC display, is on with a constant light.

  4. Exit the function. Turn the ignition off and then on again, and wait approx. 15 seconds for any fault codes to be stored.

  5. Re-establish communication and check that no fault codes are stored.

  6. If the AC control unit is replaced, continue with the function "Control cooling efficiency / compressor run-in".

    • If the function fails, check the test conditions and repair any faults.
