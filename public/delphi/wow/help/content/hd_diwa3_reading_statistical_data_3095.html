Read-out statistical data
This function is used to read out statistical data.
Test conditions:
  • Engine off.
  • Ignition on.
  • The vehicle must be at a standstill.
  • Parking brake applied.
  • Transmission in neutral.
Procedure:
  1. Start the function.
  2. Check test conditions.
  3. Check the read-out data.
  4. Function complete.
  • If the function fails, check the test conditions and try again.
