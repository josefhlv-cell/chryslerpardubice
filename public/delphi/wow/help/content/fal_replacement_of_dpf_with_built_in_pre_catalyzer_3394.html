Replacement of particulate filter with built-in pre-catalyser
This procedure should be run when the particulate filter is replaced. The command updates the parameters in the ECU and resets the number of incorrect regenerations.
Note:
After this procedure is finished the particulate filter should be regenerated.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function and follow the instructions in the program.
