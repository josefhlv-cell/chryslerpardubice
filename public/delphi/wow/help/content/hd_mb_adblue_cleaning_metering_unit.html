[469]Cleaning of dosing unit

The purpose of the test is to clean the dosing unit if it cannot dose more than 250 ml during the subtest "Checking AdBlue dosing unit's dosing amount".

The dosing unit may only be cleaned if "Checking AdBlue dosing unit's dosing amount" is outside the reference value and with a max. pressure of 5.5 bar. If a higher pressure than 5.5 bar is used, the dosing unit may be damaged by the high pressure.

The test applies to:

  • Engine 541.9 i model: 930, 932, 933 934 with code (MS4) BlueTec 4 or (MS5) BlueTec 5.

  • Engine 542.9 i model: 930, 932, 934 with code (MS4) BlueTec 4 or (MS5) BlueTec 5.

Test conditions:

  • Parking brake applied.

  • Engine off.

Procedure:

  1. Connect the test instrument to the diagnostics socket.

  2. Tilt the cab according to the manufacturer's instructions.

  3. Install a test outlet on the compressed air line's inlet to the dosing unit. See figure below!

  4. Remove SCR compressed air sensor (B128). Fill the hole 1 with distilled water until it overflows. See figure below!

  5. Install SCR compressed air sensor (B128).

  6. Connect a suitable hose to the compressed air line's test outlet, fill with distilled water until a water column of 4 cm is created in the hose, hold the hose upright during the whole test so that the water flows straight down into the test outlet.

  7. Connect a compressed air gun with suitable coupling to the hose that is connected to the test outlet.

  8. Blow clean the dosing unit with a max. pressure of 5.5 bar until all water is gone.

  9. Remove the test equipment.

  10. Start the engine.

  11. Start the test "Cleaning of dosing unit"

  12. Check that the compressed air pressure is within the reference value 1.23-2.50 bar.

  13. If the compressed air pressure is not within the reference value, repeat the cleaning procedure.

  14. If the compressed air pressure is still not within the reference value, this may be due to a defective dosing unit and then it needs to be replaced.

  15. The function is done.

    • If the function fails, check the test conditions and repair any faults.
