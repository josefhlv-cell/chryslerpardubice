[119]Leak test of air system

This function is used to check that there is no leakage in the air system. When the function is run, the trailer should have constant air pressure and brake pressure. The function's run-time is approx. 60 seconds.

Test conditions:

  • Air hoses connected to trailer.

  • Brake pressure over 5 bar.

  • Air tank pressure over 6 bar.

Procedure:

  1. Start the function.

  2. Compare pressure values after the test (they should not differ a lot).

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
