TIPM activate emission rolling test mode
This function is used to activate and deactivate a simulated signal for wheel speed, which is sent to the front wheels while driving the car on a dynamometer for 2WD.
Note:
When the test with activated signal is finished, the signal must be deactivated in this function.
Test prerequisites:
  • Ignition on, engine off.
Procedure:
  1. Start the function and follow the instructions in the program.
  • If the function fails, check the test prerequisites and repair possible fault codes.
