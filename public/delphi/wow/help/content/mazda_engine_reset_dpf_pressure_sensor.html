[1782]Reset adaptation values for pressure sensor

This function is used to reset the adaptation values for the pressure sensor for the particle filter.

Test conditions:

  • Ignition on.

Procedure:

  1. Select the function: "Resetting pressure sensor diesel particle filter" and follow instructions.

  2. The function is done.

    • If the function fails, check the test conditions and repair any faults.
