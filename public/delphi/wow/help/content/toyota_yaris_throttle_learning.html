[1236]Throttle Learning

This function is used to matches ("adapts") the throttle to the engine control unit. An adaption must be done when:

  • The throttle / control unit has been removed or replaced.

  • The electric power to the engine control unit has been disconnected.

Test prerequisites:

  • The battery voltage should be >12V.

  • Ignition on, engine off.

  • No stored fault codes.

  • Throttle does not have a malfunction.

  • The throttle pedal should be inactiv.

  • Coolant temperature: 5°C to 100°C.

  • Intake air temperature: more than 5°C

Procedure:

  1. Choose the function: Throttle learning

  2. Dialogue box: Engine off, ignition on, see help for further information. Press OK to continue.

  3. Dialogue box presents: Operation succeeded / failed.

  4. Press OK to exit function.

If the throttle learning has failed control the test prerequisites.
