Control of height level sensors
This function is used to control the height level sensors measuring value. The function is a test function. If a level adjustment is required, perform the function "Adjustment of the height level sensors".
Test conditions:
  • Ignition on, engine off.
  • Position the car on a flat and level surface.
  • No additional load or persons in the car.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Function complete.
