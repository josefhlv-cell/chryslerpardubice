[1171]Steering wheel angle sensor programming

Test conditions:

-Engine on

-Ignition on

Explanation :

STATUS 1:

- Steering wheel index not detected

- Straight wheel position not programmed

- Invalid angle value

PROGRAMMING NOT COMPLETE: perform steering wheel angle programming.

STATUS 2:

- Steering wheel index detected

- Straight wheel position not programmed

- Invalid angle value

PROGRAMMING NOT COMPLETE: perform steering wheel angle programming.

STATUS 3:

- Steering wheel index not detected

- Straight wheel position programmed

- Invalid angle value

PROGRAMMING COMPLETE, ANGLE TO BE VALIDATED: turn the steering wheel to the right limit, then to the left limit, then slowly return to the centre point and slightly exceed it.

NOTE: A current or stored fault may prevent passage to "STATUS 4" (perform the necessary repairs by referring to the fault finding manual).

STATUS 4:

- Steering wheel index detected

- Straight wheel position programmed

- Valid angle value

PROGRAMMING COMPLETE.
