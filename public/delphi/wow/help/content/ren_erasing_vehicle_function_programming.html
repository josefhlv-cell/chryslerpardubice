[1505]Reset adaption values

With this service the adaption values in the engine control module will be cleared. This can be necessary to do after repair that affect the fuel adaption, for example air leakage or changing airmass meter, EGR valve, damper valve etc.

Test prerequisities:

  • No faults in the system.

  • Ignition on, engine off.

Procedure:

  1. Press OK to start the function.
