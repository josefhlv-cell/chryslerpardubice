[381]Reset air mass sensor adaptation values

Under normal operating conditions, the air mass sensor is subject to both contamination and ageing. This will affect the difference between the stored characteristic curve and the prescribed value. This may cause symptoms such as loss of power or black smoke. The air mass sensor adaptation values can be reset to prevent this problem. Resetting adaptation values for air flow sensor is performed by the engine control unit in two operating modes. One during idling and one under load within a certain operating range.

Resetting of adaptation values for air flow sensor must be performed is the air flow sensor has been replaced.

Operating range is defined as follows:

  • Engine rpm: 1,700-3,000 rpm.

  • Boost pressure: 1,100-2,800 mbar.

  • Speed: 90-160 km/h.

  • Change of inlet air's temperature < 2 °C/s

  • Delay time: 3 sec.

Test conditions:

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Stored adaptation values for air flow sensor are read out from the control unit.

  3. Press "YES" to restore adaptation values.

  4. After the air flow sensor's adaptation values have been reset, the ignition must be turned off for at least 3 minutes.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
