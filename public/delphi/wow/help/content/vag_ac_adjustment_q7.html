[1509]Climate regulation

If the climate control unit has been replaced, or a new position motor for the temperature damper has been installed, a basic setting must be performed. When the climate regulation basic setting is performed, the control unit learns the positioning motors end positions and calculates a new value for the inlet air fan.

Note:

During the basic setting the displays for the "comfort" variant turns off for the climate control panel. For the "basis" variant the ECON button starts to flash.

Test prerequisites:

  • The battery voltage should be above 11.5 V.

  • Ignition on, engine off.

  • No fault codes should be stored in the fault memory.

  • Correctly installed and connected.

Performance:

  • Choose the function: Climate regulation.

  • During the basic setting the text "adapt" is present. After that the text change to "XX Volt" and end with "OK" when it is finished.

  • Wait about 20 seconds (new values are being stored).

  • End the function. Switch OFF/ON the ignition, wait about 15 seconds for possible fault codes to be stored.

  • Re-establish the communication and check if any fault codes have been stored.

    • If the function fails, check test prerequisites and repair possible fault codes.
