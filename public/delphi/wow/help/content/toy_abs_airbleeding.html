[416]Bleed brake system

This function is used to bleed the brake system. Make sure that the brake fluid level does not go below the minimum marking on the brake fluid reservoir. Bleeding stops automatically after 4 seconds, then the system should rest for 20 seconds.

Test conditions:

  • Ignition on, engine off.

  • Brake pedal pressed down during the whole function.

  • Parking brake applied.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
