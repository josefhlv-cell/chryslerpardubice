Calibration of steering angle sensor
This function is used to zero-compensate the value from the steering angle sensor.
Note:
Calibration should be done if:
  • The ABS control unit has been replaced.
  • The steering angle sensor has been replaced.
  • The steering column has been replaced.
  • Bodywork that affects the wheel alignment has been done.
  • The steering angle sensor has been disconnected.
  • An error code that requires zero compensation is stored in the ABS control unit.
Test condition:
  • The car should stand on a level surface with the front wheels pointing straight ahead.
  • Battery voltage above 12V.
  • No faults stored.
  • Ignition on, engine off.
Performance:
  1. Check that the steering wheel is in the correct position when the front wheels are straight ahead.
  2. Drive the car straight ahead on a flat surface to check that the car does not pull to one side when the steering wheel is held in the straight ahead position.
  3. Stop the car and make sure that the front wheels and the steering wheel are aligned.
  4. Select the function: "Steering angle calibration".
  5. A dialog presents: Operation succeeded/ failed.
  6. Press OK.
  7. Erase any fault codes.
  8. Check that the steering wheel is in the correct position when the front wheels are straight ahead.
