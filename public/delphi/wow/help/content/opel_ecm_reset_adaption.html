[1663]Reset adaptation values

This function resets the adaptation values in the engine control unit. This must be done after any repair work which affects fuel adaptation.

The following adaptation values are reset:

  • Lambda.

  • Damper position.

  • Infinitely adjustable valve setting.

Test conditions:

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Select the "Reset adaptation values" function.

  2. The function starts. A dialogue box shows: "Operation successful" or "Operation failed".

  3. Exit the function.

    • If the function fails, check the test conditions and repair any faults.
