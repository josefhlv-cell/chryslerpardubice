Parameter setting
This function is used to change parameter setting for maximum engine torque.
The list includes:
1400 Nm applies to engine model series OM936
2100 Nm applies to engine model series OM470
2500 Nm applies to engine model series OM471
3000 Nm applies to engine model series OM473
Test conditions:
  • Ignition on, engine off
Procedure:
  1. Start the function.
  2. A dialogue box shows test conditions, check these and press "OK".
  3. A dialogue box shows current parameter setting.
  4. Select new parameter setting and press "OK".
  5. A dialogue box shows new parameter setting. Press "OK".
  6. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
