Initialization of lambda mean values
This function resets the lambda mean values for idle, part throttle and full throttle.
Note:
This function must be performed:
  • After replacing the lambda sond.
  • After replacing the valve block on the gas injection.
  • After replacing a defect gas pressure sensor.
  • After replacing control unit.
Test conditions:
  • Ignition on, engine off.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. Check test conditions.
  3. Press "OK" to start the activation.
  4. Press "OK" to exit the function.
  5. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
