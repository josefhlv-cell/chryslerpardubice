[568]Reset adaptation values

This function is used to reset the adaptation memory after replacement of the transmission control unit to obtain correct transmission function.

Test conditions:

  • Ignition on, engine off.

  • Gear selector in position P.

  • No faults in the system.

  • All power consumers disconnected.

Procedure:

  1. Start the function.

  2. Adaptation values are reset. A dialogue box shows if the function succeeded or failed.

    • If the function fails, check the test conditions and repair any faults.

  3. Finish the function and disconnect the diagnostics instrument.

  4. Drive the vehicle variably to complete the learning of the new adaptation values.
