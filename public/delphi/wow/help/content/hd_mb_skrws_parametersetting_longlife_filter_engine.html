[535]Parameter setting

This function is used to change parameter setting.

If parameter is set to "YES", a long-life filter for engine oil is installed on the vehicle.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. A dialogue box shows test conditions, check these and press "OK".

  3. Select parameter setting and press "OK".

  4. A new dialogue box shows new parameter setting. Press "OK".

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
