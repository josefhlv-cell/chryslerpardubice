Enter the clutch's closed position
This function is used to enter the clutch's closed position after replacement of the control unit for the transmission.
Note:
Before the function is started, read out the value for "Clutch; closed position" on the data list.
Test conditions:
  • Engine off.
  • Ignition on.
Procedure:
  1. Read the value on the data list "Clutch; closed position".
  2. Press "OK" to start the function.
  3. Enter the value read from the data list with four digits. If the value is three-digit, start with a 0.
  4. Press "OK".
  5. The function is complete.
