[1582]Communication test with remote control

This function verifies if the communication with the remote control is functioning well.

Test prerequisites:

  • Ignition on, engine off.

Procedure:

  1. Chose the function: "CAN communication to remote control".

  2. The communication status with the remote control is presented, press "OK" to exit.

If the communication with the remote control is not OK, check and repair any faults.
