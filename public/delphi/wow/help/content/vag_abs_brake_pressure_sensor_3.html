[218]Basic setting of brake pressure sensor

With this function it is possible to perform a basic setting of brake pressure sensor 1. This should be done if:

  • The control unit for ABS has been replaced.

  • The hydraulic unit has been replaced or has been removed and then reinstalled.

  • If the brake pressure sensor has been replaced.

Note:

The ignition must not be turned off during the basic setting.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • Do not touch the brake pedal during basic setting.

Procedure:

  1. Start the function.

  2. A dialogue box with the text "Status adaptation" shows the sensor's adaptation status as well as current value.

  3. Press "OK" when the text "Adaptation in order" is shown to finish the function.

  4. Turn off the ignition and exit communication with the car for 30 seconds.

  5. Turn on the ignition, re-establish communication with the car, and check that no fault codes are stored.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
