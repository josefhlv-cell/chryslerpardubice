[383]Bleed brake system

This function is used to bleed the brake system on cars equipped with ABS brakes. This is only necessary when one of the chambers in the brake fluid reservoir has been empty, or when changing brake fluid. Before the function is used, perform a manual bleed.

The recommended order when bleeding the brake system is as follows:

  1. Right rear.

  2. Left rear.

  3. Left front.

  4. Right front.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • Correct brake fluid level.

  • No faults in the system.

  • Fluid reservoir connected on the brake bleed nipple.

Procedure:

  1. Start the function.

  2. Open the brake bleed nipple and press "OK".

  3. A dialogue box shows "Bleeding in progress!".

    • Pump the brake pedal constantly.

  4. When bleeding is finished, close the bleed nipple and press "OK".

    • If there still are air bubbles in the brake fluid, repeat the procedure.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
