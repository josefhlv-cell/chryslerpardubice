Reset adaptation values
This function is used to reset adaptation values in the control module after, e.g., replacement or adjusting components in the engine system.
The adaptation are divided into three different groups and at a reset, all adaptation values within the group will be reset.
Exhaust system
The following adaptations are included:
  • Air mass meter of heat-film type.
  • AGR valve.
  • Exhaust back pressure sensor before exhaust turbocharger.
  • Exhaust back pressure sensor before diesel particle filter.
  • Lambda sensor.
  • Selective Catalytic Reduction (SCR).
Fuel system
The following adaptations are included:
  • Electric fuel pump.
  • Quantity mean value adaptation.
  • Quantity control valve.
  • Rail pressure control valve.
  • Rail pressure sensor.
Mass air flow system
The following adaptations are included:
  • Flushing damper control.
  • Air mass meter of heat-film type.
  • Cooler for high-pressure exhaust gas return and AGR valve.
  • Monitoring intercooling.
Test conditions:
  • Ignition on, engine off.
Procedure:
  • Start the function.
  • Select from the list the group for which the adaptation values ​​should be reset.
  • After completed function, the ignition must be turned off for about 3 minutes.
