[55]Compression test

The compression test is used to decide how good the compression is in the cylinders.

Note:

Auxiliary equipment may impact the test result, therefore the engine must reach operating temperature before the test. This is necessary for the compressed air system to have time to fill up and for the fan to turn off. The compression test is used to determine compression deviations for each individual cylinder, then the starter motor is driven without injection release. For a short time the rpm reaches its minimum at top dead centre for each cylinder. That is the point of maximum compression. The result is shown in revs per minute. Make sure that the following conditions are fulfilled:

Test conditions:

  • Parking brake applied.

  • No gear engaged.

  • Battery fully charged.

  • Engine at operating temperature (at least 75°C).

Procedure:

  1. Start the function.

  2. Check test conditions and press "OK".

  3. Press "OK" and turn the key to start position.

  4. Hold the key in start position until a dialogue box shows "Stop".

  5. Check the result and press "OK".

  6. The function is done.

    • If the function fails, check the test conditions and try again.
