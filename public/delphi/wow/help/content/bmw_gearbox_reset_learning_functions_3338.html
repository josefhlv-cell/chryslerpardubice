Resetting of learning functions
This function is used to reset one or several learning functions for the automatic transmission.
The function must be used in the following cases:
  • Retrofitting trailer module.
  • Retrofitting ACC (active cruise control).
  • Incorrect installation of rear axle gear.
  • Incorrect installation of the automatic transmission.
  • When replacing GWS (gear selector switch).
  • Supplementation of shifting controls (paddles).
There is possibility in the function to select which learning function that should be reset.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Function complete.
