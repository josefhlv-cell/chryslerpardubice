[1174]Steering wheel angle calibration

Test prerequisites:

  • Before the calibration, a wheel alignment must be performed.

  • This function zero-compensates the value from the steering angle sensor.

  • The error code that requires calibration is stored in the ABS control unit.

  • Engine off.

  • Ignition on.

Procedure:

  1. Turn the steering wheel to the left or to the right more than 5 deg.

  2. Reposition the wheels straight.

  3. Start the command. Do not touch the steering wheel during calibration.

  4. Erase fault codes.
