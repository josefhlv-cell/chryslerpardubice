[1271]Adaption after replacing the engine control unit

The electronic immobiliser is composed of three main parts: immobiliser control unit, engine control unit and keys. If one of these three parts is replaced it must be adapted to the immobiliser sytem. Before a successful adapation is carried out the immobiliser warning lamp will flash on the instrument panel and the car can not be started. Before an adaption can be carried out, the engine control unit must be correctly variant coded, and on petrol engines the throttle needs to be adapted.

Note:

The function must be carried out when a new or used engine control unit is adapted to the immobiliser. During an adaption four or five digit PIN codes, must be known both for the engine and immobiliser control unit. The PIN code is found on the key tag or at an authorized workshop. After a successful adaption, the PIN code for engine control unit is the same as for the immobiliser control unit.

Test prerequisites:

  • The battery voltage should be above 12V

  • All electrical loads should be switched off.

  • Four or five digit PIN code for both control units.

  • The correct version of the engine control unit is needed.

  • The engine control unit should be correctly variant coded.

  • On petrol engines the throttle should be adapted.

  • No lockout time in immobiliser (the lockout time is availible in the data list).

Procedure:

  1. Start the function 'Engine control unit adaption'.

  2. Enter the PIN code for the engine control unit in input field and confirm with 'OK'.

    • If the control unit is old, use the PIN code from the original system.

    • If the control unit is new, use the PIN code: 00000

    • If the wrong PIN code is entered the function is aborted.

  3. Enter the PIN code for the immobiliser control unit in the input field and confirm with 'OK'.

    • If the wrong PIN code is entered the function will be aborted.

  4. A dialog box will present the chassi number.

    • If the wrong chassi number is presented the function should be aborted by the user.

    • If the timeout (control unit doesn't reply in time) is reached, check for lockout time and fault codes.

  5. If the correct chassi number is presented press 'OK' to complete the adaption.

    • If the adaption can not be performed check for fault codes.

    • If a timeout (control unit doesn't reply in time) is reached, check for the lockout time and fault codes.

  6. Exit the function and check for fault codes.

  7. The PIN code for the engine control unit is now the same as for the immobiliser unit.

  8. The cruise control should be activated/deactivated according to vehicle equipment, see separate function.
