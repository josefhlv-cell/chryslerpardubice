Calibration of gear position sensor
This function is used to calibrate the gear selector's positions.
The function shall be performed if:
  • The selector lever has been replaced.
  • Mechatronic/control unit has been replaced.
  • Work on the selector lever, controls, or parking inhibitor has been performed.
Note:
Perform the function in one sequence otherwise calibration is cancelled for time reasons.
During calibration the brake pedal shall be let up as soon as you have left position P.
When replacing Mechatronic, the functions shown below shall be performed in the following order:
  1. Calibration of gear position sensor.
  2. Calibrating position sensor.
  3. Adaptation of clutch slipping point.
Preconditions for the test:
  • Transmission oil's temperature between 20 °C - 60 °C.
  • Engine off, ignition on.
  • Parking brake applied.
  • No fault codes concerning components in the system stored.
Procedure:
  1. Start the function and follow the instructions in the program.
  • If the function fails, check the test conditions and repair any faults.
