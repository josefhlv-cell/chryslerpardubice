[1724]Testing PWM-valves and clutch

This function is used to check that the control for the clutch cylinder works.

When a valve is activated a ticking sound should be heard from the clutch cylinder and status for the valve should become "Active". When the valve is deactivated the sound should stop and status should become "Inactive".

Note:

The same PWM-valve may be activated max. 2 times within 5 min.

Test conditions:

  • Parking brake applied.

  • Air pressure in transmission between 550-1,000 kPa.

  • Engine off.

  • Battery voltage above 20 V.

  • Oil temperature in transmission above 15°C.

Procedure:

  1. Select the function, press "OK".

  2. A dialogue box shows test conditions.

  3. Activate / deactivate the valve that is to be tested, a ticking sound should be heard at activation, press "OK"

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
