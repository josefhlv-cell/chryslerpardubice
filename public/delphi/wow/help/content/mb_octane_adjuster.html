[155]Configure octane number

This correction is used to adjust the ignition timing. This prevents knocking from the combustion engine in case of poor fuel quality.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Select desired octane number and press "OK".

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
