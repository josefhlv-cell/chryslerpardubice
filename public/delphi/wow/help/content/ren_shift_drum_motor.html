[444]Activate gear selection motor

This function activates PWM-control for the shift drum's motor.

This is a component activation and shall only be used if the car is configured and equipped with the component. An activation may take up to a minute, during that time a window with the text "Please wait" is shown.

Test conditions:

  • Ignition on, engine off.

  • Gear selector in position P.

  • Do not touch the brake pedal during basic setting.

Procedure:

  1. Start the function.

  2. Wait for "Function done".

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
