[466]Test of AdBlue-system

The test is run before removing pump module and injectors.

The test releases the pressure from the circuit and determines the function of the return line and breather valve.

The air pressure must be at least 8 bar when performing this test.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
