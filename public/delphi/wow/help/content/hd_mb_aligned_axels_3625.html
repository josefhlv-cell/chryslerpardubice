Learning of aligned axles
This function calibrates the front axle and the extra axle, by these become aligned parallel to the vehicle.
Note:
  • Engine running to keep the power steering pressure activated.
  • Learning of the front axle in this function should be done before the function "Steering and learning of additional axle" is performed.
Test conditions:
  • The steering wheel is in position for driving straight ahead.
  • The rim flange is parallel with the vehicle frame.
  • The vehicle is aligned.
Procedure:
  1. Start the function.
  2. A dialogue box shows test conditions, check these and press "OK".
  3. A new dialogue box appears where you can select the front axle or the additional axle for learning.
  4. Press "Start" to begin the learning of the selected axle.
  5. When you are done with the learning of one axle or both axles. Press "OK".
  6. The function is done.
    • If the function fails, check the test conditions and repair any faults.
