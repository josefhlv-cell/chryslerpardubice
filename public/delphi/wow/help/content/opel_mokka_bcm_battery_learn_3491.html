Battery sensor module learn
This function is used for battery sensor module learning.
Note:
This function shall only be performed if one of the following items applies:
  • The battery was replaced.
  • The battery was removed from the vehicle and either charged or discharged outside the vehicle.
  • The battery was charged using incorrect charging points. The correct charging points are the battery (+) and engine ground.
After performing this procedure, the ignition must remain off for at least 4 hours.
Test prerequisites:
  • Ignition on, engine off.
  • The battery replaced or incorrect charge.
Procedure:
  1. Start the function.
  2. The learning begins.
  3. A dialogue box shows: "Learn procedure has been initiated. To complete this procedure the ignition must remain off for at least 4 hours."
  4. The battery sensor module learn procedure has been initiated.
  5. Press "OK" to exit the function and disconnect the diagnostic tool.
  6. Switch off the ignition and remove the ignition key.
  7. Close all vehicle openings.
  8. Lock the vehicle.
  9. Wait for at least 4 hours.
  10. Function complete.
