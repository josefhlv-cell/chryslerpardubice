Steering wheel angle programming
This function is used to program the steering wheel angle sensor after replacement of the power steering unit or if the battery has been disconnected.
Note:
The function shall only be performed if the data list "Steering wheel angle sensor programming" shows that the sensor is not calibrated.
Test prerequisites:
  • Ignition on.
Procedure:
  1. First turn the steering wheel to left end-position and then to right end-position.
  2. Turn the steering wheel to middle position.
  3. Start the function by pressing "OK".
  4. When the function is complete, check that the data list "Steering wheel angle sensor programming" shows that the sensor is calibrated.
