[145]Reset engine hour counter

This function is used to reset the engine hour counter after a light has been replaced.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. A dialogue box shows if the function succeeded or failed.

    • If the function fails, check the test conditions and repair any faults.
