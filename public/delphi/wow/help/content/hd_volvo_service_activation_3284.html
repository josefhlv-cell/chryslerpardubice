Activation of service warning system
With this function you can program a number of parameters to activate the function for service reminder.
Performed after conversion kit for service reminder has been installed.
Note:
  • Conversion kit for service reminder must be installed.
Test conditions:
  • Engine off.
  • Ignition on.
  • Battery voltage above 20 V.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. Parameters are programmed.
  3. Function complete.
  • If the function fails, check the test conditions and repair any faults.
