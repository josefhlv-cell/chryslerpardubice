[923]Idling check

Preconditions for the test:

  • Engine idling.

  • No faults stored.

  • No leaks in the exhaust system.

  • Engine temperature above 85 °C.

  • Induction air temperature below 60 °C.

  • All electrical loads switched off.

  • Gear selector set to ”P/N”.

  • Throttle cable adjustment OK.

Note:

  • Used to check idling.

  • Before checking the idling, see Basic setting requirements.

  • Idling, ignition advance/retard and CO value are not adjustable.

  • The idling speed is set by the control unit.

  • The CO value is controlled by the lambda regulation.

  • In the basic setting mode, the carbon canister valve is closed and the AC compressor is switched off.

Procedure:

  • Choose the function: Idling check.

  • Rev up the engine and let it idle for two minutes.

  • Read off the engine speed signal (target value). Prescribed value 780 rpm.

  • Read off the engine speed signal (actual value). Prescribed value 740-820 rpm.

  • On completion of basic setting, the carbon canister valve is activated and the AC compressor is switched on.
