[553]Calibrating seat sensor, front passenger

This function shall be run when the seat sensor has been disconnected.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • The seat must be in the position farthest back.

  • The passenger seat must be unloaded during the entire function.

Procedure:

  1. Start the function and follow the instructions in the program.

  2. The function is done.

    • If the function fails, check the test conditions and repair any faults.
