Configuration of the gearbox ECU
This function is used to configure the gearbox parameters. The new selected value will be overwritten to the gearbox ECU.
Test conditions:
  • Parking brake applied.
  • Engine off.
  • Ignition on.
Procedure:
  1. Press "OK" to start the function.
  2. Select the new configuration to be programmed.
  3. Press "Abort" to exit the function.
  4. Answer the different pop-up boxes that appears and press "OK".
  5. Exit by pressing the "OK" button in the box.
  • If the function fails, check the test conditions and repair any faults.
