[573]Service work on parking brake

The electro-mechanical parking brake is integrated in the rear wheels' brake callipers. When repairing the rear wheel brakes, a diagnostics instrument must be used to open the parking brake by pulling back the pistons to expose the brake pads. After the repair is done, a diagnostic instrument is required once again to apply and adjust the parking brake.

Test conditions:

  • Ignition on, engine off.

  • Battery charger connected to vehicle.

  • Parking brake not applied.

Procedure:

Changing brake pads:

  1. Ignition on, parking brake not applied.

  2. Select the function: Open brake callipers (when changing brake pads)

  3. Now the brakes open completely.

  4. Finish the function and change the brake pads.

    • To change pads the piston has to be pushed back manually.

    • Measure the pad thickness (without metal plate) and note it before installing the new pads.

  5. Select the function: Close brake callipers

  6. Now the brakes close completely.

  7. Select the function: Adaptation thickness brake pads

  8. Current value for brake pads' thickness is shown. Press "YES" to enter new thickness of the brake pads.

  9. Enter the thickness in mm (without metal plate) of the new pads, if the pads have different thickness the smallest value shall be entered. Value between 3 and 14 mm is approved.

  10. When the function is done, finish communication with the car, (parking brake closes completely).

  11. Press lightly on the foot brake and release the parking brake with the switch in the car.

  12. Let up the foot brake, turn off the ignition and remove the key.

  13. A recalibration is performed (brakes close and open a number of times)

  14. Check and erase any fault codes.

Other work with brakes:

  1. Ignition on, parking brake not applied.

  2. Select the function: Open brake callipers

  3. Now the brakes open completely.

  4. Do the desired job with the brakes.

  5. Select the function: Close brake callipers

  6. Now the brakes close completely.

  7. Run the basic adjustment: Basic setting of brake system

  8. Check and erase any fault codes.
