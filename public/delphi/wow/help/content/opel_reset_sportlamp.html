[1711]Reset sport lamp adaptation values

This function resets the adaptation values in the sport lamp control units - "Light intensity module" and "Adaptive headlamp control unit".

This function must only be run if one of the sport lamps' control units has been replaced!

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Press "OK" to start the function.

  2. The function is complete. Erase the trouble codes following a successful reset.

    • If the function fails, check the test conditions and repair any faults.
