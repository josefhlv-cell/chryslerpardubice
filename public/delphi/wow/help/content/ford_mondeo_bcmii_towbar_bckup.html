[65]Back-up configuration

This function is used to make a back-up of the configuration of a control unit. The back-up can be used to restore the control unit's configuration in case of any problems.

Note:

It is recommended to make a back-up of the configuration before coding in the new functions in the control unit.

Making the back-up takes up to 2 minutes, during that time the diagnostic equipment may not be disconnected.

Test conditions:

  • Battery charger connected to vehicle.

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

    • Making the back-up takes up to 2 minutes, during that time the diagnostic equipment may not be disconnected.

  3. When the back-up is done, a dialogue box will be shown with an instruction to save the configuration as a file.

    • If the function fails, exit the diagnosis and turn off the ignition for 30 seconds before trying again.
