[1204]Reset idle adaption

Before carrying out the Reset idle adaption use the Throttle stop adjustment first.

Caution:

If there is an idle fault this procedure will make it worse.

Engine running.

Ensure that the engine operating temperature and idling is correctly.

If one or more of the following components have been renewed or rectified the adaption must be performed:

  • Inlet manifold/Air leak repair

  • Throttle adjustment

  • Coolant or oil temperature sensors

  • Any fault effecting engine efficiency
