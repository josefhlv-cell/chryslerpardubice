[1069]Program keys

When adapting new keys to the car, all keys, old and new, MUST be available before programming. All keys must be reprogrammed.

Coding of keys, in steps:

  1. Read out, take care of, and erase any fault codes

  2. Collect all keys to be programmed/used with the vehicle.

  3. Scrape to see the security code

  4. Enter the security code as it is shown on the code card in the field for security code, press OK, wait for acknowledgement.

  5. Turn off the ignition.

  6. Start key programming by selecting the function: Start key programming, press OK.

  7. Turn on the ignition with an unprogrammed key.

  8. Turn off the ignition.

  9. Continue acc. to step number 7 and forward until all keys are programmed (max. 5).

  10. Turn on the ignition.

  11. Exit key programming by selecting the function: Exit key programming, press OK (NOTE ignition on).

  12. Check that all keys are programmed in data list 9.

Coding of keys is finished with a synchronization of remote controls for central lock control.

Synchronizing remote control, in steps:

  1. Perform above procedure for coding of keys for the system.

  2. After the last key has been programmed, leave the ignition on.

  3. Press and hold in the lock button on the remote control for 10 seconds.

  4. Turn off the ignition.

  5. Wait a few seconds.

  6. The remote control is now synchronized.
