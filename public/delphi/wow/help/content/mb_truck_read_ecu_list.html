[1082]Read vehicle control unit list

In the base module, information is collected regarding which control units the vehicle is equipped with. The purpose of this function is to simplify the system identification. A list of the current systems are presented in a pop-up window. It is possible to minimize the window and keep it open during the entire diagnostic session. It is not neccesary to close the window to be able to step forward to other functions.

Test prerequisites:

  • Ignition on.

Procedure:

  1. Activate the reading of the list by pressing "OK".

  2. A window containing a list with the vehicle´s control units are displayed.

  3. The window can either be closed by pressing "Exit" or minimized to be used later during the diagnostic session.
