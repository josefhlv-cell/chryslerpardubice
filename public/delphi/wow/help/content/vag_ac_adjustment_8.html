[30]Basic setting of air conditioning system

When the control unit for the AC system has been replaced or a new actuator has been installed, a basic setting of the AC system must be performed. At basic setting, the control unit learns the actuators' end-positions and stores these.

Basic setting takes approx. 15 seconds.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Select the function.

  2. During basic setting the actuators are run to their end-positions and then stabilize at a fixed value. The actuators' position is shown during the entire sequence.

  3. After approx. 15 seconds the basic setting is done and the function proceeds automatically.

  4. Press "OK" to exit basic setting.

  5. Exit communication with the car, turn off and on the ignition, wait approx. 15 seconds for any fault codes to be stored.

  6. Establish communication with the car and check that no fault codes are stored.

    • If the function fails, check the test conditions and repair any faults.
