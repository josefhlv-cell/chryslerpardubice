[1653]Initiating and adjusting active steering

This function performs initiation and adjustment of the active steering.

The active steering varies the steering gear's ratio depending on the vehicle's speed. Advantages of this is a more direct steering at lower speeds and a more indirect steering at higher speeds, this in combination with yaw angle control.

Note:

If the control unit for dynamic stability control (DSC/DXC) or the steering column's connection centre (SZL) have been replaced, then these must be coded before the function can be performed.

This function must be performed after the following jobs:

  • Replacing control unit for active steering (AL).

  • Replacing steering column's connection centre (SZL).

  • Replacing steering gear.

  • After jobs on the steering column.

  • After a wheel alignment or other work that may affect the wheel geometry.

Test conditions:

  • There may not be any error codes in the following control units: Dynamic stability control (DSC/DXC) or Engine control unit (DME/DDE).

  • The car should be standing on level ground with the front wheels in position straight ahead.

  • Ignition on, engine off.

Procedure:

  1. Set the steering wheel and the front wheels in exact position straight ahead (visual check is good enough).

  2. Start the function.

  3. Status of the steering angle sensor is checked, if status is not OK the function must be aborted and the steering angler sensor initiated. This is done in the control unit for dynamic stability control (DSC/DXC). If status is OK, continue in the function.

  4. The servo motor's position angle is reset.

  5. Start the engine.

  6. Then press "OK" and turn the steering wheel from left lock to right lock and then back to middle position, repeat at least 2 times.

  7. The warning light in the combination instrument for active steering shall go off when the servo motor's position angle has been calibrated correctly.

  8. Turn off the engine, ignition on.

  9. Error codes in control unit for active steering (AL) are erased automatically.

If the steering wheel should have an off-centre position when driving straight ahead after the function has been performed, check the steering angle. For an exactly centred steering wheel, the steering angle must be 0° (+/- 2°). If it should deviate, first perform new initiation of the steering angle sensor in the control unit for dynamic stability control (DSC/DXC) and then repeat this function.
