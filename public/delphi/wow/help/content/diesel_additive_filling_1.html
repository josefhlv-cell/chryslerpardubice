[833]Filling of diesel additive

Note:

This function must be used when the diesel additive reservoir is refilled or replaced. The function resets the parameter for the total quantity of diesel additive as has been injected from the additive reservoir (counter 2).

Observe:

If the additive pump or the additive reservoir has been replaced must five additive pump activations be performed to refill the pipes in the system.

Performance:

  1. Refill additive.

  2. Choose function: Filling of diesel additive.

  3. A dialog box presents: Operation succeeded/failed.

  4. Press OK.

  5. Abort communication with the particle emission filter by stepping backwards to the main menu.

  6. Open the fuel cap for ten seconds within one minute.

  7. Re-establish communication with the system and check in data list number two that the total quantity of diesel additive injected from the additive reservoir (counter 2) is set to zero.
