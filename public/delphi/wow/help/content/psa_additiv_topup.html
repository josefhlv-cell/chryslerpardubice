[1437]Additive tank filling.

The basic setting is used to inform the control unit that additive has been refueled.

  • Use this function only when the additive tank is refueled.

Test prerequisites:

  • Ignition on, engine off.

  • All electrical loads should be switched off.

  • Battery voltage above 12 Volts.

Procedure:

  • Start the function.

  • A dialog box presents: operation succeeded/failed.

  • If the tank has been empty, it is also necessary to refill the hose with additive.
