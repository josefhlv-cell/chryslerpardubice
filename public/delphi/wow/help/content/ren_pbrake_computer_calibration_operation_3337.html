Calibration and activation of a new control unit
This function is used to initiate a new control unit.
Note
  • Parking brake wires and control unit should always be replaced together.
  • Always check the parking brake function before the car is returned to the customer.
Test conditions:
  • Ignition on, engine off.
  • Battery charger connected to vehicle.
  • Park the vehicle on level ground.
Procedure:
  1. Start the function and follow the instructions in the program.
