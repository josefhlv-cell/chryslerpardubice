[408]Deactivate service mode on parking brake

The function must be run after the following jobs:

  • After replacing parking brake module.

  • After replacing parking brake button.

  • After replacing brake calipers' actuators.

  • After replacing brake calipers or brake pads rear.

After replacing brake calipers or brake pads rear, the parking brake only works correctly after it has been operated several times.

NOTE! The function "workshop mode" must be run before the above jobs to enable correct replacements.

Test conditions:

  • Ignition on.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
