[185]Initiating components

This function is used if any of the following components have been replaced:

  • Exhaust recirculation valve.

  • Air temperature sensor.

  • Air mass sensor.

  • Boost pressure sensor.

  • Throttle valve inlet air.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function.

  2. Follow the instructions in the programme.

  3. The function is done.
