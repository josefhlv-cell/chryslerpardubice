Initialization of control unit
This function is used to initialize the control unit to the xenon system.
Note:
The function should be performed after dismounting or replacing the following parts:
  • Control Unit.
  • Front sensor.
  • Rear sensor.
  • Attachment for any of the sensors.
  • Link rod.
Test conditions:
  • Ignition on, engine off.
  • The vehicle must stand on level ground.
  • Vehicle must be without load.
  • Parking brake released.
  • Transmission in neutral.
Procedure:
  • Start the function.
