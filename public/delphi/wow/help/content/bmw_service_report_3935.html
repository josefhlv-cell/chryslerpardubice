Service report
This function is used to read out a summary of the vehicle's stored service data.
Note:
The presented amount of data, may vary depending on the vehicle.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Data from the vehicle are read and presented in the following groups:
    • Vehicle data
    • Service data
    • Dynamic data
  3. To get a complete printout of the service report, data from all groups must be presented.
  4. The function is done.
