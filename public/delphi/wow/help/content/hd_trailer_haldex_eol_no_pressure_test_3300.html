End of line test
This function is used to check the installation of the control unit.
Test conditions:
  • The trailer is anchored and standing on a level surface.
  • The constant air supply is connected.
Procedure:
  1. Start the function.
  2. Raise the trailer.
  3. Rotate the wheel indicated by the test.
  4. The wheel stops automatically if the right wheel has been rotated, if not the test is stopped.
  5. Apply brake pressure to the trailer, run the brake pressure test until the "OK" button is displayed.
  6. Release the brake pressure.
  7. Confirm with the "OK" button.
  8. Check that the warning lamp lights.
  9. Confirm with the "OK" button.
  10. Function complete.
    • If the function fails, check the test conditions and repair any faults.
  11. Print out the test results.
