[547]Clutch bleeding

This function is used to bleed the clutch hydraulics.

After replacing the transmission, the clutch module with MTA-controller or parts of the clutch hydraulic system or hydraulic line has been opened or unloaded must the clutch hydraulics bleed.

Note:

Warning: Use only brake fluid DOT4 +.

To ensure the clutch function, bleeding should only be performed with a diagnostic tool and a brake bleeding tool. Manual bleeding is not allowed. Please note the manufacturer's instructions before using the brake bleeding tool.

Has an emergency opening been performed on the clutch, the ignition must be switched off and on again after approximately 5 seconds for the clutch to be regulated.

After completed function check and erase any trouble codes.

Test prerequisites:

  • Ignition on, engine off.

  • Brake fluid filled to "MAX".

  • Brake bleeding tool.

Procedure:

  1. Install the brake bleeding tool and attach vent hose.

  2. Start the function.

  3. Follow the instructions in the program.

Exhortations that will come up during the programming:

  • Attach the bleed reservoir to the bleeding screw. Connect the brake bleeder (set 2 bar) to the brake fluid reservoir.

  • Put on the brake bleeder, open the bleeding screw until clear and bubble-free brake fluid is visible.

  • Close the bleeding screw.

  • Remove the brake bleeder.

  • Fill the brake fluid reservoir's clutch side to the maximum level.
