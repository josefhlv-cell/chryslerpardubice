[1566]Activate system SBC

Test prerequisites:

  • The brake pads are placed on the brake discs.

  • The brake pressure is temporarily approx 60 bar.

  • The fault memory is erased.

Note:

  • Not performing this procedure after deactivating the system could cause entries to made in the fault memory

Procedure:

  1. Choose the system: ”Activate system SBC”, press "OK" to activate the system.
