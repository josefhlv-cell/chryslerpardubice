Replacing control unit for the electromechanical parking brake
When replacing control unit for parking brake, it is necessary to:
  • Code control unit for ABS again.
  • Reset adaptation values for ESP sensor unit and brake pressure sensor in ABS system.
  • Perform basic setting of parking brake.
Test conditions:
  • Parking brake released.
  • NOTE! BATTERY CHARGER MUST BE CONNECTED DURING THE WHOLE WORK.
Procedure shall take place in the following order:
  1. Select system "ABS", read out parameter "variant coding" in basic data and note relevant code.
  2. Select system "Parking brake". If possible, read out parameter ""variant coding" in basic data and note relevant code.
  3. Replace control unit.
  4. Select system "ABS".
  5. Select function "code control unit", code control unit with relevant code.
  6. Select function "Zero compensation of sensor unit ESP".
  7. Select function "Zero compensation of brake pressure sensor".
  8. Select system "Parking brake".
  9. Check that it is correctly coded, otherwise select function "code control unit"
  10. Select function "Basic setting of brake system".
  11. Check that no fault codes are stored in ABS and the parking brake system.
  12. Exit the function.
