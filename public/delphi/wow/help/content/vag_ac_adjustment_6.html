[1679]Basic setting of air conditioning system

The actuators' actual positions are adapted during basic setting.

Adaptation must be performed when:

  • An air conditioning system component has been removed or replaced.

  • The air conditioning system control unit has been replaced.

Basic setting cannot be aborted once started.

Test condition:

  • Battery voltage above 11.5 V.

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Select the "air conditioning system" function.

  2. During adaptation, a dialogue box appears containing the text "Active", which changes to "Complete" once the function is complete.

  3. Exit the function with "OK".

  4. Check that there are no stored trouble codes.

    • If basic setting fails, check the test conditions and repair any faults.
