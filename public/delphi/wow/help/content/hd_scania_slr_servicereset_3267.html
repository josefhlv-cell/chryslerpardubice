Reset service interval
This function is used to set distance to next service time.
Note:
The function uses the car's odometer reading to calculate the service.
The service warning in the vehicle has to be activated for the function to work.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Programmed values are shown, press "OK".
  3. An entry box is shown, enter the odometer reading when next service is to be performed, in km. Press "OK".
  4. Enter in km how long before service the warning is to be activated, press "OK".
  5. Programming is performed.
  6. New service parameters are shown, press "OK".
  7. Function done.
