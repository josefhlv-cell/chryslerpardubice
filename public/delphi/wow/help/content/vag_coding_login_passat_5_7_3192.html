Log-in before coding ABS-control module Bosch 5.7 with ESP
This function is used to enter correct log-in code before coding control module.
Note:
  • When the control unit is coded a valid login code first must be entered. Only valid for cars with ESP.
  • Read from the table below which login code is valid for the car.
  • The coding table refers to PR-Number (production number), these may be found on a plate close to the spare tire or on the first page in the service booklet.
Test prerequisites:
  • A valid login for control unit.
  • The battery voltage should be above 12V
  • Ignition on, engine off.
  • All the electrical loads should be switched off.
To perform coding:
  1. Read from the table below which login code is valid for the car.
  2. Enter the current code in the field for "Log-in".
  3. Click on the OK-button.
  4. A dialogue box confirms: Operation succeeded / Operation failed.
  5. Continue with the function "coding ABS".
