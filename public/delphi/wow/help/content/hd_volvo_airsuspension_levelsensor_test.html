[236]Checking level sensor

This function is used to check the level sensors' function when the trailer's height changes.

Voltage feed level sensors should be between 4.5V and 5.5V.

Level sensors' working range is between 0.5V and 4.5V

When the trailer is in driving mode the level sensors should give a signal between 2.0V and 3.0V.

Test conditions:

  • Parking brake applied.

  • Working pressure in air system.

  • Control box in position MAN1.

  • Battery voltage above 20V.

Procedure:

  1. Start the function.

  2. Choose the axle to be raised or lowered.

  3. Check that the voltage varies with the level change of the trailer.

  4. Check that right and left sensors give approx. the same value.

  5. Repeat the test for the other axles.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
