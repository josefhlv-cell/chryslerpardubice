[1588]Reset adaptation values for particle filter

After a change of particel filter this function has to be performed. This secures that the specific values in the ECU for the calculated amount of soot is set to zero or a standard value.

Note:

  • A reset of the adaptation values should only be done when the particle filter has been changed.

Test prerequisites:

  • Ignition on, engine off

  • No faults in the system

Procedure:

  1. Choose the function: "Reset adaptation values, diesel particle filter", and follow the instructions.
