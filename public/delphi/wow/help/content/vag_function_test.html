[1518]Component function test

This function test is used to check the function for some components on the vehicle. During the function test, the engine speed can be raised to 1200-3000 rpm and the current component will be opened and closed alternately.

Observe:

It is possible to abort the function test by releasing the accelerator/brake pedal.

Test prerequisities:

  • Engine idling.

Procedure:

  1. Press OK to start the function test.

  2. Depress and hold the brake pedal when the text "brake" is presented.

  3. Depress and hold the accelerator pedal when the text "full load" is presented.

  4. The engine speed can be raised to 1200-3000 rpm.

  5. If the function is ok, the component will be opened and closed alternately.

  6. Release the accelerator/brake pedal to abort the function test.

  7. Exit the function.
