Initialise remote keys
This function is an instruction to manually initialise a new key, so that the central locking remote locking will function.
Note:
The remote locking will only function for the keys that are initialised; however the vehicle can be started.
It is possible to carry out a new initialisation if any key is missing on previous initialisation occasions.
Test conditions:
  • All existing keys should be available in the vehicle.
  • The keys should be initialised in relatively quick succession.
Procedure:
  1. Enter the vehicle with the keys to be initialised.
  2. Check that all doors and the boot are closed. They must remain closed until all keys have been initialised.
  3. Insert one of the keys into the ignition lock and turn to position R (ignition position 1).
  4. Remove the key from the ignition lock again.
  5. Point the key at the rear view mirror.
  6. Press and hold the unlocking button whilst pressing the lock button three times.
  7. Release the unlocking button.
If the vehicle has accepted the key initialisation, the central locking will lock and unlock to indicate a successful result.
  1. Now point the next key to be initialised at the rear view mirror.
  2. Press and hold the unlocking button whilst pressing the lock button three times.
  3. Release the unlocking button.
If the vehicle has accepted the key initialisation, the central locking will lock and unlock to indicate a successful result.
  • Repeat steps 8 - 10 for the remaining keys to be initialised.
Once the vehicle has accepted the last key, initialisation is complete.
