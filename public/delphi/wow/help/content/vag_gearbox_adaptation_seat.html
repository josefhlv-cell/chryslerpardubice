[152]Basic setting of DSG-transmission

When the DSG-transmission's (Direct Shift Gear) gearshifting unit (mechatronic unit) is replaced, or if any of the fault codes 1078 or 18115 are stored in the control unit, then basic settings shown below shall be performed.

The following basic settings shall be performed in correct order:

  1. Gear control/position sensor

  2. Synchronization positions

  3. Clutch 1

  4. Clutch 2

  5. Main pressure, zero values

Note:

  • Basic settings shall be performed in the order according to the above.

  • During the whole basic setting procedure, the engine shall idle and the brake pedal shall be pressed down.

Test conditions:

  • Engine idling.

  • Transmission temperature between 30 and 100°C.

  • Gear selector in position P.

  • Brake pedal pressed down.

  • Gas pedal not affected.

Procedure:

  1. Select the function: "Gear control/position sensor".

    • Prescribed value: Gear control/position sensor shows "In progress" and switches to "done" when the function is finished.

  2. Select the function: "Synchronization positions".

    • Prescribed value: Synchronization positions shows "In progress" and switches to "done" when the function is finished.

  3. Select the function: "Clutch 1"

    • Prescribed value: Clutch 1, adaptation value shows "In progress" and switches to "done" when the function is finished. In some cases the basic setting is performed so fast that only "done" is shown.

  4. Select the function: "Clutch 2"

    • Prescribed value: Clutch 2, adaptation value shows "In progress" and switches to "done" when the function is finished. In some cases the basic setting is performed so fast that only "done" is shown.

  5. Select the function: "Main pressure, zero values"

    • Prescribed value: Main pressure, zero values shows "In progress" and switches to "done" when the function is finished. In some cases the basic setting is performed so fast that only "done" is shown.

  6. The basic setting is done when "Function done" is shown.

    • If the function fails, check the test conditions and the mechanics in the transmission, repair any faults.
