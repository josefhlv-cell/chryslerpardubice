Transponder key programming
This function is used when new or existing transponder keys needs to be programmed to the car.
Note:
All keys must be available and functioning. You can select to program 1 or 2 transponder keys.
Preconditions for the test:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Confirm that you want to start programming. Note that already stored keys must be programmed again.
  3. The ignition must be turned on within 20 seconds after the function has started, otherwise can not the programming be performed.
  4. Follow the instructions.
  5. The function is done.
  • If the function fails, check the test conditions and repair any faults.
