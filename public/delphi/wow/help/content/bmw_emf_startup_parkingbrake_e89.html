[717]Operationalising the parking brake

The parking brake must be operationalised after emergency activation or service mode has been initialised.

This function is used to regain the functionality of the parking brake.

Test conditions:

  • Parking brake released.

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Depress the brake pedal and keep it completely depressed.

  3. Pull the parking brake in when the brake pedal is completely depressed.

  4. Activation, wait around 10 seconds.

  5. Release the brake pedal, operationalisation is complete.

  6. The function is complete.
