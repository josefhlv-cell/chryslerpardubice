[1755]System status gateway

In cars where diagnostics communication takes place using a gateway, it is possible with this function to quickly get a list over all systems in the car and their current status. Very useful for service work, etc. The following status can be shown:

Shown in the listMeaning
No fault codesControl unit participates in data bus communication, no faults are stored in the control unit.
Fault code storedControl unit participates in data bus communication, one or several fault codes are stored in the control unit.
Coded, no communicationControl unit is registered as coded in the car's gateway, but communication is missing.
Installed, not codedControl unit participates in the car's communication but is not coded in the car's gateway.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on.

Procedure:

  1. Select the function: "System status gateway", press "OK".

  2. A list is shown with all systems that are installed in the car and their current status.

    • If the operation failed, check car selection and test conditions.

  3. Note if any system(s) has fault codes stored.

  4. Press "OK" to exit the function and return to the car selection.

  5. Select the relevant system to check and solve stored fault codes.

  6. The function is done.
