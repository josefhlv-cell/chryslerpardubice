AdBlue: Metering test component A67
This function is used to perform a metering test to check that the volume of reducing agent that is metered out matches the volume calculated by the control unit.
The following text contains information about the test. We recommend that you read the whole text before you continue and start the test.
Note:
During the test, reducing agent will come out from the metering component A67 and therefore it should be removed from the muffler.
Metering volume's reference value: 200 ml.
If the metering volume is less than 200 ml during the test, it may be that the metering unit is clogged and must be cleaned.
Test performed without metering valve A67 disconnected can cause damage to the vehicle.
See WIS document 'AR14.40-W-3020H'.
Test conditions:
  • Ignition on, engine off.
  • Battery voltage above 20V.
  • All components for the AdBlue system must be connected electrically and hydraulically correct.
  • AdBlue tank temperature above 5 °C.
  • The AdBlue tank must contain a fluid volume of at least 20%.
  • AdBlue metering valve "A67" must be disconnected.
Procedure:
  1. Disconnect AdBlue metering valve A67.
  2. Connect metering valve A67 to suitable measuring instrument.
  3. Start the function.
  4. Check that the AdBlue pressure increases and maintains the pressure.
  5. Check that there are no leaks.
