[57]Configuring oil change interval

Check the car's maintenance program before making changes.

Test conditions:

  • Engine off.

  • Ignition on.

  • Battery voltage above 12 V.

Procedure when configuring kilometres:

  1. Read the vehicle's present configuration under data list parameter "Interval oil change; in km".

  2. Enter oil change interval in kilometres divided by 1,000, for example:30,000 km / 1,000 = 30.

  3. A dialogue confirms "Operation successful" or "Operation failed".

  4. Check that data list parameter "Interval oil change; in km" has changed to desired number of kilometres.

Procedure when configuring miles:

  1. Read the vehicle's present configuration under data list parameter "Interval oil change; in miles".

  2. Calculate the oil change interval using the following example: 18,000 miles x 10 = 180,000 miles / 6 = 30,000 km.

  3. Enter the result divided by 1,000, for example 30,000 km / 1,000 = 30.

  4. A dialogue confirms "Operation successful" or "Operation failed".

  5. Check that data list parameter "Interval oil change; in km" has changed to desired number of kilometres.

Procedure when configuring months:

  1. Read the vehicle's present configuration under data list parameter "Interval oil change; in months".

  2. Enter the oil change interval in desired number of months.

  3. A dialogue confirms "Operation successful" or "Operation failed".

  4. Check that data list parameter "Interval oil change; in months" has changed to desired number of months.
