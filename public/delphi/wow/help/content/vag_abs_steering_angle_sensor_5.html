[1671]Initialise steering angle sensor

This function is used to initialise the steering angle sensor.

Initialisation is necessary if:

  • The ABS/ESP control unit has been replaced.

  • The steering angle sensor has been replaced.

  • The front axle chassis geometry has been adjusted.

Note:

The ignition must not be switched off during initialisation.

Test conditions:

  • ABS/ESP control unit correctly encoded.

  • Engine on.

  • Access to a stretch of road that fulfils the conditions set out below.

Procedure:

  1. Start the engine and turn the steering wheel approximately 90° to the left and right once.

  2. Test drive on a level surface at a maximum speed of 20 km/h and check that the steering wheel is in the correct position when driving in a straight line.

  3. Stop the vehicle while driving in a straight line and ensure that the steering wheel has not turned.

  4. Select the "Initialise steering angle sensor" function.

  5. The function starts and the text ”Adaptation in order” confirms that initialisation is complete.

    • If the text "Adaptation not possible" appears, check that the steering angle sensor is correctly fitted and the steering wheel is in the centre position (the steering angle can be read out in the data lists).

  6. Complete the function and disconnect the diagnostic tool.

  7. The ESP and steering servo test lamp comes on.

  8. Drive a short distance in a straight line so that the steering angle sensor learns the centre position. The ESP and steering servo test lamp goes out.

  9. Connect the diagnostic tool again, read out and check that there are no stored trouble codes.

  10. The function is complete.
