[615]Reset adaptation values for nitrogen oxide sensor

Note:

This function must be run after changing nitrogen oxide sensor.

Adaptations values for the nitrogen oxide sensor may only be reset if the nitrogen oxide sensor has been changed!

Test conditions:

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.
