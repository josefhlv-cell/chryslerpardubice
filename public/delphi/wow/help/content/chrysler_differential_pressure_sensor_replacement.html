[21]Reset adaptation values for differential pressure sensor

The function is used when the differential pressure sensor has been replaced. Values for the differential pressure sensor will be reset in the engine's control unit.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the function and follow the instructions.

  2. The function is done.

    • If the function fails, check the test conditions and repair any faults.
