[1394]Activation/deactivation of transport mode

Transport mode is a function that is used to keep the battery capacity in the car. With the transport mode activated, the battery ´s discharging is limited througout many functions, that have limited functionality or are shut off. "100" is indicated on the dashboard when the transport mode is activated.

Test prerequisites:

  • Ignition On

  • Battery voltage OK

Procedure:

  1. Choose the function: Activate/deactivate transport mode.

  2. A dialog box confirms: Operation succeded/failed.

  3. Exit the function and check the activation/deactivation.
