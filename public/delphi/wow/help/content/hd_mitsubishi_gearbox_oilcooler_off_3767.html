Oil cooler OFF
This function is used to test the status of the gearbox oil cooler.
Test conditions:
  • Start the engine.
  • Engine idling.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. A dialogue box shows test conditions, check these and press "Start".
  3. Start and stop activation of the selected test.
  4. At the end of the test press "OK".
  5. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
