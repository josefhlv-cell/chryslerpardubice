[29]Antenna replacement

This function checks that the antennas work and lasts for approx. 1 minute.

Note:

The function must be run if an antenna is replaced.

Likely causes of a failed result:

  • One or more antennas missing, damaged, or incorrectly installed.

  • One or more transmitters , damaged, or incorrectly installed.

  • Interference between antennas and transmitters.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function and follow the instructions in the program.
