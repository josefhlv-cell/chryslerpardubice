Tire pressure monitoring
This function is used to configure tire pressure monitoring.
Note:
Current tire pressure is saved as reference value in the control unit.
After activation a pressure-drop may be registered first after several minutes of driving.
Test conditions:
  • Ignition on, engine off.
  • Correct tire pressure.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. A dialogue box shows the current status.
  3. Press "OK" to complete the function.
  4. After activation a pressure-drop may be registered first after several minutes of driving.
If the function fails, check the test conditions and repair any faults.
