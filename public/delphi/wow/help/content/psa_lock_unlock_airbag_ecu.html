[70]Lock/unlock ECU

This function is used to lock/unlock the airbag control unit.

Locking the control unit prevents the trigger signal from reaching the ignition circuits. Components shall still be handled very carefully. The airbag's control light is activated on the instrument panel.

After repair the control unit must be unlocked using the unlocking function.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

Procedure:

Lock ECU:

  1. Select the function: "Lock ECU".

  2. A dialogue box shows: Function done/failed.

  3. Check that warning light for airbag turns on.

Unlock ECU:

  1. Select the function: "Unlock ECU".

  2. A dialogue box shows: Function done/failed.

  3. Check that warning light for airbag turns off.
