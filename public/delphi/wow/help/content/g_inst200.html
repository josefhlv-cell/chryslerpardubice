[960] Memory mode write

Preconditions for the test:

No faults stored.

Data list 2: Memory mode status is set in mode Extended memory.

Note:

Memory mode write is used to change from Extended memory mode to Reduced memory mode.

This procedure must always be carried out when a new control unit is installed.

Procedure:

Before the adjustment is performed, make sure that data list 2 (Memory mode status) is set in mode Extended memory. When the adjustment is performed return to data list 2 and check that the mode is set to Reduced memory.
