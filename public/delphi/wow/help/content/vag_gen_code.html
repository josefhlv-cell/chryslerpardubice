[1764]Version coding of control unit

When replacing a control unit, it needs to be version-coded to function correctly. The version code can be read out from the old control unit as the data list parameter "Version coding". Valid version coding is also found in workshop manual or similar.

  • The control unit must be of the correct type to approve the version code.

  • Workshop manual or read-out version code shall be available.

  • Certain control units cannot be version-coded.

Note:

Incorrect version coding may reduce the car's safety and function.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • No faults in the system.

  • Valid version code for the control unit.

Procedure:

  1. Select the function: "Code control unit", press "OK".

  2. A dialogue box shows the current code. Press "OK" to change the code.

  3. Enter the current code. Confirm with "OK".

  4. A dialogue box shows the new code. Press "OK".

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
