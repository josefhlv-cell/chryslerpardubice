[1779]Service mode flap motors

The flap motors must be set in service mode in order to enable removal and installation of the air conditioning's flap motors together with the holder plate for these. After service work, a basic setting of the air conditioning should be performed.

  • When the function is activated the display flashes on the "comfort" version and the ECON-button flashes on the "basic" version.

  • When the function is done and the ignition has been turned off, the flap motors are in service mode.

  • When the ignition is turned on or the "AUTO"-button is pressed in, the flap motors return to their original operating positions.

Test condition:

  • Battery voltage above 11.5 V.

  • Ignition on, engine off.

Procedure:

  1. Select the function: "Service mode", press "OK".

  2. A dialogue shows "service setting". Wait approx. 1 min. (flap motors assume service mode).

  3. Turn off the ignition.

    • The flap motors are now in service mode, service work can be performed.

  4. When the service work is done, turn on the ignition and check any fault codes.

    • If the function fails, check the test conditions and repair any faults.
