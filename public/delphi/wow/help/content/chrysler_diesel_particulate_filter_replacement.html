[20]Reset adaptation values for particle filter

The function is used when the diesel particle filter has been replaced. This function will reset all diesel particle filter values in the engine's control unit.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the function and follow the instructions.

  2. The function is done.

    • If the function fails, check the test conditions and repair any faults.
