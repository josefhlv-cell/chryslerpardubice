[368]Service work on the gas system

This function is used to refill the gas lines to the engine after service work.

Note:

This function may only be performed after all bolted joints have been checked for tight seal.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. The system is filled with gas.

    • The function must be repeated if it is cancelled before operating mode CNG can be used again.

  3. A dialogue box shows when the function is done.

    • If the function fails, check the test conditions and repair any faults.
