Configure speed limitation
This function is used to configure the speed limitation.
The permitted speed configurations are:
  • 90 km/h
  • 100 km/h
  • 110 km/h
  • 130 km/h
  • No limitation
Test conditions:
  • Ignition on.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. The function is done.
    • If the function fails, check the test conditions and repair any faults.
