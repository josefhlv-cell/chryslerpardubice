[1651]Bleeding ABS-brakes

Brake bleeding is only performed if air has entered the ABS-system's hydraulic unit, or in case of reduced brake function when the ABS-system has activated the ABS-function. Brake bleeding is performed separately on each wheel.

  • Check all hydraulic connections and couplings if the ABS hydraulic unit has been replaced.

  • Fill the brake fluid reservoir to max. level.

  • Adjust the pressure to between 2 and 2.5 bar.

  • Make sure that the battery is sufficiently charged. Low battery voltage may impact the brake bleeding process.

Test conditions:

  • Battery voltage above 11.5 V.

  • Ignition on, engine off.

Procedure:

  1. Select function for the wheel that is to be bled, press "OK".

  2. Bleeding is performed in the following sequence:

    • Left rear wheel

    • Left front wheel

    • Right front wheel

    • Right rear wheel

  3. Follow the instructions in the dialogue box.

  4. Press "OK" to start the bleeding function.

  5. Bleeding in progress.

  6. A dialogue box shows: "Operation successful" or "Operation failed".

  7. If air remains, repeat the bleeding function.

  8. The function is done.

If the operation failed, check test conditions.
