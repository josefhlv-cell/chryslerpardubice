[166]Correction programming of fuel amount

This correction is used to change the fuel amount.

  • Step 1: Enriching of fuel-air mixture by approx. 10%

  • Step 2: Enriching of fuel-air mixture by approx. 15%

  • Step 3: Enriching of fuel-air mixture by approx. 25%

  • Level 4: Combustion engine runs rough after start. (Level 1 )

  • Level 5: Combustion engine runs rough after start. (Level 2 )

  • Level 6: Combustion engine runs rough after start. (Level 3 )

  • Level 7: Make the fuel-air mixture leaner, to approx. 5% (Countries Lower fuel quality )

  • Level 8: Make the fuel-air mixture leaner approx. 10% (no start sequence) ( Countries Lower fuel quality )

  • Level 9: Make the fuel-air mixture leaner, to approx. 10% (Countries Lower fuel quality )

Correction works in the following operating modes:

  • Engine start

  • After start

  • Warming up and acceleration.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. Select level for adaptation and press "OK".

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
