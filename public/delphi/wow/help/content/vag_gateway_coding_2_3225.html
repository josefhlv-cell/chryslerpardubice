Configure gateway
The different CAN bus systems and control units are connected in a control unit called gateway to exchange information. All the control units that are possible to program into the car are stored in the gateway control unit. When reading the gateway coding, the control units that are programed to the car are displayed as "Coded". The other control units are displayed as "Not coded". If for example a trailer control unit is installed it is necessary to change the status of this control unit in Gateway control unit to "Coded", so the other control units in the car can exchange information with the trailer control unit. It is also possible to decode control units from the gateway if a control unit is dismounted from the car.
Note:
  • Incorrect coding may reduce the car's function.
  • Coding of the gateway control unit takes place according to a procedure in several steps that is possible to cancel/abort.
Test conditions:
  • Battery voltage above 12 V.
  • Ignition on, engine off.
  • All power consumers disconnected.
Performance:
  1. Start the function.
  2. A dialogue box with scroll list shows the control units that are possible to connect to the car. Control units that are programmed are designated as "Coded" and non-programmed as "Not coded".
  3. To program or deprogram a control unit, select the relevant control unit in the scroll list, press "OK".
  4. Coding is performed.
  5. "Coding OK" is shown if coding is successful.
  6. Press OK, current installation list is shown.
  7. Press "OK" to exit the function.
  8. Check that no fault codes are stored in any of the relevant control units.
