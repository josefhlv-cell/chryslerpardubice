[9]Bleeding brake system

This function is used to bleed the brake system.

Note:

This process should only be performed if the brake system needs to be bled. During the process you will be instructed to open and close the bleeder screws by the different wheels.

The order is as follows: Left rear wheel, left front wheel, right front wheel, and right rear wheel.

Test conditions:

  • The brake system shall seal tightly, no leaks.

  • Ignition on, engine off.

Procedure:

  1. Check that the brake system seals tight, no leaks.

  2. Pump the brake pedal several times.

  3. Top up the reservoir with brake fluid to max.

  4. Install the bleeding equipment.

  5. Pressurize the system between 2-2.5 bar.

  6. Start the process by pressing "OK".

  7. Open the bleeder screw by Left rear wheel.

  8. Press "OK" again.

  9. When the process is done, pump with the brake pedal until all air is out.

  10. Close the bleeder screw and press "OK".

  11. Start over with the next wheel from step 7.
