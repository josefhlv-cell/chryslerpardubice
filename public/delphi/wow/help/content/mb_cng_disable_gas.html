[376]Disable gas operation

This function shall be used when gas operation is to be disabled in the engine control unit.

Test conditions:

  • Ignition on.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. A dialogue box shows if the function succeeded or failed.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
