[5]Basic setting of mechatronic

For the mechatronic unit to work correctly it is necessary to perform a basic setting. Basic setting shall be performed when the mechatronic unit has been replaced or removed.

Once the basic setup is complete, it is necessary to reset the adaptation values for mechatronics.

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on.

  • Gear selector in position P.

  • Brake pedal pressed down.

  • The engine shall be started acc. to instructions in the procedure below.

Procedure:

  1. Start the function.

  2. A dialogue box shows: "Status for basic setting" and "in progress", during on-going basic setting.

  3. Start the engine when "start engine" is shown, basic setting continues and dialogue box switches to "in progress".

  4. The basic setting is finished when the dialogue box shows "done".

    • If the function fails, check the test conditions and repair any faults.

  5. Exit the function as well as diagnosis with the system, turn off the ignition.

  6. The function is done.
