Complete reset of ECU
This function is used to erase all the adaptation parameters and fault codes that are stored in the ECU memory.
Note:
When the function is complete, an adaptation procedure must be performed as described below.
Please read the entire help file before starting the function.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Press "OK" to start the function.
  2. When the function is complete, the vehicle must be driven on the second or third gear up to 2500-3000 rpm.
  3. Then release the accelerator and decelerate down to 1300-1500 rpm.
  4. Then repeat steps 2-3 four or five times.
  5. Check that the data list "Learning in interval 1 ready" have the status "YES". If the data list have the status "NO" the adaptation procedure must be performed again.
