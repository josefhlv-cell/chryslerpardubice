[594]Checking injection control's start and timing

This function is used to check the injection control's start and timing.

Note:

The reference value for start of injection control is retrieved from the following variables for operating status:

  • Engine rpm.

  • Injection volume.

  • Coolant temperature.

  • Ambient pressure.

  • Boost pressure.

  • Fuel temperature.

The engine's control unit controls the injection timing so that the difference between the reference value and the actual value is as low as possible. Fault code "0A" is stored if the difference is too big. Also, the injection timing's position is monitored and fault code "48" is stored in case of failure.

If any of the fault codes "0A" or "48" is stored, the injection rate will be limited to 25 mg/stroke.

Test conditions:

  • Engine on.

  • Working temperature reached in engine.

  • All power consumers disconnected.

  • Parking brake applied.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.
