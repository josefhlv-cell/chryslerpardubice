[1567]Basic setting of the climate control

If the climate control unit has been replaced, or a new position motor for the temperature damper has been installed, a basic setting of the climate control must be performed. When the climate control basic setting is performed, the control unit learns the position motor´s end positions and calculates a new value for the inlet air fan.

Note:

During the basic setting the ignition must not be switched off.

Test prerequisites:

  • Battery voltage higher than 11.5 V.

  • Ignition on, engine off.

  • No faults in the system.

  • Correctly installed and connected.

Performance:

  1. Press "OK" to start the function.

  2. The function starts and the new adaption values are stored. When the basic setting is done a dialog box presents: "Operation succeeded" or "Operation failed".

    • If the function fails, check the test prerequisites and adjust possible fault codes.

  3. Exit the function and disconnect the diagnostic tool.

  4. Switch off the ignition for 30 seconds, then switch it on for 30 seconds.
