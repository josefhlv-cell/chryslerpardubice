[285]Programming the key's remote control

When replacing a defective remote control or increasing number of remote controls, these must be adapted to the control unit. It is also necessary if the code of the remote control and control unit no longer match. This may occur if the transmitter button is pressed when outside the system's operating range.

Note:

  • All remote controls must always be adapted again, even the existing ones.

  • Time to adapt all remote controls may not be longer than fifteen seconds.

  • Adaptation is cancelled if a button is pressed down several times on the same remote control.

Test conditions:

  • Battery voltage at least 12 V.

  • Ignition on, engine off.

  • All power consumers disconnected.

Procedure:

  1. Start the function.

  2. Old remote controls are erased.

  3. A dialogue box is shown, enter the number of remote controls to be adapted (including existing ones), press "OK".

  4. You are now instructed to press the unlock button for at least one second in order on each remote control to be adapted.

    • Time to adapt all remote controls may not be longer than fifteen seconds.

  5. The adaptation finishes automatically when the number of remote controls to be adapted is reached.

  6. Press "OK" to exit the function.

  7. Turn off the ignition and check the function of all remote controls.

  8. The function is done.

    • If the function fails, check the test conditions and repair any faults.
