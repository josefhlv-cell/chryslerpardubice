[1610]Programming remote control

At remote control programming, the remote control is coupled to the key that is in the ignition. This key must be programmed and be stored in the control unit's memory.

Note:

Key programming shall be done before programming of remote control is performed. The remote control shall only be programmed with keys that already are stored in the control unit's memory.

After performing steps 1 - 5 below, the remote control is programmed. Repeat the steps if several remote controls are to be programmed.

Test conditions:

  • Ignition on.

Procedure:

  1. Turn on the ignition with the key that is to be coupled.

  2. Press and hold in the remote control's lock button for 10 seconds.

  3. Turn off the ignition and remove the key from the ignition.

  4. Wait approx. 5 seconds.

  5. Press on the remote control's lock button to ensure correct function.
