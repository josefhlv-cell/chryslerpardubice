[1096]Nominal tyre pressure input

The tyre pressure monitoring system is working against a nominal tyre pressure (target value). When the tyre pressure deviates from the nominal tyre pressure is the driver alerted by a message in the information display. This value is programmed into the central control unit (BSI). The nominal tyre pressure and the status of the tyres can be read in the data list parameters.

Note:

When for example the tyre dimension is changed it can be necessary to change the nominal tyre pressure to avoid erroneous warnings.

The input value shall be entered in millibar.

Ex.

Entering a new nominal tyre value of 2,5 bar.

2,5 bar = 2500 millibar

Value to edit: 2500

Performance:

  1. Write the new value in millibar in the edit box for ”Nominal tyre pressure”.

  2. Press OK.

  3. A dialog box present: Operation succeeded/operation failed.

  4. Press OK.

  5. Verify in the data list parameters that the new value is stored.
