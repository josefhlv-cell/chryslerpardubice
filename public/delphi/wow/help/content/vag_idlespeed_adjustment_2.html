[229]Configure idle speed

This function is used to change the idle rpm. The rpm can only be adapted within predetermined limit values.

Test conditions:

  • Engine idling.

  • Coolant temperature above 70°C.

Procedure:

  1. Start the function.

  2. Test conditions are checked.

  3. Current value for idle rpm is shown, press "YES" if you want to change the rpm.

  4. A scroll list with possible rpm settings is shown. Select desired rpm, press "OK"

  5. The adaptation is performed, and the new stored value is shown.

    • The new adapted value may differ slightly from the desired rpm.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
