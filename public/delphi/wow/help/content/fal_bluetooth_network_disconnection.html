[407]Disconnect bluetooth

Bluetooth equipment connected to the convergence system will be disconnected when using this function. After this the bluetooth module will be receptive to establishing new contact with other bluetooth equipment (e.g., mobile telephone).

NOTE! There is no guarantee that all mobile telephones on the market are compatible with the system.

Test conditions:

  • Ignition on.

Procedure:

  1. Activate the mobile telephone's bluetooth function.

  2. Run, from the test equipment, "Disconnection network Bluetooth".

  3. Run a search for a new bluetooth unit from the mobile telephone.

  4. A positive result is that the mobile telephone finds a new unit with the name "MY CAR".

  5. The function is done.
