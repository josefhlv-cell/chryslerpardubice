[1231]Erase keys

This function will erase all registrated immobiliser keys except for the key that is being used.

Note:

  • Erasing the keys will fail if the time limit is exceeded.

Test prerequisites:

  • The battery voltage should be >12V.

  • Ignition on, engine off.

  • No stored fault codes.

  • A registrated key.

Procedure:

  1. Choose the function: Erase keys.

  2. Dialogue box: Engine off, ignition on, see help for further information. Press OK to continue.

  3. A dialogue box presents the number of programmed keys, to continue press OK.

    • If you want to cancel erasing, press abort.

  4. Dialogue box: Press OK and then touch the ignition switch with a registrated key within 30s, make sure that the emblem side is facing the switch.

    • Note: Erasing the keys will fail if the time limit is exceeded.

    • There will be a beep when the key touches the ignition switch.

    • If you want to cancel erasing, press abort.

  5. A dialogue box displays the number of programmed keys, press OK to exit.

CAUTION: If the key code erasure has failed:

  • The time limits may have been exceeded.

  • Check the battery voltage.

  • Check that a registrated key is being used.

  • Check that no fault codes are stored.

    Restart this operation to try again.
