[1599]Testing EGR-valve

This function is used to check the function in the EGR-valve. The EGR-valve will be operated to its end-positions.

Test conditions:

  • Engine off, ignition on.

Procedure:

  1. Start the function.

  2. The EGR-valve is operated for approx. 5 seconds.

  3. Turn off the ignition for 40 seconds.

  4. Turn on the ignition again.

  5. The function is done.
