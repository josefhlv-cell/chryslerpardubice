[1624]Solenoid valve test

The function enables releasing one wheel at a time while the other wheels are braked. This makes it possible to check that each solenoid valve works.

Note:

The test requires that the brake is held down while turning the wheels. It is advantageous to perform the test on "Rolling highway".

Test conditions:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

Procedure:

  1. Select function: "Solenoid valve test" for desired wheel and press "OK".

  2. Build up the brake pressure to 1 KN by holding down the brake pedal. The wheel being tested has constant brake force.

  3. Keep the brake pedal pressed down, the solenoid valve is affected, and the brake pressure releases. The wheel being tested is released and can be turned.

  4. The function is ended. Press "YES" to exit the test.

  5. If the function failed, check test conditions and erase any error codes.
