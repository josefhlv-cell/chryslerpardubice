Steering angle calibration
This function is used to calibrate the steering angle sensor.
Run the function when the ECU has been replaced or work related to EPS has been done.
Note:
This command erase the control units adapted values.
Test conditions:
  • Ignition on.
  • Engine running.
Procedure:
  1. Start the function.
  2. Turn the steering wheel to neutral position, so that the wheels point straight ahead, tolerance +-5°.
  3. Press OK.
  4. The function is done.
