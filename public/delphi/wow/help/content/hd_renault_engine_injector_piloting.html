[41]Injector shut-off

This function is used to temporarily shut off a cylinder and check the injectors' function.

Test conditions:

  • Engine started and warm.

  • Transmission in neutral.

  • Parking brake applied.

  • Engine speed 750-1950 rpm.

Procedure:

  1. Start the function.

  2. Set desired engine rpm and turn off one cylinder at a time by pressing "Start".

  3. Press "Stop" to turn on the cylinder again.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
