[19]Write VIN

This function is used to reset existing chassis number and enter the current chassis number in the control unit. This is necessary when changing to another control unit.

Test prerequisites:

  • Battery voltage over 12V.

  • VCI connected to vehicle with ignition on engine off.

Procedure:

  1. Start the function and follow the instructions in the program.

  2. After completed function, check/erase any trouble codes in the engine and immobilizer system.
