Correction programming of fuel amount
This correction is used to change the fuel amount.
The following selections for correction are available:
  • Basic value.
  • Slightly enriched fuel mixture.
  • Enriched fuel mixture.
  • Lean fuel mixture.
Correction works in the following operating modes:
  • Engine start.
  • After start.
  • Warming up and acceleration.
Test conditions:
  • Ignition on, engine off.
  • Battery voltage above 12V.
Procedure:
  1. Start the function.
  2. Select level for adaptation and press "OK".
  3. The function is done.
    • If the function fails, check the test conditions and repair any faults.
