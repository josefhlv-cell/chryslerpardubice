[1628]Bleeding brake system

The brake bleeding function is only necessary if it is suspected that air has entered the ABS-system's hydraulic unit, or in case of reduced brake function when the ABS-system has activated the ABS-function.

Note:

  • Check all hydraulic connections and couplings if the ABS hydraulic unit has been replaced.

  • Make sure that the battery is charged. Low battery voltage may impact the brake bleeding process.

Test conditions:

  • Battery voltage above 11.5 V.

  • Ignition on, engine off.

Procedure:

  1. Select the function: "Bleed brake circuit", for the wheel that is to be bled.

  2. The bleeding sequence is now activated and the following check steps and instructions will be shown:

    • Ensure that necessary steps, according to help file, are performed.

    • Ensure that brake fluid reservoir is not empty.

  3. Open selected bleed nipple and connect reservoir to the bleed nipple.

  4. Pump on the brake pedal at 2 second intervals, this shall be done for 90 seconds.

  5. Bleeding finished. Close selected bleed nipple.

  6. Function done.
