[257]Reset adaptation values for EGR throttle valve

This function resets the adaptation values for the EGR throttle valve. This function is used when the EGR throttle valve or control module has been replaced.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function.

  2. Follow the instructions in the programme.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
