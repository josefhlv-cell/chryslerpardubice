[50]Basic setting of air conditioning system

Depending on the repair, one or several basic adjustments of the system have to be performed.

There are the following three basic adjustments for the climate control unit:

  1. "New addressing flap motors"

  2. "Teach-in end-position flap motors"

  3. "Check cooling performance / compressor run-in"

This function is used when:

  • Flap motor has been replaced or the position of the flap has changed, then basic setting 1 and 2 shall be performed in mentioned order.

  • Control unit for the air conditioning has been replaced, then basic setting 2 and 3 shall be performed in mentioned order.

    During basic setting the flap motors are run to their end-positions and the control unit stores these values.

Note:

  • During this basic setting, pressure and temperature in the air conditioning unit are checked during use.

  • A started basic setting shall not be cancelled, then a fault code is stored in the fault memory and operation of the AC will not work. If this happens, repeat the basic setting.

  • If basic setting cannot be finished correctly due to, e.g., high outdoor temperature, increase engine rpm to approx. 2,000 rpm and repeat the function.

Test conditions:

  • Battery voltage above 12 V.

  • Refrigerant circuit filled and all components connected.

  • Engine idling.

  • Air vents in instrument panel fully open.

  • No faults in the system.

  • The function "Teach-in end-position flap motors" performed.

Procedure:

  1. Start the function.

  2. Air conditioning display flashes, or AC-button (depending on equipment).

    During basic setting the following measuring values are shown:

    • Outdoor temperature

    • Refrigerant pressure

    • Compressor current

    • Temperature after evaporator

  3. When basic setting is finished the indication turns off in the air conditioning display, or AC-button, and the measuring value for outdoor temperature switches to done, (basic setting takes up to 5 minutes).

  4. Exit the function. Turn the ignition off and then on again, press "AUTO" on the air conditioning unit and wait approx. 15 seconds for any fault codes to be stored.

  5. Re-establish communication and check that no fault codes are stored.

  6. If basic setting is not finished correctly, repeat the function with an engine rpm of approx. 2000 rpm.
