Reset service message
This function is used to perform a manual service reset.
Test conditions:
  • Ignition off.
  • The ignition is turned on acc. to procedure below.
Procedure:
  1. Insert the key in the ignition.
  2. Press and hold down the button "REAR FOG LIGHT".
  3. During the time that the button is held down, turn on the ignition without starting the engine.
  4. Let up the button "REAR FOG LIGHT".
  5. Press and hold down the button "TRIP" (located on the end of the turn signal lever).
  6. Check that the message "Resetting service light" is shown on the display.
  7. The function is done.
