Learn latch sector home
This function is used to initiate the start position in the lock, by moving the sector gear to find the correct position. The function should be performed if the door is not opened, if there are active fault codes related to the sector switch and/or the sector switch is closed.
Preconditions for the test:
  • Ignition on, engine off.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Function complete.
