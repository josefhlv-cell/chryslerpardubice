[1508]Service reset

This function resets the vehicle's service interval.

Note:

  • The service reset must be done in this specific order:

    1.Oil

    2.Inspection

    3.Time

  • The service reset can only be done when it remains less than 1500 km from the indicated service interval.

Test prerequisites:

  • No faults in the system.

  • Ignition on, engine off.

Procedure:

  1. Press OK to start the function.
