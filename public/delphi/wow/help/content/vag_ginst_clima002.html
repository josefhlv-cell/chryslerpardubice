[1295]Climatronic, coding control unit

Test condition:

  • Battery voltage above 11.5 V.

  • Ignition on.

Note, coding and basic setting of Climatronic must be performed when:

  • Change of Climatronic control unit.

  • Not correct values are achieved from datalist.

  • The display is flashing after the ignition is turned on and no fault code is stored in the memory.

Procedure:

  • Read, repair and erase eventual fault code.

  • Start the function.

  • Enter correct code number.

  • Press OK.

  • Coding performed, read datalist to control the coding number after ignition off/on.

    Code table 
    Number: Market:
    01000All countries, except Japan
    01100Japan only
