[13]Reset adaptation values for transfer case

This function must always be performed after the transfer case has been replaced.

Test conditions:

  • Ignition on, engine off.

  • Correct oil level in transfer case.

Procedure:

  1. Start the function.

  2. Stored values for the classification resistor will be reset.

  3. Adaptation values for the transfer case and stored values for transmission integrator and disc integrator will be reset.

  4. Reference values for transmission integrator and disc integrator are checked if they have been reset to value 0.

  5. If all values have not been reset to 0, repeat the function.

  6. If all values have been reset to 0, replacement of the transfer case has been performed correctly.

  7. The function is done.
