[695]Resetting general adaptation value

This function allows you to reset the adaptation value for a given component in the engine control unit.

Note:

You must carry out the reset after the component has been replaced or repaired.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

Procedure:

  1. Start the function and follow the instructions in the program.

    • If the function fails, check the test conditions and repair any faults.
