[461]Calibrating gyrometer and accelerometer

This function adapts the acceleration sensor to the ABS/ESP-control unit.

This function shall be run after replacing ABS/ESP-control unit, sensor, or at fault codes for calibration of the sensor.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • All power consumers disconnected.

  • Sensors and control unit correctly installed.

  • Place the car in a bench or on a level surface where the inclination is less than 1%.

  • Correct air pressure in tires.

  • The steering wheel stands straight and the front wheels point straight forward.

  • The car shall be unloaded, only the driver may be seated in the car.

Procedure:

  1. Start the function.

  2. A dialogue box shows "Calibration in progress".

  3. A dialogue box shows if the function succeeded or failed.

    • If the function fails, check the test conditions and repair any faults.

  4. After successful calibration, read and erase fault codes.

  5. Finish and turn off the ignition for 30 seconds.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
