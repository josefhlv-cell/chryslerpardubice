[98]Configure tyre size

This function is used to configure the tyre size. The tyre dimensions must be programmed to enable the control unit to calculate the correct speed.

Note:

The tyre dimensions are divided into 2 groups: Group 1: 195/65 R15, 205/55 R16, 205/50 R17, 215/55 R16, 225/45 R17, 235/40 R18 Group 2: 215/50 R17, 225/45 R18, 235/35 R19

Test prerequisites:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. A dialogue box appears containing the stored tyre group. Press "OK" to programme the new tyre size, and follow the instructions.

  3. The programmed tyre group is displayed when programming is complete.
