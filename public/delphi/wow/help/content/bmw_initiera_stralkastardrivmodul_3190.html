Initiating headlight drive module and calibrating LED-direction indicator
This function is used to initiate a new headlight drive module and to calibrate LED-direction indicator. This must be done if a drive module has been replaced.
Note:
If both left and right drive module has been replaced, check with which type of headlight the vehicle should be equipped. If only one drive module has been replaced the check takes place automatically in the function, with a check of the opposite side. If initiation fails the cause may be that vehicle is equipped with S552A which has to be coded.
Equipment alternatives:
  • Xenon headlights with equipment code S522A.
  • Adaptive headlights with equipment code S524A.
  • Adaptive LED-headlights with equipment code S552A.
Test conditions:
  • Both headlights must be installed.
  • Headlight variant checked, see under "Note".
  • Engine off, ignition on.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Function complete.
