[1077]Login procedure for ABS.

Note:

To performe some of the basic setting functions a login code is requied.

The code is: 40168

Sometimes a login code is required to performe coding of the ABS control unit. In this case the valid login code is to be found in the respective helpfile for ABS coding.

To enter the login code:

  • Write the code in the login field.

  • Click on the OK-button.

  • A dialogue box confirms: Operation succeeded / Operation failed.

  • Proceed with the desired basic setting.
