[154]Reset adaptation values for fuel metering valve

This function resets learned values for the fuel metering valve, the function is used when the high-pressure pump has been replaced.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
