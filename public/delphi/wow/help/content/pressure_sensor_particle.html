[1113]Particle filter pressure sensor

Dismantle:

Dismantle the engine cover.

Dismantle the pressure sensor connector.

Dismantle the pressure hoses.

Dismantle the pressure sensor by loosening the screw.

Assembling:

Assemble the pressure sensor with the screw.

Assemble the pressure hoses.

Assemble the pressure sensor connector.

Assemble the engine cover.

When a new pressure sensor is assembled, use function ”Particle filter pressure sensor replaced”.This will reset the adaption values.
