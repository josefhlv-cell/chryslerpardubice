Gear actuator in position - Neutral
This function is used to disengage all gears and holds the gear actuators in the neutral position. This enables the vehicle to move when the clutch is stuck.
Note:
This function must only be performed with the engine off.
To engage the gears again, turn off the ignition and wait 10 seconds and then start the vehicle.
Test conditions:
  • Ignition on, engine off.
  • Gear selector in position P.
Procedure:
  1. Start the function and follow the instructions in the program.
    • If the function fails, check the test conditions and repair any faults.
