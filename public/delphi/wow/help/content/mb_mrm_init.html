[1569]Control unit replacement

This function shall be used when the control unit has been replaced.

Test prerequisites:

  • Control unit replaced.

  • Engine running.

  • Battery voltage above 12 Volts.

Procedure:

  1. Turn the steering wheel to end position in both directions.

  2. Press "OK" to start the function.

  3. The function starts and the new adaption values are stored. A dialog box presents: "Operation succeeded" or "Operation failed".

    • If the function fails, check the test prerequisites and adjust possible fault codes.

  4. Read out and clear possible faultcodes.

  5. Exit the function and disconnect the diagnostic tool.

  6. Switch off the ignition for 30 seconds, then switch it on for 30 seconds.
