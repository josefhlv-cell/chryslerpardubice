[1731]Programming remote control

Programming of transponder (remote control) is necessary when replacing a defective transponder or when the number of transponders shall be increased (max. four). It is also necessary if the code of the transponder and control unit no longer match. This may occur if the transmitter button is pressed in when outside the system's operating range.

  • All transponders must always be programmed again, even those that have been programmed earlier.

  • Time to program all transponders may not be longer than fifteen seconds.

  • If new ignition keys are to be programmed, then these must also be programmed to the 'immo' control unit.

Test condition:

  • Battery voltage above 12 V.

  • Ignition on, engine off.

  • All power consumers disconnected.

Procedure:

  1. Select the function: "Adaptation of remote control", press "OK".

    • All stored transponders are erased.

  2. A dialogue box shows "1" if transponder adaptation is possible.

  3. Press "Yes" to adapt transponders.

  4. Enter the number of transponders to be adapted in the entry field.

  5. A dialogue box confirms the number of transponders to be adapted.

  6. A dialogue box shows if the adaptation was successful or failed.

    • Time for adaptation (15 seconds) starts when the dialogue box "Function ready" is shown.

  7. Turn off the ignition and remove the key from the ignition (for diagnostics with the comfort system, the ignition does not have to be on to communicate with the system). Press and hold in for at least one second, one button on each transponder.

    • A flashing indicator confirms that the transponder is done.

  8. The function finishes automatically when:

    • The number of transponders to be adapted is reached.

    • A button is pressed several times on the same transponder.

    • Time for adaptation exceeds 15 seconds.

  9. Check function of all transponders.

    • If the function fails, check the test conditions and repair any faults.
