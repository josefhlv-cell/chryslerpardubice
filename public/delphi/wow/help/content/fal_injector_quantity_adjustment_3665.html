Injector programming
This function is used to individually program each injector, if one or several injectors has been replaced.
Note:
If an injector code that is entered is valid but have a poor injector quantity adjustment, this may cause a negative answer from the control unit and A:s are written to the control unit for this injector.
If a new control unit is mounted, the injector area in the control unit's EEPROM must be initiated, it is performed in this function.
The injector code consists of 7characters (numbers and letters).
If all the injectors has been replaced and the original control unit remains in the vehicle, the function "Reset fuel adaption" must be performed.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Select the function and follow the instructions in the program.
