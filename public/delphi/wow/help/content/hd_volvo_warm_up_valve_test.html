[467]Test of warm-up valve

The function is used to open and close the warm-up valve for the Adblue tank to check any electric problems in the valve.

  • Only electric problems are checked with this test.

Test conditions:

  • Parking brake applied.

  • Engine off.

  • Ignition on.

  • Battery voltage above 20V.

Procedure:

  1. Start the function.

  2. Activate the valve.

  3. Check status of the valve.

  4. The function is done.

    • If the function fails, check the conditions and repair any faults.
