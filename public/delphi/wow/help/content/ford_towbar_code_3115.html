Code trailer function
This function is used to code the trailer function.
The control unit must be coded according to the corresponding equipment in order for all functions to work correctly. For example, when retrofitting/removing trailer hitch, you have to code/decode on/off function for trailer for it to work correctly.
Note:
There must be a back-up of the configuration before coding in the new functions, see separate function.
Coding takes up to 2 minutes, during that time the diagnostic equipment may not be disconnected.
Coding shall be run in instruments and central electronics, for full functionality.
Test conditions:
  • Battery charger connected to vehicle.
  • Ignition on, engine off.
  • A back-up of the configuration.
Procedure:
  1. Start the function.
  2. A dialogue box is shown where the file with the back-up is to be selected.
  3. A dialogue box is shown where the VIN-number shall be entered to verify the back-up.
  4. The actual coding stored in the back-up is shown.
  5. A dialogue box shows a scroll list.
  6. Select the type of trailer function that has been installed/removed.
  7. Coding takes up to 2 minutes, during that time the diagnostic equipment may not be disconnected.
  8. The function is complete.
  9. If the function fails, check the test conditions and repair any faults.
