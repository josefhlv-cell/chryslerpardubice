[271]Test of AdBlue consumption

This function is used to compare expected consumed amount Adblue to actual consumption. By comparing these values to each other it is possible to detect errors in metering, or leaks in the system.

The presented values are consumed during the latest 15 driven hours.

Test conditions:

  • Ignition on, engine off.

  • Parking brake applied.

  • Adblue should be in the container.

Procedure:

  1. Start the function.

  2. Check test conditions, press "OK".

  3. Compare values, press "OK".

  4. The function is done, press "OK".

    • If the function fails, check the test conditions and repair any faults.
