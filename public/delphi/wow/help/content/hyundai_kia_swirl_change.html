[499]Reset adaptation values for swirl control valve

This function is used to reset the adaptation value for the swirl control valve. This has to be done after replacing the swirl control valve.

When adaptation is done the ignition must be turned off for 10 seconds before it is turned on again.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. If the function fails, check the test conditions and repair any faults.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
