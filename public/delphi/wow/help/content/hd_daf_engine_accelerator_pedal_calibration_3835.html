Accelerator pedal calibration
This function is used to calibrate the accelerator pedal.
Note:
Accelerator pedal calibration should be done after repair or replacement of the accelerator pedal.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. The calibration is performed.
  3. A dialogue box shows if the function succeeded or failed.
  4. If the function fails, check the test conditions.
