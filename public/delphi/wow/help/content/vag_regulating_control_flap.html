[1748]Basic setting of variable intake pipe

This function is used to perform basic setting of the control damper intake air in the engine control unit.

Basic setting shall be done when:

  • The control unit for control damper intake air has been removed and installed again.

  • The power supply to the engine control unit has been cut.

  • The engine control unit has been replaced.

After basic setting is done, the ignition should be off for at least 5 seconds to store the new values.

Test condition:

  • Ignition on, engine off.

  • Battery voltage above 11.5 V.

  • Accelerator pedal not affected.

  • Coolant temperature 5-100 °C.

  • Intake air temperature 5-100°C

Procedure:

  1. Select the function: "Control unit control damper", press "OK".

  2. During basic setting, "Adaptation in progress" is shown in the field diagnostic status.

  3. When basic setting is done, "Adaptation OK" or "Adaptation ERROR" is shown.

  4. Turn off the ignition for at least 5 seconds to store the new values.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
