Cylinder balancing
This function is used to evaluate if any or some injectors deviate too much in fuel injection so that engine properties are affected.
Test conditions:
  • PTO not active.
  • Cruise control is not active.
  • Transmission in neutral.
  • Parking brake applied.
  • Engine on.
  • Engine speed not to exceed 900 rpm.
  • Vehicle stationary.
Procedure:
  1. Start the function.
  2. Check test conditions.
  3. Check presented cylinder values.
  4. Function complete.
  • If the function fails, check the test conditions and try again.
