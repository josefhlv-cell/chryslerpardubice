Replacement air dryer
This function is used to replace a damaged air dryer control unit.
Note:
Check that a suitable new control unit is available.
When the new control unit is connected, initially it should only be connected electrically.
After approved programming, it can be installed.
Do not use any switches or any other unit during programming.
If the dryer cartridge is replaced, the air dryer shall be reset.
Test conditions:
  • Engine off.
  • Ignition on.
  • Parking brake applied.
  • Battery voltage above 20 V.
  • Fully compatible control unit available.
Procedure:
  1. Start the function.
  2. Check control unit data.
  3. Reading of data starts.
  4. Turn off the ignition and press "OK".
  5. Connect the new control unit only electrically.
  6. A dialogue box shows "Turn on ignition". Turn on the ignition, press "OK".
  7. Check that the control unit is compatible.
  8. Press "OK" to start programming.
  9. Programming is performed.
  10. Programming done.
  11. The function is done.
  • If the function fails, check the test conditions and repair any faults.
