[415]Replace control unit for electromechanical parking brake

When replacing control unit for parking brake, it is necessary to:

  • Code control unit for ABS again.

  • Perform basic setting of steering angle sensor, lateral acceleration sensor, brake pressure sensor, yaw rate sensor in ABS system.

  • Check coding / code control unit for electromechanical parking brake.

  • Perform basic setting of longitudinal acceleration sensor in electromechanical parking brake system.

  • Perform basic setting of parking brake.

Test conditions:

  • Parking brake released.

Procedure shall take place in the following order:

  1. Select system "ABS", read out parameter "variant coding" in basic data and note relevant code.

  2. Select system "Parking brake". If possible, read out parameter ""variant coding" in basic data and note relevant code.

  3. Replace control unit.

  4. Select system "ABS".

  5. Select function "code control unit", code control unit with relevant code.

  6. Select function "Initialization of the steering angle sensor".

  7. Select function "Zero compensation of lateral acceleration sensor".

  8. Select function "Zero compensation of brake pressure sensor".

  9. Select function "Zero compensation of yaw rate sensor".

  10. Select system "Parking brake".

  11. Check that it is correctly coded, otherwise select function "code control unit"

  12. Select function "Zero compensation of longitudinal acceleration sensor".

  13. Select function "Basic setting of brake system".

  14. Check that no fault codes are stored in ABS and the parking brake system.

  15. Exit the function.
