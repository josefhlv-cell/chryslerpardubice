[1066]Key programming

Test prerequisites:

  • The battery voltage should be >12V.

  • Ignition on, engine off.

  • No stored fault codes.

Procedure:

  1. Choose the function: Key programming.

  2. Observe the "Fasten seat belt"-lamp.

  3. Press periodically (1 sec) the lock-button on the key-remote until the "Fasten seat belt"-lamp flashes one time. More than 8 presses on the lock-button can be needed.

  4. If multiple keys should be programmed:

    • Remove the key from the ignition lock.

    • Insert the next key in the ignition lock.

    • Turn the key to position On.

    • Repeat steps 3 and 4.

  5. Exit the function by "Exit key programming".
