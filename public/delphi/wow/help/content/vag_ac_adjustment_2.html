[1254]Climate regulation

If the control unit for the climate regulation has been replaced, or a new shifting motor for the temperature damper has been installed, a basic setting must be performed. During the basic setting, the control unit learns the end positions of the shifting motor.

Test prerequisites:

  • The battery voltage should be above 11.5 V.

  • Ignition on, engine off.

  • No fault codes should be stored in the fault memory.

Performance:

  • Choose the function: Climate regulation.

  • At this basic setting, the temperature dampers shifting motors run to their end positions. The text: "motoren lernen" is presented and changes after a while to: "grundeinstellung durchgefuehrt".

  • Wait about 20 seconds (the climate control unit registrates the shifting motors new values and stores them).

  • End the function. Switch the ignition OFF/ON, wait about 15 seconds for possible fault codes to be stored.

  • Re-establish the communication and check if any fault codes have been stored.
