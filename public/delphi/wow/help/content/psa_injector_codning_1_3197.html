Programming injector codes
This function is used to program new injector codes in the engine control module.
Programming should be done when one or several injectors have been replaced.
The injector code compensates for manufacturing tolerances, for the engine to work optimally.
The injector code is stamped on the injector.
Note:
Valid characters are 0-9 and A-F.
Test prerequisites:
  • Ignition on, engine off.
  • Battery voltage above 12 Volts.
  • The injectors are installed correctly.
  • No faults stored.
Procedure:
  1. Start the function.
  2. A data list shows current injector codes in the control module.
  3. Select an injector to be programmed.
  4. Enter the injector code when instructed in the dialogue box.
  5. A dialogue box shows "Programming complete / Operation failed".
  6. Now it is possible to select another injector for coding.
  7. When coding is done, exit the function.
