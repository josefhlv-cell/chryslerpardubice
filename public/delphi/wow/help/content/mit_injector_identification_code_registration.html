[60]Injector programming

Since individual injectors have different properties the engine's electronic control unit corrects the injection time for each cylinder to improve injection accuracy. Corrected data is converted to an identification code containing 10 digits/letters stamped on the top of the injector.

Note:

If a new injector is not registered the engine warning indication lights up and fault code P1600 is generated.

Fault at registration of injector identification code will entail rough idling, abnormal engine noise, and poorer emissions.

Test conditions:

  • Ignition on.

Procedure:

  1. Ignition on.

  2. Select the function, "Injector programming".

  3. The old registered codes are shown. The code shown has, after the 10 digits/letters, an additional 6 zeros which are added, these zeros are not entered by the operator.

  4. Select the cylinder on which the injector is replaced.

  5. Enter the 10-digit code from the new injector, see figure.

  6. The new registered code is shown.

  7. When replacing more than 1 injector, select "Yes", otherwise "No".

  8. Fuel adaptation will be initiated in the next step.

  9. After the fuel adaptation's command has been sent the ignition shall be turned off for 30 seconds. Follow the instructions.

  10. Erase any fault codes.
