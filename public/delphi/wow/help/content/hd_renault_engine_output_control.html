[42]Output signals test

This function is used to activate a function and check that output signals are correct.

Activation is not continuous, it takes place in several cycles.

Test conditions:

  • Engine off.

  • Ignition on.

  • Parking brake applied.

  • Immobilizer inactive.

Procedure:

  1. Start the function.

  2. Press "Start" to activate the function.

  3. Check that the values change and that they are reasonable.

  4. Press "Stop" to turn off the activation.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
