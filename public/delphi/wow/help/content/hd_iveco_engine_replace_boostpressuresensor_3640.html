Reset adaptation values for the boost pressure sensor
This function is used to reset the adaptation values for the boost pressure sensor. It should be done after the boost pressure sensor has been replaced.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. The function is done.
  • If the function fails, check the test conditions and repair any faults.
