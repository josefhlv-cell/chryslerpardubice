Steering and learning of additional axle
This function controls and calibrates the additional axle's steering angle. In the function you set the steering angle, so that the vehicle is traveling straight ahead.
Note:
  • Engine running to keep the power steering pressure activated.
  • Before you run this function, learning of the front axle in the function "Learning of aligned axles" must be done.
Test conditions:
  • During actuation, the vehicle can be driven at a maximum speed of 15 km/h.
  • Learning of the front axle is done.
  • Engine running.
Procedure:
  1. Start the function.
  2. A dialogue box shows test conditions, check these and press "OK".
  3. A dialogue box shows with the steering angle on the additional axle. Press "OK".
  4. A dialogue box shows where you can set the actuation of the additional axle with the +/- buttons.
  5. Press "Set" to activate the actuation.
  6. A new dialogue box shows with the steering angle on the additional axle. Travels the vehicle straight ahead, then shall the calibration be performed by pressing "Yes". In other case press "No" to return to changing the actuation (step 4).
  7. The function is done.
    • If the function fails, check the test conditions and repair any faults.
