[1594]Erase EGR adaptation values

This function is only performed after the exhaust gas recirculation valve has been replaced.

Note:

Erase all faults that do not involve the EGR valve before programming. After having replaced the EGR valve, erase the offset value in the memory so the programming is coherent with the offset value of the new valve.

Test prerequisites:

  • Ignition on.

  • No faults which do not involve the EGR-valve.

Procedure:

  1. Start the function, follow the steps that are presented, you may abort at any time.

  2. After the offset values are erased datalists are shown, check the following parameters:

    "EGR valve position re-copy": (0.75 V - 1.5 V)

    "First EGR valve offset": (0,00 V)

    "Last EGR valve offset": (0,00 V)

    "EGR offset first programming": "Not performed"

  3. End the function, turn the ignition off and wait for the immobiliser warning light to flash.

  4. Turn ignition on and reconnect.

  5. Check the following parameters in the datalist:

    "EGR valve position re-copy": (0.75 V - 1.5 V)

    "First EGR valve offset": (0.75 V - 1.5 V)

    "Last EGR valve offset": (0.75 V - 1.5 V)

    "EGR offset first programming": "Performed"
