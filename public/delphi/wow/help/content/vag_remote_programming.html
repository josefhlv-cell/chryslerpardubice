[1383]Adaption of remote control

Adaption of a remote control (transponder) is necessary when replacing a faulty remote control or when increasing the number of remote controls (maximum four). It is also necessary if the code of the remote control and the control unit differ. This may happen if the transmit button is frequently pressed when the remote control is out of range.

Note:

  • All the remote controls must always be adapted, including the existing ones.

  • The time taken to adapt all remote controls must not exceed fifteen seconds.

  • New ignition keys must also be adapted to the immobiliser control unit.

Test prerequisites:

  • The battery voltage should be at least 12V.

  • Ignition on, engine off.

  • All electrical loads should be switched off.

Procedure:

  1. Insert one of the ignition keys in the ignition lock.

  2. Start the function 'Adaption of remote control'.

    • All old remote controls are now deleted.

    • All remote controls must always be adapted, including the existing ones.

  3. A dialog box will present '1' if an adaption of the remote control is possible, confirm with 'YES' to adapt new remote controls.

  4. Enter the total number of remote controls to be adapted in the presented input field, confirm with 'OK'.

  5. A dialog box will present the number of remote controls to be adapted, confirm with 'YES'.

  6. A dialog box will present if the system is ready for an adaption of new remote controls, confirm with 'OK'.

    • The adaption time starts when the dialog box is presented.

  7. Press a button on each remote control for at least one second.

    • A flashing in the direction indicators will confirm that the remote control is adapted.

  8. The adaption is terminated automatically when:

    • The number of remote controls to be adapted is reached.

    • A button is pressed more than once on the same remote control.

    • The time taken to adapt all remote controls exceeds fifteen seconds.

  9. Switch off the ignition and remove the ignition key.

  10. Check the operation of all the remote controls.
