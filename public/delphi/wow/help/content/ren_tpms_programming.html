[708]Programming new valve codes

Note:

This function must only be performed if one or more valves has been replaced, or during valve replacement. Before programming takes place, the tyres must be pumped to a pressure of 3.8 Bar. When the programming is complete, the tyres must be returned to the recommended pressure.

Test conditions:

  • Tyre pressure of 3.8 bar.

  • Access to a valve activator.

  • No faults in the system.

  • Ignition on, engine off.

Procedure:

  1. Fill air in the four tyres to 3.8 bar.

  2. Start the function.

  3. Follow the instructions in the program.

  4. When the function is ready, return the tyre pressure in all four wheels to the recommended pressure.
