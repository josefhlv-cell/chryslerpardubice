[1757]Testing lambda control

This function is used to see the lambda adaptation value by alternately letting the coal canister valve be "closed" or "active" (active approx. 220-900 seconds open and closed approx. 70 seconds). Lambda adaptation values for bank 1 and bank 2 are shown.

Test conditions:

  • Engine idling.

  • No faults in the system.

  • Engine temperature above 80 °C.

  • No leaks in the exhaust system.

  • Gear in position P/N.

Procedure:

  1. Select the function: "Lambda adaptation", press "OK".

  2. Read off the value columns. Required results: additive lambda adaptation (cylinder bank 1 and 2) –10% to 10% and multiplicative lambda adaptation (cylinder bank 1 and 2) –10% to 10%.

  3. Switch between coal canister "closed" or "active" using the buttons in the function.

  4. When the function finishes, the coal canister valve is activated automatically.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
