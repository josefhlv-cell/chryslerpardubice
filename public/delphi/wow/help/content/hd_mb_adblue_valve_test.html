[472]Solenoid valve test

This function is used to check solenoid valves.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. A dialogue box shows test conditions, check these and press "OK"

  3. Select component to be activated or deactivated.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
