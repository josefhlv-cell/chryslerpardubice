[608]Check emergency release

This function is used when:

  • To check the function of the emergency release.

  • Work has been done that affects the brake system.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • The vehicle must stand on level ground.

  • Make sure that the vehicle cannot start to roll.

Procedure:

  1. Start the function and follow the instructions in the program.

    • A dialogue box will be shown if braking power is not within correct interval.

  2. The function is done.

    • If the function fails, check the test conditions and repair any faults.
