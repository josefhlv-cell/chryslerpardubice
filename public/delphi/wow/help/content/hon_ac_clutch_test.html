[188]Testing AC-clutch

This test is used to check the AC-clutch's function. During the test the AC-clutch cuts in and out and a loud clicking sound is heard from the engine compartment when the AC-clutch is activated.

Test conditions:

  • Ignition on, engine off.

  • Parking brake applied.

  • Transmission in neutral.

Procedure:

  1. Start the function.

  2. Follow the instructions.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
