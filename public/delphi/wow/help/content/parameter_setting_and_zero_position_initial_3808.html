Parameter setting and zero position initialization
This function is used to set the specifications for the headlights and to initialize the height sensor.
Note:
The specifications for the headlights varies according to the vehicle model.
This function must be performed when the module or the height sensor has been replaced.
Test conditions:
  • Ignition on, engine off.
  • Battery voltage min 12 V.
  • No fault codes should be stored in the fault memory.
  • Vehicle stationary.
  • No additional load or persons in the car.
Procedure:
  1. Start the function.
  2. Follow the instructions in the program.
  3. When the function is complete, check the headlight angle and vehicle model in the data lists.
  • If the function fails, check the test conditions and repair any faults.
