[1429]Self test GEM

This function is a self test of the system, where a number of components selected by the control unit are loaded (activated). If the control unit detects an incorrect value on any component a fault code is stored in the system. The function finishes with a reading of fault codes where possible fault codes stored in the system are displayed.

Note:

  • Erase fault codes before the self test to avoid that historical fault codes are displayed.

  • The anti-theft horn and the flashers will be activated during this test.

  • Do not activate switches or controls during the self test.

Test prerequisites:

  • Battery voltage OK.

  • Vehicle stationary.

  • All doors opened.

  • Hood and boot lid closed.

  • Windscreen wipers in interval position.

Procedure:

  1. Choose the function: Self test

  2. The self test starts and the components are activated one by one.

    • The self test can be aborted by "Abort".

  3. When the self test is finished a reading of fault codes is automatically performed.
