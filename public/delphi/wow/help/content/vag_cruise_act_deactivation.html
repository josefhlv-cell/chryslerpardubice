[1516]Activate/deactivate cruise control

When an installation of the cruise control is performed, it is necessary to activate the cruise control function in the engine control unit. It is also possible to deactivate the function, if the cruise control is removed.

Note:

  • Some models require re-encoding of the control unit for steering wheel electronics for correct functionality, see manual for cruise control.

Test condition:

  • Battery voltage above 11.5 V.

  • Ignition on.

Procedure:

  • Press OK to start the function.

  • Confirm with OK to activate/deactivate the cruise control function.

  • A dialog box presents: Operation succeeded/failed. Confirm with OK.

    • If the text "Operation failed" is presented, check the cruise control installation.

  • Exit function.
