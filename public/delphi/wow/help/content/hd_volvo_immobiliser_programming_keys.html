[659]Key programming

This function copies the start key's code to the control unit and presents the key number.

Note:

The key shall be in driving position during the operation.

Other keys shall not be in the vicinity of the transponder.

If several keys shall be programmed, repeat the procedure for the non-programmed keys.

Up to 6 keys can be programmed.

Test conditions:

  • Parking brake applied.

  • Engine off.

  • Ignition on.

Procedure:

  1. Start the function.

  2. Check conditions.

  3. Check the status for the function.

  4. Check key number.

  5. Turn off the ignition.

  6. Wait 10 seconds.

  7. Turn on the ignition.

  8. The function is done.

    If the function fails, check the test conditions and repair any faults.
