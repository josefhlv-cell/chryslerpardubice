Replacing control unit
This function is used to read data from the faulty control unit and to enter data to the new control unit. The function should only be performed after replacement of control unit.
Note:
Have more components been replaced in conjunction with the control unit, the function "Replacing control unit" must always be performed first.
If the control unit to be read does not support reading, the function will not be possible to perform. This does not affect the operation of the system negatively.
In these cases, to complete replacement of the control unit, the functions below should be performed in the following order:
  1. End of line/service calibration.
  2. Clutch self-calibration.
Test conditions:
  • Ignition on, engine off.
  • Control unit not replaced.
Procedure:
  1. Start the function.
  2. Select "Store data" to read and store the data from the faulty control unit.
  3. Replace control unit.
  4. Start the function again and select "Transfer data" to download the stored data to the new control unit.
  5. The function is complete.
  6. Perform the function "End of line/service calibration".
  7. Perform the function "Clutch self-calibration".
  8. The replacement of the control unit is now complete.
