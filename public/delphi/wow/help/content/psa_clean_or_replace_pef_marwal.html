[334]Reset counter for additive

This function is used to reset the counter for additive amount injected in the particle filter. This shall only be done after cleaning or replacing particle filter (PEF) according to service instructions for the car.

Test conditions:

  • Ignition on, engine off.

  • All power consumers disconnected.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. A dialogue box shows if the function succeeded or failed.

  3. Complete the function and disconnect the diagnostic tool.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
