[1735]Activate transport mode

This function is used to activate or deactivate "Transport mode". Transport mode is intended to minimize current consumption in the car by limiting the car's functionality or completely disconnecting certain functions.

Test conditions:

  • Ignition on.

  • Battery voltage above 12 V.

Procedure:

  1. Select the function: "Transport mode".

  2. A dialogue box shows the current value. Press "OK" to change the value.

  3. Select relevant value, press "OK". A dialogue box shows the new value. Press "OK".

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
