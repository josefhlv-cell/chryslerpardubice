Programming tire size
This function is used to configure the car's tire size, to obtain a correct calculation of the car's speed.
Note:
The function should only be run if the tire size has been changed.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. A dialog box presents the current tire size. Press "OK" to program the new tire size.
  3. Select correct tire size in the list.
  4. After succeded programming is the new tire size displayed.
