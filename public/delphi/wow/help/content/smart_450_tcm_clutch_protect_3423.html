Reset the clutch safety class
This function is used to reset the stored adaptation values in the transmission's control unit.
Test Prerequisites:
  • Ignition on, engine off.
  • Vehicle stationary.
  • Battery voltage above 12V.
  • Gear selector in neutral position.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. Adaptation values are erased.
  3. A dialogue box shows "Operation successful/failed".
  4. If the function fails, check the test prerequisites and repair possible fault codes.
