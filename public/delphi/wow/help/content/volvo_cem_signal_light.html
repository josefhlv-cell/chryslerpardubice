[1647]Configuring warning sound for low beams

This service enables programming a warning for low beam position.

Programming is only possible on vehicles equipped with Bi-Xenon lights and where the light switch is programmed as "Flexstd". Two alternatives are possible:

  • "OFF"

  • "ON"

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the function: "Programming warning sound for low beams", press "OK".

  2. A dialogue box with present configuration is shown.

  3. Press "OK" to proceed.

  4. Select desired value: "ON" or "OFF", press "OK" to start programming.

  5. Programmed value is shown after successful programming.

  6. Press "OK" to exit the function.
