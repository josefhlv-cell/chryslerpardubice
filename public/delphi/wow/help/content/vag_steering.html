[1387]Steering assistance basic setting

This basic setting is used to erase the electromechanical steering assistance learning values. After this is performed, a manual procedure shall be done to learn the new values in the steering assistance system.

This must be done if:

  • The steering servo has been replaced or removed.

  • A repair of the steering angle sensor or the steering system has been performed.

  • A basic setting of the steering angle sensor has been performed.

  • A fault code that requires a basic setting is stored in the steering assistance control unit.

Note:

The steering angle sensor must have been correctly initiated before a basic setting of the steering assistance is performed.

Test prerequisities:

  • The battery voltage should be >12 V.

  • Ignition on, engine off.

Procedure:

  1. Choose the function: Steering assistance.

  2. A dialogue box confirms: operation succeeded/failed

  3. Confirm with OK.

  4. Start the engine, turn the steering wheel to the straight ahead position (the front wheels straight forward) at least 2 seconds without moving the steering wheel.

  5. Turn carefully the steering wheel to the left end position and hold for a while. Turn carefully the steering wheel to the right end position and hold for a while. Turn back the steering wheel to the straight ahead position (the front wheels straight forward). The control lamp for the electromechanical steering assistance turns off.

  6. Switch OFF/ON the ignition. Read and erase fault codes in the steering assistance system.
