[729]Activation / deactivation of the TPMS system

This function is used to activate/deactivate the TPMS system.

The function is performed in multiple systems.

Note:

The function consists of several steps that the user must perform.

Check first that the function is supported in the relevant BSI version (start BSI and check that the function can be selected).

Activate/deactivate the system in the TPMS system, and then in the BSI system.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • TPMS system fitted to the vehicle.

Procedure:

  1. Activate/Deactivate the system in the TPMS system.

  2. Select the function and follow the instructions in the program.

  3. A dialogue box shows "Operation successful/failed".

  4. Function complete.

  5. Then exit the TPMS system and enter the BSI system.

  6. Perform the same procedure in the BSI system.

  7. Follow the instructions in the program.

  8. A dialogue box shows "Operation successful/failed".

  9. Function complete.

  10. Read and erase any fault codes in the TPMS and BSI systems.

  11. Ready.
