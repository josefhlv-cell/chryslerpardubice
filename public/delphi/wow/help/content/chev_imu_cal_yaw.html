[690]Calibrate yaw angle sensor

This function is used to calibrate the yaw angle sensor.

Learning of yaw angle sensor after certain service operations:

  • Replacement of electronic brake control module (EBCM).

  • Replacement of acceleration sensor.

Note:

Calibration should be performed in the following order:

  1. Yaw Rate Sensor Reset.

  2. Yaw Rate Sensor Learn.

Test conditions:

  • Ignition on, engine off.

  • The vehicle must be standing on level ground.

  • Parking brake applied or gear selector in position P.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is complete.
