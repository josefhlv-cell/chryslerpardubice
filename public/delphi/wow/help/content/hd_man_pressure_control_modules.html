[688]Pressure control modules

This function is used to check the brake system's air lines and integrated pressure sensors.

Note:

Make sure that the vehicle's wheels are blocked to prevent it from starting to roll.

Connect a pressure gauge to the brake's connection head.

The function will apply a pressure of approx. 4 bar on the selected pressure control module.

Test conditions:

  • Ignition on.

  • Parking brake not applied.

  • Air in brake system.

  • Vehicle's wheels blocked.

Procedure:

  1. Start the function.

  2. Select the module to be tested.

  3. Press "Start".

  4. Check that the integrated pressure sensor shows approx. the same as the pressure gauge installed on the brake's connection head.

  5. Press "Stop".

  6. Repeat for the other modules.

  7. Function done.

    • If the function fails, check the test conditions and repair any faults.
