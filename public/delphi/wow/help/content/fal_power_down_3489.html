System shutdown
This function is used to perform a system shutdown.
Note:
The behavior of the function is the same as using the shut down button on the front panel. The ECU responds to the command and soon after it turns off.
Preconditions for the test:
  • Ignition on, engine off.
  • ETM (Entertainment telematics module) on.
Procedure:
  1. Start the function and follow the instructions in the program.
