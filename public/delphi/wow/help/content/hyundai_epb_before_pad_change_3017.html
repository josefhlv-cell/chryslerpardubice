Changing of brakepads.
This function releases the brake pads and must be used before replacement of the brake callipers or rear pads.
Note:
The function takes around 30 seconds. When the repair is done the service mode must be deactivated to restore the brake system.
This function must be run before work on the brake pads.
Preconditions for the test:
  • Ignition on, engine off.
  • No faults in the system.
Procedure:
  1. Depress and hold the brake pedal.
  2. Start the function.
  3. Keep the brake pedal depressed until the engine stops and the process is complete.
