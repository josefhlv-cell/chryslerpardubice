[160]Calibrate yaw sensor

This function shall be run when replacing yaw rate sensor or "ASC" control module. Before calibrating, check that there are no fault codes related to the yaw rate sensor stored in the system.

Test conditions:

  • Ignition on.

  • No faults in the system.

  • The vehicle must stand on level ground.

Procedure:

  1. Start the function.

  2. Follow instructions.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
