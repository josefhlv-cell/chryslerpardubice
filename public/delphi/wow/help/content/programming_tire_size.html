[1115]PROGRAMMING TIRE SIZE OPEL VIVARO

Programming:

  • To get the ABS-ECU the right vehicle speed signal it needs that the right tiredimension is programmed.

Following tirecodes applying to Vivaro:

  • 195/65 16 : 85

  • 205/65 16 : 127

  • 215/65 16 : 170

Performance:

  • Read which code is available for the car.

  • Write the current code in the field for programming tire size.

  • Press the OK-buttom.

  • A dialogue confirm: Operation succeed / Operation not succeed.

  • Check that the right value are programmed in data list 3.
