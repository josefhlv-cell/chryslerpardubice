Programming of valve codes
This function is used to manually enter new identification numbers for the tire pressure sensors.
Test conditions:
  • Ignition on.
  • Battery voltage above 11.5 V.
  • The 8-digit identification number available.
Procedure:
  1. Start the function.
  2. The stored values are shown, select whether you want to change any value or cancel.
  3. Select the position to be changed.
  4. Enter the 8-digit identification number (0xxxxxxx).
  5. The new values are presented, make sure that they are correct.
  6. Repeat the function if more positions should be changed.
