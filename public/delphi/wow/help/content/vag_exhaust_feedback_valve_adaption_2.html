[457]Reset adaptation values for exhaust gas recirculation valve 1

This function enables reset of the exhaust gas recirculation valve's adaptation values. This should be done if:

  • The exhaust feedback valve has been replaced.

  • The exhaust feedback valve has been repaired.

  • The engine control unit has been replaced.

During reset the control light for pre-glow time indicates.

Test conditions:

  • Engine on.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. When the function is done, exit communication with the car and turn off the ignition for 30 seconds.

  4. Turn on the ignition again, re-establish communication with the car, and check that no fault codes are stored.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
