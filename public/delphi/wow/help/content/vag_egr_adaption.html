[172]Basic setting of EGR-valve

This function is used for basic setting of the EGR-valve. This must be done if:

  • EGR-valve has been replaced.

  • Repair of EGR-valve has been performed.

  • The engine control unit has been replaced.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. Confirm with "OK". Adaptation starts and a dialogue box shows "Test active".

  3. After adaptation is complete, the display shows "Test finished".

  4. Press "OK" when the function is complete.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
