Wheel speed sensors
This function is used to check the wheel speed sensors' status.
Note:
The ASR-function is deactivated during the test to avoid control processes when the wheels are rotated.
Test conditions:
  • Engine running.
  • Ignition on.
  • Transmission in neutral.
  • Make sure that the vehicle cannot start to roll.
Procedure:
  1. Start the function.
  2. Check test conditions.
  3. Accelerate the vehicle to 10 km/h.
  4. If the sensors are correct, the test is terminated automatically.
  5. Function done.
  • If the function fails, check the test conditions and repair any faults.
