Injector programming
Due to tolerances when manufacturing the injectors the injected fuel quantity may deviate between the actual and calculated fuel quantity. After manufacture these deviations are determined for every injector and a calibration value is determined, the value is converted to a code which is stamped on the injectors. This code is programmed in the engine control unit for each cylinder. Using these codes, the engine control unit corrects the calculated fuel quantity individually for each cylinder and thus improves engine operation and exhaust emissions. With this function, new calibration values can be entered in the engine control unit when replacing injectors or the engine control unit.
Note:
All current injector codes are reset and must therefore be reprogrammed. Note the current injector codes if old valves are still in place.
Every injector has a unique code of 9 characters. The code is located at the top of the injector.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. The old registered codes are shown.
  3. To enter new injector code, press "OK".
  4. Dialogue boxes are displayed for each injector, with instructions to enter the current code.
  5. Enter the injector code when instructed in the dialogue box.
  6. When all injectors are programmed, the new injector codes are shown.
  • If the function is cancelled or fails, check fault codes and test conditions.
