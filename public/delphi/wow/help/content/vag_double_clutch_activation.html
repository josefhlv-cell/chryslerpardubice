[1472]Double clutch

In the ABS control unit in vehicles with a gearbox with a double clutch, there is a function to activate/deactivate a sportmode.

Note:

It is only possible to activate the double clutch function on control units that support the function.

Test prerequisites:

  • Ignition on.

  • Battery voltage above 12 volt.

  • No fault codes stored.

Procedure:

  1. Choose the function: 'Double clutch'.

  2. A dialog box presents the actual adaption value for the double clutch. Confirm with "Yes" to change the value. If the value should not to be changed, the function is aborted with "Abort"

    The following learning values shall be used:

    • 0= Sportmode deactivated

    • 1= Sportmode activated

  3. Write the actual value for the vehicle. Confirm with "OK".

  4. A dialog box presents the new value.

  5. Confirm with "OK" to store the new value.

    • If the dialog box "Operation failed" is presented, the function is not supported and the old value is automatically resumed.
