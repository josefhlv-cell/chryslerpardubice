[710]Calibration of the control unit for the electronic parking brake

This function is used to calibrate the electronic parking brake.

Note:

  1. Calibration must take place after the following work has taken place:

    • Replacement of the electronic parking brake controller.

    • Replacement of the "traction system hydraulic unit" and "electronic stability program control unit" components.

  2. The vehicle must be positioned so that it cannot begin to roll when the parking brake is released.

Test conditions:

  • The vehicle must be standing on level ground.

  • Make sure that the vehicle cannot start to roll.

  • Parking brake released.

  • Ignition on, engine off.

  • Battery voltage above 12.5V.

Procedure:

  1. Start the function

  2. Follow the instructions in the program.

    • If the function fails, check the test conditions and repair any faults.
