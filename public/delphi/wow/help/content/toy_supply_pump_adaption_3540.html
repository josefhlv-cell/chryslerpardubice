Supply pump initialization
This function is used to reset the learning value for the supply pump.
Note:
Use this function if:
  • The engine has problems to start after the supply pump has been replaced.
  • After the supply pump has been replaced, the engine starts but stops shortly after.
Test conditions:
  • Ignition ON.
  • Engine OFF.
Procedure:
  1. Start the function.
  2. The function is done.
  3. If the function fails, check the test conditions and repair any faults.
