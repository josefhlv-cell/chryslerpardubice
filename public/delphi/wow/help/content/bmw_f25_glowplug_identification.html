[591]Identifying glow plug

Note:

Identification of glow plug must be performed after changing glow plug control unit or glow plug.

The service function covers two functions, which are necessary in case of repairs to the glow system, these must be done in the right order to avoid malfunction of pre-flowing or damage to the glow plugs.

  • Activation of safety data entry must be performed before changing glow plug. Two fault indications will be generated at activation, these will be erased at the end of glow plug identification.

  • Glow plug identification must be performed after changing glow plug or glow plug control unit. The function checks the following:

    • The glow plug control unit identifies all glow plugs.

    • If correct glow plug type is installed.

    • That correct data entry is activated in the glow plug control unit.

Different glow plug types are used, depending on engine power. The following table shows which engines and glow plug types are used:

Test conditions:

  • Battery charger may not be connected!

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Select the procedure to be performed.

  3. Work through the selected procedure.
