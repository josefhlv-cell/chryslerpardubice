[356]Calibrate steering angle sensor

This function is used to calibrate the steering wheel angle sensor. Calibration of the steering wheel angle sensor shall be run when the following service work has been done:

  • Any change of the front wheel direction.

  • Collision or other physical damage.

  • Replacement of electronic brake control module (EBCM).

  • Intermediate shaft replacement.

  • Steering angle sensor replacement.

  • Replacing steering gear.

  • Replacement of steering column.

  • Outer tie rod replacement.

Calibration should be performed in the following order:

  1. Select "Resetting steering wheel angle sensor" in Steering wheel angle sensor module (SAS).

  2. Select "Teach-in steering wheel angle sensor" in Steering wheel angle sensor module (SAS).

  3. Select "Teach-in steering wheel angle sensor" in brake control module (EBCM).

  4. Erase any fault codes.

Test conditions:

  • Ignition on, engine off.

  • The steering wheel stands straight and the front wheels point straight forward.

  • Parking brake applied.

  • Gear selector in position P.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done

    • If the function fails, check the test conditions and repair any faults.
