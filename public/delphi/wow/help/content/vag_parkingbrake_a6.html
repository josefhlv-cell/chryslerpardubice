[386]Replace control unit for electromechanical parking brake

When replacing the control unit for parking brake it is necessary to code it again. Before coding it is necessary to perform a basic setting as well as calibration of acceleration sensor longitudinal for the parking brake.

Test conditions:

  • Parking brake released.

Procedure shall take place in the following order:

  1. If possible, read out relevant code for the old control unit.

  2. Replace control unit.

  3. Select the function "Basic setting of brake system" (see help for this function).

  4. Select the function "Zero compensation of acceleration sensor longitudinal" (see help for this function).

  5. Select the function "code control unit" (see help for this function).
