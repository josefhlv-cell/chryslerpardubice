[411]Deactivate service mode on parking brake

Run this function to return to operating mode when the parking brake is in service mode.

The parking brake shall be installed correctly before the function is used.

Test conditions:

  • Ignition on.

  • Battery voltage above 12V.

  • Vehicle stationary.

  • The vehicle must stand on level ground.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
