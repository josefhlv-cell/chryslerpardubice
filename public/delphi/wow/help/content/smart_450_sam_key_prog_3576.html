Transponder key programming
This function is used when new or existing transponder keys needs to be programmed to the car.
Note:
All keys must be available and functioning.
Preconditions for the test:
  • Ignition on, engine off.
  • When adapting new keys to the car, all keys, old and new, MUST be available before programming. All keys must be reprogrammed.
Procedure:
  1. Start the function.
  2. Confirm that you want to start programming. Note that already stored keys must be programmed again.
  3. Turn off the ignition and remove the key.
  4. Now begins a period of 30 seconds for key programming. During this period, the immobiliser lamp will begin to flash.
  5. To program a key, the lock button must be pressed twice. At successfull programming, the immobiliser lamp turns off briefly.
  6. When the immobiliser lamp begins to flash again, the next key can be programmed according to step 5.
  7. Complete the programming by inserting a key and turning the ignition on.
  8. The function is done.
