[333]Service work on transmission

This function is used if any of the following service actions have been performed:

  • Installing new automatic transmission with original transmission control unit.

  • Removing and installing gear lever or gear lever cable.

  • Draining and filling transmission oil.

  • Installing new transmission control unit.

  • Installing new automatic transmission with new transmission control unit.

Transmission and control unit shall be correctly installed and connected before the function can be started.

WorkFunction
Installing new automatic transmission with original transmission control unit.

  • Erases transmission's data before adaptation.

  • Erase tables with learned gearshifting values.

  • Reset counter for deteriorated transmission oil.

  • Neutral position teach-in

  • Instruct transmission control unit to learn the transmission's adaptive values.

    • A driving cycle shall be run in this function.

Removing and installing gear lever or gear lever cable.

  • Neutral position teach-in

Draining and filling transmission oil.

  • Reset counter for deteriorated transmission oil.

Installing new transmission control unit.

  • Neutral position teach-in

  • Instruct transmission control unit to learn the transmission's adaptive values.

    • A driving cycle shall be run in this function.

Installing new automatic transmission with new transmission control unit.

  • Neutral position teach-in

  • Instruct transmission control unit to learn the transmission's adaptive values.

    • A driving cycle shall be run in this function.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
