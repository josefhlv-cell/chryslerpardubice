Fuel injector injection amount learning
This function is used to learn the correct fuel injection amount for the vehicle injectors.
Note:
Once the learning process is started, it must not be canceled before it is completed. If it is canceled, turn off the ignition for at least 15 seconds before starting the function again. The vehicle's engine speed may change during the process.
Preconditions for the test:
  • The engine on idle running.
  • Engine temperature above 80 °C.
  • All electrical loads should be switched off.
Procedure:
  1. Press the OK button to start learning process.
