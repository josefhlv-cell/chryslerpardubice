Cylinder shut-off
This function is used to temporary turn off one injector at a time to check the injector function. The function must be performed with the engine running. When selected injector is turned off, the engine will run rough.
Test conditions:
  • Engine running.
  • Parking brake applied.
  • Transmission in neutral.
  • Do not touch the accelerator pedal during the test.
Procedure:
  1. Start the function.
  2. Select desired cylinder in the dropdown list and press "OK".
  3. To turn off selected cylinder press "OK".
  4. To turn on selected cylinder again press "OK".
  5. Then wait for 60 seconds before a new cylinder can be selected.
  6. The function is done.
    • If the function fails, check the test conditions and repair any faults.
