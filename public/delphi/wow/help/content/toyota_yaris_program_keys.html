[1235]Key programming

This function is used to registrate extra master keys or sub keys in to the immobiliser system.

Note:

  • You must start with a registrated master key.

  • Key code registration will fail if the time limit is exceeded.

Test prerequisites:

  • The battery voltage should be >12V.

  • Ignition on, engine off.

  • No stored fault codes.

  • A registrated master key in the ignition lock.

  • A new key to program.

Procedure:

  1. Choose the function: Key programming.

  2. Dialogue box: Engine off, ignition on, see help for further information. Press OK to continue.

  3. Dialogue box: Master key in the ignition lock and ignition on, confirm with OK.

    • If you want to cancel key programming, press abort.

  4. Dialogue box: Choose key.

  5. Choose if the new key should be a master key or a sub key, and press OK.

    • If you want to cancel key programming, press abort.

  6. Dialogue box: Press OK and then turn the ignition off, remove the master key and insert the key that should be programmed (the ignition must be off) within 20s.

    • Note: Programming will fail if the time limit is exceeded.

    • Note: Don´t turn ignition off before you have pressed OK.

    • Note: Ignition must be off when the new key is being programmed.

  7. Dialogue box: When security indicator stops flashing, it will take about 60s, turn ignition on and press OK.

    • The security indicator is located on the instrument panel.

  8. A dialogue box displays the number of programmed transponder keys and key discrimination.

If the key programming has failed:

  • The time limits may have been exceeded.

  • At point 6, the ignition must not be turned off before OK is pressed.

  • Check the battery voltage.

  • Check that you have started this operation with a registrated master key (read datalist: key discrimination).

  • Check that no fault codes are stored.

  • The ignition must be off when the new key is being programmed.

    Restart this function to try again.
