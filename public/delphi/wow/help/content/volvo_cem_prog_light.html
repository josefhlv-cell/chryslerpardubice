[1644]Programming light function

There are three variants of light functions to program:

  1. "Flexzero": Low beams on in all light switch positions except in position for parking lights.

    Position light switch:

    • OFF: Parking lights and running lights or Bi-Xenon lights activated by the dusk sensor.

    • Parking lights: Only parking lights activated.

    • On: Parking lights and Bi-Xenon lights activated.

  2. "Flexstd": Light switch functions as follows: off, parking lights, and low beams.

    Position light switch:

    • OFF: Running lights activated. If the dusk sensor registers insufficient light, all lighting is turned off (Bi-Xenon lights not activated).

    • Parking lights: Only parking lights activated.

    • On: Parking lights and Bi-Xenon lights activated.

  3. "Flexlgt": Low beams always on, regardless of light switch position.

    Position light switch:

    • OFF: Parking lights and running lights or Bi-Xenon lights activated depending on signal from the dusk sensor.

    • Parking lights: Parking lights and Bi-Xenon lights activated.

    • On: Parking lights and Bi-Xenon lights activated.

  4. "Stop": Reverts to the vehicle's basic setting.

Note:

Check programmed status for running lights. For running light functions "Flexzero, "Flexstd", and "Flexlgt" to work at position "OFF" on the light switch, status of running lights must be: "Activated with sensor".

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select the function: "Programming running lights", press "OK".

  2. A dialogue box with present light function is shown.

  3. Press "OK" to change running light function.

  4. Select desired "running light function", press "OK" to start programming.

  5. After successful programming, the programmed running light function is shown.

  6. Press "OK" to exit the function.
