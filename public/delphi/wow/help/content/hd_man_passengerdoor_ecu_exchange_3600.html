Replacement list for control units passenger door
This function is used when you are replacing the door module, read the list below to see which part number that you can replace with.
Procedure:
  1. Turn the ignition off.
  2. Remove the old control unit.
  3. Fit the new control unit.
  4. Turn the ignition on.
