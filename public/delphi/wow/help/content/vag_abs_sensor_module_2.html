[624]Reset adaptation for sensor unit ESP

The sensors for lateral acceleration, yaw rate, and fore-aft acceleration are all installed in the control unit for ABS and cannot be replaced separately. This function is used to reset the adaptation values for all sensor. This should be done if:

  • The ABS control unit has been replaced.

  • Error code that requires resetting is stored in the ABS control unit.

Note:

During resetting, the ignition may not be turned off.

Test conditions:

  • Battery voltage above 12V.

  • Ignition on, engine off.

Procedure:

  1. Place the car on level ground.

  2. Select basic setting "Zero compensation of sensor unit ESP".

  3. The text "Adaptation in order" confirms that reset has been performed. If the value for any of the sensors is too high the reset is not accepted.

  4. Exit the function and check the value for the sensors in the data list.
