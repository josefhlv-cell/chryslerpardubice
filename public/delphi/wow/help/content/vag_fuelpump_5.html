[1574]Fuel system bleeding

If there is air in the fuel system after a repair has been performed, it is possible to bleed the system with this function by activating the fuel pump approximately for 70 seconds.

Note:

  • This function shall only be performed on sealed fuel systems.

  • If the high pressure pump has been replaced, it may be necessary to bleed the system several times.

Test prerequisities:

  • Ignition on, engine off

  • Battery voltage higher than 12 V.

  • No faults stored.

  • No leakage in the fuel system.

Procedure:

  1. Choose the function: "Fuel pump activation" - The fuel pump starts (the value for the fuel pump status changes to "Pump on").

  2. Let the pump run for 70 seconds.

  3. Exit the function to end the bleeding.

  4. Finish the communication. Switch off the ignition.

  5. If necessary, repeat the bleeding.
