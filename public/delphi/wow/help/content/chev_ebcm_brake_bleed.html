[691]Automatic brake bleeding

This function is used to bleed the brake system.

Note:

Comply with the manufacturer's instructions before using the brake bleeding equipment.

Test conditions:

  • Ignition on, engine off.

  • Connect the necessary equipment for bleeding the brakes.

  • Battery charger connected to vehicle.

  • Place the gear lever in park or neutral.

Procedure:

  1. Start the function and follow the instructions in the program.
