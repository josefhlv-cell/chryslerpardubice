[727]Transfer of basic module parameters to the mirror memory

This function transfers data from the virtual controller and external controller to the mirror memory. You can also choose to download service life data from the controller WS to the mirror memory.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. A dialogue box shows the test conditions; check these and press "OK".

  2. A dialogue box asks "Do you want to transfer parameters in the basic module to the mirror memory" Press "YES" if you want to continue the function. Press "NO" to cancel the function.

  3. Transfer begins, follow the instructions.

  4. A dialogue box asks if you want to transfer service life data from the vehicle WS to the mirror memory.

  5. The function is complete.

    • If the function fails, check the test conditions and repair any faults.
