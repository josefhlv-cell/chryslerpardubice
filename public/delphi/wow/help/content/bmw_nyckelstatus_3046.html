Read out key status
This function is used to read out the key number and the key status. The key number is registered in the factory during initial programming and cannot be changed. There is no fixed allocation of the key number for key execution (main key, spare key, workshop key). Therefore, before a key can be blocked, the missing key number must be determined. The key status displays whether a key is active, released, blocked, used or never used. To enable the key status to be indicated, a valid, released and fault-free key must be in ignition position 1 or 2.
Note:
Keys are blocked or released using the function "Block and release central key".
Test conditions:
  • Ignition on.
Execution:
  1. Start the function.
  2. Follow the instructions in the program.
  3. Function complete.
