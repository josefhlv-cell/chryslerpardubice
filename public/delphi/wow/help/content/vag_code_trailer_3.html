[1470]Coding trailer control unit

When installation of a towbar and a trailer control unit is performed, it is necessary to code the trailer control unit to get all the functions to work correctly.

Note:

  • A new control unit can have code 0 stored.

Test prerequisities:

  • The battery voltage should be above 12V.

  • Ignition on, engine off.

  • No faults should be stored in the fault memory.

Procedure:

  1. Start the function: "Code control unit".

  2. A dialog box presents the actual code and "Change value". Confirm with YES.

  3. Enter the new code (se below) in the presented input field, confirm with OK.

    Code number:Market:
    X1Rest of the world
    X2North America
    0XFixed towbar
    1XAutomatic retractable towbar
    2XManual retractable towbar

    • Code example: manual retractable towbar, rest of the world= 21

  4. A dialog box confirms: Code stored (with the new value) in memory.

  5. Confirm with OK to exit the function.
