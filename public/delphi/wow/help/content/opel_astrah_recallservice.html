[1099]Recall service message

Conditions:

To recall service message security code must be entered (picture 1). The valid security code can be found in a Car Pass among other codes (picture 2). The safety code is a safety measure to protect the vehicle from unauthorised tampering.

Picture 1

Picture 2

Recall service message:

  1. Enter the security code(XXXX), press OK.

  2. Recall service message (Press the OK button).

Incorrect input of the security code three times or more will lead to a security waiting period. During this waiting period it is not possible to enter the code. The security waiting time will be doubled for every incorrect input.
