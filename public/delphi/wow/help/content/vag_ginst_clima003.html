[1296]Basic setting of temperature damper.

Note:

  • When the climat control unit or the temperature damper is replaced, an basic setting of the temperature damper should be performed.

Test prerequisites:

  • Battery voltage should be above 11.5 V.

  • No faults stored.

  • Ignition on.

  • Correct coding of the climat control unit.

  • All electrical loads should be switched off.

Procedure:

  • Start the function.

  • The temperature damper is now moved to cold setting and after that to warm setting, values for each position is now stored in the control unit.

  • When actual value and target value is the same as the value for warm setting the basic setting is completed, this takes approximately 20 seconds.

  • If the specifications are not attained, interrogate fault memory.

  • Exit the function.
