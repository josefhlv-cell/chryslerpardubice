Transmission adaptation
This function is used to erase adaptation values in the transmission's control unit. Reset is performed to enable the transmission to learn new values and obtain correct shifting function.
This must be done if:
  • After change of mecatronics.
  • Oil change in transmission performed.
  • Repair of couplings has been performed.
  • The transmission changes gear hard and uneven.
  • The transmission has been replaced.
Test conditions:
  • Ignition on, engine on.
  • Transmission oil's temperature between 40 °C - 100 °C.
Procedure:
  1. Start the function and follow the instructions in the program.
  2. After completed function, test drive in all gears and make an assessment of the driving.
  3. If the function fails, check the test conditions and repair any faults.
