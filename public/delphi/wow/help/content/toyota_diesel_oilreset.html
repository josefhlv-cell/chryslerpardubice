[113]Manual service light reset

After changing engine oil, the system for oil change reminder should be reset.

Only applies to vehicles with diesel engines

Test conditions:

  • Models with electronic lock and start system

Procedure:

  1. Step 1 - Change display to trip meter "A" with the engine on.

  2. Turn off the engine with the start button.

  3. Press and hold down the button for resetting the trip meter and set the start button "ENGINE START STOP" in position "ignition on" (but do not start the engine since reset will be cancelled). Continue pressing the button and keep it pressed until the information display indicates that the reset is completed

Test conditions:

  • Models without electronic lock and start system

    1. Step 1 - Change display to trip meter "A" with the engine on.

    2. Turn start key to "LOCK" position

    3. Press and hold down the button for resetting the trip meter and set the start key in position "ON" (but do not start the engine since reset will be cancelled). Continue pressing the button and keep it pressed until the information display indicates that the reset is completed.
