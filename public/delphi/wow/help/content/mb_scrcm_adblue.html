[137]Reset AdBlue-counter

This function is used after the AdBlue tank has been topped up and is completely filled. The ignition must not be turned off during the function. If the function is cancelled or fails, check fault codes and test conditions.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

  • AdBlue tank must be completely filled.

Procedure:

  1. Start the function.

  2. A dialogue box shows if the function succeeded or failed.

    • If the function is fails, check fault codes and test conditions.

  3. Exit the function.
