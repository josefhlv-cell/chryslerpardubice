[668]Reset adaptation values for electronic throttle body

Note:

This function must be run after replacing electronic throttle body.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. After finished function, turn off the ignition to enable the inlet valve to run a new programming action.

  3. Check that data list Programming of the throttle body end-positions has been Completed.

  4. If the function fails, check the test conditions and repair any faults.
