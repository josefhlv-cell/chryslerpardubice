[1131]Vehicle type.

Test prerequisites:

  • Engine Off.

  • Ignition On.

  • Battery voltage above 12 V.

Procedure:

  • Read from the table below which code that is valid for the car.

  • Write the current code in the input field.

  • Confirm with ''OK'' .

  • A dialogue box confirms: Operation succeeded / Operation failed.

  • Check the parameter list to verify the configuration.

Code table for vehicle type:

Vehicle type:Code
B / C / K / L / E 840
J84 / R841

  • B is "berline" = 5 doors Sedan.

  • C is "coupé" = 3 doors Sedan.

  • E is "cabriolet" = Coupe-Cabrio.

  • K is "break" = Estate.

  • L is "tricorps" = 4 doors Sedan.

  • J84 = Megane Scénic

  • R84 = Sénic four-wheeldrive
