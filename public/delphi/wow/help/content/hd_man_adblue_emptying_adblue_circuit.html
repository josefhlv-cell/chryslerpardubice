[514]Emptying AdBlue circuit

This function shall be performed before removal of pump module, measuring module, or dosing valve.

The function performs the following:

  • Emptying of AdBlue circuit.

  • Test of return line.

  • Test of emptying valve.

there shall be at least 8 bar pressure in the air tanks before this function is run.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
