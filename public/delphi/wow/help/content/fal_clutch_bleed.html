[563]Bleeding clutch automatic transmission

Note:

The test should be run if pipes or parts of the hydraulic circuit have been disconnected or connected and the purpose is to eliminate all air in the circuit.

Bleeding the clutch takes approx. 1 minute, hold down the brake pedal during the whole procedure.

The procedure may not have any affect if there are problems in the system.

The following is necessary for the test to succeed:

  • Engine off (Stop and Start function turned off if the car is equipped with this).

  • Clutch cylinder OK.

  • Clutch pedal sensor OK.

Test conditions:

  • Ignition on.

  • Brake pedal pressed down.

  • No error codes in the system.

Procedure:

  1. Start the function and follow the instructions in the program.
