Heater test
This function is used to check the control unit's signals to the selected component.
Note:
To prevent that the heater is filled with fuel and damaged, remove the fuel line.
Use a container to collect all the fuel.
Remove all inflammable sources and have fire extinguisher available.
Test conditions:
  • Engine off.
  • Fuel line disconnected.
  • Ignition on.
  • Parking brake applied.
Procedure:
  1. Start the function and follow the instructions in the program.
