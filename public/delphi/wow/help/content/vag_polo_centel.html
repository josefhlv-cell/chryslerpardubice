[1381]Central electronic system configuration

When configurating vehicle systems you are refered to adaption channels in the control unit. Each channel corresponds to a function in the control unit, channels and functions vary depending on type of control unit. By changing the stored value in a channel you also affect it´s features. When entering some channels, a short text can be read out as help for configuration.

Note:

  • A faulty configuration can reduce car safety and/or performance.

  • See workshop manual for complete information on configuration.

Test prerequisite:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • All electrical loads switched off.

Procedure:

  1. Start the function 'Central electronic system configuration'.

  2. Enter the channel from the table in the presented input field, confirm with 'OK'.

    • The function will be aborted if a not valid channel is entered.

  3. The current channel value can now be read.

    • If a current channel value should not be changed, the function can be aborted with 'No'

  4. Press 'Yes'. Enter a new channel value in the presented input field, confirm with 'OK'.

  5. If the presented channel value is correct, press 'Yes' to store the value.

    • If a presented channel value should not be stored, press 'No' to abort the change.

  6. Exit the function.
