Activation of supply pump AdBlue
This test is used to check complete activation (start-up) of the AdBlue supply pump.
This test must always be run when hoses have been disconnected, filters, or pump module have been replaced.
Note:
  • During start-up the AdBlue injection lines are pressurized. Where there are leaks AdBlue may run out on the vehicle.
  • If error code (6A0FE9) CAN-timeout at communication with SCR appears, it shall be resolved first.
Test conditions:
  • Ignition on, engine off.
  • All hoses and lines in the AdBlue-system must be connected before the test starts.
  • The AdBlue tank must be completely full.
Procedure:
  1. Start the function.
  2. A dialogue box shows the test conditions, check these and press "OK".
  3. Communication will be established with the control system, ACM.
  4. Check if error code (6A0FE9) has been generated. "Cancel" the function to check. If it is checked, press "OK".
  5. Start activation of the pump.
  6. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
