[704]Basic setting of brake system

This function is used to perform a function check of the electric parking brake.

Note:

After working on the rear brakes, the basic settings of the braking system must be set.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • Parking brake released.

  • No faults in the system.

  • Do not touch the brake pedal during basic setting.

Procedure:

  1. Start the function and follow the instructions in the program.

    • If the function fails, check the test conditions and repair any faults.
