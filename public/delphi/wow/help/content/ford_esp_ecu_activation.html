[504]Activate control unit

The function is used when a new, used, or blocked control unit is to be taken into use.

Test conditions:

  • Ignition on.

  • Vehicle at standstill on level ground.

  • The steering wheel stands straight and the front wheels point straight forward.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
