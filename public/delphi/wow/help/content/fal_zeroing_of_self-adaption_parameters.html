[1603]Reset adaptation values

Resetting adaptation values shall be performed after workshop actions where the battery has been disconnected or where reprogramming of the control unit has been performed. Perform "AC learning procedure" (key in position 'On' with AC on for 1 minute), to avoid "function not available" for "Fan 2 relay" and "AC compressor relay".

When reset of adaptation values is performed, the original values are stored in the control unit.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. After message has been sent, turn off the ignition for 40 seconds. The reset is performed during this time.

  3. Turn on the ignition again, the reset is done.

    • If the function fails, check the test conditions and repair any faults.
