[462]Adblue freeze monitor calibration

The function is used to check freeze monitor counters "FCC1" and "FCC2" so that these do not exceed an assumed value. The purpose is also to reset the counters when a component in the system has been replaced.

  • The first counter "FCC1" monitors if the system has been emptied of Adblue after the latest driving cycle and if it started at a temperature of -10 °C.

  • The second counter "FCC2" monitors if the system has not been properly emptied of Adblue after the latest driving cycle and if it started at a temperature of -10 °C.

  • "FCC1" has an assumed value of 5,000.

  • "FCC2" has an assumed value of 20.

  • When both counters have passed their assumed value a fault code is set in the system (PSID 89). If this fault code is in the system or any of the counters have reached their assumed value, the dosing module shall be replaced, the fault code shall be erased, and the counters reset.

  • The counters may not be reset if no component has been replaced.

Test conditions:

  • handbrake applied.

  • Engine off.

  • Ignition on.

  • Battery voltage above 20V.

Procedure:

  1. Start the function.

  2. Check conditions.

  3. Check the counters' values.

  4. Select to reset the counters or cancel the function.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
