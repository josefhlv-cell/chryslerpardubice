Temporary disconnection of the lambda regulation
This function is used to temporarily turn off the lambda regulation.
Note:
Disconnection of the lambda regulation isn't restored manually, it is automatically restored after 10 minutes or after the ignition is turned off.
Test conditions:
  • Ignition on, engine off.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. Check test conditions. Press "OK" to continue.
  3. A dialogue box with lambda data lists is shown.
  4. Press "Start".
  5. Check lambda status.
  6. Press "Stop".
  7. Press "OK" to exit the function.
  8. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
