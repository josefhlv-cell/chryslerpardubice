[43]Resetting service indicator

This function is used to reset the service indicator after service.

Test conditions:

  • Ignition off.

  • Parking brake applied.

Procedure:

  1. Start the function.

  2. Select to perform service reset or cancel.

  3. Turn on the ignition.

  4. Turn off the ignition.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
