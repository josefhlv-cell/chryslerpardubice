[551]Activation of maintenance mode

This command must be run before work can be performed on the rear brake system (brake pads, discs or calipers).

Note

Before running this command, release the parking brake using the manual control or thru activation.

Test prerequisites:

  • Ignition on, engine off

  • Parkbrake released.

Procedure:

  1. During this command, the control unit performs a complete release of the system.
