[56]Configure idle speed

This function is used to change the idle rpm.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

Procedure:

  1. Select the function.

  2. Present value for idle rpm is shown.

  3. Press "YES" to enter a new value.

  4. Enter the desired idle rpm in the dialogue box, press "OK".

    • The rpm can only be changed within certain limit values (present limit value is within brackets in the input field).

  5. New stored value for idle rpm is shown.

  6. Press "OK" to finish.

  7. Finish communication and turn off the ignition for 30 seconds to store the new value.
