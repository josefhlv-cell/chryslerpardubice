[308]Reset adaptation values in additive control unit

This function is used to reset the adaptation values in the control unit for additive. Reset should be performed when the control unit been replaced, topping up with additive, as well as when bleeding the system.

Test conditions:

  • Ignition on.

  • Gear in P/N.

  • Parking brake applied.

  • Additive reservoir filled.

  • Do not touch any controls or pedals while the function is in progress.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
