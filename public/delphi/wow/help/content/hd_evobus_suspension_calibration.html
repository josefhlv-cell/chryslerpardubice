[11]Calibrate level sensor

Calibration of level sensors shall be performed when:

  • Any level sensor has been replaced.

  • Work has been done on level sensors.

  • The control unit has been replaced.

Calibration is performed in 3 steps.

Note:

During calibration, the vehicle will be moved up and down. Therefore it is extremely important that no persons or equipment remain in the area around or under the vehicle's frame to prevent crushing injuries!

Test conditions:

  • Ignition on with external air supply connected or engine running.

  • The vehicle must be at a standstill.

  • The vehicle must stand on level ground.

  • No faults in the system.

Procedure:

  1. Select the calibration function.

  2. Set normal level with the buttons and calibrate.

  3. Set max. level with the buttons and calibrate.

  4. Set min. level with the buttons and calibrate.

  5. Exit the function.

  6. Check that no fault codes are stored in the engine control unit.

    • If the function fails, check the test conditions and repair any faults.

  7. Check the suspension function.

  8. The function is done.
