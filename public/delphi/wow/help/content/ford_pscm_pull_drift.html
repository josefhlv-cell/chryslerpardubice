[522]Reset compensation data for pulling sideways

This function is used to reset compensation data for pulling sideways that is stored in the control unit.

Note:

It is important to calibrate the steering wheel angle sensor before resetting compensation for pulling sideways if the car battery has been disconnected.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12V.

  • Vehicle at standstill on level ground.

  • The steering wheel stands straight and the front wheels point straight forward.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. A dialogue box shows if the programming was successful or failed.

    • If the function fails, check the test conditions and repair any faults.
