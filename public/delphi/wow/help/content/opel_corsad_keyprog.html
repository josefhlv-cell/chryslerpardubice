[228]Key programming

This function is used to erase and program keys. All trouble codes in the immobiliser system must be dealt with and erased before programming can be carried out. When programming all keys, old and new, must be available - all keys must be reprogrammed. To run programming, a security code must be entered (see figure 1), the valid security code is found with other codes in a Car Pass (see figure 2).

Note:

If three or more incorrect security codes are generated, a security delay is activated (see data list parameter). During this security delay, no codes may be entered. The security delay is doubled each time an incorrect code is entered.

No other key than the key that was programmed for the moment may be near the ignition. Other keys must be at a distance of min. 10 cm from the ignition.

Test conditions:

  • The ignition is turned off as stated below.

  • Battery voltage above 12V.

  • No faults in the system.

  • All keys available (max. 5 keys).

Procedure:

  1. Insert the first key in the ignition and turn on the ignition (other keys must be min. 10 cm from the ignition).

  2. Press "OK" to start the function and follow the instructions.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
