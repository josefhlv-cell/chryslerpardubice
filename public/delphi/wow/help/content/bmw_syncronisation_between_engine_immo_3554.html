Synchronization between the engine control unit and immobiliser control unit
This function is used to reset the switch codes between engine control unit and immobiliser control unit, to the common start value.
A synchronization must also be performed when installing a new engine control unit or immobiliser control unit.
Note:
When replacing control unit, the engine control unit and/or immobiliser control unit must be new, they may therefore not previously been coded to another vehicle.
The new control unit must also be correctly coded before synchronization can be performed.
Test conditions:
  • Ignition on.
  • Battery charger connected to vehicle.
Execution:
  1. Start the function.
  2. Follow the instructions in the program.
  3. Function complete.
