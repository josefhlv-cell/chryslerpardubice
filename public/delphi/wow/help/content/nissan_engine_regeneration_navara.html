[1613]Regenerating particle filter

This function performs a regeneration of the particle filter. The function cleans the particle filter from particles by burning them off. In certain driving conditions, the particle filter can not be cleaned automatically, e.g., in continuous city driving. Then this function can be used to avoid clogging of the particle filter.

Note:

  • Exhaust temperature is very high during this procedure. Therefore, perform the regeneration outdoors, without connected exhaust hose.

  • Do not activate the clutch, brake, or accelerator pedal during regeneration.

  • In case of too little soot, the regeneration will not start.

Test conditions:

  • Make sure that the vehicle is equipped with particle filter.

  • Engine on.

  • No fault in the system.

  • AC-switch on.

  • Make sure that the AC-compressor is working.

Procedure:

  1. Select the function: "Regeneration", press "OK".

  2. Follow the instructions, press "OK" to start the regeneration. A dialogue shows the status: "Regeneration in progress".

    • Regeneration may be in progress for up to 75 min. When the engine rpm returns to idle, regeneration has been completed.

  3. When the dialogue shows: "Regeneration done", exit the function.

  4. Let the engine idle for a few minutes to stabilize engine operation.

  5. After finished regeneration, read out error codes to exclude any malfunctions.

If regeneration fails, check test conditions, also check that soot amount is not too small.
