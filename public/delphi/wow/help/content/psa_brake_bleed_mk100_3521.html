Bleeding the brake system
This basic setting is used when bleeding antilock brake systems (ABS). This is only needed when at least one of the chambers in the brake fluid reservoir has been emptied, or when changing the brake fluid.
Note:
A manual brake bleeding should be performed before starting this function. The bleeding should be done in a sequence of several steps by the user. Wait at least 5 minutes before bleeding the same wheel again.
2 persons are required for the performing.
Bleeding sequence: Left front, right front, left rear, right rear.
Test prerequisites:
  • Battery voltage above 12 V.
  • Ignition on, engine off.
  • Correct brakefluid level.
  • The brake fluid reservoir should be pressurized to about 2 bar (bleeding equipment).
  • Manual bleeding done before.
Procedure:
  1. Start the function.
  2. First, an automatic bleeding phase is performed during approx. 1 minute. Pump with the brake pedal during this phase.
  3. Follow the instructions shown in the function.
  4. A dialogue box presents the result of the bleeding process.
  5. After ended bleeding procedure, check fault codes. If there are any fault these shall be fixed and the bleeding procedure should be done again.
