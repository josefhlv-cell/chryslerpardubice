[1771]Reset the adaptation values for particle filter

When replacing particle filter, the adaptation values for soot quantity and soot volume must be reset in the engine control unit.

Test condition:

  • Engine on.

Procedure:

  1. Select the function: "Particle filter replaced", press "OK".

  2. A dialogue box shows if the operation was successful or failed.

    • If the function failed, check test conditions.

  3. Exit the function and return to the car selection.

  4. Turn off the ignition for 30 seconds to store the new values.

  5. The function is done.
