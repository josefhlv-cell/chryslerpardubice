Activation camshaft position
This function is a component activation and is used to regulate the camshaft position.
Note:
The camshaft position is activated between 0° - 20°.
Test prerequisites:
  • Engine idling.
  • Gear selector set to P/N.
  • handbrake applied.
  • Lock the drive wheels.
Procedure:
  • Start the function.
  • Follow instructions.
  • The function is done.
