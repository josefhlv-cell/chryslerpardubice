[1368]Adaption after replacing the immobiliser control unit (immobiliser generation 3)

The electronic immobiliser is composed of three main parts: immobiliser control unit, engine control unit and keys. If one of these three parts is replaced, it must be adapted to the immobiliser system. Before a successful adapation is carried out, the immobiliser warning lamp will flash on the instrument panel, fault code 01177 is stored and the car can not be started. Before an adaption can be carried out, the immobiliser control unit must be correctly variant coded.

Note:

This function should only be used with the immobiliser version 3. It's possible to read out the version from the datalist parameters. The function must be carried out when a new or used immobiliser is adapted to the engine control unit. During an adaption, the four or five digit PIN codes must be known, both for the immobiliser and the engine control unit. The PIN code is found on the key tag or at an authorized workshop. After a successful adaption, the PIN code for the immobiliser control unit is the same as for the engine control unit.

Test prerequisites:

  • The battery voltage should be above 12V.

  • All electrical loads should be switched off.

  • Four or five digit PIN codes for both control units.

  • The correct version of the immobiliser control unit.

  • The immobiliser control unit should be correctly variant coded.

  • No lockout time in the immobiliser (the lockout time is availible in the data list).

  • If the fault code 01778 is present, a key adaption is also necessary.

Procedure:

  1. Start the function 'Immobiliser adaption'.

  2. Enter the PIN code for the immobiliser control unit in the input field and confirm with 'OK'

    • If the control unit is old, use the PIN code from the original system.

    • If the control unit is new, use the PIN code from the engine control unit.

    • If the PIN is valid the immobilizer warning lamp will light up continuously.

    • If the PIN is faulty entered three times or more, a lockout time is set in the control unit. 'Fail' is shown in the instrument cluster during a short period.

    • During the lockout time the ignition must be on.

    • The adaption is not possible during the lockout time.

  3. Enter the PIN code for the engine control unit in the input field and confirm with 'OK'.

    • If a wrong PIN code is entered, a fault reason is presented and the function is aborted.

  4. A dialog box will present the vehicle´s chassi number.

    • If the wrong chassi number is presented, the function should be aborted by the user.

    • If the timeout (the control unit doesn't reply in time) is reached, check for the lockout time and fault codes.

  5. If the correct chassi number is presented, press 'OK' to complete the adaption.

    • If the adaption can not be performed check for fault codes.

    • If a timeout (the control unit doesn't reply in time) is reached, check for the lockout time and fault codes.

  6. Exit the function, turn ignition off/on and check for fault codes.

  7. The PIN code for the immobiliser control unit is now the same as for the engine control unit.

  8. After a successful adaption, the keys must be adapted to the immobiliser with a separate function.
