[32]Changing control unit

This function shall only be run when the control unit has been replaced.

Note:

NOTE! if the function is cancelled in steps 1 -2 the saved data is lost and you have to start over from the beginning.

This function is performed in 5 steps.

  1. First read out data from the old control unit, the data is saved automatically in the program.

  2. Replace the control unit.

  3. Loads the saved data automatically to the new control unit.

  4. Activation of the control unit takes place automatically.

  5. For the transmitters to be initiated and start communicating with antennas and control unit, the vehicle must be driven at least 20 km/h for at least 5 minutes.

Test conditions:

  • Ignition on.

Procedure:

  1. Start the function and follow the instructions in the program.
