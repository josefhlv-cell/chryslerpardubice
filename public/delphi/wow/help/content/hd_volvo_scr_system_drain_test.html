[464]Test of SCR-system emptying

The function is used to empty the system if this was not done when turning off.

  • When the test is done the UDS-unit will turn off completely, which means that all communication with the unit stops. This means that fault code MID128 PSID229 is set. This fault code must be erased when the UDS-unit has been reset.

  • Reset the UDS-unit by turning off the main electric power and waiting at least 10 seconds before turning it on again.

Test conditions:

  • Parking brake applied.

  • Engine off.

  • Ignition on.

  • Battery voltage above 20V.

Procedure:

  1. Start the function.

  2. Wait until status of the test is shown.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
