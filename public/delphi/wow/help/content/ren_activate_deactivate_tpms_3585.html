Activate/deactivate tyre pressure monitoring
This function is used to activate or deactivate the tyre pressure monitoring.
Preconditions for the test:
  • Engine off.
  • Ignition on.
Procedure:
  1. Start the function.
  2. A data list presents the current vehicle configuration.
  3. Select "Activate" or "Deactivate" in the list.
  4. Press "OK" to change the configuration.
