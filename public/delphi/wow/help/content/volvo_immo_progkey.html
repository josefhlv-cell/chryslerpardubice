[1744]Key programming

This function is used to program the key that is inserted in the ignition, max. 5 keys can be programmed.

PIN-code "Immobilizer pin" is required. Supplied with new key, see figure 1.

Figure 2 shows control unit: "Immo2".

Test conditions:

  • Ignition on, engine off.

  • No faults in the system.

  • Non-programmed key in the ignition.

Procedure:

  1. Select the function, press "OK".

  2. Number of programmed keys is shown, press "OK" to program key.

  3. Number of programmed keys is shown after programming, press "OK".

  4. Repeat steps 1-4 if several keys are to be programmed.

  5. The function is done.

    • If the function fails, check the test conditions and repair any faults.
