[533]Read out data from configuration files

This function reads out basic data from the configuration files used when replacing control units.

Test conditions:

  • Trailer supplied with voltage.

Procedure:

  1. Start the function.

  2. Select the file to be read out.

  3. Check that the file corresponds to the system that is selected in the truck selection, otherwise wrong data is shown.

  4. The file is read out.

  5. The function is done.
