[450]Activate electromagnetic lock of gear selector

This function is used to lock the electromagnet for the gear selector. This is a component activation and shall only be used if the car is configured and equipped with the component. An activation may take up to a minute, during that time a window with the text "Please wait" is shown.

Test conditions:

  • Ignition on, engine off.

  • Vehicle stationary.

  • Gear selector in position N.

Procedure:

  1. Start the function.

  2. Wait for "Function done".

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
