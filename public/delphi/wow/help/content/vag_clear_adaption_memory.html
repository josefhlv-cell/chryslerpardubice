[1597]Clear adaption memory

The engine control unit learns and corrects possible deviations in for example the lambda regulation system. These deviations are stored in the adaption memory. If a faulty lambda sond has been replaced or a leaking exhaust system has been repaired, it is possible to clear the old adaption values with this function.

Note:

After reset of the adaption memory, the electronic throttle control must be adapted with the function: "Electronic thottle control".

Test prerequisites:

  • Ignition on, engine off.

  • All loads switched off.

Procedure:

  1. Choose the function: "Clear adaption memory", press "OK".

  2. The function starts, the adaption values are cleared. A dialog box presents: "Operation succeeded" or "Operation failed".

  3. Press "OK" to exit the function.

  4. Continue with a basic setting of the electronic throttle control.
