Classification of injectors
This function is used when the classification of all injectors has changed.
Due to tolerances when manufacturing the injectors, the injected fuel quantity may deviate between the actual and calculated fuel quantity. After manufacture these deviations are determined for every injector and a calibration value is determined, the value is converted to a code which is stamped on the injectors.
Note:
The function is only required if the classification category is changed from the previously stored value.
Injectors with different classification numbers may not be used.
Test conditions:
  • Ignition on.
  • Battery voltage above 12V.
  • Correct classification numbers on all injectors.
Procedure:
  • Start the function.
  • The stored classification is shown. Choose whether it is to be changed or if the function is to be stopped.
  • Choose the classification to be stored.
  • The function is done.
  • If the function fails, check the test conditions and repair any faults.
