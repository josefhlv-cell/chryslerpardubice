[131]Fuel shut-off

This function is used to lock the injectors and shut off the fuel flow regulators so that the engine cannot be started as well as to check cylinder compression without risk of fuel injection.

The function is only active until the ignition is turned off and the start inhibitor light flashes for a few seconds.

Test conditions:

  • Ignition on and engine off.

Procedure:

  1. Start the function.

  2. Select engagement or disengagement of fuel shut-off in the scroll list and press "OK".

  3. To deactivate fuel shut-off, select "Disengage fuel shut-off", press "OK". or turn off the ignition.

  4. The function is done.

    • If the function fails, check the test conditions and repair any faults.
