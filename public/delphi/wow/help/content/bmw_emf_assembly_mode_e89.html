[716]Activate service mode on parking brake

Before the rear brake linings are replaced the parking brake must be set in service mode.

This function is used to activate service mode. Both the rear adjustment motors will be run to service mode.

Test conditions:

  • Parking brake released.

  • Make sure the vehicle cannot start to roll.

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is complete.

  4. Perform the parking brake operationalisation function when replacement is complete.

    Step 4 must be performed to enable the parking brake function.
