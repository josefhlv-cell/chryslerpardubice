[1706]Calibrate damper actuators

This function is used to calibrate the damper actuators. The damper is actuated and moves to its limit position to store these values in the memory.

Test conditions:

  • Ignition on, engine off

  • Battery voltage above 12 V.

Procedure:

  1. Start function, press "OK".

  2. Follow the instructions in the dialogue box.

  3. The status for each damper is displayed when the function is complete.

    • If the function fails, check the test conditions and repair any faults.
