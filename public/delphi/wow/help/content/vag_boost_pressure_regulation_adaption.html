[215]Basic setting of boost pressure regulator

This function is used to perform a basic setting of the boost pressure regulator. This should be done if:

  • The boost pressure regulator has been replaced.

  • The boost pressure regulator has been repaired.

  • The engine control unit has been replaced.

During basic setting the control light for pre-glow time indicates.

Test conditions:

  • Ignition on, engine on.

  • Battery voltage above 12V.

  • No faults in the system.

Procedure:

  1. Start the function.

  2. A dialogue box shows: "Status for basic setting" shows "in progress" and changes to "done" when basic setting is finished.

  3. Exit the function.

    • If the function fails, check the test conditions and repair any faults.
