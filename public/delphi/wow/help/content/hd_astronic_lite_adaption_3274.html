Adaptation
This function is used for self-adaptation of transmission system and clutch adaptation.
Test conditions:
  • Engine off.
  • Ignition on.
  • Vehicle stationary.
  • Parking brake applied.
  • Transmission in neutral.
Procedure:
  1. Start the function.
  2. Check conditions.
  3. Wait until the function has been completed.
  4. Function complete.
  • If the function fails, check the test conditions and repair any faults.
