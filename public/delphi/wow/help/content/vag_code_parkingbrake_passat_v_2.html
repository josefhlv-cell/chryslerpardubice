[388]Code electromechanical parking brake

The control unit must be coded according to the corresponding equipment in order for all functions to work correctly.

  • Incorrect coding may reduce the car's safety and function.

  • The control unit must be of the correct type to approve the code.

Test condition:

  • Battery voltage above 12V.

  • Ignition on, engine off.

  • All power consumers disconnected

Procedure:

  1. Start the function.

  2. Existing code in control unit is shown, press "YES" to change value.

  3. Enter the desired code (see below) in the displayed entry field, press "OK".

    Code number:Function:
    X X X X X 1 0Without Auto-Hold function, North America
    X X X X X 1 1Without Auto-Hold function, Other
    X X X X X 1 2With Auto-Hold function, Other
    X X X X X 1 3With Auto-Hold function, North America
    Coding example:

    Parking brake with Auto-Hold function, other = 0000012

  4. A dialogue box shows that the code is stored (with the new value) in the memory.

  5. Press "OK" to exit the function.

  6. Turn off the ignition for 60 seconds to store new values.

  7. Turn on the ignition again and re-establish communication with the system.

  8. Check and solve any fault codes stored in the system.

  9. Check that the new code is stored.

  10. The function is done.

    • If the function fails, check the test conditions and repair any faults.
