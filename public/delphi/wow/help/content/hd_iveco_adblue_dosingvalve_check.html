[491]Test of dosing valve

This function is used to determine that injected amount AdBlue matches reference values. The test may only be run if the dosing module has been removed and aimed into a measuring container.

The results for the different positions are reached by opening the dosing valve for varying times and with varying high flows.

The amount of injected AdBlue shall be + / - 10% of the reference value.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Select desired position and press "OK" to start the test.

    • If the function fails, check the test conditions and repair any faults.
