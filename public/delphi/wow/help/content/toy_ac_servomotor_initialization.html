[427]Servo motor initializing

This function is used to initialise the air conditioning's servo motors. The function is run when the control unit (ECU) for the servo motor has been replaced, AC amplifier has been replaced, or when the battery is disconnected.

Test conditions:

  • Ignition on.

  • AC off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.
