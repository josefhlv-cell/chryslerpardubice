[1390]Tire size adjustment.

When the ABS control unit is exchanged or coded, it is necessary to adjust the tire size (brake caliper size) in the ABS control unit to get the tyre pressure monitoring (RKA) to work correctly.

Note:

  • Only for vehicles with tyre pressure monitoring (RKA).

  • A faulty configuration can reduce the car´s safety and/or performance.

  • The basic setting can only be done after entering a login code. Use the function: Login.

Test prerequisites:

  • The battery voltage should be above 12V.

  • Ignition on, engine off.

Performance:

  1. Choose the function: Login. Enter the login code: 40168, press OK.

  2. Choose the function: 'Tire size adjustment'.

  3. A dialog box presents the actual adaption value for the tire size. Confirm with yes to change the value. If the value should not be changed, the function is aborted with "Abort".

    The following learning values shall be used:

    • 0 = Brake caliper for tire size 15 inch.

    • 1 = Brake caliper for tire size 16 inch and larger.

  4. Write the actual value for the vehicle. Confirm with "OK".

  5. A dialog box presents the new value.

  6. Confirm with "OK" to store the new value.
