Forced regeneration
This function is used to run a forced regeneration.
Regeneration is performed only if the soot in the particle filter exceeds a certain amount.
Note:
This is a two-person job and the diagnostic tool must be connected during the time that the regeneration is run.
The vehicle must be driven faster than 40 km/h and the function is estimated to take approx. 15 minutes.
The speed must be kept above 40 km/h during the whole function, if it is lower for more than 5 minutes the function must be restarted.
Test conditions:
  • Engine temperature above 60 °C.
Procedure:
  1. Start the function and follow the instructions in the program.
