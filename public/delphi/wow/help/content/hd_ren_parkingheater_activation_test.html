[643]Activation test extra heater

This function is used to check the functionality of the heater's fan and fuel pump.

Note:

Check that the activated component emits sound during the test.

Test conditions:

  • Ignition on.

  • Parking brake applied.

  • Extra heater turned on.

  • Battery voltage above 20 V.

Procedure:

  1. Start the function.

  2. Check conditions.

  3. Select to continue or abort the function.

  4. Wait 30 seconds.

  5. Select which of the tests you want to run.

  6. Wait while the test is in progress.

  7. Select if you want to run more tests or cancel.

  8. If "Yes", repeat the procedure from step 5.

  9. Function done.

    • If the function fails, check the test conditions and repair any faults.
