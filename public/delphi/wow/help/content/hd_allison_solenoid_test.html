[375]Solenoid valve test

This function is used to check control unit's signals to selected solenoid valve. The test does not check the solenoid valves' electric properties such as internal resistance and leads.

The engine must be off to run the test.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. A dialogue box shows test conditions, check these and press "OK"

  3. Select solenoid valve to be tested.

  4. Start and stop activation of selected valve.

  5. Repeat the procedure for valves to be tested.

  6. The function is done.

    • If the function fails, check the test conditions and repair any faults.
