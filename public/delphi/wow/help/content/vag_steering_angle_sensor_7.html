[562]Basic setting of steering angle sensor

This function resets the adaptation values for the power steering and initialises and adapts the steering angle sensor to the power steering.

This should be done if:

  • The steering servo has been replaced or reinstalled after repair.

  • Repairs have been done on the steering.

  • The front axle chassis geometry has been adjusted.

  • A fault code that requires basic setting is stored in the power steering control unit.

    If the power steering control unit has been replaced, it must be correctly adapted.

Test conditions:

  • Before basic setting is carried out on the steering angle sensor, the power steering adaptation values must be cleared. This is done using the "Power steering" function.

  • Engine on.

  • Access to a stretch of road that fulfils the conditions in the procedure below.

  • The ignition must not be turned off during basic setting.

Procedure:

  1. Test drive on a level surface at a maximum speed of 20 km/h and check that the steering wheel is in the correct position when driving in a straight line.

  2. Stop the car and turn the steering wheel almost to lock to the right and left.

  3. Set the steering wheel in position for travel straight ahead.

  4. Select the function: "Power steering", control light for steering servo comes on.

  5. Once this function is complete, select the "Steering wheel angle sensor initialisation".

  6. A dialogue box shows: "correct” to confirm that initialisation has been successful.

  7. Complete the function and disconnect the diagnostic tool.

  8. Test-drive a short distance (10-20 metres) straight ahead to learn the middle position.

  9. Let the engine run at idle, set the steering wheel in middle position (front wheels straight ahead) for at least 2 seconds without touching the steering wheel.

  10. Turn the steering wheel to left full lock and hold it there until you hear 3 beeps.

  11. Turn the steering wheel to right full lock and hold it there until you hear 3 beeps.

  12. Turn back the steering wheel to middle position (front wheels straight ahead). The control light for electromechanical steering turns off.

  13. Check that no trouble codes are stored in the power steering control unit.

  14. Exit the function.

    • If the function fails, check that the steering wheel is in the centre position and that the components are correctly fitted.
