[703]Adaptation camshafts

This function is used to perform an adaptation of the camshaft regulation.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function and follow the instructions in the program.

  2. When the adaptation has been made, start the engine and allow it to idle for around 1 minute.

  3. Test drive the vehicle for around 15 minutes so that the new camshaft values are programmed into the engine.
