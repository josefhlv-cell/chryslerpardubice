[108]Calibrate clutch

This function must be run if the clutch has been replaced, or if repair work has been carried out on the clutch involving replacement of the plates.

Note:

This function may only be run on vehicle without control unit GS.

Test conditions:

  • Parking brake applied.

  • Engine off, ignition on.

  • Battery voltage above 20 V.

Procedure:

  1. Select calibration of clutch with replacement of plates.

  2. A dialogue shows the test conditions, check these.

  3. A dialogue shows "Do you want to perform calibration". Press "Yes" to continue or "No" to cancel the function.

  4. A dialogue shows "Let up clutch pedal". Press "OK".

  5. A dialogue shows "Press down clutch pedal". Press "OK".

  6. A dialogue shows "Calibration performed". Press "OK".

  7. A dialogue shows "Let up clutch pedal". Press "OK".

  8. A dialogue shows "Function done". Press "OK".

  9. The function is done.
