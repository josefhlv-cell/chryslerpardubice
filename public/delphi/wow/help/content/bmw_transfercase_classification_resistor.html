[15]Reset adaptation values for classification resistor

This function must always be performed after the transfer case's classification resistor has been replaced.

The classification resistor is located on the transfer case's actuator and makes sure that the transfer case's mechanics are within tolerance values.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Stored values for the classification resistor will be reset.

  3. The function is done.
