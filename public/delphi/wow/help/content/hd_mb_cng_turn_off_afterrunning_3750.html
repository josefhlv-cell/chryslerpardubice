Temporary shut off of engine after-running
This function is used to turn off the engine after-running. The engine after-running is turned off only once when this function is started.
Engine after-running means that the engine, after the ignition (terminal 15) is turned off, continues to run for about 2 seconds to burn the residual gas contained in the lines (to protect the catalyst).
By interrupting the engine after-running once with the "Diagnostic tool", you can check all the inlet valves.
Note:
This function should be performed with engine at idle!
After the ignition is turned off, this function is deactivated.
Test conditions:
  • Ignition on, engine off.
  • Parking brake applied.
Procedure:
  1. Start the function.
  2. Check test conditions. Press "OK".
  3. Press "START to start the activation.
  4. Check the "live" data list.
  5. Press "OK" to exit the function.
  6. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
