[1497]ESP calibration

This function adapts the sensors for lateral, longitudinal acceleration and yaw rate sensor to the ABS control unit. Carry out an adaption when:

  • A fault code regarding adaption of sensor is present.

  • When a sensor has been replaced.

  • The ABS control unit has been replaced.

Note:

During adaption, the ignition must not be switched off.

Test prerequisites:

  • Ignition on, engine off.

  • Sensor / control unit connected and installed correctly.

  • Battery voltage above 12 Volts.

Procedure:

  1. Position the car on a flat and level surface.

  2. Start the function, press OK.

  3. The adaption is carried out. A dialog box presents: operation succeeded/ failed.

    • If the function fails, check test prerequisites and repair possible fault codes.

  4. Switch off the ignition for 15 seconds, and then switch it on for 30 seconds.

  5. The function is now completed.
