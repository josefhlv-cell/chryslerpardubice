[463]Test of fuel system

The test is used to check and bleed the system.

This test must always be run when hoses have been disconnected, filters or pump module have been replaced.

All hoses and lines must be connected before starting the test.

Test conditions:

  • Ignition on, engine off.

Procedure:

  1. Start the function.

  2. Follow the instructions in the program.

  3. The function is done.

    • If the function fails, check the test conditions and repair any faults.
