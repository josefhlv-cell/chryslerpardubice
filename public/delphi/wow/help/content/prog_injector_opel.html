[1118]Injector programming

Conditions:

After replacing 1 or more injectors, the following programming function has to be performed.

Engine off

Ignition on

Procedure:

Caution: Before injector programming all injectors must be reset, exit the diagnosis and turn off ignition, Then the programming can be performed:

  1. Turn on ignition and enter the diagnosis

  2. Program injector 1

  3. Exit diagnosis and turn off ignition

  4. Turn on ignition and enter the diagnosis again

  5. Program each injector and repeat from step 3

  6. Check and erase faultcodes

    Note! The ignition must be turned off and on after each programming, otherwise the programming can be failed.
