[1707]A/C cooling test

This function is used to test the cooling capacity of the A/C system.

For the test to yield a successful result, the temperature at the cold sensor must drop by 6°C, or the cold sensor must reach 0°C during the test. The cooling test will not start if the cold sensor is below 18°C.

Test conditions:

  • Engine on.

  • Cold sensor above 18°C.

Procedure:

  1. Start function, press "OK".

  2. Follow the instructions in the dialogue box.

  3. Data parameters are displayed when the test is complete.

    • If the function fails, check the test conditions and repair any faults.
