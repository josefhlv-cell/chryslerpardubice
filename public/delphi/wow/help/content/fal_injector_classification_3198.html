Classification injector
This function is used to change classification of the injectors, the classification is saved and used by the engine control unit.
Note:
The injectors' classification procedure must be performed according to the class that is stamped above the solenoid on the injectors. Classification must also be performed even if only one injector has been replaced or if the control module has been replaced.
The classification is common for all cylinders.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Select the function and follow the instructions.
