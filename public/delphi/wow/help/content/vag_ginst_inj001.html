[1308]Injection time correction.

Test condition:

  • Engine running.

  • No faults stored.

  • Gear selector set to P/N.

Note:

  • In this procedure the injection timing valve is timed.

Procedure:

  • Start the function.

  • Injection timing should be 6.5-9.5° TDC.

  • After 10sec the injection corrector moves to the retarded position.

  • Injection timing should be 2.5-5.5° TDC.

  • Exit.
