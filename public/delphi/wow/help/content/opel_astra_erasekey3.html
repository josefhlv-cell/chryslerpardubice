[1721]Erase keys

This function is used to erase all keys. After erasing, the keys to be used for the vehicle must be programmed and stored again in the control unit.

Note:

A security code must be entered before erasing (see image 1). The valid security code can be found, along with other codes, in the vehicle's Car Pass (see image 2).

If an incorrect security code is entered three or more times, a safety delay is activated (see parameter in the data list). During this safety delay, no codes may be entered. The safety delay is doubled each time an incorrect code is entered.

Test conditions:

  • Ignition on, engine off.

  • Battery voltage above 12 V.

Procedure:

  1. Select the function and press "OK" to start the function.

  2. A dialogue box shows the status of transponders 1-5. Press "OK" to proceed and follow the instructions.

  3. Once erasing is complete, the current transponder status is displayed.
