Update control unit from central data memory, CDS
This function transfers the control units' parameters, stored in the central data memory CDS, to the control units.
Test conditions:
  • Ignition on, engine off.
Procedure:
  1. Start the function.
  2. A dialogue box shows the test conditions; check these and press "OK".
  3. Select to which control unit the transfer shall take place.
  4. Transfer starts, follow instructions.
  5. The function is complete.
    • If the function fails, check the test conditions and repair any faults.
