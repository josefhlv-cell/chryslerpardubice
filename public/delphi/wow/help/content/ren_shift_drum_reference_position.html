[473]Configuration shiftdrums

This function Program the reference position for the two shiftdrums.

Note:

This configuration should only be done if the vehicle is equipped with this component. The configuration could take up to one minute, and in the meantime, a window appears with the text "Please wait".

Test prerequisites:

  • Gearlever in position N

  • Ignition on

  • Engine off

  • Brakepedal pressed

  • Battery voltage over 9V

Procedure:

  1. Start the function

  2. Wait for "Function complete"

  3. If the function failed, check the test prerequisites.
