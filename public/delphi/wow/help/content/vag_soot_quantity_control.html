[214]Checking soot quantity in particle filter

This function is used to check current soot quantity in the particle filter. When it exceeds a certain limit value (shown in the function) the particle filter has to be replaced.

Test conditions:

  • Ignition on.

  • Battery voltage above 12V.

Procedure:

  1. Start the function.

  2. A dialogue box is shown with current soot quantity + limit value for particle filter replacement.

  3. Press "OK" to exit the function.

    • If the function fails, check the test conditions and repair any faults.
